## 開場：研究數，從研究「包含它的體」開始

第一部結束在一個教訓：要理解 FLT，必須理解那些比 $\mathbb{Z}$、$\mathbb{Q}$ 更大的數系 —— Euler 闖進的 $\mathbb{Q}(\sqrt{-3})$、Lamé 倚賴的 $\mathbb{Q}(\zeta_p)$。第二部就是系統地研究這些「更大的世界」。而研究它們的工具，是 Galois 理論 —— 現代數論的中樞神經。

Galois 理論的出發點是一個視角轉換。傳統上，我們問「某個方程式有沒有根」。Galois 教我們改問：**為了裝下這些根，需要把有理數體擴大到什麼程度？而這個「擴大」本身有什麼結構？** 把 $\mathbb{Q}$ 擴大到包含 $\sqrt 2$，得到 $\mathbb{Q}(\sqrt 2)$；擴大到包含 $\zeta_p$，得到 $\mathbb{Q}(\zeta_p)$。這些「擴大的體」叫**體擴張**（field extension），它們是 Galois 理論的研究對象。

本章建立體擴張的基本詞彙：擴張次數、代數元、最小多項式、分裂體。核心發現是一件出人意料的事 —— **體擴張可以用「維度」來度量**，於是第 1.1 章的線性代數，意外地成了研究數域的工具。這個橋樑（體擴張 ↔ 向量空間維度）是第二部的第一個關鍵，下一章的 Galois 對應將建立在它之上。

## 擴張與次數

::: {.definition}
若體 $K$ 是體 $L$ 的子體，稱 $L/K$ 為**體擴張**（讀作「$L$ over $K$」）。
:::

關鍵觀察：$L$ 可以看成 $K$ 上的向量空間 —— $L$ 裡的元素是「向量」，$K$ 裡的元素是「純量」，加法與純量乘法就是體本身的運算（第 1.1 章已用 $\mathbb{C}/\mathbb{R}$ 預演過）。於是：

::: {.definition}
擴張 $L/K$ 的**次數** $[L : K]$ 是 $L$ 作為 $K$-向量空間的維度 $\dim_K L$。若有限稱**有限擴張**。
:::

::: {.example}
- $[\mathbb{C} : \mathbb{R}] = 2$，基底 $\{1, i\}$。
- $[\mathbb{Q}(\sqrt 2) : \mathbb{Q}] = 2$，基底 $\{1, \sqrt 2\}$。
- $[\mathbb{Q}(\zeta_p) : \mathbb{Q}] = p - 1$，基底 $\{1, \zeta_p, \dots, \zeta_p^{p-2}\}$ —— 第 0.5 章那個 $p-1$ 的精確身分，至此完全確立。
:::

次數最有用的性質，是它在「擴張的塔」中相乘：

::: {.theorem name="塔定理"}
設 $K \subseteq M \subseteq L$ 為體的塔。則
$$[L : K] = [L : M]\,[M : K].$$
:::

::: {.proof}
設 $\{m_i\}$ 是 $M$ 作為 $K$-空間的基底（$[M:K]$ 個），$\{l_j\}$ 是 $L$ 作為 $M$-空間的基底（$[L:M]$ 個）。宣稱 $\{m_i l_j\}$ 是 $L$ 作為 $K$-空間的基底。

**生成：** 任何 $\alpha \in L$，先用 $\{l_j\}$ 寫成 $\alpha = \sum_j \beta_j l_j$（$\beta_j \in M$），再把每個 $\beta_j$ 用 $\{m_i\}$ 寫成 $\sum_i c_{ij} m_i$（$c_{ij} \in K$），合併得 $\alpha = \sum_{i,j} c_{ij} m_i l_j$。

**線性無關：** 若 $\sum_{i,j} c_{ij} m_i l_j = 0$，按 $l_j$ 分組 $\sum_j (\sum_i c_{ij} m_i) l_j = 0$。$\{l_j\}$ 在 $M$ 上無關，故每個 $\sum_i c_{ij} m_i = 0$；$\{m_i\}$ 在 $K$ 上無關，故所有 $c_{ij} = 0$。

於是 $L$ 有 $[L:M][M:K]$ 個基底向量。
:::

塔定理把「次數」變成一個乘法的記帳系統。它將反覆出現 —— 例如第 1.6 章 $\mathbb{Z}[\zeta_3]$ 與 $\mathbb{Z}[\sqrt{-3}]$ 的層級，正是 $[\mathbb{Q}(\zeta_3) : \mathbb{Q}] = 2$ 這座小塔的算術。

## 代數元與最小多項式

::: {.definition}
擴張 $L/K$ 中的元素 $\alpha \in L$ 稱為**代數的**（over $K$），若它是某個非零 $K$-係數多項式的根；否則稱**超越的**。
:::

$\sqrt 2$ 在 $\mathbb{Q}$ 上代數（$x^2 - 2$ 的根）；$\zeta_p$ 代數（$\Phi_p$ 的根）。$\pi$ 在 $\mathbb{Q}$ 上超越（Lindemann 定理），但本書只關心代數的世界。

每個代數元都有一個「最經濟」的方程：

::: {.theorem name="最小多項式"}
設 $\alpha$ 在 $K$ 上代數。則存在唯一的**首一**多項式 $m_\alpha(x) \in K[x]$，次數最小、以 $\alpha$ 為根。它**不可約**，且任何以 $\alpha$ 為根的 $K$-多項式都被 $m_\alpha$ 整除。$m_\alpha$ 稱為 $\alpha$ 的**最小多項式**。
:::

::: {.proof}
考慮所有以 $\alpha$ 為根的非零 $K$-多項式，取次數最小者並調為首一，記 $m_\alpha$。

**不可約：** 若 $m_\alpha = fg$（次數皆較低），則 $0 = m_\alpha(\alpha) = f(\alpha)g(\alpha)$，因 $L$ 是體（無零因子）故 $f(\alpha) = 0$ 或 $g(\alpha) = 0$，與 $m_\alpha$ 次數最小矛盾。

**整除性：** 設 $f(\alpha) = 0$。多項式除法 $f = q\,m_\alpha + r$，$\deg r < \deg m_\alpha$。代入 $\alpha$ 得 $r(\alpha) = 0$，若 $r \ne 0$ 則違反最小性，故 $r = 0$，即 $m_\alpha \mid f$。唯一性由整除性立得。
:::

最小多項式把代數元的「複雜度」量化了 —— 而這個複雜度恰好就是擴張次數：

::: {.theorem name="單擴張的次數"}
設 $\alpha$ 在 $K$ 上代數，最小多項式次數為 $n$。則 $K(\alpha)$（$K$ 添加 $\alpha$ 生成的最小體）滿足
$$[K(\alpha) : K] = n,$$
且 $\{1, \alpha, \alpha^2, \dots, \alpha^{n-1}\}$ 是一組基底。
:::

::: {.proof}
這正是第 1.4 章「商環造體」的具體化：$K(\alpha) \cong K[x]/(m_\alpha)$，同構把 $x$ 送到 $\alpha$。因 $m_\alpha$ 不可約、次數 $n$，商環中每個元素有唯一的次數 $< n$ 代表，即 $\{1, \alpha, \dots, \alpha^{n-1}\}$ 的 $K$-線性組合。這 $n$ 個元素線性無關（否則 $\alpha$ 滿足更低次方程），故為基底，維度 $n$。
:::

::: {.remark name="兩個觀點的合流"}
這條定理把第 1.4 章末的伏筆完全兌現。當時我們說 $\mathbb{Q}[x]/(x^2-2) \cong \mathbb{Q}(\sqrt 2)$、$\mathbb{Q}[x]/(\Phi_p) \cong \mathbb{Q}(\zeta_p)$，是「商環造體」的範例。現在看清了：商環造出的體，其次數正是被取商的不可約多項式的次數。第 0.5 章證 $\Phi_p$ 不可約、次數 $p-1$，於是 $[\mathbb{Q}(\zeta_p):\mathbb{Q}] = p-1$ —— 三章之前埋下的數字，在這裡由「最小多項式次數 = 擴張次數」這條定理正式蓋章。

「代數元的最小多項式」與「向量空間的維度」是同一件事的兩面：前者是多項式的語言，後者是線性代數的語言。Galois 理論的全部威力，來自能在這兩種語言間自由切換。
:::

## 分裂體：裝下一個多項式所有根的最小體

最小多項式關注**單個**代數元。下一個概念關注**單個多項式的全部根**。

::: {.definition}
設 $f \in K[x]$。$f$ 的**分裂體**（splitting field）是 $K$ 的最小擴張 $L$，使得 $f$ 在 $L[x]$ 中完全分解成一次因式之積（即 $f$ 的所有根都在 $L$ 裡）。
:::

代數基本定理（第 0.5 章）保證根都在 $\mathbb{C}$ 裡，分裂體就是 $K$ 添加這些根生成的子體。分裂體是 Galois 理論真正的主角 —— 因為「方程的對稱性」正是分裂體裡根與根之間的可置換性。

::: {.example name="$x^3 - 2$ 的分裂體"}
根是 $\sqrt[3]{2},\ \omega\sqrt[3]{2},\ \omega^2\sqrt[3]{2}$，其中 $\omega = \zeta_3$。要裝下全部三個根，需要 $\sqrt[3]{2}$ **與** $\omega$。分裂體是 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$。

算它的次數，用塔定理。$[\mathbb{Q}(\sqrt[3]{2}) : \mathbb{Q}] = 3$（最小多項式 $x^3 - 2$，由 Eisenstein 不可約）。$\omega$ 滿足 $x^2 + x + 1$，在 $\mathbb{Q}(\sqrt[3]{2})$（一個實體）上仍不可約（$\omega$ 非實），故 $[L : \mathbb{Q}(\sqrt[3]{2})] = 2$。於是
$$[L : \mathbb{Q}] = 3 \times 2 = 6.$$
這個 $6$ 不是巧合 —— 它等於 $|S_3|$。下一章會看到：$x^3 - 2$ 的 Galois 群恰好是 $S_3$（三個根可任意置換），而 **Galois 群的階等於分裂體的次數**。第 1.3 章習題 1.3.7 你已經預言過這個 $S_3$，現在它有了精確的次數座標。
:::

::: {.remark name="為什麼分裂體通往 Galois 群"}
分裂體 $L/K$ 的對稱性，是指那些「固定 $K$、但置換 $f$ 的根」的體自同構 —— 它們構成的群就是 Galois 群 $\mathrm{Gal}(L/K)$。一個自同構必須把根送到根（因為它保持係數在 $K$ 的方程），所以 Galois 群作用在「根的集合」上（第 1.3 章的群作用！），而這個作用通常忠實地反映在根的置換上。

於是三條線在分裂體匯合：**體擴張**（本章）提供舞台 $L/K$，**群**（第 1.3 章）提供對稱性 $\mathrm{Gal}(L/K)$，**群作用**把後者實現為根的置換。下一章的 Galois 對應，就是證明這個舞台與這個群之間有一個完美的字典 —— 體的中間層 ↔ 群的子群。那是第二部的最高峰，而本章剛剛架好了通往它的全部腳手架。
:::

## 本章地圖與下一章預告

- **體擴張與次數**：$L$ 是 $K$-向量空間，$[L:K] = \dim_K L$。
- **塔定理**：$[L:K] = [L:M][M:K]$，次數的乘法記帳。
- **代數元與最小多項式**：唯一首一不可約多項式；複雜度的度量。
- **單擴張次數 = 最小多項式次數**：商環造體的兌現；$[\mathbb{Q}(\zeta_p):\mathbb{Q}] = p-1$ 蓋章。
- **分裂體**：裝下多項式全部根的最小體；$x^3-2$ 給出次數 $6 = |S_3|$。

下一章《Galois 理論》是第二部的核心，也是全書的一座高峰。我們將定義 Galois 群 $\mathrm{Gal}(L/K)$，並證明 **Galois 基本定理**：分裂體 $L/K$ 的「中間體」與 Galois 群的「子群」之間，存在一個一一對應（且反轉包含關係）。這個對應把「體的問題」翻譯成「群的問題」，是 Galois 理論改變數學的核心洞見。有了它，「絕對 Galois 群 $\mathrm{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$」—— FLT 證明的中央舞台 —— 才能被有意義地談論。

## 習題

**2.1.1**　求 $[\mathbb{Q}(\sqrt 2, \sqrt 3) : \mathbb{Q}]$，並寫出一組 $\mathbb{Q}$-基底。（提示：用塔定理；驗證 $\sqrt 3 \notin \mathbb{Q}(\sqrt 2)$。）

**2.1.2 ★**　求 $\sqrt 2 + \sqrt 3$ 在 $\mathbb{Q}$ 上的最小多項式，並由其次數確認 $\mathbb{Q}(\sqrt 2 + \sqrt 3) = \mathbb{Q}(\sqrt 2, \sqrt 3)$。（這展示了「單擴張」有時等於「多元素擴張」—— 本原元定理的雛形。）

**2.1.3**　求 $\sqrt[4]{2}$ 在 $\mathbb{Q}$ 上的最小多項式與 $[\mathbb{Q}(\sqrt[4]{2}) : \mathbb{Q}]$。再求 $[\mathbb{Q}(\sqrt[4]{2}) : \mathbb{Q}(\sqrt 2)]$，用塔定理驗證一致。

**2.1.4 ★**　求 $x^4 - 2$ 在 $\mathbb{Q}$ 上的分裂體及其次數。（提示：根是 $\pm\sqrt[4]{2}, \pm i\sqrt[4]{2}$，需要 $\sqrt[4]{2}$ 與 $i$。）

**2.1.5**　求 $x^p - 1$（$p$ 質數）在 $\mathbb{Q}$ 上的分裂體與次數。（提示：分裂體是 $\mathbb{Q}(\zeta_p)$，次數 $p-1$ —— 與第 0.5 章呼應。）

**2.1.6 ★**　證明：若 $[L : K]$ 是質數，則 $K$ 與 $L$ 之間沒有真中間體。（提示：塔定理 + 質數無真因數分解。這預示「沒有中間體 ↔ Galois 群沒有真子群」，是下一章對應的特例。）

**2.1.7（前瞻）**　$x^3 - 2$ 的分裂體 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$ 次數為 $6$。試著列出你能想到的「固定 $\mathbb{Q}$、置換三個根」的對稱操作有幾種，猜測 $\mathrm{Gal}(L/\mathbb{Q})$ 是什麼群。（你正在親手發現 Galois 群 —— 下一章會嚴格證明你的猜測。）
