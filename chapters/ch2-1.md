## 開場：研究數，從研究「包含它的體」開始

第一部結束在一個教訓：要理解 FLT，必須理解那些比 $\mathbb{Z}$、$\mathbb{Q}$ 更大的數系 —— Euler 闖進的 $\mathbb{Q}(\sqrt{-3})$、Lamé 倚賴的 $\mathbb{Q}(\zeta_p)$。第二部就是系統地研究這些「更大的世界」。而研究它們的工具，是 Galois 理論 —— 現代數論的中樞神經。

Galois 理論的出發點是一個視角轉換。傳統上，我們問「某個方程式有沒有根」。Galois 教我們改問：**為了裝下這些根，需要把有理數體擴大到什麼程度？而這個「擴大」本身有什麼結構？** 把 $\mathbb{Q}$ 擴大到包含 $\sqrt 2$，得到 $\mathbb{Q}(\sqrt 2)$；擴大到包含 $\zeta_p$，得到 $\mathbb{Q}(\zeta_p)$。這些「擴大的體」叫**體擴張**（field extension），它們是 Galois 理論的研究對象。

本章建立體擴張的基本詞彙：擴張次數、代數元、最小多項式、分裂體。核心發現是一件出人意料的事 —— **體擴張可以用「維度」來度量**，於是第 1.1 章的線性代數，意外地成了研究數域的工具。這個橋樑（體擴張 ↔ 向量空間維度）是第二部的第一個關鍵，下一章的 Galois 對應將建立在它之上。

## 本章前置檢查點

進入本章前，你必須已經擁有下列四件東西。若有任何一項不確定，先回頭補上 —— 本章與其後的每一章都會反覆使用它們。

1. **向量空間與維度**（第 1.1 章）：什麼是基底、什麼是 $\dim_F V$、為什麼維度不依賴基底的選取。
2. **環、理想、商環**（第 1.4 章）：特別是「不可約多項式 $f$ $\Rightarrow$ $(f)$ 極大 $\Rightarrow$ $F[x]/(f)$ 是體」這條造體定理。
3. **多項式除法與不可約性**（第 0.5 章）：Eisenstein 判準，以及 $\Phi_p(x) = x^{p-1} + \cdots + 1$ 在 $\mathbb{Q}$ 上不可約的證明。
4. **單位根**（第 0.5 章）：$\zeta_n = e^{2\pi i/n}$、本原根、$\zeta_n^a$ 本原 $\iff \gcd(a, n) = 1$。

## 本書的「證明狀態」標記法

從第二部起，數學的深度陡增，而一本書不可能對每條定理都給出完整證明。含糊其詞是不誠實的，所以本書從這一章開始，為每一條**承重定理**（在通往 FLT 的邏輯鏈上真正出力的定理）標註三件事：**假設**（用它需要什麼前提）、**用途**（它在這條路上做什麼工作）、**狀態**（本書對它的證明做到什麼程度）。狀態只有五種：

| 標記 | 意義 |
|---|---|
| **完整證明** | 本書給出從已有結果到結論的完整論證，你可以逐行檢驗。 |
| **特例證明** | 本書只證某個特例（通常是我們真正需要的那個），一般情形取用。 |
| **證明骨架** | 本書給出論證的完整架構與關鍵步驟，並**明確指出**哪一步被略過、難在哪裡。 |
| **直觀說明** | 只給圖像與動機，不構成證明；用來理解「這在說什麼」。 |
| **外部黑盒** | 本書不證，直接取用，並指出出處。這類定理的正確性由文獻背書，不由本書背書。 |

這個標記法不是形式主義。讀完全書後，你應該能區分「我親手驗證過的部分」與「我知道其存在、但信任文獻的部分」—— 這兩者的界線在哪裡，正是一個人數學成熟度的指標。第七部尤其如此：任何宣稱一本書能讓人逐行驗證 Wiles 全文的說法都是不誠實的，而誠實的作法，就是把界線畫清楚。

## 擴張與次數

::: {.definition}
若體 $K$ 是體 $L$ 的子體，稱 $L/K$ 為**體擴張**（讀作「$L$ over $K$」）。
:::

關鍵觀察：$L$ 可以看成 $K$ 上的向量空間 —— $L$ 裡的元素是「向量」，$K$ 裡的元素是「純量」，加法與純量乘法就是體本身的運算（第 1.1 章已用 $\mathbb{C}/\mathbb{R}$ 預演過）。於是：

::: {.definition}
擴張 $L/K$ 的**次數** $[L : K]$ 是 $L$ 作為 $K$-向量空間的維度 $\dim_K L$。若有限稱**有限擴張**。
:::

::: {.example}
- $[\mathbb{C} : \mathbb{R}] = 2$，基底 $\{1, i\}$。
- $[\mathbb{Q}(\sqrt 2) : \mathbb{Q}] = 2$，基底 $\{1, \sqrt 2\}$。
- $[\mathbb{Q}(\zeta_p) : \mathbb{Q}] = p - 1$，基底 $\{1, \zeta_p, \dots, \zeta_p^{p-2}\}$ —— 第 0.5 章那個 $p-1$ 的精確身分，本章稍後正式確立。
:::

次數最有用的性質，是它在「擴張的塔」中相乘：

::: {.theorem name="塔定理"}
設 $K \subseteq M \subseteq L$ 為體的塔，且 $[M:K]$ 與 $[L:M]$ 皆有限。則
$$[L : K] = [L : M]\,[M : K].$$
:::

**假設**：兩層都是有限擴張（無窮情形需另行處理，本書不需要）。**用途**：把「次數」變成一套乘法記帳系統 —— 第 2.3 章數分圓體的中間體、第 3.1 章算 $\mathcal{O}_K$ 的秩，都靠它。**狀態**：完整證明（下方）。

::: {.proof}
設 $\{m_i\}_{i=1}^{s}$ 是 $M$ 作為 $K$-空間的基底（$s = [M:K]$），$\{l_j\}_{j=1}^{t}$ 是 $L$ 作為 $M$-空間的基底（$t = [L:M]$）。宣稱 $\{m_i l_j\}$ 是 $L$ 作為 $K$-空間的基底。

**生成：** 任何 $\alpha \in L$，先用 $\{l_j\}$ 寫成 $\alpha = \sum_j \beta_j l_j$（$\beta_j \in M$），再把每個 $\beta_j$ 用 $\{m_i\}$ 寫成 $\sum_i c_{ij} m_i$（$c_{ij} \in K$），合併得 $\alpha = \sum_{i,j} c_{ij} m_i l_j$。

**線性無關：** 若 $\sum_{i,j} c_{ij} m_i l_j = 0$（$c_{ij} \in K$），按 $l_j$ 分組得 $\sum_j \bigl(\sum_i c_{ij} m_i\bigr) l_j = 0$。括號內的量屬於 $M$，而 $\{l_j\}$ 在 $M$ 上線性無關，故每個 $\sum_i c_{ij} m_i = 0$；再由 $\{m_i\}$ 在 $K$ 上線性無關，得所有 $c_{ij} = 0$。

於是 $L$ 有恰好 $st = [L:M][M:K]$ 個基底向量。
:::

塔定理把「次數」變成一個乘法的記帳系統。它將反覆出現 —— 例如第 1.6 章 $\mathbb{Z}[\zeta_3]$ 與 $\mathbb{Z}[\sqrt{-3}]$ 的層級，正是 $[\mathbb{Q}(\zeta_3) : \mathbb{Q}] = 2$ 這座小塔的算術。

## 代數元與最小多項式

::: {.definition}
擴張 $L/K$ 中的元素 $\alpha \in L$ 稱為**代數的**（over $K$），若它是某個非零 $K$-係數多項式的根；否則稱**超越的**。
:::

$\sqrt 2$ 在 $\mathbb{Q}$ 上代數（$x^2 - 2$ 的根）；$\zeta_p$ 代數（$\Phi_p$ 的根）。$\pi$ 在 $\mathbb{Q}$ 上超越（Lindemann 定理，本書**外部黑盒**，且完全不需要它）。本書只關心代數的世界。

每個代數元都有一個「最經濟」的方程：

::: {.theorem name="最小多項式"}
設 $\alpha \in L$ 在 $K$ 上代數。則存在唯一的**首一**多項式 $m_\alpha(x) \in K[x]$，次數最小、以 $\alpha$ 為根。它在 $K[x]$ 中**不可約**，且任何以 $\alpha$ 為根的 $K$-多項式都被 $m_\alpha$ 整除。$m_\alpha$ 稱為 $\alpha$ 的**最小多項式**。
:::

**假設**：$\alpha$ 在 $K$ 上代數；$L$ 是體（無零因子）。**用途**：把「一個數的複雜度」量化成一個整數（次數），是下一條定理與整個 Galois 理論的計數基礎。**狀態**：完整證明（下方）。

::: {.proof}
考慮所有以 $\alpha$ 為根的非零 $K$-多項式，這個集合非空（$\alpha$ 代數）。取其中次數最小者並把首項係數除掉調為首一，記為 $m_\alpha$。

**不可約：** 若 $m_\alpha = fg$ 且 $\deg f, \deg g < \deg m_\alpha$，則 $0 = m_\alpha(\alpha) = f(\alpha)g(\alpha)$；因 $L$ 是體（無零因子），故 $f(\alpha) = 0$ 或 $g(\alpha) = 0$，與 $m_\alpha$ 次數最小矛盾。

**整除性：** 設 $f \in K[x]$ 且 $f(\alpha) = 0$。多項式除法給 $f = q\,m_\alpha + r$，$\deg r < \deg m_\alpha$。代入 $\alpha$ 得 $r(\alpha) = 0$；若 $r \ne 0$ 則違反最小性，故 $r = 0$，即 $m_\alpha \mid f$。

**唯一性：** 若 $m, m'$ 都符合條件，則互相整除且皆首一，故相等。
:::

最小多項式把代數元的「複雜度」量化了 —— 而這個複雜度恰好就是擴張次數：

::: {.theorem name="單擴張的次數"}
設 $\alpha \in L$ 在 $K$ 上代數，最小多項式次數為 $n$。則 $K(\alpha)$（$L$ 中包含 $K$ 與 $\alpha$ 的最小子體）滿足
$$[K(\alpha) : K] = n,$$
且 $\{1, \alpha, \alpha^2, \dots, \alpha^{n-1}\}$ 是一組 $K$-基底。
:::

**假設**：$\alpha$ 代數，$m_\alpha$ 次數 $n$。**用途**：這是「代數 $\to$ 線性代數」的翻譯機。有了它，$[\mathbb{Q}(\zeta_p):\mathbb{Q}] = p-1$ 這種斷言才有嚴格根據。**狀態**：完整證明（下方，依賴第 1.4 章的商環造體定理）。

::: {.proof}
這正是第 1.4 章「商環造體」的具體化。考慮求值同態 $\mathrm{ev}: K[x] \to L$，$f \mapsto f(\alpha)$。它的核恰是 $(m_\alpha)$（由上一條定理的整除性），像是 $K[\alpha]$（$\alpha$ 的多項式全體）。由第一同構定理，
$$K[x]/(m_\alpha) \;\cong\; K[\alpha].$$
因 $m_\alpha$ 不可約，$(m_\alpha)$ 極大（第 1.4 章），故左邊是體，於是 $K[\alpha]$ 是體；而包含 $K$ 與 $\alpha$ 的體必包含 $K[\alpha]$，故 $K[\alpha] = K(\alpha)$。

商環中每個元素有唯一的次數 $< n$ 的代表（多項式除以 $m_\alpha$ 取餘式），即 $\{1, \alpha, \dots, \alpha^{n-1}\}$ 的 $K$-線性組合，且這 $n$ 個元素線性無關（否則 $\alpha$ 滿足次數 $< n$ 的非零方程，違反最小性）。故它們是基底，維度 $n$。
:::

::: {.example name="$[\mathbb{Q}(\zeta_p):\mathbb{Q}] = p-1$ 正式蓋章"}
$\zeta_p$ 是 $\Phi_p(x) = x^{p-1} + x^{p-2} + \cdots + 1$ 的根，而第 0.5 章已用 Eisenstein 判準**完整證明** $\Phi_p$ 在 $\mathbb{Q}$ 上不可約。首一、不可約、以 $\zeta_p$ 為根 —— 由最小多項式的唯一性，$m_{\zeta_p} = \Phi_p$，次數 $p-1$。代入上條定理：
$$[\mathbb{Q}(\zeta_p) : \mathbb{Q}] = p - 1, \qquad \text{基底 } \{1, \zeta_p, \dots, \zeta_p^{p-2}\}.$$
第 0.5 章埋下、第 1.4 章預告的那個數字 $p-1$，到這裡才真正有了證明。注意這個論證的依賴鏈是單向的：$\Phi_p$ 不可約（0.5，完整證明）$\Rightarrow$ 最小多項式次數（本章，完整證明）$\Rightarrow$ 擴張次數。沒有循環。
:::

::: {.remark name="兩個觀點的合流"}
「代數元的最小多項式」與「向量空間的維度」是同一件事的兩面：前者是多項式的語言，後者是線性代數的語言。Galois 理論的全部威力，來自能在這兩種語言間自由切換 —— 一個關於「方程的根」的問題，被翻譯成一個關於「維度與子空間」的問題，再翻譯成下一章「群與子群」的問題。
:::

## 分裂體：裝下一個多項式所有根的最小體

最小多項式關注**單個**代數元。下一個概念關注**單個多項式的全部根**。

::: {.definition}
設 $f \in K[x]$ 非常數。$K$ 的擴張 $L$ 稱為 $f$ 的**分裂體**（splitting field），若 (i) $f$ 在 $L[x]$ 中完全分解成一次因式之積；(ii) $L$ 由 $K$ 與 $f$ 的那些根生成（即沒有多餘的部分）。
:::

::: {.theorem name="分裂體的存在與唯一"}
任何非常數 $f \in K[x]$ 都有分裂體，且任兩個分裂體之間存在一個固定 $K$ 逐點不動的體同構（即「在同構意義下唯一」）。
:::

**假設**：$K$ 是體，$f$ 非常數。**用途**：讓「$f$ 的分裂體」成為一個定冠詞可用的對象 —— 下一章整部 Galois 字典都寫在「**這個**分裂體」上，沒有唯一性就無從談起。**狀態**：外部黑盒（存在性用「反覆對不可約因子取商環造體」，唯一性用同構的逐步延拓；見 Dummit–Foote 第 13 章）。本書只使用結論。

::: {.remark name="一個要小心的簡化"}
本書幾乎所有數域都是 $\mathbb{C}$ 的子體。在這個情形，分裂體有一個省事的描述：代數基本定理（第 0.5 章）保證 $f$ 的根都落在 $\mathbb{C}$ 裡，於是分裂體就是 $K$ 添加這些具體複數所生成的 $\mathbb{C}$ 的子體，存在性不必再構造。但請記得這是**簡化而非一般情形**：對抽象的體（例如 $\mathbb{F}_p$ 上的多項式），沒有現成的 $\mathbb{C}$ 可用，必須靠上面那條定理。本書在第六部處理 $\mathrm{GL}_2(\mathbb{F}_p)$ 時會回到一般情形。
:::

分裂體是 Galois 理論真正的主角 —— 因為「方程的對稱性」正是分裂體裡根與根之間的可置換性。

::: {.example name="$x^3 - 2$ 的分裂體"}
根是 $\sqrt[3]{2},\ \omega\sqrt[3]{2},\ \omega^2\sqrt[3]{2}$，其中 $\omega = \zeta_3$。要裝下全部三個根，需要 $\sqrt[3]{2}$ **與** $\omega$（有了這兩個就有全部三根；少了任一個就不夠）。故分裂體是 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$。

算它的次數，用塔定理。$[\mathbb{Q}(\sqrt[3]{2}) : \mathbb{Q}] = 3$（最小多項式 $x^3 - 2$，由 Eisenstein 判準（$p = 2$）不可約）。$\omega$ 滿足 $x^2 + x + 1$；這個二次式在 $\mathbb{Q}(\sqrt[3]{2})$ 上仍不可約，因為 $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$ 而 $\omega \notin \mathbb{R}$，故 $x^2+x+1$ 在該體中無根。於是 $[L : \mathbb{Q}(\sqrt[3]{2})] = 2$，
$$[L : \mathbb{Q}] = 3 \times 2 = 6.$$
這個 $6$ 不是巧合 —— 它等於 $|S_3|$。下一章會看到：$x^3 - 2$ 的 Galois 群恰好是 $S_3$（三個根可任意置換），而對分裂體而言 **Galois 群的階等於擴張次數**。第 1.3 章習題 1.3.7 你已經預言過這個 $S_3$，現在它有了精確的次數座標。
:::

::: {.remark name="檢查點 2.1.A"}
不看下文，自己回答三個問題（答案在括號裡，先想再看）：

1. $[\mathbb{Q}(\sqrt 2, \sqrt 3):\mathbb{Q}]$ 是多少？（$4$。用塔定理：$[\mathbb{Q}(\sqrt2):\mathbb{Q}] = 2$，而 $\sqrt 3 \notin \mathbb{Q}(\sqrt 2)$ 故上一層也是 $2$。）
2. $\mathbb{Q}(\sqrt[3]{2})$ 是不是 $x^3 - 2$ 的分裂體？（**不是**。它只含一個根 $\sqrt[3]{2}$，另兩根是複數。這個「裝不下全部根」的缺陷，正是下一章 Galois 對應在它身上失效的原因。）
3. $[\mathbb{Q}(\zeta_7):\mathbb{Q}]$ 是多少？依據是什麼？（$6$。依據是 $\Phi_7$ 不可約（第 0.5 章，完整證明）＋ 單擴張次數定理（本章，完整證明）。）

第 3 題若答不出「依據」，請回頭重讀「單擴張的次數」那一節 —— 從第二部起，答案本身不算數，你必須同時知道答案倚賴哪條定理、那條定理的狀態是什麼。
:::

::: {.remark name="為什麼分裂體通往 Galois 群"}
分裂體 $L/K$ 的對稱性，是指那些「固定 $K$ 逐點不動、但可以置換 $f$ 的根」的體自同構 —— 它們構成的群就是 Galois 群 $\mathrm{Gal}(L/K)$。一個這樣的自同構必須把根送到根（因為它保持係數在 $K$ 的方程），所以 Galois 群作用在「根的集合」這個**有限**集合上（第 1.3 章的群作用！），而由於 $L$ 恰由這些根生成，這個作用是忠實的 —— 自同構被它在根上的效果完全決定。

於是三條線在分裂體匯合：**體擴張**（本章）提供舞台 $L/K$，**群**（第 1.3 章）提供對稱性 $\mathrm{Gal}(L/K)$，**群作用**把後者實現為根的置換。下一章的 Galois 對應，就是證明這個舞台與這個群之間有一個完美的字典 —— 體的中間層 ↔ 群的子群。那是第二部的最高峰，而本章剛剛架好了通往它的全部腳手架。
:::

## 本章地圖與下一章預告

- **體擴張與次數**：$L$ 是 $K$-向量空間，$[L:K] = \dim_K L$。
- **塔定理**：$[L:K] = [L:M][M:K]$，次數的乘法記帳。
- **代數元與最小多項式**：唯一首一不可約多項式；複雜度的度量。
- **單擴張次數 = 最小多項式次數**：商環造體的兌現；$[\mathbb{Q}(\zeta_p):\mathbb{Q}] = p-1$ 正式蓋章。
- **分裂體**：裝下多項式全部根的最小體，在同構意義下唯一；$x^3-2$ 給出次數 $6 = |S_3|$。

下一章《Galois 理論》是第二部的核心，也是全書的一座高峰。我們將定義 Galois 群 $\mathrm{Gal}(L/K)$，並處理 **Galois 基本定理**：分裂體 $L/K$ 的「中間體」與 Galois 群的「子群」之間，存在一個一一對應（且反轉包含關係）。這個對應把「體的問題」翻譯成「群的問題」，是 Galois 理論改變數學的核心洞見。

關於證明狀態，先打個預防針：下一章**不會**只丟一句「證明見教材」。我們會把基本定理拆成兩個引理（Dedekind 特徵無關性、Artin 定理），其中第一個給完整證明、第二個給證明骨架，然後從它們**完整推導**基本定理的四個部分。你將清楚看到：這條定理不是魔法，它建立在一個關於「線性無關」的初等事實之上。

## 習題

**2.1.1**　求 $[\mathbb{Q}(\sqrt 2, \sqrt 3) : \mathbb{Q}]$，並寫出一組 $\mathbb{Q}$-基底。（提示：用塔定理；驗證 $\sqrt 3 \notin \mathbb{Q}(\sqrt 2)$ —— 假設 $\sqrt 3 = a + b\sqrt 2$ 並平方，導出矛盾。）

**2.1.2 ★**　求 $\sqrt 2 + \sqrt 3$ 在 $\mathbb{Q}$ 上的最小多項式，並由其次數確認 $\mathbb{Q}(\sqrt 2 + \sqrt 3) = \mathbb{Q}(\sqrt 2, \sqrt 3)$。（這展示了「單擴張」有時等於「多元素擴張」—— 本原元定理的雛形，下一章會用到它的一般版。）

**2.1.3**　求 $\sqrt[4]{2}$ 在 $\mathbb{Q}$ 上的最小多項式與 $[\mathbb{Q}(\sqrt[4]{2}) : \mathbb{Q}]$。再求 $[\mathbb{Q}(\sqrt[4]{2}) : \mathbb{Q}(\sqrt 2)]$，用塔定理驗證一致。

**2.1.4 ★**　求 $x^4 - 2$ 在 $\mathbb{Q}$ 上的分裂體及其次數。（提示：根是 $\pm\sqrt[4]{2}, \pm i\sqrt[4]{2}$，需要 $\sqrt[4]{2}$ 與 $i$。答案是 $8$。）

**2.1.5**　求 $x^p - 1$（$p$ 質數）在 $\mathbb{Q}$ 上的分裂體與次數。（提示：分裂體是 $\mathbb{Q}(\zeta_p)$，次數 $p-1$。注意 $x^p - 1 = (x-1)\Phi_p(x)$ 本身可約，但分裂體的定義不要求 $f$ 不可約。）

**2.1.6 ★**　證明：若 $[L : K]$ 是質數，則 $K$ 與 $L$ 之間沒有真中間體。（提示：塔定理 + 質數無真因數分解。這預示「沒有中間體 $\leftrightarrow$ Galois 群沒有真子群」，是下一章對應的特例。）

**2.1.7（狀態練習）**　把本章的六條定理，各用一句話說出它的**假設**與**狀態**，不看書。若有任何一條你只記得結論而說不出假設，那條定理你其實還沒學會 —— 這是第二部起的自我檢查標準。

**2.1.8（前瞻）**　$x^3 - 2$ 的分裂體 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$ 次數為 $6$。試著列出你能想到的「固定 $\mathbb{Q}$、置換三個根」的對稱操作有幾種，猜測 $\mathrm{Gal}(L/\mathbb{Q})$ 是什麼群。（你正在親手發現 Galois 群 —— 下一章會嚴格證明你的猜測。）
