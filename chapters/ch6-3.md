## 開場：從另一側建立表示

上一章深入了橢圓曲線的 Galois 表示 $\rho_{E,\ell}$。這一章轉到模形式這一側 —— 模形式也給出 Galois 表示 $\rho_{f,\ell}$（第 6.1 章引用的 Deligne 定理）。要證明谷山–志村（兩側表示同構），必須先把兩側都建好。本章建立模形式側，並引入一個核心概念：**模的 Galois 表示**。

這個概念是 Wiles 證明的目標的精確形式。一個 Galois 表示稱為「模的」，若它來自某個模形式。谷山–志村的表示版（第 6.1 章）說：每條橢圓曲線的表示 $\rho_{E,\ell}$ 都是模的。Wiles 要證的，正是這個「表示的模性」。本章還會引入 Serre 猜想 —— Ribet 定理（第 6.6 章）正是它的一部分，也是 Frey 曲線降 level 的定理依據。

## Deligne 表示的性質字典

第 6.1 章陳述了 Deligne 定理：權重 $2$、級 $N$ 的特徵形式 $f$ 給出二維表示 $\rho_{f,\ell}$，$\mathrm{tr}\,\rho_{f,\ell}(\mathrm{Frob}_p) = a_p(f)$。這一章深入它的結構 —— 模形式的每個性質，都對應表示的一個性質。這部「字典」是模性理論的核心。

::: {.theorem name="模形式–表示字典　〔接受〕"}
特徵形式 $f$（權重 $k$、級 $N$）的 Galois 表示 $\rho_{f,\ell}$ 滿足：

| 模形式 $f$ 的性質 | 表示 $\rho_{f,\ell}$ 的性質 |
|---|---|
| 權重 $k$ | $\det\rho_{f,\ell} = \chi^{k-1}$（分圓特徵的冪） |
| 級 $N$ | 在 $p \mid N$ 處分歧（導體 $= N$） |
| 特徵值 $a_p$ | $\mathrm{tr}\,\rho_{f,\ell}(\mathrm{Frob}_p) = a_p$ |
| 新形式（newform） | $\rho_{f,\ell}$ 不可約（對幾乎所有 $\ell$） |
| 在 $p \nmid N\ell$ | 不分歧 |
:::

::: {.remark name="字典的誠實邊界"}
這部字典是**〔接受〕**的 —— 它是 Deligne 構造（第 6.1 章）的性質，本書不證明。注意其中一行需要精確化：**「新形式」**（newform，第 5.5 章）的表示對幾乎所有 $\ell$ 不可約，但**一般的尖形式**未必 —— 一個尖形式可能對應可約的表示（例如來自 Eisenstein 同餘的）。所以字典裡那行應讀作「新形式 → 不可約（幾乎所有 $\ell$）」，而不是「所有尖形式 → 不可約」。這個細節在第七部 Wiles 的論證裡會再次出現：他需要的是**新形式**的表示。
:::

::: {.remark name="級就是導體"}
字典裡最關鍵的一行是「級 $N$ ↔ 導體 $N$」。模形式的「級」（它對哪個 $\Gamma_0(N)$ 對稱，第 5.4 章）與它的 Galois 表示的「導體」（分歧的程度，Artin 導體）是同一個 $N$。這與第 5.3 章「橢圓曲線的導體 = 對應模形式的級」完美對齊 —— 因為若 $E$ 對應 $f$，則 $\rho_{E,\ell} \cong \rho_{f,\ell}$，兩者的導體當然相等。

這個對齊不是巧合，是模性的核心內容：橢圓曲線的導體（壞約化記錄，第 5.3 章）、模形式的級（對稱群，第 5.4 章）、Galois 表示的導體（分歧結構，本章）—— 三個來自不同世界的「$N$」，在模的表示上合為一個。$N$ 是貫穿橢圓曲線、模形式、Galois 表示三界的同一個數字。Frey 曲線那個「異常小的導體」，將同時是它對應模形式的「異常小的級」與它 Galois 表示的「異常小的分歧」—— 三重的小，三重地導向矛盾。
:::

## 模的 Galois 表示

現在給出 Wiles 證明目標的精確概念。

::: {.definition name="模的表示"}
一個 Galois 表示 $\rho: G_{\mathbb{Q}} \to \mathrm{GL}_2(\overline{\mathbb{Q}_\ell})$ 稱為**模的**（modular），若存在某個特徵形式 $f$ 使 $\rho \cong \rho_{f,\ell}$。類似地，mod $\ell$ 表示 $\bar\rho: G_{\mathbb{Q}} \to \mathrm{GL}_2(\overline{\mathbb{F}_\ell})$ 稱為**模的**，若它來自某個模形式的表示的約化。
:::

::: {.remark name="把谷山–志村變成一句話"}
有了這個概念，谷山–志村猜想變成一句極簡潔的話：

> **每條橢圓曲線的 Galois 表示 $\rho_{E,\ell}$ 都是模的。**

這就是 Wiles 要證的（半穩定情形）。注意這個陳述完全活在「Galois 表示」的世界裡 —— 它不再提橢圓曲線的點、不再提模形式的 $q$ 展開，只說「一個表示來自一個模形式」。這種抽象，正是力量所在：證明「一個表示是模的」，可以用變形理論（第七部）—— 一套專門操控表示的機器，而那套機器在原始的橢圓曲線或模形式語言裡根本無法表述。

第 6.1 章說過「語言的選擇決定能用的工具」。把目標表述為「表示的模性」，就解鎖了變形理論這個工具。Wiles 的天才，一半在於看出 FLT 可以化約到「表示的模性」，另一半在於發明證明它的變形機器。本章完成了前一半的鋪墊：把目標精確地放進表示的語言。
:::

## Serre 猜想：mod ℓ 的模性

模性也有 mod $\ell$ 的版本，由 Serre 在 1987 年提出 —— 它是 Ribet 定理的母體。

::: {.theorem name="Serre 猜想（現已由 Khare–Wintenberger 證明）　〔接受〕"}
每個不可約、**奇**的 mod $\ell$ 表示 $\bar\rho: G_{\mathbb{Q}} \to \mathrm{GL}_2(\overline{\mathbb{F}_\ell})$ 都是模的，且來自一個權重 $k(\bar\rho)$、級 $N(\bar\rho)$ 的模形式，其中 $k, N$ 由 $\bar\rho$ 的局部行為**明確算出**（Serre 的權重與級公式）。
:::

「奇」（odd）指 $\det\bar\rho(c) = -1$（$c$ 為複共軛）—— 橢圓曲線與模形式的表示都是奇的（因 $\det = \chi^{k-1}$，而 $\chi(c) = -1$）。Serre 不只猜「奇不可約表示是模的」，還給出**精確公式**預測它來自哪個級、哪個權重的模形式。

::: {.remark name="Serre 猜想的精確假設"}
注意 Serre 猜想的**兩個假設**：**不可約**與**奇**。這兩個條件都不是裝飾：

- **不可約**：可約的 mod $\ell$ 表示（例如來自 Eisenstein 同餘的）一般**不是**模的，或至少模性需要額外處理。Serre 猜想只對不可約表示宣稱模性。
- **奇**：偶表示（$\det\bar\rho(c) = +1$）一般**不是**模的 —— 這與模形式表示必為奇（$\det = \chi^{k-1}$，$\chi(c) = -1$）一致。偶表示是模性理論的盲區，至今未解。

對 FLT 而言，Frey 表示 $\bar\rho_{E,p}$ 恰好**同時滿足**這兩個條件：不可約（第 6.2 章）且奇（$\det = \chi$，$\chi(c) = -1$）。所以它落在 Serre 猜想的射程內。這個「恰好落在射程內」不是巧合 —— 它是 Frey 曲線構造的精心設計。
:::

::: {.remark name="四層：模的表示"}
「模的表示」是第六部第三條**中央箭頭**「表示 → 模性」的內容。用四層拆解：

**第一層，直觀圖像。** 「模的」是一個**性質**：一個 Galois 表示是模的，若它來自某個模形式。這就像說一個數是「有理的」（來自分數）或一個函數是「代數的」（來自多項式方程）。模性把表示世界與模形式世界連起來。

**第二層，精確定義。** 上面方框裡的定義：$\rho \cong \rho_{f,\ell}$ 對某個特徵形式 $f$。注意它要求**同構**（整個表示結構相同），而不只是跡相等 —— 雖然對半單表示兩者等價（第 6.1 章）。

**第三層，在 FLT 中的角色。** 谷山–志村猜想變成「每個 $\rho_{E,\ell}$ 都是模的」。Wiles 證明的正是這個（半穩定情形）。而 Serre 猜想是更強的陳述：它不只說「存在某個模形式」，還精確預測**哪個**級、**哪個**權重 —— 這個預測是 Ribet 定理（第 6.6 章）的原料。

**第四層，技術深潛（選讀）。** Serre 猜想在 2009 年由 Khare–Wintenberger 證明，是二十世紀末數論的里程碑。但對 FLT 而言，**只需要它的 level lowering 部分**（Ribet 1986 年證明），不需要完整猜想。本書把完整 Serre 猜想當作〔接受〕的黑盒子，但**只用**其中已被 Ribet 證明的、對 FLT 足夠的那一小塊。這是「黑盒子」與「黑盒子裡我們需要的那一小塊」的區別 —— 我們需要的那一小塊，Ribet 已經替我們證明了。
:::

::: {.remark name="Serre 的級公式就是 level lowering"}
Serre 級公式是 Ribet 定理的核心。它說：一個 mod $\ell$ 表示 $\bar\rho$ 的「最佳級」$N(\bar\rho)$，由它在每個質數的局部分歧決定 —— 一個質數 $p$ 只有在 $\bar\rho$ 於 $p$ 處**真正分歧**時才進入 $N(\bar\rho)$。

對 Frey 曲線：上一章證明了 $\bar\rho_{E,p}$ 在**奇質數** $\ell \mid abc$ 處「分歧被 $p$ 次方吸收」—— 即 mod $p$ 看，它在那裡**不分歧**。於是 Serre 級公式預測 $\bar\rho_{E,p}$ 的最佳級 $N(\bar\rho)$ **不含** $abc$ 的奇質因子，只剩下 $2$（來自 $x(x-a^p)(x+b^p)$ 在 $2$ 處的不可避免的壞約化，因子 $16$ 非 $p$ 次方）。Serre 級公式把 Frey 曲線的「假裝低 level」變成精確的「level $= 2$」。

Ribet 在 1986 年證明的，正是 Serre 級公式的這個情形（從一個級降到更低級，「level lowering」）。它早於完整 Serre 猜想的證明（2009 Khare–Wintenberger），但對 FLT 已經足夠。本章的「模的表示」與「Serre 級公式」，是第 6.6 章 Ribet 收網的全部理論準備。下一章先把模性翻譯成更完整的表示陳述，然後 6.5 構造 Frey 曲線，6.6 讓 Ribet 與 Serre 級公式合力，把 Frey 表示逼到「級 $2$」的死角。
:::

## 兩側表示的對接

把橢圓曲線側（第 6.2 章）與模形式側（本章）的表示並排，模性就是它們的「對接」：

$$\underbrace{\rho_{E,\ell}}_{\text{橢圓曲線（6.2）}} \quad\cong\quad \underbrace{\rho_{f,\ell}}_{\text{模形式（6.3）}}$$

::: {.remark name="對接的兩個方向"}
模性這個對接，可以從兩個方向理解，對應證明的兩個歷史階段：

**Wiles 方向（橢圓曲線 → 模形式）**：給一個橢圓曲線表示 $\rho_{E,\ell}$，證明存在模形式 $f$ 使它 $\cong \rho_{f,\ell}$。這是「橢圓曲線是模的」，Wiles 證明的方向，第七部的內容。

**Ribet 方向（模形式 → 模形式）**：給一個模形式表示，證明它在 mod $p$ 約化後來自一個更低級的模形式（level lowering）。這是 Frey 曲線導出矛盾的方向，第 6.6 章。

FLT 的證明是兩個方向的合力：Wiles 證明 Frey 曲線（若存在）的表示是模的（來自某模形式），Ribet 證明這個模形式可以降到級 $2$，但級 $2$ 沒有合適的模形式 —— 矛盾。兩個方向在 Frey 曲線的表示 $\bar\rho_{E,p}$ 上相遇，把它擠到一個不存在的模形式上。本章建立的「模的表示」概念，是讓這兩個方向能夠對話的共同語言 —— 它們都在說「某個表示是否模的」，只是一個證明「是」（Wiles），一個利用「是」導出矛盾（Ribet）。
:::

## 檢查點：你跟上這條鏈了嗎？

第三條中央箭頭「表示 → 模性」已經建立。用三個問題確認：

1. **模的表示**：什麼是「模的」表示？谷山–志村猜想用這個概念怎麼說？（答案：$\rho \cong \rho_{f,\ell}$；「每個 $\rho_{E,\ell}$ 都是模的」。）
2. **Serre 猜想的假設**：Serre 猜想對什麼樣的表示宣稱模性？為什麼 Frey 表示恰好滿足？（答案：不可約 + 奇；Frey 表示不可約且 $\det = \chi$ 故奇。）
3. **級公式**：為什麼 Frey 表示的最佳級是 $2$ 而非 $\mathrm{rad}(abc)$？（答案：奇質數 $\ell \mid abc$ 不分歧被剝離，$2$ 例外留下。）

若三題都答得出來，你已經掌握了模性與 Serre 猜想的框架。下一章把谷山–志村完整重述為表示語言，並精確陳述 Wiles 定理的形式。

## 本章地圖與下一章預告

- **模形式–表示字典**（〔接受〕）：權重 ↔ 行列式、級 ↔ 導體、$a_p$ ↔ Frobenius 跡；新形式 → 不可約。
- **級 = 導體**：橢圓曲線、模形式、表示三界的同一個 $N$。
- **模的表示**：$\rho \cong \rho_{f,\ell}$；谷山–志村 = 「每個 $\rho_{E,\ell}$ 模」。
- **Serre 猜想**（〔接受〕）：奇不可約 mod $\ell$ 表示都模；級公式 = level lowering；Frey 表示恰好落在射程內。
- **兩側對接**：Wiles 方向（橢圓→模）+ Ribet 方向（降 level）。

下一章《「模性」的表示版》把谷山–志村猜想完整地重述為表示語言，並精確陳述 Wiles 定理的形式：半穩定橢圓曲線的 mod $\ell$ 表示是模的。我們會把前三章（Galois 表示通論、橢圓曲線側、模形式側）綜合，給出 FLT 證明所需的精確命題。然後 6.5 構造 Frey 曲線、6.6 是 Ribet 收網、6.7 是歷史 —— 第六部的後半，是把所有零件組裝成「Frey 曲線不可能存在」的完整論證骨架，只留下「半穩定曲線都是模的」這一塊（Wiles 的工作）給第七部。

## 習題

**6.3.1**　Deligne 字典說「權重 $k$ ↔ $\det\rho = \chi^{k-1}$」。對權重 $2$ 模形式，驗證 $\det\rho_{f,\ell} = \chi$，與橢圓曲線 $\det\rho_{E,\ell} = \chi$（第 6.1 章）一致 —— 故橢圓曲線對應權重 $2$。

**6.3.2 ★**　解釋「級 = 導體」為什麼是模性的必然：若 $\rho_{E,\ell} \cong \rho_{f,\ell}$，為什麼 $E$ 的導體必等於 $f$ 的級？（提示：同構的表示有相同的分歧結構。）

**6.3.3**　「奇」表示指 $\det\bar\rho(c) = -1$。用 $\det\bar\rho = \chi^{k-1}$ 與 $\chi(c) = -1$ 驗證權重 $2$ 表示是奇的。

**6.3.4 ★**　Serre 級公式說「$p$ 進入 $N(\bar\rho)$ $\iff$ $\bar\rho$ 在 $p$ 分歧」。Frey 表示在**奇質數** $\ell \mid abc$ 不分歧（第 6.2 章）。推論 $N(\bar\rho_{E,p})$ 不含 $abc$ 的奇質因子。為什麼最後剩下 $2$？（提示：$2$ 處的壞約化無法被 $p$ 次方吸收。）

**6.3.5**　用「模的表示」概念，把谷山–志村猜想寫成一句話。再寫出 Wiles 實際證明的（半穩定）版本。

**6.3.6（前瞻）**　FLT 證明是「Wiles 方向」與「Ribet 方向」的合力。用一句話說明：為什麼需要**兩個**方向，而不能只靠一個？（提示：Wiles 證「Frey 表示是模的」，但「是模的」本身不矛盾 —— 需要 Ribet 證明它模到一個不存在的地方。）
