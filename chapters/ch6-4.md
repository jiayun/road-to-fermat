## 開場：把目標說精確

前三章建立了 Galois 表示的語言（6.1）、橢圓曲線側的表示（6.2）、模形式側的表示（6.3）。這一章把它們綜合，給出 FLT 證明所需的**精確命題** —— Wiles 定理的確切形式 —— 並預覽 Wiles 證明它的策略骨架。

這一章是承上啟下的樞紐。它之前，我們在建立語言；它之後（6.5–6.6），我們用這個語言把 Frey 曲線逼入絕境；而它本身，把「FLT」這個目標，一路翻譯到 Wiles 真正動手證明的那個精確命題：**半穩定橢圓曲線的 mod $\ell$ 表示是模的**。理解這個翻譯，就理解了第七部 Wiles 在證什麼。

## 模性的層次

「橢圓曲線是模的」有幾個強弱不同的層次，釐清它們是理解 Wiles 策略的關鍵。

::: {.definition name="模性的三個層次"}
1. **$\ell$-進模性**（最強）：$\rho_{E,\ell}: G_{\mathbb{Q}} \to \mathrm{GL}_2(\mathbb{Z}_\ell)$ 是模的。這等價於 $E$ 是模的（谷山–志村）。
2. **mod $\ell$ 模性**（中）：剩餘表示 $\bar\rho_{E,\ell}: G_{\mathbb{Q}} \to \mathrm{GL}_2(\mathbb{F}_\ell)$ 是模的。
3. **單一質數的 mod $\ell$ 模性**（起點）：對某個特定的 $\ell$，$\bar\rho_{E,\ell}$ 是模的。
:::

層次 $1$ 是目標（它就是谷山–志村）。層次 $2$、$3$ 較弱，但 Wiles 的天才在於發現：**可以從弱的層次，提升到強的層次**。

::: {.remark name="提升的策略"}
Wiles 證明的核心邏輯，是一條「模性提升」（modularity lifting）的鏈：

$$\underbrace{\text{某個 }\bar\rho_{E,\ell}\text{ 模}}_{\text{層次 3，起點}} \;\Longrightarrow\; \underbrace{\rho_{E,\ell}\text{ 模}}_{\text{層次 1，目標}}.$$

即：如果**剩餘表示**（mod $\ell$，有限、可控）是模的，那麼**完整的 $\ell$-進表示**也是模的。這個提升是整個證明的引擎，由第七部的變形理論（$R = \mathbb{T}$）提供。

為什麼這是聰明的策略？因為直接證明 $\ell$-進表示 $\rho_{E,\ell}$ 模，是面對一個無窮的對象（$\mathrm{GL}_2(\mathbb{Z}_\ell)$ 無限）。但 mod $\ell$ 剩餘表示 $\bar\rho_{E,\ell}$ 落在**有限**群 $\mathrm{GL}_2(\mathbb{F}_\ell)$ 裡（第 1.1 章算過它的階），可以用有限的、具體的工具處理。Wiles 把「無窮的模性」化約成「有限的模性 + 提升」—— 而提升本身，用變形理論控制「$\bar\rho$ 的所有可能提升」來完成。把無窮問題拆成「有限起點 + 受控提升」，是 Wiles 策略的靈魂。
:::

## 起點：為什麼 mod 3

提升策略需要一個起點 —— 至少一個 $\ell$ 使 $\bar\rho_{E,\ell}$ 模。Wiles 選了 $\ell = 3$，這個選擇回收了第 1.1 章一個古老的伏筆。

::: {.theorem name="Langlands–Tunnell（應用形式）"}
若 $\bar\rho_{E,3}$ 的像在 $\mathrm{GL}_2(\mathbb{F}_3)$ 裡是「可解的」，則 $\bar\rho_{E,3}$ 是模的。
:::

::: {.remark name="$48$ 的回歸"}
為什麼是 $3$？關鍵在 $\mathrm{GL}_2(\mathbb{F}_3)$ 這個具體有限群的結構。第 1.1 章我們算過 $|\mathrm{GL}_2(\mathbb{F}_3)| = 48$，並在習題 1.1.5 暗示它與小對稱群的關係。事實是：$\mathrm{PGL}_2(\mathbb{F}_3) \cong S_4$（四個元素的對稱群），而 $S_4$ 是**可解群**（第 2.2 章：它有子群鏈 $S_4 \triangleright A_4 \triangleright V_4 \triangleright \{e\}$，商都交換）。

於是 $\bar\rho_{E,3}$ 的像（落在 $\mathrm{GL}_2(\mathbb{F}_3)$ 裡）總是可解的！而 Langlands–Tunnell 定理（基於可解情形的 Langlands 綱領，第 2.2、5.7 章）說：**可解像的 mod $3$ 表示自動是模的**。這就給了 Wiles 一個免費的起點 —— 對任何橢圓曲線，$\bar\rho_{E,3}$ 一開始就是模的，無需證明。

第 1.1 章那個樸素的計數 $|\mathrm{GL}_2(\mathbb{F}_3)| = 48$、第 2.2 章那個「$S_4$ 可解、$S_5$ 不可解」的可解性理論、第 5.7 章 Langlands 綱領 —— 三條看似獨立的線，在 Wiles 的起手式 $\ell = 3$ 上交會。$\mathrm{GL}_2(\mathbb{F}_3)$ 之所以是正確的起點，正因為它小到可解，於是落入 Langlands–Tunnell 的射程。整本書最早的那個 $48$，是 Wiles 證明的第一塊踏腳石。第 2.2 章我說過可解性的影子會在最意想不到的地方出現 —— 就是這裡。
:::

## Wiles 定理的精確形式

把所有東西綜合，給出 Wiles 1994 年證明的精確命題。

::: {.theorem name="Wiles（模性定理，半穩定情形），1994"}
每一條**半穩定**的橢圓曲線 $E/\mathbb{Q}$ 都是模的：存在權重 $2$、級 $N$（$= E$ 的導體）的特徵形式 $f$，使 $\rho_{E,\ell} \cong \rho_{f,\ell}$。
:::

「半穩定」（第 4.5 章：壞約化全為乘性）是 Wiles 證明覆蓋的範圍。它比完整谷山–志村（所有橢圓曲線）弱，但對 FLT 已經足夠 —— 因為 Frey 曲線恰好半穩定（第 5.3 章）。完整版要等 2001 年 Breuil–Conrad–Diamond–Taylor。

::: {.remark name="證明的三步骨架"}
Wiles 證明半穩定模性的骨架，可以濃縮成三步（細節是第七部）：

**步驟 A（起點）**：對半穩定 $E$，$\bar\rho_{E,3}$ 的像可解，由 Langlands–Tunnell 模。起點到手。

**步驟 B（提升）**：證明「$\bar\rho_{E,3}$ 模 $\Rightarrow \rho_{E,3}$ 模」。這是模性提升定理，核心是變形理論的 $R = \mathbb{T}$（第七部全部內容）。提升完成，$E$ 模。

**步驟 C（例外處理）**：步驟 B 需要 $\bar\rho_{E,3}$ 不可約。當它可約時，改用 $\ell = 5$：$\bar\rho_{E,5}$ 此時可證不可約，但 $\bar\rho_{E,5}$ 的模性不能直接由 Langlands–Tunnell 得到（$\mathrm{GL}_2(\mathbb{F}_5)$ 像未必可解）。Wiles 用一個巧妙的「$3$–$5$ 切換」：構造一條輔助曲線，它的 $\bar\rho_3$ 模（給 $\bar\rho_5$ 模性）又與原曲線的 $\bar\rho_5$ 相關，繞過障礙。

這三步 —— 起點（Langlands–Tunnell）、提升（$R = \mathbb{T}$）、切換（$3$–$5$）—— 是 Wiles 證明的全貌。第七部會展開步驟 B（佔據絕大部分篇幅）與步驟 C。本章先讓你看見整座山的輪廓：Wiles 不是直接登頂，而是先找到一個低處的立足點（mod $3$ 模性），再沿著變形理論這條繩索，一路提升到頂（$\ell$-進模性）。
:::

## FLT 的完整邏輯，現在可以寫下

有了精確的 Wiles 定理，加上 Frey（6.5）與 Ribet（6.6），FLT 的完整邏輯鏈現在可以精確寫下（細節在後兩章）：

::: {.theorem name="FLT 的證明骨架"}
假設 $a^p + b^p = c^p$ 有解（$p \ge 5$）。則：

1. **Frey（6.5）**：構造半穩定橢圓曲線 $E: y^2 = x(x-a^p)(x+b^p)$。
2. **Wiles（本章）**：$E$ 半穩定，故模 —— $\bar\rho_{E,p}$ 模。
3. **Ribet（6.6）**：$\bar\rho_{E,p}$ 不可約、半穩定、判別式 $p$ 次方，故 level lowering 把它降到級 $2$ —— 它來自一個權重 $2$、級 $2$ 的模形式。
4. **矛盾**：權重 $2$、級 $2$ 的尖形式空間是零維（$X_0(2)$ 虧格 $0$，第 5.6 章）—— 不存在這樣的模形式。

矛盾。故 $a^p + b^p = c^p$ 無解。FLT 成立。
:::

::: {.remark name="繩索已經套好"}
這個骨架是 FLT 證明的全部邏輯。注意 Wiles 定理（步驟 2）在其中的位置：它證明 Frey 曲線**是**模的，而 Ribet（步驟 3）把這個「是」推向一個不存在的地方（級 $2$）。Wiles 與 Ribet 從兩端拉緊套在 Frey 曲線上的繩索 —— Wiles 說「它必須是模的」，Ribet 說「如果它模，必來自級 $2$」，而級 $2$ 空空如也。Frey 曲線被擠到一個邏輯上不存在的位置，於是它不存在，於是 FLT 反例不存在。

本章完成了這個骨架的中央一環（Wiles 定理的精確陳述）。剩下的兩章補上兩端：6.5 構造 Frey 曲線（步驟 1），6.6 證明 Ribet 的 level lowering（步驟 3）。然後第六部完成，FLT 的邏輯鏈就完整了 —— 只剩 Wiles 定理本身的證明（步驟 2 的內部），那是第七部的登頂。我們離終點只剩一座山：證明「半穩定橢圓曲線都是模的」。
:::

## 本章地圖與下一章預告

- **模性的三層次**：$\ell$-進（目標）、mod $\ell$、單一質數（起點）。
- **模性提升**：剩餘表示模 $\Rightarrow$ $\ell$-進表示模；無窮化約為有限 + 提升。
- **mod 3 起點**：$\mathrm{PGL}_2(\mathbb{F}_3) \cong S_4$ 可解，Langlands–Tunnell 給免費起點；$48$ 的回歸。
- **Wiles 定理**：半穩定 $E$ 都模；三步骨架（起點、提升、$3$–$5$ 切換）。
- **FLT 骨架**：Frey + Wiles + Ribet + $X_0(2)$ 虧格 $0$ = 矛盾。

下一章《Frey 曲線》正式構造這條傳奇的曲線。給定假想的 FLT 反例 $a^p + b^p = c^p$，Frey 把它變成橢圓曲線 $y^2 = x(x-a^p)(x+b^p)$，並計算它的判別式、導體，證明它半穩定、它的 $\bar\rho_{E,p}$ 具有前面說的四個特殊性質。我們會看到這條曲線如何把「整數方程的解」編碼成「橢圓曲線的存在」—— 這個編碼是整個現代證明的關鍵轉軸，把費馬的數論問題轉化成 Wiles 與 Ribet 能用表示論攻擊的形式。Frey 曲線是古典與現代之間的那道門。

## 習題

**6.4.1**　寫出模性的三個層次，並說明為什麼層次 $1$（$\ell$-進）最強、層次 $3$（單一質數 mod $\ell$）最弱。

**6.4.2 ★**　$\mathrm{PGL}_2(\mathbb{F}_3) \cong S_4$。驗證 $|\mathrm{PGL}_2(\mathbb{F}_3)| = |\mathrm{GL}_2(\mathbb{F}_3)|/|\mathbb{F}_3^\times| = 48/2 = 24 = |S_4|$。再用第 2.2 章說明 $S_4$ 可解（給出子群鏈）。

**6.4.3**　解釋為什麼 Wiles 選 $\ell = 3$ 作起點，而不是 $\ell = 5$ 或更大。（提示：$\mathrm{PGL}_2(\mathbb{F}_3) \cong S_4$ 可解，$\mathrm{PGL}_2(\mathbb{F}_5) \cong S_5$ 不可解。）

**6.4.4 ★**　模性提升 $\bar\rho$ 模 $\Rightarrow \rho$ 模，把無窮問題化約為有限。用一句話說明為什麼 mod $\ell$ 表示「有限可控」而 $\ell$-進表示「無窮」（提示：$\mathrm{GL}_2(\mathbb{F}_\ell)$ vs $\mathrm{GL}_2(\mathbb{Z}_\ell)$ 的基數）。

**6.4.5**　寫出 FLT 證明的四步骨架（Frey、Wiles、Ribet、矛盾），標出每一步用到本書哪一章的結果。

**6.4.6（前瞻）**　步驟 B（模性提升）是 $R = \mathbb{T}$，第七部的核心。用一句話預測：「$R$」（變形環，第 2.5 章泛性質）與「$\mathbb{T}$」（Hecke 代數，第 5.5 章）相等，為什麼能推出「$\bar\rho$ 的所有提升都模」？（提示：$R$ 參數化所有提升，$\mathbb{T}$ 參數化模的提升，相等即「全部 = 模的」。）
