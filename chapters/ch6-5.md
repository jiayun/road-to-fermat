## 開場：一條改變一切的曲線

整個現代 FLT 證明，繞著一條曲線轉。它由 Gerhard Frey 在 1985 年提出，是把費馬方程與橢圓曲線連起來的那道門。在 Frey 之前，沒人想到費馬最後定理（一個關於整數的問題）會與橢圓曲線的模性（一個關於複分析與 Galois 表示的問題）有任何關係。Frey 的洞見，把三百五十年的數論問題，轉化成一個能用二十世紀最強機器攻擊的形式。

這一章構造 Frey 曲線，計算它的判別式與導體，證明它半穩定，並確認它的 Galois 表示 $\bar\rho_{E,p}$ 具有第 6.2 章說的四個特殊性質。走完它，我們就理解了 Frey 曲線為何「太特殊以致不可能存在」—— 而那個「不可能」，正是 FLT 的證明。

## 構造：把反例變成曲線

::: {.definition name="Frey 曲線"}
任何 FLT 反例都可先約成一個互質、非零的整數解
$$a^p+b^p+c^p=0,\qquad p\ge5\text{ 為質數}.$$
這裡已用古典結果排除指數 $3$與 $4$：若一般指數 $n>2$ 有反例，取 $n$ 的奇質因子，或在 $n$ 是 $2$ 的冪時降到指數 $4$，就得到這種約化。把三項重排後可使 $b$ 為偶數；必要時將 $(a,b,c)$ 同時乘上 $-1$，再使 $a\equiv-1\pmod4$。這種有符號的正規化對以下 $2$-進最小模型是必要的。**Frey 曲線**定義為
$$E: y^2 = x(x - a^p)(x + b^p).$$
:::

這是一條橢圓曲線，三個根是 $0$、$a^p$、$-b^p$。展開成 Weierstrass 形：$y^2 = x^3 + (b^p - a^p)x^2 - a^p b^p x$。原本的正整數寫法 $A^p+B^p=C^p$ 只是把其中一項改成負號；這不改變反證的內容。

::: {.remark name="方向：反例 → 曲線（不是等價）"}
這裡要精確：**反例的存在，給出這條特定曲線的存在** —— 給定正規化的 $a^p+b^p+c^p=0$，我們就寫得出 $E$。但**反過來不成立**：一條也可寫成 $y^2=x(x-a^p)(x+b^p)$ 的曲線，並不自動附帶所需的互質 FLT 方程解。所以這是單向構造，不是等價。

這對證明沒有影響，因為我們用的是**單向**推理：假設反例存在 → 構造曲線 → 導出矛盾。我們不需要「曲線存在 $\iff$ 反例存在」這個等價；只需要「反例存在 $\Rightarrow$ 曲線存在」這個方向。本書在此修正一個常見的過度陳述：Frey 曲線不是「FLT 反例的等價物」，而是「FLT 反例的**編碼**」—— 一個方向（反例 → 曲線）是乾淨的，另一個方向（曲線 → 反例）既不需要、也不成立。
:::

::: {.remark name="編碼的巧思"}
Frey 曲線的精妙在於「編碼」：它把一個關於**整數**的陳述（$a^p + b^p = c^p$ 有解）轉化成一個關於**橢圓曲線**的陳述（這條特定的 $E$ 存在）。這個轉化是整個現代證明的關鍵轉軸。

對比第三部 Kummer 的策略：Kummer 直接在費馬方程裡工作，在分圓域 $\mathbb{Q}(\zeta_p)$ 裡分解，撞上正則性的牆。Frey 完全不碰費馬方程的內部結構，而是把整個反例「打包」成一條曲線的係數，然後去研究**那條曲線的性質**。問題的舞台從「分圓域的算術」搬到「橢圓曲線的模性」—— 而後者有 Wiles 與 Ribet 的重武器。

這種「把問題編碼成另一個對象，再研究那個對象」的策略，是現代數學的典型手法。Frey 曲線是它最輝煌的範例：費馬的整數謎題，被編碼成一條曲線的 DNA，而那條曲線的 DNA 裡藏著一個致命的矛盾。
:::

## 判別式：完全 $p$ 次方

Frey 曲線的第一個異常，是它的判別式。

::: {.theorem name="Frey 曲線的判別式　〔算〕"}
$$\Delta = 16\,(a^p)^2(b^p)^2(a^p + b^p)^2 = 16\,(abc)^{2p}.$$
:::

::: {.proof}
三次曲線 $y^2 = (x - e_1)(x - e_2)(x - e_3)$ 的判別式正比於 $\prod_{i<j}(e_i - e_j)^2$。這裡根是 $e_1 = 0, e_2 = a^p, e_3 = -b^p$，三個差對應 $a^p$、$b^p$、$a^p+b^p=-c^p$。平方消去符號，於是
$$\Delta = 16\,(a^p)^2(b^p)^2(c^p)^2 = 16\,(abc)^{2p}. \qquad\square$$
:::

數值範例（借 $a^2 + b^2 = c^2$ 的 $3,4,5$ 展示結構）：$\Delta = 16(9 \cdot 16 \cdot 25)^2 = 207360000 = 16 \cdot 60^4 = 16(abc)^{2p}$，精確相符。

關鍵在那個指數 $2p$：判別式（除了因子 $16$）是一個**完全 $p$ 次方**。這個性質，是 Frey 曲線一切異常的根源。

::: {.remark name="最小判別式：不能用因子 16 解釋 2 處分歧"}
這裡要修正一個常見的錯誤：**不能用非最小模型裡的因子 $16$ 來解釋 $2$ 處的分歧**。上面算的 $\Delta = 16(abc)^{2p}$ 是**非最小模型** $y^2 = x(x-a^p)(x+b^p)$ 的判別式，這個模型在 $2$ 處**一般不是最小的**（minimal）。

在標準歸一化（$b$ 偶、$a \equiv -1 \pmod 4$）下，Frey 曲線的**最小判別式**是
$$\Delta_{\min} = 2^{-8}(abc)^{2p},$$
其 $2$-進賦值是
$$v_2(\Delta_{\min}) = 2p\,v_2(b) - 8.$$
對 $p \ge 5$，這個數**不被 $p$ 整除**（因為 $2p\,v_2(b)$ 是 $p$ 的倍數，但 $-8$ 不是）。所以 $2$ 處的分歧**無法被 $p$ 次方吸收** —— 這才是 $2$ 留在級裡的正確理由，而不是「非最小模型的因子 $16$」。

對奇質數 $q \mid abc$ 且 $q \ne p$，$v_q(\Delta_{\min}) = 2p\,v_q(abc)$ 是 $p$ 的倍數，故分歧被 $p$ 次方吸收，$\bar\rho_{E,p}$ 在 $q$ 處不分歧。若 $q=p$，同一整除性給出的是 finite-flat，而非不分歧。這兩種奇質數輸出與 $2$ 處 $v_2(\Delta_{\min})$ 不被 $p$ 整除的對比，是整個降級論證的數論核心。
:::

## 導體：異常的小

判別式 $(abc)^{2p}$ 巨大（含高次冪）。但導體 —— 記錄壞約化的精細不變量（第 5.3 章）—— 卻異常小。

::: {.theorem name="Frey 曲線半穩定且導體小　〔證〕/〔接受〕"}
適當選取 $a, b, c$ 的符號與奇偶（可設 $b$ 偶、$a \equiv -1 \pmod 4$），Frey 曲線是**半穩定**的，且導體
$$N = \prod_{\ell \mid abc}\ell = \mathrm{rad}(abc)$$
（無平方因子，每個壞質數只取一次方）。
:::

::: {.remark name="導體公式的狀態拆分"}
這條定理的狀態需要**拆分**，因為它的不同部分可信度不同：

**其一，奇質數處的半穩定性是〔證〕的。** 對每個奇質數 $q \mid abc$（包括可能的 $q=p$），Frey 曲線在 $q$ 處是乘性約化，導體貢獻 $f_q=1$。這是曲線的約化性質，與稍後我們選擇 mod $p$ 表示是兩件事，所以不應在此排除 $q=p$。

**其二，$2$ 處的完整處理是〔接受〕的。** $2$ 處的最小模型、半穩定性與導體公式需要細緻的 $2$-進分析（Tate 演算法），本書不展開。在 $b$ 偶、$a \equiv -1 \pmod 4$ 的選取下，$2$ 處也是乘性約化，但這個驗證標為〔接受〕。

**其三，導體公式是〔接受〕的。** 說「導體 $= \mathrm{rad}(abc)$」依賴於「乘性約化 $\iff$ 導體貢獻 $1$」這個標準事實（第 5.3 章），以及對 $2$ 處的細緻處理。本書把「半穩定 $\implies$ 導體無平方因子」當作已證（第 4.5 章），但把「Frey 曲線在每個壞質數確實是乘性約化」的完整驗證（尤其 $2$ 處）標為〔接受〕。

**總結：** 奇質數處的半穩定性與導體貢獻是〔證〕的；$2$ 處的最小模型、半穩定性與完整導體公式是〔接受〕的。本書誠實標出這個拆分 —— 不假裝 $2$ 處的細節是本書證的。
:::

::: {.remark name="判別式大、導體小的反差"}
這裡是 Frey 曲線的核心異常，第 5.3、5.7 章一直預告的那個。並排看：
$$\Delta_{\min} = 2^{-8}(abc)^{2p}\ (\text{巨大，含 } p \text{ 次冪}), \qquad N = \mathrm{rad}(abc)\ (\text{微小，無平方因子}).$$

乘性約化時，最小判別式的賦值可以很大，而曲線導體指數仍只是 $1$；所以「判別式冪次高，導體冪次也應該高」並非一般定律。Frey 曲線真正對降級致命的是更精確的整除性：對奇壞質數 $q$，$p\mid v_q(\Delta_{\min})$。這讓 $E[p]$ 在 $q$ 處 finite，而不只是讓導體「看起來小」。

這個反差就是 Frey 曲線「不該存在」的數值徵兆。一條導體這麼小的曲線，「應該」對應一個級這麼小的模形式（若它模）；但它的 mod $p$ 表示又攜帶著判別式那 $p$ 次冪的資訊。這兩件事的張力，在 Ribet 定理下爆發成矛盾。Frey 看到這個反差時的直覺是：這條曲線太奇怪了，它好到不可能是模的 —— 而所有橢圓曲線又都該是模的（谷山–志村）。矛盾的氣味，從判別式與導體的反差裡就能聞到。
:::

## Galois 表示的四個性質

把第 6.2 章的分析用在 Frey 曲線上，確認它的 mod $p$ 表示 $\bar\rho_{E,p}$ 的四個特殊性質。這些只是**曲線側輸入**；模性、權重 $2$、平凡 Nebentypus 與平方自由原級等 Ribet 假設要到第 6.6 章才補齊：

::: {.theorem name="Frey 表示的性質　〔接受〕"}
設 $E$ 是指數 $p\ge5$ 的 Frey 曲線。則 $\bar\rho_{E,p}: G_{\mathbb{Q}} \to \mathrm{GL}_2(\mathbb{F}_p)$ 滿足：

1. **絕對不可約**（Mazur 的同源定理加上 Frey 曲線的特殊局部計算，第 6.2 章）。
2. **半穩定**（所有壞約化乘性）。
3. **精確的局部性質**：在奇壞質數 $q\ne p$ 處不分歧；若 $p\mid abc$，在 $q=p$ 處 finite-flat；在 $q=2$ 處不 finite。三項都由 Tate 曲線的 finite 判準與 $v_q(\Delta_{\min})$ 的整除或不整除決定；第三項恰好是因為整除失敗。
4. **行列式 $= \chi$**（分圓特徵，第 6.1 章）。
:::

::: {.remark name="四層：反例 → Frey 曲線 → 特殊表示"}
這條定理是第六部第五條**中央箭頭**「反例 → Frey 曲線 → 特殊表示」的內容。用四層拆解：

**第一層，直觀圖像。** 給定一個假想的 FLT 反例，Frey 曲線把它「打包」成一條曲線，而這條曲線的 mod $p$ 表示是一個偽裝者：它在所有奇質數 $q \ne p$ 處看不出分歧，只在 $2$ 處露餡。它假裝自己來自級 $2$ 的世界。

**第二層，精確定理。** 上面四條。注意性質 $1$ 不是從「Mazur 只允許 $p\le163$」直接得到：那個一般分類仍留下 $5,7,11,13,17,19,37,43,67,163$，必須用 Frey 曲線的特殊資料排除。性質 $3$ 也必須保留 $q\ne p$、$q=p$、$q=2$ 的三分法。

**第三層，在 FLT 中的角色。** 這四條供應來自曲線的資料；Wiles 還要供應「模性」，Ribet 定理本身還有權重 $2$、平凡 Nebentypus、$q\parallel N$ 等模形式側假設。所以不應把這四條稱為「Ribet 的全部前提」；第 6.6 章會做完整對齊。

**第四層，技術深潛（選讀）。** 若 $\bar\rho_{E,p}$ 可約，則 $E$ 有有理 $p$-同源。Mazur 的定理先把可能質數限制在明確的十二個數，然後 Frey 曲線的半穩定局部性質與完整有理 $2$-撓點排除其中的 $p>3$ 情形。本書接受這一整塊。性質 $3$ 則用 Tate 曲線判準：$p\mid v_q(\Delta_{\min})$ 當且僅當 $E[p]$ 在 $q$ 處 finite；$q\ne p$ 時這是不分歧，$q=p$ 時這是 finite-flat。
:::

::: {.remark name="繩索收緊"}
這四個性質，是套在 Frey 曲線脖子上的繩索。在奇質數 $q\ne p$ 處的不分歧性讓普通 level lowering 可移除 $q$；若 $p\mid abc$，finite-flat 性讓 $q=p$ 版本先移除 $p$；$2$ 處不 finite，所以不能移除。這才是從原導體走到級 $2$ 的實際路線。

換句話說：Frey 曲線的導體是 $\mathrm{rad}(abc)$（可能很大），但它的 mod $p$ 表示的 prime-to-$p$ 導體是 $2$（極小）。表示「假裝」自己來自一個級 $2$ 的世界。如果這個表示是模的（Wiles 證明它是），那它必須來自一個級 $2$ 的模形式 —— 但那種模形式不存在。Frey 曲線的性質 $3$，是把它推向級 $2$ 死角的那隻手。

第 6.2 章我說過要看清繩索的材質，第 6.4 章說過要把繩索套好。現在繩索已經套在 Frey 曲線脖子上，四個性質扣得死死的。下一章 Ribet 定理，是收緊繩索、讓 Frey 曲線在級 $2$ 的死角窒息的最後一拉。
:::

## 古典與現代之門

::: {.remark name="Frey 曲線的歷史位置"}
Frey 曲線是 FLT 證明史上的轉折點，是古典與現代之間的那道門。

**門之前**（第三部）：FLT 是分圓域的算術問題，用類數、理想、正則質數攻擊，逐個 $p$ 處理，撞牆於非正則質數。

**門之後**（第六、七部）：FLT 是橢圓曲線的模性問題，用 Galois 表示、變形理論攻擊，一次處理所有 $p$。

Frey 曲線就是這道門本身。它的構造（1985）讓 Serre 提出精確猜想（$\varepsilon$-猜想，即後來 Ribet 證明的 level lowering），Ribet 證明它（1986），Wiles 證明半穩定模性（1994）—— 一條曲線，啟動了整個現代證明的連鎖反應。在 Frey 之前，谷山–志村猜想與 FLT 是兩個不相干的問題；Frey 之後，前者蘊涵後者。一條由假想反例構造的、注定不存在的曲線，成了連接二十世紀數論兩大主題的橋樑。

這正是數學中最深刻的那類連結 —— 把兩個看似無關的領域焊在一起，然後一個的解決順帶解決另一個。Frey 曲線是這種連結的化身，也是本書從第零部費馬邊注一路走來，終於看見終點的地方：費馬的整數謎題，現在是一條橢圓曲線是否模的問題，而那條曲線，不可能是模的。
:::

## 檢查點：你跟上這條鏈了嗎？

第五條中央箭頭「反例 → Frey 曲線 → 特殊表示」已經建立。用三個問題確認：

1. **方向**：反例存在與 Frey 曲線存在是等價的嗎？證明需要哪個方向？（答案：不等價；反例 ⇒ 曲線，單向即可。）
2. **最小判別式**：$\Delta_{\min} = 2^{-8}(abc)^{2p}$。哪部分的 $v_q$ 是 $p$ 的倍數、哪部分不是？這如何決定局部行為？（答案：奇質數 $q\ne p$ 處得到不分歧，$q=p$ 處得到 finite-flat；$v_2(\Delta_{\min})=2p\,v_2(b)-8$ 不被 $p$ 整除，故 $2$ 不 finite。）
3. **四條性質**：Frey 表示的四條性質各是〔算〕、〔證〕還是〔接受〕？（答案：非最小判別式是〔算〕，$2$-進最小化是〔接受〕；奇質數處半穩定是〔證〕；絕對不可約是 Mazur 同源定理加 Frey 特殊局部計算〔接受〕；三種 finite 行為用 Tate 曲線判準〔接受〕；$\det=\chi$ 是 Weil 配對的結果〔接受〕。）

若三題都答得出來，你已經掌握了 Frey 曲線的構造與它的特殊表示。下一章 Ribet 定理收網，把這四條性質變成矛盾。

## 本章地圖與下一章預告

- **Frey 曲線**：$y^2 = x(x-a^p)(x+b^p)$；把 FLT 反例編碼成橢圓曲線（單向：反例 ⇒ 曲線）。
- **判別式**（〔算〕）：$\Delta = 16(abc)^{2p}$；最小判別式 $\Delta_{\min} = 2^{-8}(abc)^{2p}$，$v_2(\Delta_{\min}) = 2p\,v_2(b) - 8$。
- **導體**（〔證〕/〔接受〕）：$N = \mathrm{rad}(abc)$；奇質數處半穩定〔證〕、$2$ 處與完整導體公式〔接受〕。
- **四個表示性質**：絕對不可約〔接受〕、曲線半穩定〔證／$2$ 處接受局部計算〕、三種局部行為（$q\ne p,2$ 不分歧；$q=p$ finite-flat；$q=2$ 不 finite）〔接受 Tate 判準〕、$\det=\chi$〔接受〕。
- **古典與現代之門**：Frey 啟動 Serre–Ribet–Wiles 連鎖；谷山–志村蘊涵 FLT。

下一章《Serre 猜想與 Ribet 定理》是第六部的收網。Ribet 證明：Frey 曲線的 $\bar\rho_{E,p}$ 若是模的，先以 finite-flat 分支移除可能的 $q=p$，再移除不分歧的 $q\ne p,2$，因而由 $S_2(\Gamma_0(2))$ 中的非零特徵形式給出。但這個尖形式空間是零維（$X_0(2)$ 虧格 $0$，第 5.6 章），於是矛盾。歷史上只差「Frey 曲線確實模」這一塊；本書以 Wiles 定理〔接受〕它，第七部解釋其架構。下一章，繩索收緊。

## 習題

**6.5.1**　展開 Frey 曲線 $y^2 = x(x-a^p)(x+b^p)$ 成 Weierstrass 形 $y^2 = x^3 + Ax^2 + Bx$，求 $A, B$（用 $a^p, b^p$ 表示）。

**6.5.2 ★**　驗證判別式 $\Delta = 16(abc)^{2p}$：用三根 $0, a^p, -b^p$ 的兩兩差，計算 $\prod_{i<j}(e_i - e_j)^2$，並使用 $a^p+b^p=-c^p$。再引用本章〔接受〕的 $2$-進最小化，寫出 $\Delta_{\min}=2^{-8}(abc)^{2p}$；不要把這一步冒充為只靠三根計算即可證明。

**6.5.3**　為什麼 Frey 曲線最小判別式在奇質數處的賦值可被 $p$ 整除如此關鍵？用一句話分別連到 $q\ne p$ 的不分歧與 $q=p$ 的 finite-flat。（提示：兩者都由 Tate 曲線 finite 判準控制，但「finite」在兩種局部特徵下意義不同。）

**6.5.4 ★**　Frey 曲線導體 $N = \mathrm{rad}(abc)$ 無平方因子。對比一般橢圓曲線（導體可含平方因子）。為什麼「無平方因子」等價於「半穩定」？（連到第 4.5 章乘性約化。）

**6.5.5**　列出 Frey 表示 $\bar\rho_{E,p}$ 的四個性質，並指出每一個用到本書哪一章的結果。

**6.5.6（前瞻）**　Serre 級公式給出 $\bar\rho_{E,p}$ 的 prime-to-$p$ 導體 $N(\bar\rho) = 2$。用一句話說明：為什麼是 $2$ 而不是 $1$？（提示：曲線在 $2$ 處有不可避免的壞約化，$v_2(\Delta_{\min}) = 2p\,v_2(b) - 8$ 不是 $p$ 的倍數，故 $2$ 處的分歧無法被 $p$ 次方吸收。下一章 Ribet。）
