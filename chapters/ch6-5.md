## 開場：一條改變一切的曲線

整個現代 FLT 證明，繞著一條曲線轉。它由 Gerhard Frey 在 1985 年提出，是把費馬方程與橢圓曲線連起來的那道門。在 Frey 之前，沒人想到費馬最後定理（一個關於整數的問題）會與橢圓曲線的模性（一個關於複分析與 Galois 表示的問題）有任何關係。Frey 的洞見，把三百五十年的數論問題，轉化成一個能用二十世紀最強機器攻擊的形式。

這一章構造 Frey 曲線，計算它的判別式與導體，證明它半穩定，並確認它的 Galois 表示 $\bar\rho_{E,p}$ 具有第 6.2 章說的四個特殊性質。走完它，我們就理解了 Frey 曲線為何「太特殊以致不可能存在」—— 而那個「不可能」，正是 FLT 的證明。

## 構造：把反例變成曲線

::: {.definition name="Frey 曲線"}
假設 FLT 有反例：存在互質正整數 $a, b, c$ 與質數 $p \ge 5$ 使 $a^p + b^p = c^p$。**Frey 曲線**定義為
$$E: y^2 = x(x - a^p)(x + b^p).$$
:::

這是一條橢圓曲線（三次曲線），它的三個根是 $0$、$a^p$、$-b^p$。展開成 Weierstrass 形：$y^2 = x^3 + (b^p - a^p)x^2 - a^p b^p x$。它的係數直接由假想反例的 $a, b$ 構成 —— 反例的存在，等價於這條曲線的存在。

::: {.remark name="編碼的巧思"}
Frey 曲線的精妙在於「編碼」：它把一個關於**整數**的陳述（$a^p + b^p = c^p$ 有解）轉化成一個關於**橢圓曲線**的陳述（這條特定的 $E$ 存在）。這個轉化是整個現代證明的關鍵轉軸。

對比第三部 Kummer 的策略：Kummer 直接在費馬方程裡工作，在分圓域 $\mathbb{Q}(\zeta_p)$ 裡分解，撞上正則性的牆。Frey 完全不碰費馬方程的內部結構，而是把整個反例「打包」成一條曲線的係數，然後去研究**那條曲線的性質**。問題的舞台從「分圓域的算術」搬到「橢圓曲線的模性」—— 而後者有 Wiles 與 Ribet 的重武器。

這種「把問題編碼成另一個對象，再研究那個對象」的策略，是現代數學的典型手法。Frey 曲線是它最輝煌的範例：費馬的整數謎題，被編碼成一條曲線的 DNA，而那條曲線的 DNA 裡藏著一個致命的矛盾。
:::

## 判別式：完全 $p$ 次方

Frey 曲線的第一個異常，是它的判別式。

::: {.theorem name="Frey 曲線的判別式"}
$$\Delta = 16\,(a^p)^2(b^p)^2(a^p + b^p)^2 = 16\,(a^p b^p c^p)^2 = 16\,(abc)^{2p}.$$
:::

::: {.proof}
三次曲線 $y^2 = (x - e_1)(x - e_2)(x - e_3)$ 的判別式正比於 $\prod_{i<j}(e_i - e_j)^2$。這裡根是 $e_1 = 0, e_2 = a^p, e_3 = -b^p$，三個差是 $a^p$、$-b^p$、$a^p + b^p = c^p$。於是
$$\Delta = 16\,(a^p)^2(b^p)^2(c^p)^2 = 16\,(abc)^{2p}. \qquad\square$$
:::

數值範例（借 $a^2 + b^2 = c^2$ 的 $3,4,5$ 展示結構）：$\Delta = 16(9 \cdot 16 \cdot 25)^2 = 207360000 = 16 \cdot 60^4 = 16(abc)^{2p}$，精確相符。

關鍵在那個指數 $2p$：判別式（除了因子 $16$）是一個**完全 $p$ 次方**。這個性質，是 Frey 曲線一切異常的根源。

## 導體：異常的小

判別式 $(abc)^{2p}$ 巨大（含高次冪）。但導體 —— 記錄壞約化的精細不變量（第 5.3 章）—— 卻異常小。

::: {.theorem name="Frey 曲線半穩定且導體小"}
適當選取 $a, b, c$ 的符號與奇偶（可設 $b$ 偶、$a \equiv -1 \pmod 4$），Frey 曲線是**半穩定**的，且導體
$$N = \prod_{\ell \mid abc}\ell = \mathrm{rad}(abc)$$
（無平方因子，每個壞質數只取一次方）。
:::

::: {.remark name="判別式大、導體小的反差"}
這裡是 Frey 曲線的核心異常，第 5.3、5.7 章一直預告的那個。並排看：
$$\Delta = 16(abc)^{2p}\ (\text{巨大，含 } p \text{ 次冪}), \qquad N = \mathrm{rad}(abc)\ (\text{微小，無平方因子}).$$

一般橢圓曲線的判別式與導體的質因子大致同步（判別式裡某質數冪次高，導體裡也相應高）。但 Frey 曲線判別式裡的高次冪（$2p$ 次）完全沒有反映在導體裡 —— 導體把每個壞質數壓縮成一次方。這個反差源於判別式是 $p$ 次方：那些 $p$ 次冪在「壞約化的程度」上被完全吸收了（第 6.2 章：分歧被 $p$ 次方吸收）。

這個反差就是 Frey 曲線「不該存在」的數值徵兆。一條導體這麼小的曲線，「應該」對應一個級這麼小的模形式（若它模）；但它的 mod $p$ 表示又攜帶著判別式那 $p$ 次冪的資訊。這兩件事的張力，在 Ribet 定理下爆發成矛盾。Frey 看到這個反差時的直覺是：這條曲線太奇怪了，它好到不可能是模的 —— 而所有橢圓曲線又都該是模的（谷山–志村）。矛盾的氣味，從判別式與導體的反差裡就能聞到。
:::

## Galois 表示的四個性質

把第 6.2 章的分析用在 Frey 曲線上，確認它的 mod $p$ 表示 $\bar\rho_{E,p}$ 的四個特殊性質（這些是 Ribet 定理的全部前提）：

::: {.theorem name="Frey 表示的性質"}
設 $E$ 是 Frey 曲線，$p \ge 5$。則 $\bar\rho_{E,p}: G_{\mathbb{Q}} \to \mathrm{GL}_2(\mathbb{F}_p)$ 滿足：

1. **不可約**（Mazur + Frey 結構，第 6.2 章）。
2. **半穩定**（所有壞約化乘性）。
3. **判別式 $p$ 次方** $(abc)^{2p}$，故在所有 $\ell \mid abc$ 處分歧被吸收，$\bar\rho_{E,p}$ 在那裡**不分歧**。
4. **行列式 $= \chi$**（分圓特徵，第 6.1 章）。
:::

::: {.remark name="繩索收緊"}
這四個性質，是套在 Frey 曲線脖子上的繩索。性質 $3$ 是致命的：判別式的 $p$ 次方結構，讓 $\bar\rho_{E,p}$ 在所有壞質數 $\ell \mid abc$ 處不分歧。於是由 Serre 級公式（第 6.3 章），$\bar\rho_{E,p}$ 的「最佳級」$N(\bar\rho)$ 不含 $abc$ 的任何質因子 —— 只剩下 $2$（來自曲線在 $2$ 處不可避免的壞約化）。

換句話說：Frey 曲線的導體是 $\mathrm{rad}(abc)$（可能很大），但它的 mod $p$ 表示的「最佳級」是 $2$（極小）。表示「假裝」自己來自一個級 $2$ 的世界。如果這個表示是模的（Wiles 證明它是），那它必須來自一個級 $2$ 的模形式 —— 但那種模形式不存在。Frey 曲線的性質 $3$，是把它推向級 $2$ 死角的那隻手。

第 6.2 章我說過要看清繩索的材質，第 6.4 章說過要把繩索套好。現在繩索已經套在 Frey 曲線脖子上，四個性質扣得死死的。下一章 Ribet 定理，是收緊繩索、讓 Frey 曲線在級 $2$ 的死角窒息的最後一拉。
:::

## 古典與現代之門

::: {.remark name="Frey 曲線的歷史位置"}
Frey 曲線是 FLT 證明史上的轉折點，是古典與現代之間的那道門。

**門之前**（第三部）：FLT 是分圓域的算術問題，用類數、理想、正則質數攻擊，逐個 $p$ 處理，撞牆於非正則質數。

**門之後**（第六、七部）：FLT 是橢圓曲線的模性問題，用 Galois 表示、變形理論攻擊，一次處理所有 $p$。

Frey 曲線就是這道門本身。它的構造（1985）讓 Serre 提出精確猜想（$\varepsilon$-猜想，即後來 Ribet 證明的 level lowering），Ribet 證明它（1986），Wiles 證明半穩定模性（1994）—— 一條曲線，啟動了整個現代證明的連鎖反應。在 Frey 之前，谷山–志村猜想與 FLT 是兩個不相干的問題；Frey 之後，前者蘊涵後者。一條由假想反例構造的、注定不存在的曲線，成了連接二十世紀數論兩大主題的橋樑。

這正是數學中最深刻的那類連結 —— 把兩個看似無關的領域焊在一起，然後一個的解決順帶解決另一個。Frey 曲線是這種連結的化身，也是本書從第零部費馬邊注一路走來，終於看見終點的地方：費馬的整數謎題，現在是一條橢圓曲線是否模的問題，而那條曲線，不可能是模的。
:::

## 本章地圖與下一章預告

- **Frey 曲線**：$y^2 = x(x-a^p)(x+b^p)$；把 FLT 反例編碼成橢圓曲線。
- **判別式**：$\Delta = 16(abc)^{2p}$；完全 $p$ 次方（除因子 $16$）。
- **導體**：$N = \mathrm{rad}(abc)$；半穩定、無平方因子；判別式大、導體小的反差。
- **四個表示性質**：不可約、半穩定、判別式 $p$ 次方（⇒ 不分歧 ⇒ 最佳級 $2$）、$\det = \chi$。
- **古典與現代之門**：Frey 啟動 Serre–Ribet–Wiles 連鎖；谷山–志村蘊涵 FLT。

下一章《Serre 猜想與 Ribet 定理》是第六部的收網。Ribet 證明：Frey 曲線的 $\bar\rho_{E,p}$（不可約、半穩定、判別式 $p$ 次方），若是模的，必來自一個權重 $2$、級 $2$ 的模形式 —— 這是 Serre 級公式的具體情形，「level lowering」。但權重 $2$、級 $2$ 的尖形式空間是零維（$X_0(2)$ 虧格 $0$，第 5.6 章）。於是若 Frey 曲線模，就需要一個不存在的模形式 —— 矛盾。Ribet 定理把第六部所有的鋪墊收成一個矛盾，只差「Frey 曲線確實模」這一塊（Wiles，第七部）。下一章，繩索收緊。

## 習題

**6.5.1**　展開 Frey 曲線 $y^2 = x(x-a^p)(x+b^p)$ 成 Weierstrass 形 $y^2 = x^3 + Ax^2 + Bx$，求 $A, B$（用 $a^p, b^p$ 表示）。

**6.5.2 ★**　驗證判別式 $\Delta = 16(abc)^{2p}$：用三根 $0, a^p, -b^p$ 的兩兩差，計算 $\prod_{i<j}(e_i - e_j)^2$，代入 $a^p + b^p = c^p$。

**6.5.3**　為什麼 Frey 曲線的判別式「是完全 $p$ 次方」如此關鍵？用一句話連到第 6.2 章「分歧被 $p$ 次方吸收」。

**6.5.4 ★**　Frey 曲線導體 $N = \mathrm{rad}(abc)$ 無平方因子。對比一般橢圓曲線（導體可含平方因子）。為什麼「無平方因子」等價於「半穩定」？（連到第 4.5 章乘性約化。）

**6.5.5**　列出 Frey 表示 $\bar\rho_{E,p}$ 的四個性質，並指出每一個用到本書哪一章的結果。

**6.5.6（前瞻）**　Serre 級公式給出 $\bar\rho_{E,p}$ 的最佳級 $N(\bar\rho) = 2$。用一句話說明：為什麼是 $2$ 而不是 $1$？（提示：曲線在 $2$ 處有不可避免的壞約化，$\ell = 2$ 無法被吸收。下一章 Ribet。）
