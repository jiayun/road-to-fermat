## 開場：橢圓曲線的指紋

前兩章從幾何（群律）與整體（有理點）認識橢圓曲線。這一章轉向**局部** —— 橢圓曲線在每個質數 $p$ 處的 mod $p$ 行為。這個局部資訊濃縮成一個序列
$$a_2, a_3, a_5, a_7, a_{11}, \dots$$
稱為橢圓曲線的**算術指紋**。它是本書下半場的中心對象：谷山–志村猜想斷言，每條橢圓曲線的指紋 $\{a_p\}$，恰好等於某個模形式的指紋 $\{a_p(f)\}$。要陳述這個猜想（第 5.7 章），必須先把橢圓曲線這一側的指紋完全講清楚。

本章定義 $a_p$、導體 $N$、L 函數 $L(E,s)$，並證明約束指紋的 Hasse 界。這些都是第 4.5 章「$a_p = p+1-\#E(\mathbb{F}_p)$」的深化。走完這一章，主角一號的刻畫就完整了，接下來就輪到主角二號 —— 模形式 —— 登場，去和這個指紋比對。

## $a_p$：數點得到的指紋

::: {.definition}
設 $E/\mathbb{Q}$ 在 $p$ 處有好約化（第 4.5 章）。定義
$$a_p = p + 1 - \#E(\mathbb{F}_p),$$
其中 $\#E(\mathbb{F}_p)$ 是約化曲線 $E \bmod p$ 在 $\mathbb{F}_p$ 上的點數（含無窮遠點）。
:::

$a_p$ 衡量「實際點數」與「期望點數」$p+1$ 的偏差。為什麼期望是 $p+1$？因為對每個 $x \in \mathbb{F}_p$（共 $p$ 個），$y^2 = x^3+ax+b$ 平均有一個 $y$ 解（$\mathbb{F}_p$ 中半數是平方剩餘），加上無窮遠點，期望約 $p+1$。$a_p$ 就是這個平均的漲落。

::: {.example name="$y^2 = x^3 - x$ 的指紋"}
逐 $p$ 數點，得到指紋的前幾項：
$$a_2 = 0,\ a_3 = 0,\ a_5 = -2,\ a_7 = 0,\ a_{11} = 0,\ a_{13} = 6,\ a_{17} = 2,\ a_{19} = 0,\ \dots$$
（例如 $p = 5$：$E(\mathbb{F}_5)$ 有 $8$ 個點，$a_5 = 5 + 1 - 8 = -2$。）這串數字是 $y^2 = x^3 - x$ 獨有的身分證 —— 它編碼了這條曲線在每個質數處的算術行為。第 5.7 章會看到，這串數字恰好來自一個具體的模形式。
:::

## Hasse 界：指紋的約束

$a_p$ 不能任意大。它被一個漂亮的界限約束 —— 這是橢圓曲線理論的第一個深定理。

::: {.theorem name="Hasse 界，1933"}
對好約化質數 $p$，
$$|a_p| \le 2\sqrt p.$$
:::

::: {.proof}
（梗概）Frobenius 自同態 $\phi: (x,y) \mapsto (x^p, y^p)$ 作用在 $E(\overline{\mathbb{F}_p})$ 上，$\#E(\mathbb{F}_p)$ 等於 $\phi$ 的不動點數 $= \deg(\phi - 1)$。在撓點上 $\phi$ 滿足二次方程 $\phi^2 - a_p\phi + p = 0$（第 1.2 章習題 1.2.6 的特徵多項式！）。$\phi$ 的兩個特徵值 $\alpha, \bar\alpha$ 滿足 $\alpha\bar\alpha = p$、$\alpha + \bar\alpha = a_p$。一個正定性論證（高度配對非負）給出 $|\alpha| = \sqrt p$，於是 $|a_p| = |\alpha + \bar\alpha| \le 2\sqrt p$。
:::

::: {.remark name="Hasse 界 = 黎曼假設的曲線版"}
數值驗證確認了它：$y^2 = x^3 - x$ 的每個 $a_p$ 都落在 $[-2\sqrt p, 2\sqrt p]$ 內（$a_5 = -2$ vs $2\sqrt5 \approx 4.47$；$a_{29} = -10$ vs $2\sqrt{29} \approx 10.77$，貼著界但沒越界）。

Hasse 界其實是**黎曼假設的橢圓曲線版本**。回憶第 1.2 章習題：$|a_p| \le 2\sqrt p \iff$ Frobenius 的兩個特徵值是一對共軛複數（落在 $|\alpha| = \sqrt p$ 的圓上）而非兩個實數。這個「特徵值落在臨界圓上」，正是黎曼假設「zeta 零點落在臨界線上」的曲線類比。Hasse 證了曲線版（1933），Weil 推廣到高維（Weil 猜想，1949 提出、Deligne 1974 證明），而原始的黎曼假設至今未解。橢圓曲線的指紋 $a_p$，每一項都默默服從一條黎曼假設 —— 這是它深刻性的又一個記號。第 1.2 章習題 1.2.6 那個「$|a_p| \le 2\sqrt p$ 對應特徵值為共軛複數」的玩具觀察，在這裡成了 Hasse 定理。
:::

## 導體 $N$：壞約化的記錄

好約化質數給出 $a_p$；壞約化質數（第 4.5 章）則記錄在**導體**裡。

::: {.definition}
橢圓曲線 $E/\mathbb{Q}$ 的**導體** $N$ 是
$$N = \prod_{p \text{ 壞}} p^{f_p},$$
其中乘性（節點）約化貢獻 $f_p = 1$，加性（尖點）約化貢獻 $f_p = 2$（$p \ge 5$；$p = 2, 3$ 更複雜）。
:::

導體是第 3.1 章「判別式偵測分歧」的橢圓曲線版，但更精細：它不只記錄「哪些 $p$ 壞」，還記錄「壞到什麼程度」。半穩定曲線（壞約化全為乘性）的導體是無平方因子的（$N = \prod p$）。

::: {.remark name="導體與谷山–志村的「級」"}
導體 $N$ 是連接橢圓曲線與模形式的關鍵數字。谷山–志村猜想說「$E$ 對應一個模形式 $f$」，而那個 $f$ 的「級」（level，第 5.4 章）恰好等於 $E$ 的導體 $N$。導體相同的橢圓曲線與模形式，才可能配對。

對 FLT 至關重要的是 Frey 曲線的導體。由假想反例 $a^p + b^p = c^p$ 構造的 Frey 曲線（第 6.5 章）
$$y^2 = x(x - a^p)(x + b^p),$$
其判別式形如 $(abc)^{2p}$，但導體 $N = \prod_{\ell \mid abc}\ell$（每個壞質數只取一次方，因為半穩定）—— **導體異常小，且無平方因子**。這個「判別式巨大、導體卻很小」的反差，是 Frey 曲線的核心異常，也是 Ribet 定理能對它「降低 level」的前提。本章的導體定義，是第六部那場致命論證的數論基礎。
:::

## L 函數：把指紋編成解析物件

最後，把整個指紋序列 $\{a_p\}$ 打包成一個解析函數。

::: {.definition}
橢圓曲線 $E$ 的 **L 函數**是 Euler 乘積
$$L(E, s) = \prod_{p \text{ 好}} \frac{1}{1 - a_p p^{-s} + p^{1-2s}} \times \prod_{p \text{ 壞}}(\text{局部因子}).$$
:::

每個好約化質數貢獻一個局部因子，其中的 $a_p$ 正是本章的指紋。展開成 Dirichlet 級數 $L(E,s) = \sum_n a_n n^{-s}$，係數 $a_n$ 由 $a_p$ 透過乘性關係決定。

::: {.remark name="L 函數是兩位主角的會合點"}
L 函數是橢圓曲線指紋的「解析化身」—— 它把離散的序列 $\{a_p\}$ 編碼成一個複變函數。它在 FLT 之路上扮演三重角色：

**其一，BSD 的舞台**（第 5.2 章）：$L(E,s)$ 在 $s=1$ 的行為預測秩。但 $s=1$ 在 Euler 乘積的收斂範圍外，需要解析延拓（第 4.2 章）—— 而「$L(E,s)$ 能延拓」這件事，在 Wiles 之前對一般 $E$ 是未知的。

**其二，谷山–志村的橋**：模形式也有 L 函數 $L(f,s) = \sum a_n(f) n^{-s}$。猜想說 $L(E,s) = L(f,s)$ —— 兩位主角的 L 函數相等。由恆等定理（第 4.1 章），這等價於指紋逐項相等 $a_p = a_p(f)$。L 函數是橢圓曲線與模形式**真正相遇的地方**。

**其三，延拓的保證**：模形式的 L 函數已知能解析延拓（且有好的函數方程）。所以一旦證明 $E$ 是模的（$L(E,s) = L(f,s)$），$L(E,s)$ 的延拓就自動成立 —— 模性「免費」給出了 BSD 所需的延拓。這是「模性為什麼是樞紐」的又一個面向。

下一章模形式登場後，這個 L 函數的等式 $L(E,s) = L(f,s)$ 將成為谷山–志村猜想的精確陳述。本章把橢圓曲線這一側準備完畢。
:::

## 主角一號刻畫完成

橢圓曲線的三章到此完成，主角一號的全貌：

- **幾何**（5.1）：Weierstrass 方程、弦切群律、$E(\mathbb{C})$ 是環面。
- **整體**（5.2）：$E(\mathbb{Q}) = \mathbb{Z}^r \times$ 撓；Mordell–Weil、秩、BSD。
- **局部**（5.3）：指紋 $\{a_p\}$、Hasse 界、導體 $N$、L 函數。

橢圓曲線同時是幾何物件（環面）、代數物件（方程）、算術物件（指紋）。這個多重身分，使它能在不同的數學語言間翻譯 —— 而模形式，將從一個完全不同的世界（解析、上半平面）走來，帶著一個一模一樣的指紋。它們指紋相同這件事（谷山–志村），是 FLT 證明的全部關鍵。

## 本章地圖與下一章預告

- **$a_p = p+1-\#E(\mathbb{F}_p)$**：數點得到的算術指紋。
- **Hasse 界**：$|a_p| \le 2\sqrt p$；黎曼假設的曲線版；Frobenius 特徵值在臨界圓上。
- **導體 $N$**：壞約化的記錄；對應模形式的「級」；Frey 曲線導體異常小。
- **L 函數**：指紋的解析化身；BSD 舞台、谷山–志村橋、延拓保證。

下一章《模形式 I》主角二號登場。模形式是上半平面 $\mathbb{H}$ 上的全純函數，在 $\mathrm{SL}_2(\mathbb{Z})$（或其子群 $\Gamma_0(N)$）作用下有特定的變換性質。我們會定義權重、級、$q$ 展開 —— 而 $q$ 展開的係數 $a_n(f)$，正是模形式的指紋。第 1.5 章證了 $q$ 展開收斂、第 4.1 章證了它全純、第 4.2 章的 $g_2, g_3$（Eisenstein 級數）已是最早的模形式 —— 這些線索將在第 5.4 章匯成模形式的正式定義。兩位主角即將各就各位，第 5.7 章的世紀相會在望。

## 習題

**5.3.1**　計算 $y^2 = x^3 + 1$ 的指紋 $a_5, a_7, a_{11}$（數 $\#E(\mathbb{F}_p)$）。驗證每個都滿足 Hasse 界 $|a_p| \le 2\sqrt p$。

**5.3.2 ★**　$y^2 = x^3 - x$ 在 $p = 5$ 的 $a_5 = -2$。直接驗證：列出 $E(\mathbb{F}_5)$ 的所有 $8$ 個點，確認 $a_5 = 5 + 1 - 8 = -2$。

**5.3.3**　證明 Hasse 界蘊涵 $\#E(\mathbb{F}_p) \in [p + 1 - 2\sqrt p,\ p + 1 + 2\sqrt p]$。對 $p = 7$，這給出點數的什麼範圍？

**5.3.4 ★**　Frobenius 滿足 $\phi^2 - a_p \phi + p = 0$。寫出兩個特徵值 $\alpha, \bar\alpha$ 的乘積與和，並用 $|a_p| \le 2\sqrt p$ 論證 $|\alpha| = \sqrt p$（特徵值落在臨界圓上）。（連到第 1.2 章習題 1.2.6。）

**5.3.5**　$y^2 = x^3 - x$ 的判別式 $\Delta = 64$，導體 $N = 32$。哪些質數是壞約化？（壞約化質數整除 $\Delta$。）

**5.3.6（前瞻）**　Frey 曲線 $y^2 = x(x-a^p)(x+b^p)$ 的判別式約為 $(abc)^{2p}$（巨大），但導體 $N = \prod_{\ell \mid abc}\ell$（小，無平方因子）。用一句話說明：為什麼這個「判別式大、導體小」的反差，使 Frey 曲線成為一個「不該存在」的曲線？（提示：導體小意味著它「應該」對應一個級很小的模形式，但那樣的模形式空間可能是空的 —— 第 6.6 章 Ribet。）
