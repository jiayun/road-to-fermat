## 開場：換座標，不換動作

上一章從零建立了向量空間、基底與線性映射，並固定**欄向量慣例**：矩陣第 $j$ 欄是第 $j$ 個基底向量的像。現在問：同一個線性映射，能否換一組基底，讓矩陣變得一眼就懂？

**依賴箭頭：** 1.1 的基底、座標欄、矩陣、行列式
$\longrightarrow$ 換基底 $\longrightarrow$ 特徵值與特徵向量
$\longrightarrow$ 對角化 $\longrightarrow$ 同時對角化
$\longrightarrow$ 後文的 Hecke 特徵值語言。

本章沿用五種結果標籤：**【完整證明】、【特殊情形】、【證明略圖】、【直覺】、【接受的黑箱】**。定義不掛結果標籤。

## 換基底公式

設 $T:V\to V$，舊基底下的矩陣是 $A$。把新基底向量在舊基底下的座標依次排成**欄**，得到可逆矩陣
$$P=\bigl([v_1]_{\rm old}\ \cdots\ [v_n]_{\rm old}\bigr).$$
若 $[v]_{\rm new}$ 是新座標，則 $[v]_{\rm old}=P[v]_{\rm new}$。作用後再換回新座標：
$$[T(v)]_{\rm new}=P^{-1}AP[v]_{\rm new}.$$

::: {.proposition name="【完整證明】換基底公式"}
同一算子在新基底下的矩陣為
$$A_{\rm new}=P^{-1}AP,$$
其中 $P$ 的**各欄**是新基底向量的舊座標。
:::

::: {.proof}
上面的三步等式已逐一說明：$P$ 把新座標轉成舊座標，$A$ 在舊座標作用，$P^{-1}$ 把答案轉回新座標。合成矩陣依第 1.1 章規則由右向左相乘，故為 $P^{-1}AP$。
:::

**檢查點 1.2.A**　若你記不住 $P^{-1}AP$，請用「新 $\to$ 舊 $\to$ 作用 $\to$ 新」重新推出，不要死背。

## 特徵值與特徵向量

::: {.definition name="算子、特徵值、特徵向量"}
從 $V$ 到自身的線性映射 $T:V\to V$ 稱為**線性算子**。若有非零向量 $v$ 與純量 $\lambda$ 使
$$T(v)=\lambda v,$$
則 $v$ 是特徵向量，$\lambda$ 是相應的特徵值。
:::

這種向量被 $T$ 作用後沒有轉向，只縮放 $\lambda$ 倍。要找它們，把等式移項：
$$(A-\lambda I)v=0.$$
依第 1.1 章的可逆判準，這個方程有非零解，恰在 $A-\lambda I$ 不可逆時發生，也就是
$$\det(\lambda I-A)=0.$$

::: {.definition name="特徵多項式與特徵空間"}
$n\times n$ 矩陣 $A$ 的**特徵多項式**是
$$\chi_A(t)=\det(tI-A).$$
特徵值是它在純量體中的根。對特徵值 $\lambda$，子空間
$$E_\lambda=\ker(A-\lambda I)$$
稱為 $\lambda$ 的特徵空間。
:::

::: {.example name="【完整證明】找特徵方向"}
取
$$A=\begin{pmatrix}2&1\\1&2\end{pmatrix}.$$
則
$$\chi_A(t)=\det\begin{pmatrix}t-2&-1\\-1&t-2\end{pmatrix}
=(t-2)^2-1=(t-1)(t-3).$$
特徵值是 $1,3$。解 $(A-3I)v=0$ 得 $v=(1,1)^{\mathsf T}$ 的倍數；解 $(A-I)v=0$ 得 $v=(1,-1)^{\mathsf T}$ 的倍數。直接乘矩陣可核對
$$A\begin{pmatrix}1\\1\end{pmatrix}=3\begin{pmatrix}1\\1\end{pmatrix},\qquad
A\begin{pmatrix}1\\-1\end{pmatrix}=1\begin{pmatrix}1\\-1\end{pmatrix}.$$
:::

特徵值是否存在，會依純量體而變。旋轉矩陣
$\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ 的特徵多項式是 $t^2+1$；在 $\mathbb R$ 無根，在 $\mathbb C$ 有根 $\pm i$。因此「換到更大的體看見根」不是裝飾，而是必要動作。

## 對角化

::: {.definition name="可對角化"}
算子 $T$ **可對角化**，若 $V$ 有一組完全由 $T$ 的特徵向量構成的基底。等價地，在某組基底下，其矩陣為對角矩陣。
:::

若把特徵向量 $v_1,\ldots,v_n$ 排成矩陣的**各欄**
$$P=\bigl(v_1\ \cdots\ v_n\bigr),$$
那麼
$$P^{-1}AP=\operatorname{diag}(\lambda_1,\ldots,\lambda_n).$$
這再次使用第 1.1 章的欄慣例；把特徵向量排成行會得到錯誤的換基底矩陣。

::: {.lemma name="【完整證明】相異特徵值的特徵向量線性無關"}
對應於兩兩相異特徵值的特徵向量必線性無關。
:::

::: {.proof}
若有非平凡線性關係，取項數最少的一條
$c_1v_1+\cdots+c_rv_r=0$，其中每個 $c_i\ne0$。用 $T$ 作用，再減去原式的 $\lambda_r$ 倍，得到
$$\sum_{i=1}^{r-1}c_i(\lambda_i-\lambda_r)v_i=0.$$
因特徵值相異，所有顯示的係數仍非零；這是一條項數更少的非平凡關係，與最少性矛盾。
:::

::: {.corollary name="【完整證明】相異特徵值充分條件"}
$n$ 維空間上的算子若有 $n$ 個相異特徵值，就可對角化。
:::

::: {.proof}
各取一個特徵向量。前一引理說這 $n$ 個向量線性無關；在 $n$ 維空間中，它們便構成基底。
:::

反例
$$J=\begin{pmatrix}1&1\\0&1\end{pmatrix}$$
只有特徵值 $1$，且 $E_1=\{(x,0)^{\mathsf T}\}$ 只有一個獨立方向，所以找不到兩個特徵向量當基底；$J$ 不可對角化。

**檢查點 1.2.B**　「有 $n$ 個根（計重數）」不等於「有 $n$ 個相異根」，也不保證有 $n$ 個獨立特徵向量；矩陣 $J$ 正是警告。

## 內積、自伴算子與譜定理

::: {.definition name="複內積"}
複向量空間的**內積** $\langle u,v\rangle$ 對第一個變數線性，並滿足
$$\langle u,v\rangle=\overline{\langle v,u\rangle},\qquad
\langle v,v\rangle>0\quad(v\ne0).$$
若 $\langle u,v\rangle=0$，稱 $u,v$ 正交。標準例子是
$\langle u,v\rangle=\sum_i u_i\overline{v_i}$。
:::

::: {.definition name="自伴算子"}
算子 $T$ 稱為**自伴**，若
$$\langle Tu,v\rangle=\langle u,Tv\rangle$$
對所有 $u,v$ 成立。標準正交基底下，它的矩陣滿足 $A=\overline A^{\mathsf T}$。
:::

::: {.theorem name="【完整證明；依賴第 0.5 章黑箱】有限維譜定理"}
有限維複內積空間上的自伴算子有一組正交規一的特徵向量基底，且全部特徵值為實數。
:::

::: {.proof}
先證特徵值為實。若 $Tv=\lambda v$ 且 $v\ne0$，則
$$\lambda\langle v,v\rangle
=\langle Tv,v\rangle
=\langle v,Tv\rangle
=\overline\lambda\langle v,v\rangle,$$
故 $\lambda=\overline\lambda$。

接著對維度歸納。維度 $1$ 顯然。維度大於 $1$ 時，特徵多項式由第 0.5 章接受的「代數基本定理」在 $\mathbb C$ 有根，因此有單位特徵向量 $v$。令
$$v^\perp=\{w:\langle w,v\rangle=0\}.$$
若 $w\in v^\perp$，則
$$\langle Tw,v\rangle=\langle w,Tv\rangle
=\langle w,\lambda v\rangle=\overline\lambda\langle w,v\rangle=0,$$
所以 $T$ 保持 $v^\perp$。限制在較低維的 $v^\perp$ 上仍自伴，由歸納假設有正交規一特徵基底；再加入 $v$，便得到整個空間的所求基底。
:::

這裡唯一外借的是第 0.5 章明列的代數基本定理；其餘步驟已寫全。

## 交換的自伴算子可以同時對角化

::: {.theorem name="【完整證明】同時對角化（自伴版本）"}
有限維複內積空間上一族兩兩交換的自伴算子，有一組共同的正交規一特徵基底。
:::

::: {.proof}
對空間維度歸納。若族中每個算子都是純量乘法，任何正交規一基底都可以。否則選一個非純量算子 $S$。由譜定理，空間分解成 $S$ 的若干互相正交、維度都更小的特徵空間。

若 $T$ 與 $S$ 交換，且 $Sv=\lambda v$，則
$$S(Tv)=T(Sv)=T(\lambda v)=\lambda T(v),$$
所以 $T$ 保持每個 $S$-特徵空間。族中所有算子限制到每個特徵空間後仍兩兩交換且自伴。對每個較小空間使用歸納假設，再把所得基底合併，便是整族的共同特徵基底。
:::

::: {.remark name="【接受的黑箱／路線定位】Hecke 算子"}
後文會在有限維模形式空間上定義 Hecke 算子。在適當的複內積空間、並對相關的好質數算子，它們具有交換與自伴（或可同時譜分解）的性質；精確的級數、內積與壞質數條件必須到模形式章節才陳述。本章只證線性代數的「若滿足這些條件，便有共同特徵基底」。

共同特徵向量 $f$ 滿足 $T_pf=a_p(f)f$；這是「特徵形式」一詞的線性代數來源。這段沒有宣稱已證任何模性定理。
:::

## 跡、行列式與二階特徵多項式

::: {.definition name="跡"}
矩陣的**跡** $\operatorname{tr}(A)$ 是對角線元素之和。
:::

::: {.proposition name="【完整證明】二階特徵多項式"}
若 $A=\begin{pmatrix}a&b\\c&d\end{pmatrix}$，則
$$\chi_A(t)=t^2-\operatorname{tr}(A)t+\det(A).$$
:::

::: {.proof}
直接展開：
$$\det\begin{pmatrix}t-a&-b\\-c&t-d\end{pmatrix}
=(t-a)(t-d)-bc
=t^2-(a+d)t+(ad-bc).$$
:::

**【完整證明（行列式部分依賴第 1.1 章黑箱）】換基底不改變跡與行列式。** 換基底後矩陣變成 $P^{-1}AP$。行列式由第 1.1 章的乘法性黑箱立刻得到。對跡，若 $X=(x_{ij})$、$Y=(y_{ij})$，則
$$\operatorname{tr}(XY)=\sum_i\sum_jx_{ij}y_{ji}
=\sum_j\sum_i y_{ji}x_{ij}=\operatorname{tr}(YX),$$
所以
$$\operatorname{tr}(P^{-1}AP)=\operatorname{tr}(APP^{-1})=\operatorname{tr}(A).$$
所以它們描述的是算子本身，而不是某次座標選擇。

::: {.remark name="【直覺／後文記號】Frobenius 的跡"}
後面若看到 $\operatorname{tr}(\rho(\mathrm{Frob}_p))=a_p$，字面意思只是：一個二維表示把某個群元素送到 $2\times2$ 矩陣，而該矩陣對角線之和是 $a_p$。表示的建造、Frobenius 的定義與等式成立的條件都屬後文結果；此處沒有預先證明它們。
:::

**檢查點 1.2.C**　請說出三個層次：(1) 特徵值是什麼；(2) 可對角化多要求什麼；(3) 同時對角化又多要求什麼。能分清「有根」「有特徵基底」「有共同特徵基底」，就能進入群論。

## 本章地圖與下一章預告

$$\text{欄向量換基底 }P^{-1}AP
\to Tv=\lambda v
\to\text{特徵基底}
\to\text{自伴譜定理}
\to\text{交換族共同特徵基底}.$$

下一章從頭定義群、子群、陪集、同態與群作用。第 1.1 章為了定義表示先給過群的最小版本；下一章會把缺少的推理機器完整補上。

## 習題

**1.2.1 ★**　求 $A=\begin{pmatrix}3&1\\0&2\end{pmatrix}$ 的特徵值與各一個特徵向量，把特徵向量排成 $P$ 的各欄，核對 $P^{-1}AP$ 為對角矩陣。

**1.2.2 ★**　完整算出 $J=\begin{pmatrix}1&1\\0&1\end{pmatrix}$ 的特徵空間，說明為何只有一個獨立方向。

**1.2.3**　旋轉矩陣 $R=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ 在 $\mathbb C^2$ 找出兩個特徵向量並對角化。指出為何同一件事在 $\mathbb R^2$ 做不到。

**1.2.4 ★**　驗證 $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 的兩個特徵向量正交，並把它們各自除以長度，得到正交規一基底。

**1.2.5**　逐項證明同尺寸矩陣滿足 $\operatorname{tr}(XY)=\operatorname{tr}(YX)$，再推出跡在換基底下不變。

**1.2.6 ★**　若 $S,T$ 交換，證明 $T$ 保持 $S$ 的每個特徵空間。請指出證明中哪一步使用 $ST=TS$。

**1.2.7（前瞻）**　假設 $2\times2$ 矩陣的跡為 $a_p$、行列式為 $p$。寫出特徵多項式，並求其判別式。只做代數計算，不預設這個矩陣真的來自橢圓曲線。
