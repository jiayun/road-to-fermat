## 開場：第二座山頭

第一部到此用一場歷史回望收尾。我們把代數工具暫時擱下，回到 FLT 的主線戰場，看人類在費馬之後攻下的第二個指數：$n = 3$。

時間是 1770 年前後，主角是 Leonhard Euler。他要證明的是
$$x^3 + y^3 = z^3 \quad \text{無正整數解}.$$
這比費馬的 $n = 4$ 晚了一百多年，難度卻是質的躍升。原因前面已經預告過（第 0.4 章末）：$n = 4$ 可以靠畢氏分類在 $\mathbb{Z}$ 內解決，但 $n = 3$ 沒有對應的初等分類。Euler 被迫做一件當時看來大膽、事後看來危險的事 —— **離開整數，走進一個含有 $\sqrt{-3}$ 的新數系做因式分解**。

這一章有雙重目的。其一，讓你看見 $n = 3$ 證明的真實樣貌（無窮遞降仍是骨架，但血肉換成了新數系的算術）。其二，更重要的：精確指出 Euler 在哪一步**默默假設了唯一分解**，而他踩的那塊地板，其實在他選的數系裡是會塌的 —— 只是僥倖，他要的結論恰好還站得住。這個「僥倖」是第三部整場戲的序曲，也是理解「為什麼 Kummer 的工作是必要的」的最佳切入點。

## 證明的骨架：仍是無窮遞降

Euler 的證明在最外層仍是費馬的老招（第 0.1、0.4 章）：假設存在正整數解，化約到本原解，取 $z$ 最小的一組，然後設法造出更小的一組，逼出矛盾。

化約到本原（兩兩互質）的步驟與前面完全相同。接著做奇偶與整除的初步分析，可以證明：在本原解中，$x, y, z$ 恰有一個是偶數，且不妨假設 $x, y$ 為奇（習題 1.6.1）。於是 $x + y$ 與 $x - y$ 都是偶數，令
$$x = a + b, \qquad y = a - b,$$
則 $a, b$ 一奇一偶、互質。代入 $x^3 + y^3$：
$$x^3 + y^3 = (a+b)^3 + (a-b)^3 = 2a^3 + 6ab^2 = 2a(a^2 + 3b^2).$$
所以 $z^3 = 2a(a^2 + 3b^2)$。

關鍵的數論內容，全部濃縮在那個因子 $a^2 + 3b^2$ 上。可以證明（在適當的互質假設下）$2a$ 與 $a^2 + 3b^2$ 互質或共享一個受控的小因子，於是 **$a^2 + 3b^2$ 本身必須非常接近一個完全立方數**。整個證明的成敗，就壓在下面這個引理上：

> 若 $a, b$ 互質、一奇一偶，且 $a^2 + 3b^2$ 是一個完全立方數，那麼 $a, b$ 能用更小的一對數表示出來，產生遞降。

而要證這個引理，Euler 做了那個關鍵動作。

## 危險的一步：走進 $\mathbb{Z}[\sqrt{-3}]$

$a^2 + 3b^2$ 在普通整數裡是頑固的二次型，但只要允許 $\sqrt{-3}$，它立刻裂開：
$$a^2 + 3b^2 = (a + b\sqrt{-3})(a - b\sqrt{-3}).$$
這正是第 0.5 章「代數基本定理是因式分解的許可證」的具體運用。Euler 在數系
$$\mathbb{Z}[\sqrt{-3}] = \{\, a + b\sqrt{-3} : a, b \in \mathbb{Z} \,\}$$
裡工作。他的推理是這樣的：

1. $a^2 + 3b^2 = (a + b\sqrt{-3})(a - b\sqrt{-3})$ 是一個立方數。
2. 兩個因子 $a + b\sqrt{-3}$ 與 $a - b\sqrt{-3}$ **互質**（在 $\mathbb{Z}[\sqrt{-3}]$ 中）。
3. **兩個互質的數，乘積是立方數，則各自都是立方數** —— 所以 $a + b\sqrt{-3} = (\text{某個元素})^3$。
4. 把那個元素寫成 $u + v\sqrt{-3}$，展開 $(u + v\sqrt{-3})^3$ 並比較係數，就解出 $a, b$ 用更小的 $u, v$ 表示，完成遞降。

第 3 步是心臟。請把它與第 0.3 章畢氏三元數證明裡那句「互質 × 互質 = 平方 $\Rightarrow$ 各自平方」並排 —— 它們是同一個原理，只是「平方」換成「立方」，而且**舞台從 $\mathbb{Z}$ 搬到了 $\mathbb{Z}[\sqrt{-3}]$**。

問題就在這裡。在 $\mathbb{Z}$ 裡，「互質因子的乘積是立方 $\Rightarrow$ 各自立方」是算術基本定理的乾淨推論（第 0.2、0.3 章）。但這個推論**依賴唯一分解**。而 Euler 默默假設了 $\mathbb{Z}[\sqrt{-3}]$ 也有唯一分解 —— 他沒有證明這一點，當時甚至沒有意識到這需要證明。

## 地板會塌：$\mathbb{Z}[\sqrt{-3}]$ 不是唯一分解環

Euler 假設的東西，是錯的。$\mathbb{Z}[\sqrt{-3}]$ **不具有**唯一分解性質。最乾淨的反例：
$$4 = 2 \cdot 2 = (1 + \sqrt{-3})(1 - \sqrt{-3}).$$
用範數 $N(a + b\sqrt{-3}) = a^2 + 3b^2$（它滿足 $N(\alpha\beta) = N(\alpha)N(\beta)$，習題 1.6.2）來分析：$N(2) = 4$，$N(1 \pm \sqrt{-3}) = 4$。可以證明 $2$、$1 + \sqrt{-3}$、$1 - \sqrt{-3}$ 在 $\mathbb{Z}[\sqrt{-3}]$ 中都**不可分解**（若 $2 = \alpha\beta$ 非平凡，則 $N(\alpha) = N(\beta) = 2$，但 $a^2 + 3b^2 = 2$ 無整數解），且彼此不相伴。同一個 $4$，兩種本質不同的分解 —— 唯一分解破裂。

更精確地說，破裂的是 Euclid 引理（第 0.2 章那個「質數的兩種定義」的區分在此生死攸關）：$2$ 整除乘積 $(1+\sqrt{-3})(1-\sqrt{-3}) = 4$，卻不整除任一個因子。$2$ 在 $\mathbb{Z}[\sqrt{-3}]$ 裡是「不可分解的」，卻不是「質的」。一旦 Euclid 引理失效，「互質因子的乘積是立方則各自立方」這個第 3 步的論證，就**沒有根據**。

Euler 的證明，邏輯上有一個洞。

## 僥倖：他要的結論其實對

戲劇性的轉折是：**Euler 的結論仍然正確**。$x^3 + y^3 = z^3$ 確實無解。他的證明能被修好，而修補的方式揭示了一個深刻的教訓。

問題出在 Euler 選錯了數系。$\sqrt{-3}$ 真正自然的家不是 $\mathbb{Z}[\sqrt{-3}]$，而是更大一點的**Eisenstein 整數**環
$$\mathbb{Z}[\zeta_3] = \{\, a + b\zeta_3 : a, b \in \mathbb{Z} \,\}, \qquad \zeta_3 = \frac{-1 + \sqrt{-3}}{2}$$
（第 0.5 章的本原三次單位根）。注意 $\zeta_3$ 含一個分母 $2$，所以 $\mathbb{Z}[\zeta_3]$ 嚴格大於 $\mathbb{Z}[\sqrt{-3}]$ —— 它多收了 $\frac{1 + \sqrt{-3}}{2}$ 這類「半整數」元素。而關鍵事實是：

> **Eisenstein 整數 $\mathbb{Z}[\zeta_3]$ 是一個唯一分解環。**

在這個正確的環裡，先前的反例消失了。$1 + \sqrt{-3}$ 不再是不可分解的，因為
$$1 + \sqrt{-3} = 2 \cdot \frac{1 + \sqrt{-3}}{2} = 2(1 + \zeta_3)$$
（驗證：$2\zeta_3 = -1 + \sqrt{-3}$，故 $2 + 2\zeta_3 = 1 + \sqrt{-3}$）。於是 $4 = 2 \cdot 2$ 與 $4 = (1+\sqrt{-3})(1-\sqrt{-3})$ 兩種分解，在 $\mathbb{Z}[\zeta_3]$ 裡其實是**同一種**分解的偽裝 —— 第二種只是第一種乘上一些單位後重新組合。$\mathbb{Z}[\zeta_3]$ 有六個單位 $\{\pm 1, \pm\zeta_3, \pm\zeta_3^2\}$（範數為 $1$ 的元素，習題 1.6.3），充裕的單位讓兩種分解得以調和。唯一分解在正確的環裡安然無恙，Euler 的第 3 步論證得救，結論成立。

::: {.remark name="這個僥倖是整本書的轉捩點"}
請務必體會這裡發生了什麼，因為它是 FLT 故事的核心隱喻。

Euler 在 $n = 3$ 僥倖過關 —— 不是因為他的論證正確（在他選的環裡是錯的），而是因為換到正確的環 $\mathbb{Z}[\zeta_3]$ 後，唯一分解**恰好成立**。$n = 3$ 對應的數系，運氣好，是個 UFD。

但這個運氣不會一直有。當 Lamé 在 1847 年想對一般的奇質數 $p$ 重施故技 —— 在 $\mathbb{Z}[\zeta_p]$ 裡分解 $x^p + y^p = \prod(x + \zeta_p^k y)$ 並假設唯一分解（第 0.5 章預告過）—— 他撞上了一堵牆：**對某些質數 $p$（最小的是 $p = 23$），$\mathbb{Z}[\zeta_p]$ 不是 UFD，而且沒有任何「換個環」的補救能讓它變回 UFD。** $n = 3$ 的僥倖無法複製。

於是核心問題浮現，它將定義整個第三部：

> 當唯一分解真的、無可挽回地失效時，怎麼辦？

Kummer 的答案 —— 發明「理想數」，用理想（第 1.4 章的環論概念）恢復一種更精緻的唯一分解 —— 是十九世紀數論的高峰，也是「理想」這個詞之所以叫 ideal（理想的、想像的）的歷史來源。Euler 的僥倖讓他不必面對這個問題；Kummer 的偉大在於他正面解決了它；而這兩者之間的張力，是第三部的全部劇情。

你現在站在第一部的終點，剛好看清了那道將在第三部裂開的縫隙。前五章的代數機器（群、環、體、理想），正是為了在那道縫隙前不至於墜落而準備的。
:::

## 第一部完結：回望與前瞻

第一部到此真正完成。我們花了六章建立基礎語言：

- **線性代數**（1.1–1.2）：表示的舞台、Hecke 算子的本體。
- **群**（1.3）：對稱性、Galois 群的母結構。
- **環與體**（1.4）：數環、理想、$\mathbb{F}_p$。
- **分析**（1.5）：模形式作為解析物件的後盾。
- **歷史插曲**（1.6）：Euler 的 $n = 3$，唯一分解第一次在實戰中動搖。

這一部的暗線，是「唯一分解」這個第零部建立的支柱，如何在進入更大數系時開始鬆動。$n = 3$ 僥倖、$n = 23$ 將崩潰。第二部與第三部，就是去正面理解那些「更大的數系」—— 它們的對稱性（Galois 理論，第二部）與它們的算術（代數數論，第三部）。

## 本章地圖與下一章預告

- **$n = 3$ 的骨架**：無窮遞降 + 在新數系裡因式分解。
- **危險一步**：$a^2 + 3b^2 = (a+b\sqrt{-3})(a-b\sqrt{-3})$，默認唯一分解。
- **地板會塌**：$\mathbb{Z}[\sqrt{-3}]$ 非 UFD，$4 = 2\cdot 2 = (1+\sqrt{-3})(1-\sqrt{-3})$。
- **僥倖得救**：正確的環 $\mathbb{Z}[\zeta_3]$（Eisenstein 整數，六個單位）是 UFD。
- **轉捩點**：$n = 3$ 的運氣 $p = 23$ 不會重演 —— 第三部的核心問題就此提出。

下一部進入 **Galois 理論**。第 2.1 章《體擴張》正式建立「把體擴大」的理論：擴張次數、代數元、最小多項式、分裂體 —— 把第 1.4 章末「商環造體」系統化。本章出現的 $\mathbb{Z}[\zeta_3]$、$\mathbb{Q}(\sqrt{-3})$ 之間的層級，到時會在「體擴張的塔」裡獲得精確座標。我們開始正式研究那些 Euler 莽撞闖入、而 Kummer 將小心翼翼丈量的更大世界。

## 習題

**1.6.1**　補上 $n = 3$ 證明開頭的奇偶分析：在本原解 $x^3 + y^3 = z^3$ 中，證明 $x, y, z$ 恰有一個為偶數。（提示：用第 0.2 章立方數模 $9$ 或模 $2$ 的性質。）

**1.6.2 ★**　驗證 $\mathbb{Z}[\sqrt{-3}]$ 上的範數 $N(a + b\sqrt{-3}) = a^2 + 3b^2$ 是乘性的：$N(\alpha\beta) = N(\alpha)N(\beta)$。並用它證明 $2$ 在 $\mathbb{Z}[\sqrt{-3}]$ 中不可分解。

**1.6.3 ★**　Eisenstein 整數 $\mathbb{Z}[\zeta_3]$ 的範數是 $N(a + b\zeta_3) = a^2 - ab + b^2$。(a) 找出所有單位（範數 $= 1$ 的元素），驗證恰有六個。(b) 說明這六個單位就是六個 $\zeta_6$ 的冪（即正六邊形頂點），與第 0.5 章單位根的幾何呼應。

**1.6.4**　明確展開 $(u + v\sqrt{-3})^3$，寫出實部與 $\sqrt{-3}$ 部。由此說明 Euler 證明第 4 步「比較係數解出 $a, b$」具體是哪兩條方程。

**1.6.5 ★**　驗證唯一分解在 $\mathbb{Z}[\zeta_3]$ 中如何「修復」反例：證明 $1 + \sqrt{-3} = 2(1 + \zeta_3)$，並計算 $N(1 + \zeta_3)$，說明 $1 + \zeta_3$ 是什麼（不可分解元還是單位的倍數）。由此論證 $4$ 的兩種分解在 $\mathbb{Z}[\zeta_3]$ 中相伴。

**1.6.6（前瞻）**　查閱「類數」（class number）的概念。$\mathbb{Z}[\zeta_3]$ 的類數是 $1$（等價於它是 UFD）。$\mathbb{Z}[\zeta_{23}]$ 的類數是 $3$（不是 $1$，故非 UFD）。用一兩句話預測：類數這個數字，將如何量化「一個數環離唯一分解有多遠」？（第三部 3.3 節的核心，你已經摸到它的門把。）
