## 開場：換一片大陸

第三部結束在古典數論的盡頭。第四部換一片完全不同的數學大陸 —— 複分析與幾何。乍看之下，這像是離題：FLT 是個整數問題，複變函數與它何干？但第三部末尾已經給出方向 —— FLT 的現代證明需要橢圓曲線與模形式，而這兩者本質上都是**複分析與幾何**的對象。橢圓曲線在 $\mathbb{C}$ 上是一個圓環面（第 5.1 章），模形式是上半平面上的全純函數（第 5.4 章）。要讓它們登場，必須先建好複分析這個舞台。

這一章建立複分析的核心：全純函數、Cauchy 定理、留數。第 1.5 章已預告「模形式是解析物件」，並用 $\varepsilon$–$\delta$ 證明它的 $q$ 展開收斂。本章把那個分析基礎深化到複變的層次 —— 因為模形式不只是收斂的，它是**全純**的（處處複可微），而全純性帶來一種實分析完全沒有的「剛性」，那正是模形式威力的根源。

## 全純函數：複可微的奇蹟

::: {.definition}
複函數 $f: U \to \mathbb{C}$（$U \subseteq \mathbb{C}$ 開集）在 $z_0$ **複可微**，若極限
$$f'(z_0) = \lim_{h \to 0} \frac{f(z_0 + h) - f(z_0)}{h}$$
存在（$h$ 是複數，可從任何方向趨於 $0$）。若 $f$ 在 $U$ 上處處複可微，稱 $f$ 為**全純**（holomorphic）。
:::

「$h$ 可從任何方向趨於 $0$」是關鍵。實函數可微只要求左右兩個方向一致；複可微要求**所有**方向（整個複平面的每個角度）都給出同一個極限。這是極強的限制，它逼出一組方程：

::: {.theorem name="Cauchy–Riemann 方程"}
寫 $f(x + iy) = u(x, y) + i\,v(x, y)$。則 $f$ 全純 $\iff$
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}.$$
:::

::: {.proof}
（梗概）讓 $h$ 分別沿實軸（$h \to 0$ 實）與虛軸（$h \to 0$ 純虛）趨零，兩個方向的導數極限必須相等，比較實部虛部即得 Cauchy–Riemann 方程。反向（這組方程加可微性蘊涵複可微）需要一點實分析。
:::

::: {.remark name="全純 = 剛性"}
複可微的「全方向一致」要求，使全純函數異常**剛硬**。一個全純函數的局部行為，幾乎決定它的全部 —— 這與柔軟的實函數天差地別。本章後面會看到三個剛性的展現：(1) 全純函數**自動無窮可微**（一次複可微就保證無窮次，實函數絕無此事）；(2) 全純函數**等於它的冪級數**（解析）；(3) **恆等定理** —— 兩個全純函數若在一小段上相等，則處處相等。

這個剛性是模形式理論的命脈。模形式由它的 $q$ 展開 $\sum a_n q^n$ 決定，而「係數 $a_n$ 完全決定模形式」正是恆等定理的後果。第五部谷山–志村猜想之所以能「逐項比較係數」來斷言兩個對象相等，全靠全純函數這種「局部決定整體」的剛性。柔軟的實函數做不到這件事 —— 你不能靠有限資訊釘死一個實函數。複分析的剛性，是讓「模性」成為一個可驗證命題的根本原因。
:::

## Cauchy 積分定理與公式

複分析的核心，是沿著複平面上的**路徑**做積分。一個出人意料的事實開啟了一切：

::: {.theorem name="Cauchy 積分定理"}
若 $f$ 在單連通區域 $U$ 上全純，則對 $U$ 內任何封閉路徑 $\gamma$，
$$\oint_\gamma f(z)\,dz = 0.$$
:::

全純函數沿任何封閉迴路的積分為零 —— 這說明積分只依賴端點、不依賴路徑（在單連通區域內）。由它推出複分析最有用的工具：

::: {.theorem name="Cauchy 積分公式"}
$f$ 在含閉圓盤的區域上全純，$\gamma$ 是圓盤邊界（逆時針），$a$ 在圓盤內。則
$$f(a) = \frac{1}{2\pi i}\oint_\gamma \frac{f(z)}{z - a}\,dz.$$
:::

這個公式說一件驚人的事：**全純函數在區域內部任一點的值，完全由它在邊界上的值決定**。邊界資訊「全息地」編碼了內部的一切 —— 又一個剛性的展現。

::: {.example name="數值驗證"}
取 $f(z) = e^z$，$a = 0$，$\gamma$ 為單位圓。公式給出
$$\frac{1}{2\pi i}\oint_{|z|=1} \frac{e^z}{z}\,dz = e^0 = 1.$$
沿單位圓數值積分，確實得到 $1$。
:::

Cauchy 公式的一個直接推論，是兌現第 0.5 章欠下的一張支票：

::: {.corollary name="代數基本定理"}
每個次數 $\ge 1$ 的複係數多項式在 $\mathbb{C}$ 中有根。
:::

::: {.proof}
（Liouville 式論證）若多項式 $p(z)$ 無根，則 $1/p(z)$ 處處全純且有界（$|z| \to \infty$ 時 $\to 0$）。但 Cauchy 公式推出的 **Liouville 定理**說「有界全純函數必為常數」，矛盾。故 $p$ 必有根。
:::

第 0.5 章我們承諾「代數基本定理的完整證明等第四部複分析」—— 現在兌現了。三行解決，靠的全是全純函數的剛性（有界 + 全純 ⇒ 常數，這在實分析裡完全不成立，$\sin x$ 就是有界非常數的反例）。

## 留數：奇點處的指紋

全純函數沿封閉迴路積分為零（Cauchy 定理）—— 除非迴路內有**奇點**（函數爆掉的點）。奇點貢獻的，正是「留數」。

::: {.definition}
若 $f$ 在 $z_0$ 附近（除 $z_0$ 外）全純，它有 Laurent 展開 $f(z) = \sum_{n=-\infty}^\infty c_n (z - z_0)^n$。其中 $c_{-1}$ 稱為 $f$ 在 $z_0$ 的**留數** $\mathrm{Res}_{z_0} f$。
:::

::: {.theorem name="留數定理"}
$f$ 在區域內除有限個奇點外全純，$\gamma$ 是繞這些奇點的封閉路徑。則
$$\oint_\gamma f(z)\,dz = 2\pi i \sum_k \mathrm{Res}_{z_k} f.$$
:::

留數定理把「沿路徑積分」化約成「在奇點處算留數」—— 一個分析問題變成代數計算。它是複分析最強大的計算工具。

::: {.example name="數值驗證"}
$f(z) = \dfrac{1}{z^2 + 1} = \dfrac{1}{(z-i)(z+i)}$ 在 $z = i$ 處有奇點，留數 $\mathrm{Res}_i f = \dfrac{1}{2i}$。繞 $i$ 的小圓積分應得 $2\pi i \cdot \dfrac{1}{2i} = \pi$。數值積分確實得到 $\pi$。留數定理也是計算大量實積分（如 $\int_{-\infty}^\infty \frac{dx}{x^2+1} = \pi$）的標準手法 —— 把實積分提升到複平面，用留數秒殺。
:::

## 全純函數的剛性定理

把前面散落的剛性現象收成三條定理，它們都是第五部的直接工具。

::: {.theorem name="解析性"}
全純函數在每一點附近等於一個收斂的冪級數 $f(z) = \sum_{n \ge 0} c_n (z - z_0)^n$。特別地，全純函數無窮可微。
:::

::: {.theorem name="恆等定理"}
若兩個全純函數 $f, g$ 在區域 $U$ 內某個有極限點的集合上相等（例如在一小段曲線上、或一個收斂點列上），則 $f = g$ 於整個 $U$。
:::

::: {.remark name="恆等定理就是「係數決定一切」"}
恆等定理是第五部的關鍵引擎，值得單獨強調。它說：全純函數被它在「很少」的地方的值釘死。對模形式而言，這意味著它被 $q$ 展開的係數 $\{a_n\}$ 完全決定 —— 知道所有 $a_n$（甚至只要知道足夠多個，配合模形式空間的有限維性，第 5.5 章），就知道整個模形式。

這正是谷山–志村猜想能被表述為「逐項比較」的根源。猜想說「橢圓曲線 $E$ 的 $a_p(E)$ 序列等於某個模形式 $f$ 的 $a_p(f)$ 序列」—— 如果這些係數相等，由恆等定理，兩個解析對象（$E$ 的 L 函數與 $f$）就是同一個。沒有全純函數的剛性，「兩個無窮序列相等就保證兩個對象相同」這個推論根本不成立。複分析在這裡不是背景，而是讓「模性」這個等式有意義的邏輯基礎。
:::

## 通往上半平面

最後指出本章與模形式的直接接點。模形式定義在**上半平面** $\mathbb{H} = \{\tau \in \mathbb{C} : \mathrm{Im}(\tau) > 0\}$ 上 —— 它是一個全純函數，且在某個離散群（$\mathrm{SL}_2(\mathbb{Z})$，第 5.4 章）的作用下有特殊的變換性質。本章建立的全純性、Cauchy 理論、剛性，全部是定義與研究模形式所需。

特別地，模形式的 $q$ 展開 $f(\tau) = \sum a_n q^n$（$q = e^{2\pi i\tau}$）是一個全純函數的冪級數展開 —— 第 1.5 章證了它收斂，本章的解析性定理保證這個展開「就是」模形式本身，而恆等定理保證係數決定一切。三章（1.5、4.1、5.4）合力，才讓「模形式」成為一個既嚴格又可計算的對象。

::: {.remark name="Euler 公式的歸還"}
順帶歸還第 0.5 章借用的另一樣東西：$e^{i\theta} = \cos\theta + i\sin\theta$。當時我們當記號用，承諾複分析會證明它。現在可以了：$e^z$ 定義為冪級數 $\sum z^n/n!$（在 $\mathbb{C}$ 上處處收斂、全純），代入 $z = i\theta$ 並按實虛部重組，恰好得到 $\cos\theta + i\sin\theta$ 的冪級數。Euler 公式是冪級數的恆等式，而全純函數的解析性保證這個操作合法。第 0.5 章的單位根 $\zeta_n = e^{2\pi i/n}$，至此有了完全嚴格的複分析基礎。
:::

## 本章地圖與下一章預告

- **全純函數**：複可微（全方向一致）；Cauchy–Riemann 方程。
- **剛性**：全純 ⇒ 無窮可微、解析、恆等定理；模形式「係數決定一切」的根源。
- **Cauchy 定理與公式**：封閉迴路積分為零；邊界值決定內部；代數基本定理兌現。
- **留數定理**：奇點處的指紋；積分化約為留數計算。
- **恆等定理**：全純函數被局部釘死；谷山–志村「逐項比較」的邏輯基礎。

下一章《複分析 II》深化兩個對模形式至關重要的主題：解析延拓（把全純函數從小區域唯一地擴張出去 —— L 函數的定義靠它）與**橢圓函數** $\wp$（Weierstrass 函數）。後者是橢圓曲線「在 $\mathbb{C}$ 上是圓環面」這個關鍵事實的鑰匙：$\wp$ 函數把複平面對一個格 $\Lambda$ 的商 $\mathbb{C}/\Lambda$，映射成一條橢圓曲線。第 3.3 章 Minkowski 用過的「格」概念，將在這裡與橢圓曲線相遇 —— 那是第五部主角登場前的最後準備。

## 習題

**4.1.1**　驗證 $f(z) = z^2$ 滿足 Cauchy–Riemann 方程（寫出 $u, v$ 並計算偏導）。再驗證 $f(z) = \bar z$（複共軛）**不**全純。

**4.1.2 ★**　用留數定理計算 $\displaystyle\int_{-\infty}^\infty \frac{dx}{x^2 + 1}$。（提示：在上半平面用半圓圍道，只有 $z = i$ 的留數貢獻，圓弧部分趨零。答案 $\pi$。）

**4.1.3**　求 $f(z) = \dfrac{1}{z(z-1)}$ 在 $z = 0$ 與 $z = 1$ 的留數，並計算繞兩個奇點的大圓積分。

**4.1.4 ★**　用恆等定理證明：若全純函數 $f$ 在實軸的一段區間上恆等於 $0$，則 $f \equiv 0$。（這解釋了為什麼解析延拓是唯一的 —— 下一章主題。）

**4.1.5**　從 $e^z = \sum z^n/n!$ 出發，代入 $z = i\theta$，分離實虛部，嚴格推導 Euler 公式 $e^{i\theta} = \cos\theta + i\sin\theta$。（歸還第 0.5 章的借據。）

**4.1.6 ★**　證明 Liouville 定理：有界全純函數必為常數。（提示：用 Cauchy 積分公式對導數的估計 $|f'(a)| \le M/R$，令 $R \to \infty$。）由此補完代數基本定理的證明。

**4.1.7（前瞻）**　模形式的 $q$ 展開 $f(\tau) = \sum a_n q^n$，$q = e^{2\pi i\tau}$。說明當 $\mathrm{Im}(\tau) \to \infty$ 時 $q \to 0$，並解釋為什麼這對應「模形式在『無窮遠尖點』的行為由 $a_0$ 決定」。（尖形式 cusp form 是 $a_0 = 0$ 的模形式，第五部主角。你正在認識上半平面的幾何。）
