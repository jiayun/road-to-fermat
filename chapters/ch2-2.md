## 開場：一部字典

這一章是第二部的高峰，也是全書的核心觀念之一。Galois 理論的成就，可以濃縮成一個詞：**字典**。它在兩個看似無關的世界之間，建立了一個精確、完美、互相翻譯的對應 ——

$$\boxed{\;\text{Galois 擴張 } L/K \text{ 的中間體}\quad\longleftrightarrow\quad \text{Galois 群 } \mathrm{Gal}(L/K) \text{ 的子群}\;}$$

左邊是**體**的世界（連續、無窮、難以直接掌握）；右邊是**群**的世界（離散、有限、結構清晰）。Galois 基本定理說：這兩個世界透過這部字典完全對應，左邊的每一個問題都能翻譯成右邊的一個問題。研究數域的算術，於是變成研究有限群的結構 —— 這是十九世紀數學最深刻的洞見之一。

對 FLT 而言，這部字典是不可或缺的。Wiles 證明的核心對象 $\rho: \mathrm{Gal}(\overline{\mathbb{Q}}/\mathbb{Q}) \to \mathrm{GL}_2$，其定義域正是一個（無窮版的）Galois 群。要理解 Galois 群如何「作用」、如何被「表示」，必須先在有限的情形把這部字典讀通。

**本章的證明策略，先講清楚。** Galois 基本定理常被當成黑盒丟給讀者（「證明見教材」），本書不這樣做。我們會證明一條初等的線性無關引理（**Dedekind 特徵無關性**，完整證明），用它推出一條計數定理（**Artin 定理**，證明骨架），再從 Artin 定理**完整推導**基本定理的前三部分與第四部分的骨架。讀完你會清楚知道：這條看似神祕的定理，地基是一個關於「線性無關」的十行論證。

## 本章前置檢查點

1. **群、子群、正規子群、商群、Lagrange 定理**（第 1.3 章）。第 4 部分的對應完全建立在「正規子群 ↔ 商群」之上。
2. **群作用**（第 1.3 章）：Galois 群作用在根的集合上。
3. **體擴張、次數、塔定理、分裂體**（第 2.1 章）。
4. **線性方程組**：$n$ 個方程、$m > n$ 個未知數的齊次系統必有非零解（第 1.1 章）。Artin 定理的兩個方向都靠它。

## Galois 群

回憶第 2.1 章末的觀察：分裂體的對稱性，是那些「固定底體、置換根」的自同構。把它正式化。

::: {.definition}
體擴張 $L/K$ 的**自同構群**是所有「固定 $K$ 逐點不動」的體自同構 $\sigma: L \to L$ 構成的群（運算是合成）：
$$\mathrm{Aut}(L/K) = \{\sigma: L \xrightarrow{\sim} L \text{ 體同構} \mid \sigma(a) = a\ \ \forall a \in K\}.$$
:::

一個自同構 $\sigma$ 必須尊重加法與乘法，又固定 $K$，所以它把任何 $K$-係數多項式的根送到根（習題 2.2.1）。於是 $\mathrm{Aut}(L/K)$ 作用在「$K$-多項式的根」這個有限集合上 —— 第 1.3 章的群作用在此具體現身。

::: {.example name="兩個基本例子"}
**$\mathbb{Q}(\sqrt 2)/\mathbb{Q}$：** 自同構必把 $\sqrt 2$ 送到 $x^2 - 2$ 的根，即 $\pm\sqrt 2$。兩種選擇各給一個自同構（恆等與「共軛」$\sqrt 2 \mapsto -\sqrt 2$），故 $\mathrm{Aut} \cong \mathbb{Z}/2\mathbb{Z}$，階 $2 = [\mathbb{Q}(\sqrt2):\mathbb{Q}]$。

**$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$：** 自同構須把 $\sqrt[3]{2}$ 送到 $x^3 - 2$ 的根。但 $\mathbb{Q}(\sqrt[3]{2})$ 是**實**體，只含一個實根 $\sqrt[3]{2}$（另兩個根 $\omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}$ 是複數，不在裡面）。所以唯一的自同構是恆等，$\mathrm{Aut}$ 是平凡群，階 $1 < 3 = [\mathbb{Q}(\sqrt[3]2):\mathbb{Q}]$。
:::

第二個例子暴露一個問題：對稱性「不夠多」，字典會壞掉。原因是 $\mathbb{Q}(\sqrt[3]{2})$ 沒有裝下 $x^3 - 2$ 的**所有**根。要讓字典完美，必須要求擴張「夠大」。

## Galois 擴張：讓字典完美的條件

::: {.definition}
有限擴張 $L/K$ 稱為 **Galois 擴張**，若 $|\mathrm{Aut}(L/K)| = [L : K]$（自同構數達到最大可能）。此時記 $\mathrm{Gal}(L/K) := \mathrm{Aut}(L/K)$，稱 **Galois 群**。
:::

這個簡潔的定義等價於兩個更具幾何意味的條件同時成立：

- **正規性**（normal）：$L$ 是某個 $K$-多項式的分裂體 —— 即「只要裝了一個根，就裝下全部共軛根」。$\mathbb{Q}(\sqrt[3]{2})$ 不正規（裝了實根卻漏掉複根），這正是它失敗的原因。
- **可分性**（separable）：$L$ 中每個元素的最小多項式沒有重根。在特徵 $0$（如所有數域）或有限體上，這自動成立，本書幾乎不必操心。

::: {.theorem name="Galois 擴張的判準"}
設 $L/K$ 有限。下列三者等價：

(a) $|\mathrm{Aut}(L/K)| = [L:K]$（即 $L/K$ Galois）；
(b) $L^{\mathrm{Aut}(L/K)} = K$（被整個自同構群固定的元素恰好是 $K$ 的元素）；
(c) $L$ 是某個可分多項式 $f \in K[x]$ 的分裂體。
:::

**假設**：$L/K$ 有限擴張。**用途**：(b) 是「對稱豐富到能用不變量刻畫底體」的說法，是基本定理的引擎；(c) 是實際檢驗某個擴張是否 Galois 的操作手冊（對數域，「Galois」實質上就是「分裂體」）。**狀態**：(a) $\iff$ (b) 由下方 Artin 定理**完整推導**（見「兩條引理」節末）；(a) $\iff$ (c) 是**外部黑盒**（Dummit–Foote 第 14 章）。

最後那個條件 $L^G = K$ 特別有用：它說 Galois 擴張裡，「除了 $K$ 的元素，沒有別的東西被所有對稱固定」。對稱足夠豐富，豐富到能用「不變量」精確地刻畫底體。

於是對我們關心的數域，「Galois」實質上就是「分裂體」。$x^3 - 2$ 的分裂體 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$ 是 Galois 的，而 $\mathbb{Q}(\sqrt[3]{2})$ 不是。

## 兩條引理：字典的地基

基本定理不是憑空的。它站在兩條引理上，而第一條完全初等。

::: {.lemma name="Dedekind：特徵的線性無關性"}
設 $G$ 是一個群，$L$ 是一個體。則任何一組**相異**的群同態 $\chi_1, \dots, \chi_n : G \to L^\times$，作為 $G \to L$ 的函數，在 $L$ 上線性無關：若 $a_1, \dots, a_n \in L$ 使得
$$a_1\chi_1(g) + \cdots + a_n\chi_n(g) = 0 \quad \text{對所有 } g \in G,$$
則 $a_1 = \cdots = a_n = 0$。
:::

**假設**：$\chi_i$ 兩兩相異的群同態到 $L^\times$。**用途**：把「相異的自同構」轉成「線性無關的函數」，於是可以對它們用線性代數的維度計數 —— 這是 Artin 定理的唯一非形式輸入。**狀態**：完整證明（下方）。

::: {.proof}
反證。在所有非平凡關係式中，取**非零係數個數最少**的一個；不妨設它是 $a_1\chi_1 + \cdots + a_n\chi_n = 0$，其中所有 $a_i \ne 0$，且 $n$ 最小。

若 $n = 1$：$a_1\chi_1(g) = 0$ 對所有 $g$，但 $\chi_1(g) \in L^\times$ 非零，故 $a_1 = 0$，矛盾。所以 $n \ge 2$。

因 $\chi_1 \ne \chi_2$，存在 $g_0 \in G$ 使 $\chi_1(g_0) \ne \chi_2(g_0)$。對任意 $g$，把 $g_0 g$ 代入關係式：
$$\sum_{i=1}^n a_i \chi_i(g_0 g) = \sum_{i=1}^n a_i \chi_i(g_0)\chi_i(g) = 0. \tag{$*$}$$
另一方面，把原關係式整體乘上 $\chi_1(g_0)$：
$$\sum_{i=1}^n a_i \chi_1(g_0)\chi_i(g) = 0. \tag{$**$}$$
$(*)$ 減 $(**)$：
$$\sum_{i=2}^{n} a_i\bigl(\chi_i(g_0) - \chi_1(g_0)\bigr)\,\chi_i(g) = 0 \quad \text{對所有 } g.$$
這是一個只用到 $\chi_2, \dots, \chi_n$ 的關係式，而 $i = 2$ 的係數 $a_2(\chi_2(g_0) - \chi_1(g_0)) \ne 0$。於是我們得到一個非零係數個數**更少**的非平凡關係式，與 $n$ 的最小性矛盾。
:::

把這條引理用在 $G = L^\times$、並取 $\chi_i$ 為相異的體自同構（限制到乘法群上就是相異的群同態），立刻得到：**$L$ 的相異自同構，作為 $L \to L$ 的函數，線性無關。** 這句話是下一條定理的全部燃料。

::: {.theorem name="Artin 定理"}
設 $L$ 是體，$G = \{\sigma_1 = \mathrm{id}, \sigma_2, \dots, \sigma_n\}$ 是 $L$ 的自同構構成的**有限**群，$K = L^G$ 是它的固定體。則
$$[L : K] = |G| = n.$$
:::

**假設**：$G$ 是**有限**的自同構群（不是任意集合）。**用途**：這是整部字典的計數核心 —— 它保證「群 $\to$ 固定體」這個方向不會遺失資訊。基本定理的每一部分都要用到它。**狀態**：證明骨架（下方給出兩個不等式的完整機制；被略過的只是兩處線性代數的細部驗算，見 Lang《Algebra》論 Galois 理論的一章）。

::: {.proof}
（骨架）分別證兩個不等式，兩邊都是「$n$ 個方程 vs. 更多未知數」的線性代數論證。

**$[L:K] \le n$：** 若不然，$L$ 中存在 $n+1$ 個在 $K$ 上線性無關的元素 $\alpha_1, \dots, \alpha_{n+1}$。考慮 $L$-係數的齊次線性系統
$$\sum_{j=1}^{n+1} \sigma_i(\alpha_j)\,x_j = 0, \qquad i = 1, \dots, n.$$
這是 $n$ 個方程、$n+1$ 個未知數，故有非零解 $(x_j) \in L^{n+1}$。取一個非零分量最少的解並正規化（使某個 $x_j = 1$）。對這個解施加任意 $\sigma \in G$（$G$ 是群，$\sigma$ 只是把方程重新排序），得到另一個解；兩者相減得到一個非零分量更少的解，由最少性它必為零解，於是原解的每個分量被所有 $\sigma$ 固定，即 $x_j \in K$。但 $i = 1$（$\sigma_1 = \mathrm{id}$）那條方程就成了 $\sum_j \alpha_j x_j = 0$ 且 $x_j \in K$ 不全為零 —— 與 $\alpha_j$ 在 $K$ 上線性無關矛盾。

**$[L:K] \ge n$：** 若不然，設 $[L:K] = m < n$，取 $K$-基底 $\omega_1, \dots, \omega_m$。考慮系統
$$\sum_{i=1}^{n} \sigma_i(\omega_j)\,y_i = 0, \qquad j = 1, \dots, m.$$
這是 $m$ 個方程、$n > m$ 個未知數，故有非零解 $(y_i) \in L^n$。因每個 $\alpha \in L$ 都是 $\omega_j$ 的 $K$-線性組合，而 $\sigma_i$ 固定 $K$，由線性性可得 $\sum_i y_i \sigma_i(\alpha) = 0$ 對**所有** $\alpha \in L$ 成立。這說明相異自同構 $\sigma_1, \dots, \sigma_n$ 線性相關 —— 與 Dedekind 引理矛盾。

**本書略過的部分：** 上面第一段中「相減得到更少非零分量的解」需要一段索引簿記，第二段中「由線性性推廣到所有 $\alpha$」需要一次交換求和次序的驗算。兩者都是機械的，不含新想法。
:::

有了 Artin 定理，判準中的 (a) $\iff$ (b) 立刻可證：

::: {.proof}
記 $G = \mathrm{Aut}(L/K)$（有限，因為它忠實地作用在 $L$ 的一組有限生成元的共軛上），$K' = L^G$。由定義 $K \subseteq K' \subseteq L$，且 Artin 定理給 $[L : K'] = |G|$。於是由塔定理
$$[L:K] = [L:K']\,[K':K] = |G| \cdot [K':K].$$
故 $|G| = [L:K] \iff [K':K] = 1 \iff K' = K$。
:::

## Galois 基本定理

字典的兩個方向，由兩個自然構造給出。

**從群到體（取固定體）：** 給 $G = \mathrm{Gal}(L/K)$ 的子群 $H$，定義它的**固定體**
$$L^H = \{a \in L : \sigma(a) = a\ \ \forall \sigma \in H\}.$$
它是 $K$ 與 $L$ 之間的一個中間體。

**從體到群（取自同構）：** 給中間體 $M$（$K \subseteq M \subseteq L$），對應子群 $\mathrm{Gal}(L/M) \le \mathrm{Gal}(L/K)$（固定 $M$ 的那些自同構）。

::: {.theorem name="Galois 基本定理"}
設 $L/K$ 為**有限 Galois** 擴張，$G = \mathrm{Gal}(L/K)$。則：

1. **一一對應**：「中間體 $M$」與「子群 $H \le G$」之間，$M \mapsto \mathrm{Gal}(L/M)$ 與 $H \mapsto L^H$ 互為逆雙射。
2. **反轉包含**：$M_1 \subseteq M_2 \iff \mathrm{Gal}(L/M_1) \supseteq \mathrm{Gal}(L/M_2)$。越大的體對應越小的群。
3. **次數對應指標**：$[L : M] = |\mathrm{Gal}(L/M)|$，$[M : K] = [G : \mathrm{Gal}(L/M)]$。
4. **正規對應正規**：中間體 $M$ 滿足「$M/K$ 是 Galois 擴張」$\iff$ $\mathrm{Gal}(L/M)$ 是 $G$ 的正規子群；此時限制映射給出同構 $\mathrm{Gal}(M/K) \cong G/\mathrm{Gal}(L/M)$。
:::

**假設**：$L/K$ **有限且 Galois**（兩個條件缺一不可 —— $\mathbb{Q}(\sqrt[3]2)/\mathbb{Q}$ 有限但非 Galois，字典就壞了；無窮情形需要拓撲，見本章末）。**用途**：把數域的算術問題轉譯成有限群的結構問題。第 2.3 章數分圓體的中間體、第 3.4 章分析 $\mathbb{Q}(\zeta_p)$ 的子域，全靠它。**狀態**：第 1–3 部分**完整證明**（下方，輸入是 Artin 定理與判準 (c)）；第 4 部分**證明骨架**（一處嵌入延拓被略過）。

::: {.proof}
先建立兩條關鍵事實。

**(A) 對任何中間體 $M$，$L/M$ 是 Galois 擴張，且 $L^{\mathrm{Gal}(L/M)} = M$。**
由判準 (c)，$L$ 是某可分 $f \in K[x]$ 的分裂體。同一個 $f$ 也可視為 $M[x]$ 的元素，而 $L$ 由 $M$ 與 $f$ 的根生成、$f$ 在 $L$ 中分裂，故 $L$ 也是 $f$ 在 $M$ 上的分裂體，仍可分。於是 $L/M$ Galois，再由判準 (b) 得 $L^{\mathrm{Gal}(L/M)} = M$，且 $|\mathrm{Gal}(L/M)| = [L:M]$。

**(B) 對任何子群 $H \le G$，$\mathrm{Gal}(L/L^H) = H$。**
一方面 $H \subseteq \mathrm{Gal}(L/L^H)$（$H$ 的元素依定義固定 $L^H$）。另一方面，由 Artin 定理 $[L : L^H] = |H|$；而把 (A) 用在中間體 $M = L^H$ 上得 $|\mathrm{Gal}(L/L^H)| = [L : L^H] = |H|$。兩個有限群，一個含於另一個且階相同，故相等。

**第 1 部分：** (A) 說 $H \mapsto L^H$ 之後接 $M \mapsto \mathrm{Gal}(L/M)$ 回到原處；(B) 說反向的合成也回到原處。兩個映射互為逆，故都是雙射。

**第 2 部分：** $M_1 \subseteq M_2$ 時，固定 $M_2$ 的自同構自動固定 $M_1$，故 $\mathrm{Gal}(L/M_2) \subseteq \mathrm{Gal}(L/M_1)$。反向：若 $\mathrm{Gal}(L/M_2) \subseteq \mathrm{Gal}(L/M_1)$，取固定體並用 (A)，得 $M_2 = L^{\mathrm{Gal}(L/M_2)} \supseteq L^{\mathrm{Gal}(L/M_1)} = M_1$。

**第 3 部分：** $[L:M] = |\mathrm{Gal}(L/M)|$ 已在 (A) 中得到。再由塔定理與 Lagrange 定理（第 1.3 章），記 $H = \mathrm{Gal}(L/M)$，
$$[M:K] = \frac{[L:K]}{[L:M]} = \frac{|G|}{|H|} = [G : H].$$

**第 4 部分（骨架）：** 先驗證一條恆等式：對 $\sigma \in G$ 與中間體 $M$，
$$\mathrm{Gal}(L/\sigma M) = \sigma\,\mathrm{Gal}(L/M)\,\sigma^{-1}$$
（直接檢查：$\tau$ 固定 $\sigma M$ $\iff$ $\sigma^{-1}\tau\sigma$ 固定 $M$）。由第 1 部分的雙射，
$$\sigma M = M \ \text{對所有 } \sigma \in G \iff \sigma H \sigma^{-1} = H \ \text{對所有 } \sigma \in G \iff H \trianglelefteq G.$$
剩下要說明：「$M/K$ 是 Galois 擴張」$\iff$「每個 $\sigma \in G$ 都把 $M$ 映到 $M$」。$\Leftarrow$ 方向：此時限制映射 $\mathrm{res}: G \to \mathrm{Aut}(M/K)$ 有定義，核恰是 $H$，故像的階至少 $|G|/|H| = [M:K]$，於是 $|\mathrm{Aut}(M/K)| \ge [M:K]$，而反向不等式恆成立，故 $M/K$ Galois 且 $\mathrm{res}$ 滿射，第一同構定理給 $\mathrm{Gal}(M/K) \cong G/H$。$\Rightarrow$ 方向需要「$K$-嵌入 $M \to L$ 可延拓成 $L$ 的自同構」這條標準引理（**本書略過**，見 Dummit–Foote 第 14 章關於嵌入延拓的標準引理）：有了它，$M/K$ 正規就給出 $\sigma(M) = M$。
:::

::: {.remark name="這條定理不是黑盒"}
停下來看看剛才發生了什麼。基本定理四個部分的證明，總共只用了三樣東西：Dedekind 引理（十行、完全初等）、Artin 定理（兩次「方程比未知數少」的線性代數）、塔定理與 Lagrange 定理（第 1.3、2.1 章）。真正被本書外包出去的只有兩件事：判準 (c)（Galois $\iff$ 可分多項式的分裂體）與第 4 部分的嵌入延拓引理。

這就是本書想教的閱讀態度。「證明見教材」是一句沒有資訊的話；「本書完整推導了 1–3，第 4 部分缺一條嵌入延拓引理，而整條鏈的地基是 Dedekind 的線性無關性」是一句有資訊的話。你現在知道，如果哪天想把這條定理補到完全嚴格，該去補哪兩塊。
:::

第 3 點裡 $[L:M] = |\mathrm{Gal}(L/M)|$ 正是 Galois 擴張定義的局部版，呼應第 2.1 章「分裂體次數 = Galois 群階」。第 4 點是字典最精緻的一格：群論的「正規子群」（第 1.3 章）恰好對應體論的「Galois 中間體」，而商群 $G/H$ 對應商擴張 $M/K$ —— 兩個世界連「取商」的操作都同步。

## 字典實例：把抽象變具體

定理抽象，例子讓它活過來。我們完整讀兩頁字典。

::: {.example name="$\mathbb{Q}(\sqrt 2, \sqrt 3)/\mathbb{Q}$ 與 Klein 四元群"}
$L = \mathbb{Q}(\sqrt 2, \sqrt 3)$，$[L:\mathbb{Q}] = 4$（習題 2.1.1）。$L$ 是 $(x^2-2)(x^2-3)$ 的分裂體、特徵 $0$ 故可分，由判準 (c) 是 Galois。自同構由 $\sqrt 2 \mapsto \pm\sqrt 2$、$\sqrt 3 \mapsto \pm\sqrt 3$ 獨立決定，共 $4$ 個 $= [L:\mathbb{Q}]$，故 $G \cong \mathbb{Z}/2 \times \mathbb{Z}/2$（Klein 四元群 $V_4$）。每個非恆等元都是 $2$ 階。

$V_4$ 的子群恰有 $5$ 個：$\{e\}$、三個 $2$ 階子群、全群。字典逐格對應：

| 子群 | 固定體 | $[\text{中間體}:\mathbb{Q}]$ |
|---|---|---|
| $\{e\}$ | $L = \mathbb{Q}(\sqrt 2,\sqrt 3)$ | $4$ |
| $\langle \sqrt 2 \mapsto -\sqrt 2\rangle$ | $\mathbb{Q}(\sqrt 3)$ | $2$ |
| $\langle \sqrt 3 \mapsto -\sqrt 3\rangle$ | $\mathbb{Q}(\sqrt 2)$ | $2$ |
| $\langle \sqrt 2,\sqrt 3 \text{ 同時變號}\rangle$ | $\mathbb{Q}(\sqrt 6)$ | $2$ |
| $V_4$ | $\mathbb{Q}$ | $1$ |

第三列值得算一次：把 $\sqrt2 \mapsto -\sqrt2$、$\sqrt3\mapsto-\sqrt3$ 的自同構作用在 $\sqrt 6 = \sqrt2\cdot\sqrt3$ 上，兩個負號相消，$\sqrt 6$ 不動 —— 所以固定體含 $\mathbb{Q}(\sqrt 6)$，再由第 3 部分的次數對應（指標 $2$）知恰好等於它。

$5$ 個子群 $\leftrightarrow$ $5$ 個中間體，包含關係完全反轉（最大的群 $V_4$ 對應最小的體 $\mathbb{Q}$）。因 $V_4$ 交換，所有子群正規，所以由第 4 部分，**每個**中間體都是 $\mathbb{Q}$ 的 Galois 擴張 —— 確實，$\mathbb{Q}(\sqrt d)/\mathbb{Q}$ 都是 Galois。
:::

::: {.example name="$x^3 - 2$ 與 $S_3$：非交換的字典"}
$L = \mathbb{Q}(\sqrt[3]{2}, \omega)$，$[L:\mathbb{Q}] = 6$（第 2.1 章）。$L$ 是 $x^3-2$ 的分裂體，故 Galois。Galois 群作用在三個根 $\{\sqrt[3]{2}, \omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}\}$ 上，這個作用忠實（根生成 $L$），給出單射 $G \hookrightarrow S_3$；因 $|G| = 6 = |S_3|$，故 $G \cong S_3$ —— 第一個**非交換**的 Galois 群。

$S_3$ 有 $6$ 個子群：$\{e\}$、三個 $2$ 階子群 $\langle\text{對換}\rangle$、一個 $3$ 階子群 $A_3 = \langle\text{三循環}\rangle$、全群。對應 $6$ 個中間體：

| 子群（階） | 固定體 | $[\,\cdot:\mathbb{Q}]$ | 正規？ |
|---|---|---|---|
| $\{e\}$ (1) | $L$ | $6$ | — |
| $\langle\tau_i\rangle$ (2)，三個 | $\mathbb{Q}(\omega^i\sqrt[3]{2})$，三個 | $3$ | 否 |
| $A_3$ (3) | $\mathbb{Q}(\omega)$ | $2$ | **是** |
| $S_3$ (6) | $\mathbb{Q}$ | $1$ | — |

關鍵在第 4 點的活用：$A_3 \trianglelefteq S_3$ 是唯一的真正規子群，對應的中間體 $\mathbb{Q}(\omega)$ 是**唯一**的 Galois 中間體（$\mathbb{Q}(\omega)/\mathbb{Q}$ 確實 Galois，因 $\mathbb{Q}(\omega)$ 含 $x^2+x+1$ 的全部根）。而三個 $\mathbb{Q}(\omega^i\sqrt[3]{2})$ 不是 Galois（各只含一個根），對應的三個 $2$ 階子群不正規 —— 群論的非正規性，精確翻譯成體論的「裝不下所有共軛根」。第 1.3 章習題 1.3.7、第 2.1 章習題 2.1.8 你預言的 $S_3$，在此處連同它的整張子群格獲得完整解析。
:::

::: {.remark name="檢查點 2.2.A"}
先自己作答再看括號。

1. $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 有 $3$ 個中間體嗎？基本定理適用嗎？（**不適用** —— 它不是 Galois 擴張，$|\mathrm{Aut}| = 1 \ne 3$。基本定理的假設不成立時，不能套結論。實際上它沒有真中間體（習題 2.1.6，次數是質數）。）
2. $\mathbb{Q}(\zeta_7)/\mathbb{Q}$ 有幾個中間體？（$4$ 個。次數 $6$，Galois 群階 $6$；下一章會證它是循環群 $\mathbb{Z}/6$，而循環群的子群個數 = $6$ 的因數個數 = $4$。注意這個答案完全來自**群論**，沒有碰任何一個具體的體。這就是字典的用法。）
3. 上一題你用了基本定理的哪一部分？（第 1 部分給「中間體個數 = 子群個數」；若要進一步知道每個中間體的次數，用第 3 部分。）
:::

## 可解性：Galois 理論的第一個勝利

Galois 發明這套理論，原本是為了回答一個古老問題：**為什麼五次以上的方程沒有求根公式？** 答案漂亮地落在字典的群論這一側。

::: {.definition}
群 $G$ **可解**（solvable），若存在子群鏈 $G = G_0 \trianglerighteq G_1 \trianglerighteq \cdots \trianglerighteq G_n = \{e\}$，每個商 $G_i/G_{i+1}$ 都是交換群。
:::

::: {.theorem name="Galois 可解性判準"}
設 $K$ 是特徵 $0$ 的體，$f \in K[x]$。則 $f$ 的根能用 $K$ 的元素經「加減乘除與開方」表示（**根式可解**）$\iff$ $f$ 的分裂體對應的 Galois 群 $\mathrm{Gal}(f)$ 是可解群。
:::

**假設**：特徵 $0$（正特徵需額外條件，本書不需要）。**用途**：本身不在 FLT 主線上；它的價值是示範字典的威力，並為第 7.2 章 Langlands–Tunnell 的「可解情形」提供直覺。**狀態**：外部黑盒（Dummit–Foote 第 14 章論根式擴張的一節）。本書不使用它推導任何後續結果。

「開方」對應「在群裡逐層剝掉交換的商」。對 $n \le 4$，一般 $n$ 次方程的 Galois 群（$S_n$ 的子群）總是可解，故有公式（二次、三次、四次求根公式）。但 $n = 5$ 時，一般五次方程的 Galois 群是 $S_5$，而 **$S_5$ 不可解** —— 因為它唯一的正規子群鏈卡在 $A_5$ 上，而 $A_5$ 是非交換的**單群**（沒有非平凡正規子群，故無法再往下剝出交換商）。於是一般五次方程沒有根式解 —— Abel 與 Galois 各自的結論，在這裡得到結構性的解釋。

（注意「一般五次方程」的意思：**存在**係數在 $\mathbb{Q}$ 的五次方程無根式解，例如 $x^5 - 6x + 3$。這不表示每個五次方程都沒有 —— $x^5 - 2$ 顯然有。）

::: {.remark name="可解性與 FLT 的若即若離"}
誠實地說：FLT 的證明**不直接**使用可解性判準，本書後續也不再引用它。講它，一是因為它是 Galois 理論最著名的應用；二是它示範了字典的威力 —— 一個關於「公式存不存在」的問題，被徹底翻譯成「群可不可解」的純代數問題。

但可解性的影子會在 FLT 之路上飄過。第 7.2 章 Wiles 用到的 **Langlands–Tunnell 定理**，處理的正是「Galois 表示的像落在某個**可解**子群裡」的情形（具體說，是像落在 $\mathrm{GL}_2(\mathbb{F}_3)$ 的某個可解子群的情況）—— 那是整個 mod 3 起手式能成立的根基。可解群在那裡不是用來判斷方程有無公式，而是用來保證某個 Galois 表示「已經是模的」。同一個概念，兩種完全不同的用法。
:::

## 通往絕對 Galois 群

把所有有限 Galois 擴張「疊起來」取極限，得到 $\overline{\mathbb{Q}}/\mathbb{Q}$ 的**絕對 Galois 群**
$$G_{\mathbb{Q}} = \mathrm{Gal}(\overline{\mathbb{Q}}/\mathbb{Q}) = \varprojlim_{L/\mathbb{Q}\ \text{有限 Galois}} \mathrm{Gal}(L/\mathbb{Q}).$$
它是無窮群（裝下所有代數數的對稱）。

::: {.theorem name="無窮 Galois 對應（Krull）"}
$G_{\mathbb{Q}}$ 帶有一個自然的拓撲（**Krull 拓撲**，由「固定某個有限擴張逐點不動」的子群作為單位元的鄰域基給出）。在這個拓撲下，$\overline{\mathbb{Q}}/\mathbb{Q}$ 的中間體與 $G_{\mathbb{Q}}$ 的**閉**子群一一對應。
:::

**假設**：需要拓撲；**「閉」不能省略** —— 對無窮 Galois 群，一般（非閉）子群**不**對應中間體，這是有限情形沒有的現象。**用途**：讓「$G_{\mathbb{Q}}$ 的子群 = 代數擴張」這句直覺有嚴格版本；第六部談「不分歧」「局部子群」時，用的都是閉子群。**狀態**：外部黑盒（Neukirch《Algebraic Number Theory》第 IV 章）。本書只在需要「連續表示」這個詞時使用它。

$G_{\mathbb{Q}}$ 是現代數論的「聖杯」—— 理解它，幾乎等於理解全部代數數論。而理解它的策略，正是本書的主線：不直接面對這個龐然大物，而是看它如何**表示**成矩陣群 $\mathrm{GL}_n$（第六部）。每一個這樣的（連續）表示 $\rho: G_{\mathbb{Q}} \to \mathrm{GL}_n$，都是 $G_{\mathbb{Q}}$ 的一張「線性側影」。橢圓曲線提供一張二維側影，模形式提供另一張，而 FLT 的證明，是證明在關鍵情形下這兩張側影重合。

## 本章地圖與下一章預告

- **Galois 群**：固定底體的自同構，忠實地作用在根上。
- **Galois 擴張**：$|\mathrm{Aut}| = [L:K]$，等價於「$L^G = K$」，也等價於「可分多項式的分裂體」。
- **兩條引理**：Dedekind 線性無關（完整證明）$\Rightarrow$ Artin 定理（骨架）$\Rightarrow$ 基本定理。
- **Galois 基本定理**：中間體 $\leftrightarrow$ 子群的一一對應，反轉包含、次數對應指標、正規對應正規。1–3 完整證明，4 給骨架。
- **字典實例**：$V_4$（$\mathbb{Q}(\sqrt2,\sqrt3)$）與 $S_3$（$x^3-2$）的完整子群-中間體對應。
- **可解性**：$S_5$ 不可解 $\Rightarrow$ 一般五次無公式；外部黑盒，不在主線。
- **絕對 Galois 群** $G_{\mathbb{Q}}$：需要 Krull 拓撲與**閉**子群；透過表示來研究。

下一章《分圓體》把這套字典用在最重要的一族擴張上：$\mathbb{Q}(\zeta_n)/\mathbb{Q}$。我們會證明它的 Galois 群嵌入 $(\mathbb{Z}/n\mathbb{Z})^\times$（這部分完整證明），並釐清「這個嵌入何時是同構」恰好等價於分圓多項式 $\Phi_n$ 的不可約性（本書對 $n = p$ 已完整證明，一般 $n$ 取用文獻）。然後一瞥 Kronecker–Weber 定理。這既是 Galois 理論的漂亮應用，也是第三部 Kummer 戰場 $\mathbb{Q}(\zeta_p)$ 的直接準備。

**2.2.1**　證明：$L/K$ 的自同構 $\sigma$ 把任何 $K$-係數多項式的根送到根。（提示：$\sigma$ 保持加法乘法且固定 $K$，作用在 $f(\alpha) = 0$ 兩邊。）

**2.2.2 ★**　驗證 $\mathbb{Q}(\sqrt 2, \sqrt 3)/\mathbb{Q}$ 的四個自同構，並確認它們構成 $V_4$（每個非恆等元 $2$ 階）。明確寫出固定 $\mathbb{Q}(\sqrt 6)$ 的那個子群。

**2.2.3 ★**　$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是 Galois。用判準 (b) 說明為什麼：算出 $\mathrm{Aut}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q})$ 的固定體，確認它是整個 $\mathbb{Q}(\sqrt[3]{2})$ 而非 $\mathbb{Q}$。

**2.2.4**　對 $x^3 - 2$ 的分裂體，明確寫出 $S_3$ 中對應「複共軛」的那個自同構（它固定 $\sqrt[3]{2}$，交換另兩根），並指出它生成哪個子群、對應哪個中間體。

**2.2.5 ★**　用 Galois 對應證明：$\mathbb{Q}(\sqrt 2, \sqrt 3)$ 恰有三個次數為 $2$ 的中間體。（不靠硬算，靠數 $V_4$ 的 $2$ 階子群。）

**2.2.6**　證明 $A_3 \trianglelefteq S_3$，並驗證 $S_3/A_3 \cong \mathbb{Z}/2$。用 Galois 基本定理第 4 點解釋這對應到 $\mathbb{Q}(\omega)/\mathbb{Q}$ 是 Galois、且 $\mathrm{Gal}(\mathbb{Q}(\omega)/\mathbb{Q}) \cong \mathbb{Z}/2$。

**2.2.7 ★（讀證明）**　重讀 Dedekind 引理的證明，回答：如果去掉「$\chi_i$ 兩兩相異」這個假設，證明在哪一步垮掉？（提示：找 $g_0$ 那一步。這說明假設不是裝飾。）

**2.2.8 ★（讀證明）**　Artin 定理的兩個不等式，各自用到了什麼？（答：$\le$ 用「解的極小性 + $G$ 是群」，$\ge$ 用 Dedekind 引理。）若 $G$ 只是自同構構成的**集合**而非群，哪個方向會失效？

**2.2.9（前瞻）**　$A_5$ 是最小的非交換單群，這是 $S_5$ 不可解的根源。用一句話說明：為什麼「單群」在 Galois 可解性中扮演「不可再分解的障礙」角色？（這與第 1.3 章 Lagrange、商群的精神一脈相承 —— 單群是群論的「質數」。）
