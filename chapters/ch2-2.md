## 開場：一部字典

這一章是第二部的高峰，也是全書的核心觀念之一。Galois 理論的成就，可以濃縮成一個詞：**字典**。它在兩個看似無關的世界之間，建立了一個精確、完美、互相翻譯的對應 ——

$$\boxed{\;\text{體擴張 } L/K \text{ 的中間體}\quad\longleftrightarrow\quad \text{Galois 群 } \mathrm{Gal}(L/K) \text{ 的子群}\;}$$

左邊是**體**的世界（連續、無窮、難以直接掌握）；右邊是**群**的世界（離散、有限、結構清晰）。Galois 基本定理說：這兩個世界透過這部字典完全對應，左邊的每一個問題都能翻譯成右邊的一個問題。研究數域的算術，於是變成研究有限群的結構 —— 這是十九世紀數學最深刻的洞見之一，二十歲的 Évariste Galois 在決鬥前夜潦草寫下它，二十五年後才被世界讀懂。

對 FLT 而言，這部字典是不可或缺的。Wiles 證明的核心對象 $\rho: \mathrm{Gal}(\overline{\mathbb{Q}}/\mathbb{Q}) \to \mathrm{GL}_2$，其定義域正是一個（無窮版的）Galois 群。要理解 Galois 群如何「作用」、如何被「表示」，必須先在有限的情形把這部字典讀通。本章就是教你讀它。

## Galois 群

回憶第 2.1 章末的觀察：分裂體的對稱性，是那些「固定底體、置換根」的自同構。把它正式化。

::: {.definition}
體擴張 $L/K$ 的**自同構群**是所有「固定 $K$ 逐點不動」的體自同構 $\sigma: L \to L$ 構成的群（運算是合成）：
$$\mathrm{Aut}(L/K) = \{\sigma: L \xrightarrow{\sim} L \text{ 體同構} \mid \sigma(a) = a\ \forall a \in K\}.$$
:::

一個自同構 $\sigma$ 必須尊重加法與乘法，又固定 $K$，所以它把任何 $K$-係數多項式的根送到根（習題 2.2.1）。於是 $\mathrm{Aut}(L/K)$ 作用在「$K$-多項式的根」這個有限集合上 —— 第 1.3 章的群作用在此具體現身。

::: {.example name="兩個基本例子"}
**$\mathbb{Q}(\sqrt 2)/\mathbb{Q}$：** 自同構必把 $\sqrt 2$ 送到 $x^2 - 2$ 的根，即 $\pm\sqrt 2$。兩種選擇各給一個自同構（恆等與「共軛」$\sqrt 2 \mapsto -\sqrt 2$），故 $\mathrm{Aut} \cong \mathbb{Z}/2\mathbb{Z}$。

**$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$：** 自同構須把 $\sqrt[3]{2}$ 送到 $x^3 - 2$ 的根。但 $\mathbb{Q}(\sqrt[3]{2})$ 是**實**體，只含一個實根 $\sqrt[3]{2}$（另兩個根 $\omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}$ 是複數，不在裡面）。所以唯一的自同構是恆等，$\mathrm{Aut}$ 是平凡群。
:::

第二個例子暴露一個問題：$[\mathbb{Q}(\sqrt[3]{2}):\mathbb{Q}] = 3$，但自同構群只有 $1$ 個元素 —— 對應「壞掉」了。原因是 $\mathbb{Q}(\sqrt[3]{2})$ 沒有裝下 $x^3 - 2$ 的**所有**根。要讓字典完美，必須要求擴張「夠大」。

## Galois 擴張：讓字典完美的條件

::: {.definition}
有限擴張 $L/K$ 稱為 **Galois 擴張**，若 $|\mathrm{Aut}(L/K)| = [L : K]$（自同構數達到最大可能）。此時記 $\mathrm{Gal}(L/K) := \mathrm{Aut}(L/K)$，稱 **Galois 群**。
:::

這個簡潔的定義等價於兩個更具幾何意味的條件同時成立（證明見標準教材，本書取用）：

- **正規性**（normal）：$L$ 是某個 $K$-多項式的分裂體 —— 即「只要裝了一個根，就裝下全部共軛根」。$\mathbb{Q}(\sqrt[3]{2})$ 不正規（裝了實根卻漏掉複根），這正是它失敗的原因。
- **可分性**（separable）：最小多項式沒有重根。在特徵 $0$（如 $\mathbb{Q}$）或有限體上，這自動成立，本書幾乎不必操心。

於是對我們關心的數域，「Galois」實質上就是「分裂體」。$x^3 - 2$ 的分裂體 $L = \mathbb{Q}(\sqrt[3]{2}, \omega)$ 是 Galois 的，而 $\mathbb{Q}(\sqrt[3]{2})$ 不是。

::: {.theorem name="Galois 擴張的判準"}
$L/K$ 有限。則 $L/K$ Galois $\iff$ $L$ 是某個可分多項式的分裂體 $\iff$ $L^{\mathrm{Aut}(L/K)} = K$（被整個自同構群固定的元素恰好是 $K$）。
:::

最後那個條件 $L^G = K$ 特別有用：它說 Galois 擴張裡，「除了 $K$ 的元素，沒有別的東西被所有對稱固定」。對稱足夠豐富，豐富到能用「不變量」精確地刻畫底體。

## 固定體與 Galois 基本定理

字典的兩個方向，由兩個自然構造給出。

**從群到體（取固定體）：** 給 Galois 群的子群 $H \le \mathrm{Gal}(L/K)$，定義它的**固定體**
$$L^H = \{a \in L : \sigma(a) = a\ \forall \sigma \in H\}.$$
它是 $K$ 與 $L$ 之間的一個中間體。

**從體到群（取自同構）：** 給中間體 $M$（$K \subseteq M \subseteq L$），對應子群 $\mathrm{Gal}(L/M) \le \mathrm{Gal}(L/K)$（固定 $M$ 的那些自同構）。

Galois 基本定理斷言這兩個方向互為逆，且性質完美匹配。

::: {.theorem name="Galois 基本定理"}
設 $L/K$ 為 Galois 擴張，$G = \mathrm{Gal}(L/K)$。則：

1. **一一對應**：「中間體 $M$」與「子群 $H$」之間，$M \mapsto \mathrm{Gal}(L/M)$ 與 $H \mapsto L^H$ 互為逆雙射。
2. **反轉包含**：$M_1 \subseteq M_2 \iff \mathrm{Gal}(L/M_1) \supseteq \mathrm{Gal}(L/M_2)$。越大的體對應越小的群。
3. **次數對應指標**：$[L : M] = |\mathrm{Gal}(L/M)|$，$[M : K] = [G : \mathrm{Gal}(L/M)]$。
4. **正規對應正規**：中間體 $M/K$ 是 Galois 擴張 $\iff$ $\mathrm{Gal}(L/M)$ 是 $G$ 的正規子群；此時 $\mathrm{Gal}(M/K) \cong G/\mathrm{Gal}(L/M)$。
:::

證明需要幾個引理（Artin 定理、本原元定理），完整版見標準教材；本書著重它的**使用**。第 3 點裡 $[L:M] = |\mathrm{Gal}(L/M)|$ 正是 Galois 擴張定義的局部版，呼應第 2.1 章「分裂體次數 = Galois 群階」。第 4 點是字典最精緻的一格：群論的「正規子群」（第 1.3 章）恰好對應體論的「Galois 中間體」，而商群 $G/H$ 對應商擴張 $M/K$ —— 兩個世界連「取商」的操作都同步。

## 字典實例：把抽象變具體

定理抽象，例子讓它活過來。我們完整讀兩頁字典。

::: {.example name="$\mathbb{Q}(\sqrt 2, \sqrt 3)/\mathbb{Q}$ 與 Klein 四元群"}
$L = \mathbb{Q}(\sqrt 2, \sqrt 3)$，$[L:\mathbb{Q}] = 4$。自同構由 $\sqrt 2 \mapsto \pm\sqrt 2$、$\sqrt 3 \mapsto \pm\sqrt 3$ 獨立決定，共 $4$ 個，故 $L/\mathbb{Q}$ Galois，$G \cong \mathbb{Z}/2 \times \mathbb{Z}/2$（Klein 四元群 $V_4$）。每個非恆等元都是 $2$ 階。

$V_4$ 的子群恰有 $5$ 個：$\{e\}$、三個 $2$ 階子群、全群。字典逐格對應：

| 子群 | 固定體 | $[\text{中間體}:\mathbb{Q}]$ |
|---|---|---|
| $\{e\}$ | $L = \mathbb{Q}(\sqrt 2,\sqrt 3)$ | $4$ |
| $\langle \sqrt 2 \mapsto -\sqrt 2\rangle$ | $\mathbb{Q}(\sqrt 3)$ | $2$ |
| $\langle \sqrt 3 \mapsto -\sqrt 3\rangle$ | $\mathbb{Q}(\sqrt 2)$ | $2$ |
| $\langle \sqrt 2,\sqrt 3 \text{ 同時變號}\rangle$ | $\mathbb{Q}(\sqrt 6)$ | $2$ |
| $V_4$ | $\mathbb{Q}$ | $1$ |

$5$ 個子群 ↔ $5$ 個中間體，包含關係完全反轉（最大的群 $V_4$ 對應最小的體 $\mathbb{Q}$）。因 $V_4$ 交換，所有子群正規，所以**每個**中間體都是 $\mathbb{Q}$ 的 Galois 擴張 —— 確實，$\mathbb{Q}(\sqrt d)/\mathbb{Q}$ 都是 Galois。
:::

::: {.example name="$x^3 - 2$ 與 $S_3$：非交換的字典"}
$L = \mathbb{Q}(\sqrt[3]{2}, \omega)$，$[L:\mathbb{Q}] = 6$（第 2.1 章）。Galois 群作用在三個根 $\{\sqrt[3]{2}, \omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}\}$ 上，可實現全部 $6$ 種置換，故 $G \cong S_3$ —— 第一個**非交換**的 Galois 群。

$S_3$ 有 $6$ 個子群：$\{e\}$、三個 $2$ 階子群 $\langle\text{對換}\rangle$、一個 $3$ 階子群 $A_3 = \langle\text{三循環}\rangle$、全群。對應 $6$ 個中間體：

| 子群（階） | 固定體 | $[\,\cdot:\mathbb{Q}]$ | 正規？ |
|---|---|---|---|
| $\{e\}$ (1) | $L$ | $6$ | — |
| $\langle\tau_i\rangle$ (2)，三個 | $\mathbb{Q}(\omega^i\sqrt[3]{2})$，三個 | $3$ | 否 |
| $A_3$ (3) | $\mathbb{Q}(\omega)$ | $2$ | **是** |
| $S_3$ (6) | $\mathbb{Q}$ | $1$ | — |

關鍵在第 4 點的活用：$A_3 \trianglelefteq S_3$ 是唯一的真正規子群，對應的中間體 $\mathbb{Q}(\omega)$ 是**唯一**的 Galois 中間體（$\mathbb{Q}(\omega)/\mathbb{Q}$ 確實 Galois，因 $\mathbb{Q}(\omega)$ 含 $x^2+x+1$ 的全部根）。而三個 $\mathbb{Q}(\omega^i\sqrt[3]{2})$ 不是 Galois（各只含一個根），對應的三個 $2$ 階子群不正規 —— 群論的非正規性，精確翻譯成體論的「裝不下所有共軛根」。第 1.3 章習題 1.3.7、第 2.1 章習題 2.1.7 你預言的 $S_3$，在此處連同它的整張子群格獲得完整解析。
:::

## 可解性：Galois 理論的第一個勝利

Galois 發明這套理論，原本是為了回答一個古老問題：**為什麼五次以上的方程沒有求根公式？** 答案漂亮地落在字典的群論這一側。

::: {.definition}
群 $G$ **可解**（solvable），若存在子群鏈 $G = G_0 \trianglerighteq G_1 \trianglerighteq \cdots \trianglerighteq G_n = \{e\}$，每個商 $G_i/G_{i+1}$ 都是交換群。
:::

::: {.theorem name="Galois 可解性判準"}
多項式 $f$ 的根能用「加減乘除與開方」表示（根式可解）$\iff$ 其 Galois 群 $\mathrm{Gal}(f)$ 是可解群。
:::

「開方」對應「在群裡逐層剝掉交換的商」。對 $n \le 4$，對應的 Galois 群（$S_n$ 的子群）總是可解，故有公式（二次、三次、四次求根公式）。但 $n = 5$ 時，一般五次方程的 Galois 群是 $S_5$，而 **$S_5$ 不可解**（它的子群鏈卡在非交換的單群 $A_5$ 上）。於是五次方程沒有一般根式解 —— Abel 與 Galois 各自的結論，在這裡得到結構性的解釋。

::: {.remark name="可解性與 FLT 的若即若離"}
誠實地說：FLT 的證明**不直接**使用可解性判準。我們講它，一是因為它是 Galois 理論最著名的應用、不講可惜；二是它示範了字典的威力 —— 一個關於「公式存不存在」的分析問題，被徹底翻譯成「群可不可解」的純代數問題。

但可解性的某些影子，會在 FLT 之路上飄過。第 7.2 章 Wiles 用到的 **Langlands–Tunnell 定理**，正是處理「Galois 群的像是可解群」的情形（具體說，是像落在 $\mathrm{GL}_2(\mathbb{F}_3)$ 裡某個可解子群的情況）—— 那是整個 mod 3 起手式能成立的根基。可解群在那裡不是用來判斷方程，而是用來保證某個 Galois 表示「已經是模的」。所以本節的概念，會在最意想不到的地方、以最意想不到的方式，成為登頂的一塊踏腳石。字典一旦學會，到處都用得上。
:::

## 通往絕對 Galois 群

把所有有限 Galois 擴張「疊起來」，取極限，得到 $\overline{\mathbb{Q}}/\mathbb{Q}$ 的**絕對 Galois 群**
$$G_{\mathbb{Q}} = \mathrm{Gal}(\overline{\mathbb{Q}}/\mathbb{Q}).$$
它是無窮群（裝下所有代數數的對稱），但 Galois 基本定理的精神延續：它的（閉）子群仍與 $\mathbb{Q}$ 的代數擴張一一對應。$G_{\mathbb{Q}}$ 是現代數論的「聖杯」—— 理解它，幾乎等於理解全部代數數論。

而理解它的策略，正是本書的主線：不直接面對這個龐然大物，而是看它如何**表示**成矩陣群 $\mathrm{GL}_n$（第六部）。每一個這樣的表示 $\rho: G_{\mathbb{Q}} \to \mathrm{GL}_n$，都是 $G_{\mathbb{Q}}$ 的一張「線性側影」。橢圓曲線提供一張二維側影，模形式提供另一張，而 FLT 的證明，是證明在關鍵情形下這兩張側影重合。本章讓你第一次嚴格地擁有「Galois 群」這個概念 —— 從此 $G_{\mathbb{Q}}$ 不再是神祕符號，而是一個你知道如何作用、如何取子群、如何（將來）表示的具體對象。

## 本章地圖與下一章預告

- **Galois 群**：固定底體的自同構，作用在根上。
- **Galois 擴張**：$|\mathrm{Aut}| = [L:K]$，等價於「正規（分裂體）+ 可分」。
- **Galois 基本定理**：中間體 ↔ 子群的一一對應，反轉包含、次數對應指標、正規對應正規。
- **字典實例**：$V_4$（$\mathbb{Q}(\sqrt2,\sqrt3)$）與 $S_3$（$x^3-2$）的完整子群-中間體對應。
- **可解性**：$S_5$ 不可解 ⇒ 五次無公式；其影子將出現在 Langlands–Tunnell。
- **絕對 Galois 群** $G_{\mathbb{Q}}$：聖杯，透過表示來研究。

下一章《分圓體》把這套字典用在最重要的一族擴張上：$\mathbb{Q}(\zeta_n)/\mathbb{Q}$。我們會證明它的 Galois 群恰是 $(\mathbb{Z}/n\mathbb{Z})^\times$（第 1.3 章預告過），並一瞥 Kronecker–Weber 定理 —— 所有「交換的」$\mathbb{Q}$ 擴張都藏在分圓體裡。這既是 Galois 理論的漂亮應用，也是第三部 Kummer 戰場 $\mathbb{Q}(\zeta_p)$ 的直接準備：要研究 $\mathbb{Z}[\zeta_p]$ 的算術，得先掌握 $\mathbb{Q}(\zeta_p)$ 的對稱。

## 習題

**2.2.1**　證明：$L/K$ 的自同構 $\sigma$ 把任何 $K$-係數多項式的根送到根。（提示：$\sigma$ 保持加法乘法且固定 $K$，作用在 $f(\alpha) = 0$ 兩邊。）

**2.2.2 ★**　驗證 $\mathbb{Q}(\sqrt 2, \sqrt 3)/\mathbb{Q}$ 的四個自同構，並確認它們構成 $V_4$（每個非恆等元 $2$ 階）。明確寫出固定 $\mathbb{Q}(\sqrt 6)$ 的那個子群。

**2.2.3 ★**　$\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ 不是 Galois。用「$L^{\mathrm{Aut}} = K$ 才 Galois」的判準說明為什麼：算出 $\mathrm{Aut}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q})$ 的固定體，看它是否等於 $\mathbb{Q}(\sqrt[3]{2})$ 而非 $\mathbb{Q}$。

**2.2.4**　對 $x^3 - 2$ 的分裂體，明確寫出 $S_3$ 中對應「複共軛」的那個自同構（它固定 $\sqrt[3]{2}$，交換另兩根），並指出它生成哪個子群、對應哪個中間體。

**2.2.5 ★**　用 Galois 對應證明：$\mathbb{Q}(\sqrt 2, \sqrt 3)$ 恰有三個次數為 $2$ 的中間體。（不靠硬算，靠數 $V_4$ 的 $2$ 階子群。）

**2.2.6**　證明 $A_3 \trianglelefteq S_3$，並驗證 $S_3/A_3 \cong \mathbb{Z}/2$。用 Galois 基本定理第 4 點解釋這對應到 $\mathbb{Q}(\omega)/\mathbb{Q}$ 是 Galois、且 $\mathrm{Gal}(\mathbb{Q}(\omega)/\mathbb{Q}) \cong \mathbb{Z}/2$。

**2.2.7（前瞻）**　$A_5$ 是最小的非交換單群（無真正規子群），這是 $S_5$ 不可解的根源。查閱並用一句話說明：為什麼「單群」在 Galois 可解性中扮演「不可再分解的障礙」角色？（這與第 1.3 章 Lagrange、商群的精神一脈相承 —— 單群是群論的「質數」。）
