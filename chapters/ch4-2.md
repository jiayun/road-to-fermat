## 開場：兩件通往主角的工具

上一章建立了全純函數與它的剛性。這一章深化兩個主題，它們各自直通第五部的一位主角。

第一是**解析延拓** —— 把全純函數從一個小區域唯一地擴張到更大的範圍。它是「L 函數」得以定義的機制：橢圓曲線與模形式各自的 L 函數，最初只在某個半平面收斂，必須靠解析延拓才能談論它們在 $s = 1$ 附近的行為（BSD 猜想、谷山–志村的核心）。

第二是 **Weierstrass $\wp$ 函數** —— 一個雙週期的全純函數。它將完成第四部最重要的揭示：**橢圓曲線在 $\mathbb{C}$ 上，就是一個複環面 $\mathbb{C}/\Lambda$**。第 3.3 章 Minkowski 用過的「格」（lattice），將在這裡與橢圓曲線相認。這個「環面 = 曲線」的對應，是橢圓曲線一切深刻性質的幾何源頭，也是第五部的起點。

## 解析延拓

::: {.definition}
設 $f$ 在區域 $U$ 上全純，$g$ 在更大的區域 $V \supseteq U$ 上全純，且 $g|_U = f$。則稱 $g$ 是 $f$ 的**解析延拓**。
:::

由上一章的恆等定理，解析延拓**若存在則唯一** —— 兩個在 $U$ 上相等的全純函數，在它們共同的定義域上處處相等。這個唯一性是解析延拓威力的根源：一個函數在小區域的行為，已經唯一決定了它在所有能延拓到的地方的行為。

::: {.example name="幾何級數的延拓"}
$f(z) = \sum_{n \ge 0} z^n$ 只在 $|z| < 1$ 收斂。但它在那裡等於 $\frac{1}{1-z}$，而後者在整個 $\mathbb{C} \setminus \{1\}$ 上全純。所以 $\frac{1}{1-z}$ 是 $f$ 的解析延拓 —— 級數「看不見」的地方，閉形式看得見。原級數在 $|z| \ge 1$ 發散，但被延拓的函數在那裡有完全確定的值。
:::

::: {.remark name="zeta 函數與 L 函數"}
最重要的例子是 Riemann zeta 函數 $\zeta(s) = \sum_{n \ge 1} n^{-s}$。這個級數只在 $\mathrm{Re}(s) > 1$ 收斂，但它可以唯一地解析延拓到整個複平面（除 $s = 1$ 的單極點）。延拓後，原本「發散」的表達式獲得確定的值 —— 著名的 $\zeta(-1) = -\frac{1}{12}$（第 3.4 章 Bernoulli 數正是這些特殊值）就是這樣來的，它不是「$1 + 2 + 3 + \cdots = -\frac{1}{12}$」的字面意思，而是解析延拓後函數在 $s = -1$ 的值。

這對 FLT 之路至關重要。橢圓曲線的 L 函數 $L(E, s) = \prod_p (\text{局部因子})$ 和模形式的 L 函數，最初都只在某半平面收斂。BSD 猜想（第五部）談的是 $L(E, s)$ 在 $s = 1$ 的行為 —— 而 $s = 1$ 恰在原始收斂範圍之外，必須先解析延拓才能談論。**而「橢圓曲線的 L 函數能延拓」這件事本身，在 Wiles 之前並不知道對所有橢圓曲線成立 —— 它正是谷山–志村猜想的推論之一**。模性保證了延拓的存在：因為模形式的 L 函數已知能延拓，一旦證明 $E$ 是模的，$L(E,s)$ 的延拓就自動成立。解析延拓在這裡不是技術細節，而是「為什麼模性如此重要」的答案之一。
:::

## 雙週期函數與格

現在轉向第二個主題。回憶第 0.5 章：$e^{i\theta}$ 是週期函數（週期 $2\pi$）。如果一個函數有**兩個**獨立的複週期，會發生什麼？

::: {.definition}
$\mathbb{C}$ 中的**格**（lattice）是 $\Lambda = \mathbb{Z}\omega_1 + \mathbb{Z}\omega_2$，其中 $\omega_1, \omega_2$ 線性無關（$\omega_1/\omega_2 \notin \mathbb{R}$）。函數 $f$ 稱**橢圓函數**（相對於 $\Lambda$），若它全純（除極點外）且雙週期：$f(z + \omega) = f(z)$ 對所有 $\omega \in \Lambda$。
:::

格 $\Lambda$ 把複平面鋪成無數個平行四邊形（基本胞腔）。雙週期函數在每個胞腔裡長得一模一樣，所以它真正的定義域是**商空間** $\mathbb{C}/\Lambda$ —— 把基本平行四邊形的對邊黏起來，得到一個**環面**（甜甜圈面）。

::: {.remark name="格：離散與連續的橋，再次出現"}
第 3.3 章 Minkowski 用「格」研究數域的算術（理想嵌入 $\mathbb{R}^n$ 成格）。現在格以另一種身分回歸：$\mathbb{C}$ 中的格給出環面 $\mathbb{C}/\Lambda$。同一個幾何對象（格），在數論裡量類數，在複分析裡造環面 —— 它確實是「連接離散與連續的橋」，我在第 3.3 章預告過它會回來，現在它帶著橢圓曲線回來了。
:::

## Weierstrass $\wp$ 函數

要造出非平凡的橢圓函數，Weierstrass 給了一個明確構造。

::: {.definition}
**Weierstrass $\wp$ 函數**：
$$\wp(z) = \frac{1}{z^2} + \sum_{\omega \in \Lambda \setminus \{0\}}\left(\frac{1}{(z - \omega)^2} - \frac{1}{\omega^2}\right).$$
:::

它在每個格點處有二階極點，雙週期，是「最基本的」橢圓函數。它的導數 $\wp'(z)$ 也是橢圓函數。而它們之間滿足一條決定性的關係：

::: {.theorem name="$\wp$ 的微分方程"}
$$\wp'(z)^2 = 4\wp(z)^3 - g_2\,\wp(z) - g_3,$$
其中 $g_2 = 60\sum_{\omega \ne 0}\omega^{-4}$，$g_3 = 140\sum_{\omega \ne 0}\omega^{-6}$（由格 $\Lambda$ 決定的常數，稱 Eisenstein 級數）。
:::

::: {.proof}
（梗概）$\wp$ 與 $\wp'$ 在原點的 Laurent 展開可以直接計算。構造 $\wp'^2 - 4\wp^3 + g_2\wp + g_3$，驗證它在原點的主部全部抵消，故它是一個**無極點**的橢圓函數 —— 由 Liouville 型定理（橢圓函數無極點必為常數），它是常數，再驗證常數項為零。
:::

數值驗證確認了這個方程：取方格 $\Lambda = \mathbb{Z} + \mathbb{Z}i$，算出 $g_2 \approx 189.07$、$g_3 \approx 0$（方格的對稱使 $g_3 = 0$），在任意點 $z$ 計算 $\wp'(z)^2$ 與 $4\wp(z)^3 - g_2\wp(z) - g_3$，兩者相符。

## 揭示：環面就是橢圓曲線

盯著那條微分方程
$$\wp'^2 = 4\wp^3 - g_2\wp - g_3.$$
令 $x = \wp(z)$、$y = \wp'(z)$。則 $(x, y)$ 滿足
$$y^2 = 4x^3 - g_2 x - g_3$$
—— 這是一條**橢圓曲線**的方程（第 5.1 章會把它標準化成 $y^2 = x^3 + ax + b$）！於是映射
$$\mathbb{C}/\Lambda \longrightarrow E, \qquad z \mapsto (\wp(z), \wp'(z))$$
把環面 $\mathbb{C}/\Lambda$ 送到橢圓曲線 $E$ 上。

::: {.theorem name="複環面 = 橢圓曲線"}
映射 $z \mapsto (\wp(z), \wp'(z))$（補上 $z = 0 \mapsto$ 無窮遠點）是 $\mathbb{C}/\Lambda$ 與橢圓曲線 $E: y^2 = 4x^3 - g_2 x - g_3$ 之間的**雙全純同構**（且保持群結構）。
:::

::: {.remark name="這是第五部的全部起點"}
這個定理是第四部的頂點，也是橢圓曲線理論的基石。它說：一條複數橢圓曲線，骨子裡就是一個環面 $\mathbb{C}/\Lambda$。這個身分揭示帶來三個深遠後果，全是第五部的核心：

**其一，群結構的來源。** 環面 $\mathbb{C}/\Lambda$ 顯然是一個群（複數加法模格）。透過 $\wp$ 同構，橢圓曲線**繼承**了這個群結構 —— 這就是第 0.3 章預告的「橢圓曲線上的點可以相加」的真正來源。$\mathbb{C}/\Lambda$ 上的加法 $z_1 + z_2$，對應到曲線上著名的「弦切加法」（第 5.1 章）。第 0.3 章那條「過兩點的直線交曲線於第三點」的幾何規則，其代數本質就是環面上的加法。

**其二，撓點的結構。** 環面上滿足 $nz \equiv 0 \pmod \Lambda$ 的點（$n$-撓點），恰好是 $\frac{1}{n}\Lambda / \Lambda$，構成 $(\mathbb{Z}/n\mathbb{Z})^2$ —— 一個**二維**的結構！第 1.1 章反覆強調的「維度 = 2」、$\mathrm{GL}_2$ 的由來，根就在這裡：撓點是二維的，所以 Galois 群作用在它上面給出 $2 \times 2$ 矩陣（第 6.2 章）。環面的雙週期性，直接生出了那個關鍵的 $2$。

**其三，模形式的舞台。** 一個格 $\Lambda$ 決定一條橢圓曲線；而「所有格的空間」（模掉伸縮與旋轉）正是模形式生活的上半平面 $\mathbb{H}$（第 5.4 章）。$g_2, g_3$ 作為格的函數，本身就是最早的模形式（Eisenstein 級數，第 1.5 章習題已見過 $E_4$）。於是橢圓曲線（單個格）與模形式（格的空間上的函數）透過 $\wp$ 共享同一個幾何源頭 —— 它們的深刻聯繫（谷山–志村）並非偶然，而是植根於「格」這個共同的母體。
:::

## 本章地圖與下一章預告

- **解析延拓**：唯一擴張全純函數；zeta 與 L 函數的定義機制；模性保證 L 函數可延拓。
- **格與橢圓函數**：雙週期函數活在環面 $\mathbb{C}/\Lambda$ 上；格再次作為離散–連續的橋。
- **Weierstrass $\wp$**：明確的橢圓函數；滿足 $\wp'^2 = 4\wp^3 - g_2\wp - g_3$。
- **環面 = 橢圓曲線**：$z \mapsto (\wp, \wp')$；群結構、二維撓點、模形式舞台的共同源頭。

下一章《代數曲線》從另一個角度逼近橢圓曲線：不是複分析的環面，而是**代數幾何**的曲線。我們會引入射影平面、平滑性、虧格（genus）—— 一條曲線的「洞數」這個拓撲不變量。關鍵事實是：橢圓曲線的虧格是 $1$（環面有一個洞），而這個「$1$」正是它既不像直線（虧格 $0$，有理點要多少有多少）、也不像高虧格曲線（虧格 $\ge 2$，有理點有限，Faltings 定理）的根本原因。FLT 對應的費馬曲線 $x^n + y^n = z^n$ 在 $n \ge 4$ 時虧格 $\ge 2$ —— 那是它有理點稀少（乃至 FLT 成立）的幾何解釋。虧格，是理解「為什麼 $n = 2$ 解無窮多、$n \ge 3$ 解稀少」的最終答案。

## 習題

**4.2.1**　驗證幾何級數延拓：$\sum z^n$ 在 $|z| < 1$ 等於 $\frac{1}{1-z}$，說明後者是前者到 $\mathbb{C} \setminus \{1\}$ 的唯一解析延拓。

**4.2.2 ★**　證明：非常數橢圓函數必有極點。（提示：若無極點，它在基本胞腔上全純有界，故在整個 $\mathbb{C}$ 上有界，由 Liouville 定理為常數。這是上一章 Liouville 的橢圓版應用。）

**4.2.3**　驗證 $\wp(z)$ 是偶函數（$\wp(-z) = \wp(z)$），$\wp'(z)$ 是奇函數。（直接從定義的對稱性。）

**4.2.4 ★**　從 $\wp$ 的微分方程 $\wp'^2 = 4\wp^3 - g_2\wp - g_3$，令 $x = \wp, y = \wp'$，寫出橢圓曲線方程。再用變數代換 $x \mapsto x/4$ 之類，把它化成 $y^2 = x^3 + ax + b$ 的標準形（第 5.1 章的 Weierstrass 形）。

**4.2.5**　$n$-撓點 $\{z : nz \in \Lambda\}/\Lambda$ 是 $\frac1n\Lambda/\Lambda$。證明它同構於 $(\mathbb{Z}/n\mathbb{Z})^2$，特別地有 $n^2$ 個元素。（這個「$n^2$」與「二維」是第六部 Galois 表示的幾何基礎。）

**4.2.6（前瞻）**　$g_2(\Lambda), g_3(\Lambda)$ 隨格 $\Lambda$ 變化。證明它們是「權重齊次」的：$g_2(\lambda\Lambda) = \lambda^{-4}g_2(\Lambda)$，$g_3(\lambda\Lambda) = \lambda^{-6}g_3(\Lambda)$。（這個「權 $4$」「權 $6$」正是模形式「權重」的起源 —— $g_2, g_3$ 是權 $4, 6$ 的模形式。你正在觸碰模形式的定義。）
