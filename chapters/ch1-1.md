## 開場：從零搭起矩陣的舞台

本章**不假設你學過線性代數**。我們從「可以相加、也可以乘上一個數的東西」開始，逐步定義向量空間、基底、線性映射與矩陣。後面看到的每個矩陣，都應該能沿著這條路還原成一個具體動作。

**依賴箭頭：** 第 0.2 章的模算術 + 第 0.5 章的複數
$\longrightarrow$ 體 $\longrightarrow$ 向量空間 $\longrightarrow$ 基底與座標
$\longrightarrow$ 線性映射 $\longrightarrow$ 矩陣 $\longrightarrow \mathrm{GL}_2$ 與表示。

全書從本章起採用五種結果標籤：**【完整證明】**表示本書已補齊每一步；**【特殊情形】**表示只證了明說的範圍；**【證明略圖】**只交代主幹；**【直覺】**只幫助想像，不能當證明；**【接受的黑箱】**表示暫時使用、但本書此處不證。定義不是待證命題，因此不掛結果標籤。

為什麼 FLT 的路需要這些語言？後面會有群作用在橢圓曲線的撓點上；選定基底後，每個作用會變成一個 $2\times2$ 可逆矩陣。這只是**路線預告**，不是本章已證的研究定理。

## 先定義純量：什麼是體

向量要能乘上「純量」。純量不能隨便選；為了能解線性方程，我們希望除以非零純量永遠可行。

::: {.definition name="體"}
一個**體** $F$ 是一個有加法與乘法的集合，滿足：

1. 加法可結合、可交換，有 $0$，且每個 $a$ 有加法逆元 $-a$；
2. 乘法可結合、可交換，有 $1\ne0$，且每個 $a\ne0$ 有乘法逆元 $a^{-1}$；
3. 分配律 $a(b+c)=ab+ac$ 成立。

也就是說，在 $F$ 中可以做加、減、乘，並可除以任何非零元素。
:::

$\mathbb Q,\mathbb R,\mathbb C$ 都是體；$\mathbb Z$ 不是，因為例如 $2$ 在整數中沒有乘法逆元。第 0.2 章的工具還立刻給出有限體：

::: {.proposition name="【完整證明／特殊情形】質數模算術形成體"}
若 $p$ 是質數，餘數類 $\mathbb F_p=\{0,1,\ldots,p-1\}$ 配上模 $p$ 加法與乘法，是一個體。
:::

::: {.proof}
加法與乘法的結合、交換、分配規則都由整數運算取模後保留。唯一需補的是非零元可逆：若 $a\not\equiv0\pmod p$，則 $\gcd(a,p)=1$；第 0.2 章 Bézout 等式給 $ax+py=1$，所以 $ax\equiv1\pmod p$。因此 $x$ 是 $a$ 的逆元。
:::

最小的例子是
$$\mathbb F_2=\{0,1\},$$
加法與乘法都把答案除以 $2$ 取餘數，所以 $1+1=0$。第 1.4 章會把同一事實放進環與商環的完整脈絡。

::: {.example name="【完整證明】在 $\mathbb F_2$ 解方程"}
$x+1=0$ 的解是 $x=1$，因為在 $\mathbb F_2$ 中 $1+1=0$。這提醒我們：線性代數不只在實數上運作；純量體改變，計算規則也跟著改變。
:::

**檢查點 1.1.A**　為什麼 $\mathbb Z$ 不是體？為什麼 $\mathbb Q$ 是？若答案能明確提到「非零元素的乘法逆元」，就可以往下。

## 向量空間：可加、可縮放的世界

::: {.definition name="向量空間"}
設 $F$ 是體。$F$ 上的**向量空間** $V$ 是一個集合，帶有向量加法 $u+v$ 與純量乘法 $cv$，並對 $u,v,w\in V$、$a,b\in F$ 滿足：

- $u+v=v+u$，且 $(u+v)+w=u+(v+w)$；
- 有零向量 $0_V$ 使 $v+0_V=v$，每個 $v$ 有 $-v$ 使 $v+(-v)=0_V$；
- $a(u+v)=au+av$，$(a+b)v=av+bv$；
- $(ab)v=a(bv)$，且 $1v=v$。

$V$ 的元素叫**向量**，$F$ 的元素叫**純量**。
:::

最熟悉的例子是 $F^2$：向量寫成直欄
$$\begin{pmatrix}x\\y\end{pmatrix},$$
逐項相加與乘純量。直欄不是裝飾，而是本書固定的**欄向量慣例**。

::: {.example name="【完整證明】向量運算"}
在 $\mathbb R^2$ 中，
$$2\begin{pmatrix}1\\-1\end{pmatrix}
+3\begin{pmatrix}0\\2\end{pmatrix}
=\begin{pmatrix}2\\4\end{pmatrix}.$$
在 $\mathbb F_2^2$ 中，同一個形式要模 $2$ 計算：
$$\begin{pmatrix}1\\1\end{pmatrix}
+\begin{pmatrix}1\\0\end{pmatrix}
=\begin{pmatrix}0\\1\end{pmatrix}.$$
:::

只取一部分向量，有時仍保留全部規則。

::: {.definition name="子空間"}
子集 $W\subseteq V$ 稱為**子空間**，若 $0_V\in W$，且 $u,v\in W$、$c\in F$ 時都有 $u+v\in W$ 與 $cv\in W$。
:::

例如 $\mathbb R^2$ 中過原點的直線 $W=\{(t,2t)^{\mathsf T}:t\in\mathbb R\}$ 是子空間；不過原點的直線 $y=2x+1$ 不是，因為它不含零向量。

## 線性組合、生成、無關、基底

::: {.definition name="線性組合與生成"}
$v_1,\ldots,v_k$ 的**線性組合**是
$$c_1v_1+\cdots+c_kv_k\qquad(c_i\in F).$$
所有這些線性組合形成的集合稱為它們的**生成空間**，記作
$\operatorname{span}(v_1,\ldots,v_k)$。
:::

::: {.definition name="線性無關、基底、維度"}
若
$$c_1v_1+\cdots+c_kv_k=0_V$$
只可能在 $c_1=\cdots=c_k=0$ 時成立，就稱 $v_1,\ldots,v_k$ **線性無關**。若它們線性無關，又生成整個 $V$，就稱它們是一組**基底**。

有限維向量空間任一基底的向量個數稱為**維度**，記作 $\dim_FV$。
:::

::: {.example name="【完整證明】標準基底與座標"}
在 $\mathbb R^2$ 中令
$$e_1=\begin{pmatrix}1\\0\end{pmatrix},\qquad
e_2=\begin{pmatrix}0\\1\end{pmatrix}.$$
每個 $v=(x,y)^{\mathsf T}$ 都唯一寫成 $xe_1+ye_2$，所以 $(e_1,e_2)$ 是基底，$\dim_{\mathbb R}\mathbb R^2=2$；$v$ 在這組基底的座標欄就是 $[v]=\begin{pmatrix}x\\y\end{pmatrix}$。

另一方面，$(1,0)^{\mathsf T}$ 與 $(2,0)^{\mathsf T}$ 線性相關，因為
$2(1,0)^{\mathsf T}-(2,0)^{\mathsf T}=0$ 有非零係數。
:::

同一集合的維度會依純量體改變：$\mathbb C$ 作為 $\mathbb C$-向量空間以 $(1)$ 為基底，維度是 $1$；作為 $\mathbb R$-向量空間以 $(1,i)$ 為基底，維度是 $2$。

::: {.theorem name="【接受的黑箱】有限維空間的基底事實"}
在有限維向量空間中：

1. 任兩組基底的向量個數相同；
2. 任一線性無關組可擴充成基底；
3. 任一生成組可刪減成基底。
:::

這三句可由「交換引理」用有限次消元證明。為了不把入口淹沒在索引裡，本章把它們明列為接受的黑箱；後面的「維度」與「擴充基底」都只在這個標籤下使用，沒有假裝已證明。

**檢查點 1.1.B**　對一組基底，為什麼每個向量的座標不只存在而且唯一？提示：兩種表示相減後，用線性無關。

## 線性映射與矩陣：欄是基底向量的像

::: {.definition name="線性映射"}
設 $V,W$ 是同一體 $F$ 上的向量空間。映射 $T:V\to W$ 稱為**線性**，若
$$T(u+v)=T(u)+T(v),\qquad T(cv)=cT(v)$$
對所有 $u,v\in V$、$c\in F$ 成立。
:::

::: {.example name="【完整證明】從映射讀出矩陣"}
令 $T:\mathbb R^2\to\mathbb R^2$，
$$T\begin{pmatrix}x\\y\end{pmatrix}
=\begin{pmatrix}x+2y\\3x-y\end{pmatrix}.$$
直接代入可驗證 $T$ 保持加法與純量乘法，所以它線性。對標準基底計算：
$$T(e_1)=\begin{pmatrix}1\\3\end{pmatrix},\qquad
T(e_2)=\begin{pmatrix}2\\-1\end{pmatrix}.$$
因此矩陣是
$$A=\begin{pmatrix}1&2\\3&-1\end{pmatrix}.$$
請注意：$T(e_j)$ 的座標放在矩陣的**第 $j$ 欄**，不是第 $j$ 行。於是
$$A\begin{pmatrix}x\\y\end{pmatrix}
=xT(e_1)+yT(e_2)
=\begin{pmatrix}x+2y\\3x-y\end{pmatrix}.$$
:::

一般地，若 $B=(v_1,\ldots,v_n)$ 是 $V$ 的有序基底，$C$ 是 $W$ 的有序基底，則 $T$ 的矩陣 $[T]_{C\leftarrow B}$ 的第 $j$ 欄是 $[T(v_j)]_C$，並滿足
$$[T(v)]_C=[T]_{C\leftarrow B}[v]_B.$$

::: {.proposition name="【完整證明】合成對應矩陣乘法"}
若 $S:U\to V$、$T:V\to W$ 線性，在固定基底下矩陣分別是 $A,B$，則 $T\circ S$ 的矩陣是 $BA$。
:::

::: {.proof}
對任意座標欄 $[u]$，先用 $S$ 得 $[S(u)]=A[u]$，再用 $T$ 得
$$[T(S(u))]=B[S(u)]=BA[u].$$
兩個線性映射若對每個座標欄作用相同，就相同。因此合成的矩陣是 $BA$。這也解釋了順序：先做 $A$、後做 $B$，乘積寫成 $BA$。
:::

## 核、像與維度記帳

::: {.definition name="核、像、秩、零度"}
線性映射 $T:V\to W$ 的**核**與**像**為
$$\ker T=\{v\in V:T(v)=0\},\qquad
\operatorname{im}T=\{T(v):v\in V\}.$$
兩者都是子空間。$\dim(\operatorname{im}T)$ 稱為秩，$\dim(\ker T)$ 稱為零度。
:::

在上一個例子中，方程 $T(x,y)=0$ 給出 $x+2y=0$ 與 $3x-y=0$，只有 $(0,0)$，所以核只有零向量。

::: {.theorem name="【完整證明】秩－零度定理"}
若 $V$ 有限維，則
$$\dim V=\dim(\ker T)+\dim(\operatorname{im}T).$$
:::

::: {.proof}
取核的基底 $u_1,\ldots,u_k$，利用已明列的「基底擴充」黑箱，把它擴成
$u_1,\ldots,u_k,w_1,\ldots,w_m$ 這組 $V$ 的基底。

$T(w_1),\ldots,T(w_m)$ 生成像：任意 $v$ 用上述基底展開後，$u_i$ 部分全被送到零。它們也線性無關：若 $\sum c_jT(w_j)=0$，則 $\sum c_jw_j\in\ker T$，故可寫成 $u_i$ 的組合；整組基底線性無關，迫使所有 $c_j=0$。所以它們是像的基底。

因此 $\dim V=k+m=\dim(\ker T)+\dim(\operatorname{im}T)$。
:::

::: {.corollary name="【完整證明】同維有限空間的單射、滿射與可逆"}
若 $V,W$ 維度相同且有限，則線性映射 $T:V\to W$ 單射、滿射、可逆三者等價。
:::

::: {.proof}
單射等價於 $\dim\ker T=0$。秩－零度此時給 $\dim\operatorname{im}T=\dim V=\dim W$，等價於像為全部 $W$，也就是滿射。單射且滿射的映射有反函數；由 $T$ 保持線性運算可直接核對 $T^{-1}$ 也線性，所以 $T$ 可逆。反向則顯然。
:::

## 可逆矩陣、$\mathrm{GL}_n$ 與表示

先補兩個只需現在就懂的抽象代數定義；第 1.3 章會從頭發展群論。

::: {.definition name="群與群同態（本章所需版本）"}
**群**是帶有一種運算的集合：運算封閉且可結合，有單位元，每個元素有逆元。保持運算的映射 $\rho:G\to H$，即滿足 $\rho(gh)=\rho(g)\rho(h)$，稱為**群同態**。
:::

::: {.definition name="一般線性群與表示"}
$\mathrm{GL}_n(F)$ 是所有 $n\times n$ 可逆 $F$-矩陣在矩陣乘法下形成的群。群 $G$ 的 $n$ 維 $F$-**表示**，就是群同態
$$\rho:G\longrightarrow\mathrm{GL}_n(F).$$
:::

對 $2\times2$ 矩陣
$$A=\begin{pmatrix}a&b\\c&d\end{pmatrix},$$
定義行列式 $\det A=ad-bc$。

::: {.proposition name="【完整證明／特殊情形】二階矩陣可逆判準"}
$A$ 可逆若且唯若 $\det A\ne0$；此時
$$A^{-1}=\frac1{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.$$
:::

::: {.proof}
若 $ad-bc\ne0$，直接左右相乘可驗證顯示的矩陣是逆矩陣。反之若 $ad-bc=0$：若第一行 $(a,b)$ 非零，非零欄 $(b,-a)^{\mathsf T}$ 被 $A$ 送到零；第二列也為零，因其值是 $cb-da=0$。若第一行為零而第二行非零，改用非零欄 $(d,-c)^{\mathsf T}$。兩種情形都有非零核向量，所以 $A$ 不可能有逆矩陣。
:::
高階行列式的完整定義與性質不是本書主線；需要時使用下列明示黑箱。

::: {.theorem name="【接受的黑箱】一般行列式判準"}
$n\times n$ 矩陣可逆若且唯若其行列式非零，且 $\det(AB)=\det(A)\det(B)$。
:::

::: {.proposition name="【完整證明】$\mathrm{GL}_2(\mathbb F_p)$ 的元素個數"}
對質數 $p$，
$$|\mathrm{GL}_2(\mathbb F_p)|=(p^2-1)(p^2-p).$$
:::

::: {.proof}
按**欄**選矩陣。第一欄可取 $\mathbb F_p^2$ 中任何非零向量，共 $p^2-1$ 種。固定第一欄後，它的所有純量倍共有 $p$ 個；第二欄不能落在其中，否則兩欄線性相關而矩陣不可逆，所以有 $p^2-p$ 種。相乘即得公式。
:::

例如 $p=2$ 時共有 $(4-1)(4-2)=6$ 個；$p=3$ 時共有 $(9-1)(9-3)=48$ 個。

行列式的乘法性還說明
$$\det:\mathrm{GL}_n(F)\longrightarrow F^\times$$
是群同態，其中 $F^\times=\{a\in F:a\ne0\}$ 在乘法下成群。這是一個一維表示的例子。

::: {.remark name="【直覺】為什麼 $\mathrm{GL}_2$ 會出現在 FLT 路線"}
後面橢圓曲線的某些撓點會形成二維有限體向量空間。對稱性保持加法，因此給出線性映射；選基底後，就得到 $2\times2$ 矩陣。這條「作用 $\to$ 線性映射 $\to$ 矩陣」才是 $\mathrm{GL}_2$ 出場的理由。相關研究定理都留待後文，這裡只建立字面意義。
:::

**檢查點 1.1.C**　給定 $T(e_1)=(1,3)^{\mathsf T}$、$T(e_2)=(2,-1)^{\mathsf T}$，請不看前文寫出矩陣。若把兩個像排成兩**欄**，你已掌握本章最容易出錯的約定。

## 本章地圖與下一章預告

本章的依賴鏈已經閉合：

$$\text{體}\to\text{向量空間}\to\text{基底與座標}
\to\text{線性映射}\to\text{矩陣（像放在欄）}
\to\mathrm{GL}_n\to\text{表示}.$$

下一章研究同一個線性算子在不同基底下的模樣。特徵向量會提供一組「最看得懂作用」的基底；同時也會嚴格區分哪些對角化結果已證、哪些只作為後文黑箱。

## 習題

**1.1.1 ★**　在 $\mathbb R^2$ 中判斷下列集合是否為子空間：(a) $y=2x$；(b) $y=2x+1$；(c) 第一、三象限連同座標軸。每題逐一檢查零向量、加法、純量乘法。

**1.1.2 ★**　證明 $(1,1)^{\mathsf T},(1,-1)^{\mathsf T}$ 是 $\mathbb R^2$ 的基底，並求 $(4,2)^{\mathsf T}$ 在此基底的座標欄。

**1.1.3 ★**　令 $T(x,y)=(2x-y,x+y)$。(a) 直接驗證線性；(b) 依欄向量慣例寫出矩陣；(c) 計算 $T(3,4)$，比較公式與矩陣答案。

**1.1.4**　設 $S(x,y)=(x+y,y)$、$T(x,y)=(2x,x-y)$。分別寫出矩陣，計算 $T\circ S$，核對合成矩陣是 $[T][S]$ 而非相反順序。

**1.1.5 ★**　求線性映射 $T:\mathbb R^3\to\mathbb R^2$、$T(x,y,z)=(x+y,y+z)$ 的核與像的一組基底，並用秩－零度核對維度。

**1.1.6**　列出 $\mathrm{GL}_2(\mathbb F_2)$ 的六個元素，逐一核對兩欄線性無關。

**1.1.7（前瞻）**　$\mathbb Q(\sqrt2)=\{a+b\sqrt2:a,b\in\mathbb Q\}$ 可視為 $\mathbb Q$-向量空間。驗證 $(1,\sqrt2)$ 是基底。第 2.1 章會把這個維度叫作體擴張次數。
