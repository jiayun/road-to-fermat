## 開場：有理點群的形狀

上一章建立了橢圓曲線的群結構。這一章聚焦最重要的那個群 —— **有理點群** $E(\mathbb{Q})$，因為它正是 FLT 真正關心的對象。費馬方程 $x^n + y^n = z^n$ 的解，就是某些曲線上的有理點；理解有理點群的結構，是理解 FLT 的核心。

核心定理是 **Mordell–Weil**：$E(\mathbb{Q})$ 雖然可能有無窮多個點，卻是「有限生成」的 —— 由有限多個點透過群運算就能造出全部。這個結構定理把 $E(\mathbb{Q})$ 拆成兩部分：一個有限的「撓子群」和一個自由的「$\mathbb{Z}^r$」。後者的秩 $r$，是橢圓曲線最深的祕密，也是千禧年百萬美元問題 BSD 猜想的核心。

你會發現這個結構與第 3.3 章的 Dirichlet 單位定理驚人地相似 —— 它們是「孿生兄弟」，數域與橢圓曲線各演一次同一個結構模式。

## Mordell–Weil 定理

::: {.theorem name="Mordell–Weil, 1922"}
對任何定義在 $\mathbb{Q}$ 上的橢圓曲線 $E$，有理點群 $E(\mathbb{Q})$ 是**有限生成交換群**。由有限生成交換群的結構定理，
$$E(\mathbb{Q}) \;\cong\; \mathbb{Z}^r \times E(\mathbb{Q})_{\mathrm{tors}},$$
其中 $r \ge 0$ 是**秩**（rank），$E(\mathbb{Q})_{\mathrm{tors}}$ 是有限的**撓子群**。
:::

::: {.proof}
（結構梗概，完整證明見 Silverman）兩大步：

**弱 Mordell–Weil**：證明 $E(\mathbb{Q})/nE(\mathbb{Q})$ 對某個 $n$（如 $n = 2$）是有限的。這用到 Galois 上同調與「下降」（descent）—— 把有理點問題化約到有限多個「同源類」。

**高度函數**：在 $E(\mathbb{Q})$ 上定義一個「高度」$h$（衡量點的座標複雜度），證明它有「二次型」性質且滿足有限性（高度有界的點有限多）。

兩者結合，用「下降法」（第 0.1、0.4 章無窮遞降的高級版！）證明有限多個點生成全部。
:::

::: {.remark name="無窮遞降的回歸"}
Mordell–Weil 證明的核心技術「下降」，正是費馬無窮遞降法（第 0.1、0.4 章）的現代後裔。費馬用遞降證明「解不存在」（從假想解造更小的解，矛盾）；Mordell–Weil 用下降證明「點群有限生成」（每個點可以『下降』到有限多個基本點的組合）。同一個「不能無限往下」的良序原理精神（第 0.1 章），從證明 $n = 4$ 的 FLT，一路用到二十世紀橢圓曲線的奠基定理。第零部那把最樸素的刀，從未離開過 FLT 的戰場 —— 它只是不斷被磨利、升級。
:::

## 撓子群：被完全分類

撓子群 $E(\mathbb{Q})_{\mathrm{tors}}$ 是 $E(\mathbb{Q})$ 中「有限階」的點（$nP = O$ for some $n$）。它相對容易掌握 —— 事實上，它被一個驚人的定理完全分類。

::: {.theorem name="Mazur, 1977"}
橢圓曲線 $E/\mathbb{Q}$ 的撓子群只能是以下 $15$ 種之一：
$$\mathbb{Z}/n\mathbb{Z}\ (n = 1, \dots, 10, 12), \qquad \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2m\mathbb{Z}\ (m = 1, 2, 3, 4).$$
特別地，撓子群的階至多是 $16$，且 $\mathbb{Z}/11$、$\mathbb{Z}/13$ 等不可能出現。
:::

::: {.example name="$y^2 = x^3 + 1$ 的撓子群"}
這條曲線有有理點 $(2, 3)$。計算它的倍數：$2(2,3) = (0,1)$、$3(2,3) = (-1,0)$、$4(2,3) = (0,-1)$、$5(2,3) = (2,-3)$、$6(2,3) = O$。所以 $(2,3)$ 是 $6$-撓點，撓子群 $\cong \mathbb{Z}/6\mathbb{Z}$ —— Mazur 列表中的一員。整條曲線的有理點就這 $6$ 個（秩為 $0$），全是撓點。
:::

::: {.remark name="Mazur 定理的分量"}
Mazur 定理的證明，是橢圓曲線與**模曲線**理論的一個里程碑 —— 它分析了模曲線 $X_1(N)$ 的有理點，本質上是「哪些 $N$ 使得模曲線有非平凡有理點」。這個證明用到的技術（模曲線、Eisenstein 理想），與 Wiles 證明同源，而 Mazur 本人正是 Wiles 變形理論（第七部）的奠基者。撓子群的完全分類，是「用模曲線研究橢圓曲線」這套方法的早期勝利 —— 同一套方法，後來會證明 FLT。
:::

## 秩：深不可測的祕密

撓子群被馴服了，但秩 $r$ 完全是另一回事。

::: {.example name="不同的秩"}
- $y^2 = x^3 - x$：秩 $0$（只有撓點，有理點有限）。
- $y^2 = x^3 - 2$：秩 $1$（有無窮多有理點，全由 $(3, 5)$ 生成的軌道加撓點構成）。
- 存在秩高達 $28$ 以上的橢圓曲線（已知記錄不斷被刷新）。
:::

秩衡量「有理點有多少獨立的無窮方向」。關於它，幾乎一切都是謎：

- **沒有已知演算法**保證能算出任意曲線的秩。
- **秩是否有界**（是否存在最大可能的秩）至今未知。
- 秩的行為由 **BSD 猜想**（Birch–Swinnerton-Dyer）預測 —— 它斷言秩等於 L 函數 $L(E, s)$ 在 $s = 1$ 的零點階數。這是千禧年七大問題之一，懸賞百萬美元，至今未解。

::: {.remark name="孿生兄弟：Mordell–Weil 與 Dirichlet"}
把 Mordell–Weil 與第 3.3 章的 Dirichlet 單位定理並排：
$$E(\mathbb{Q}) \cong \mathbb{Z}^r \times (\text{撓子群}) \qquad \longleftrightarrow \qquad \mathcal{O}_K^\times \cong \mathbb{Z}^{r_1+r_2-1} \times \mu_K.$$
左邊是橢圓曲線的有理點，右邊是數域的單位 —— 兩者都是「自由部分 $\mathbb{Z}^r$ × 有限部分」的形狀。這不是巧合：它們都是「算術對象的整點/有理點構成有限生成群」這個深層原理的實例。

更深的平行在「秩」與「L 函數」的關係上：第 3.3 章的類數公式把 $h_K \cdot R_K$（類數 × 單位調節子）與 $\zeta_K$ 在 $s=1$ 的行為相連；BSD 猜想把 $E$ 的秩與 Sha 與 $L(E,s)$ 在 $s=1$ 的行為相連。**Dirichlet 類數公式是 BSD 的祖先**（第 3.3 章已預告）—— 同一條「算術不變量 = L 函數特殊值」的旋律，數域版已證（Dirichlet），橢圓曲線版未解（BSD）。橢圓曲線是「彎曲的數域」，它的算術比數域深一個維度，所以它的「類數公式」至今仍是猜想。
:::

## 回到 FLT：費馬 $n = 3$ 是秩零

把這套理論接回 FLT，看一個具體的翻譯。費馬方程 $x^3 + y^3 = z^3$ 經過標準變數代換，等價於橢圓曲線
$$E: y^2 = x^3 - 432.$$
（變換把費馬曲線的有理點對應到 $E$ 的有理點。）於是：

> $x^3 + y^3 = z^3$ 無非平凡解 $\iff$ $E: y^2 = x^3 - 432$ 的有理點只有平凡的（撓點）$\iff$ $E$ 的秩為 $0$。

Euler 對 $n = 3$ 的證明（第 1.6 章），用現代語言說，就是**證明了 $E: y^2 = x^3 - 432$ 的秩為零**。他在 $\mathbb{Z}[\zeta_3]$ 裡的無窮遞降，本質上是這條橢圓曲線的「下降論證」—— 跟 Mordell–Weil 證明用的是同一把工具的原始版本。

::: {.remark name="兩條路的分野"}
這個翻譯揭示了 FLT 兩種攻擊路線的根本差異。

**古典路線（Kummer，第三部）**：把 $x^p + y^p = z^p$ 當成分圓域 $\mathbb{Q}(\zeta_p)$ 的問題，研究類數。撞上正則性的牆。

**現代路線（將從第 6.5 章開始）**：把 FLT 反例變成一條橢圓曲線（Frey 曲線），但**不是**直接研究它的秩（那會像 Euler 一樣逐個 $p$ 處理），而是研究它的**模性** —— 證明這條曲線「不可能是模的」，但所有橢圓曲線又「必須是模的」，矛盾。

關鍵差異：秩是逐曲線、逐 $p$ 的局部資訊（難算、無統一規律）；模性是所有橢圓曲線共享的整體結構（一旦證明，一網打盡）。Euler 走秩的路線拿下 $n = 3$，但秩之路無法推廣到所有 $p$。Frey–Wiles 走模性的路線，繞過了秩，這才是能一次解決所有指數的關鍵。下一章開始建立模形式，正是為了定義「模性」這個概念。
:::

## 本章地圖與下一章預告

- **Mordell–Weil**：$E(\mathbb{Q}) \cong \mathbb{Z}^r \times$ 撓子群；證明用「下降」（無窮遞降的後裔）。
- **撓子群**：Mazur 定理完全分類為 $15$ 種；用模曲線證明，與 Wiles 同源。
- **秩**：深不可測；無演算法、是否有界未知；BSD 猜想。
- **孿生兄弟**：Mordell–Weil ↔ Dirichlet 單位定理；BSD ↔ Dirichlet 類數公式。
- **費馬 $n=3$ = 秩零**：Euler 證明的橢圓曲線翻譯；秩路線 vs 模性路線。

下一章《橢圓曲線 III》深入橢圓曲線在 mod $p$ 的算術 —— 好/壞約化（第 4.5 章的詞彙）、導體 $N$、$a_p$ 序列、Hasse 界。我們會精確定義「橢圓曲線的算術指紋」$\{a_p\}$，並證明 Hasse 界 $|a_p| \le 2\sqrt p$（第 1.2 章習題預告過）。這個 $a_p$ 序列，正是下半部（模形式）要比對的對象 —— 谷山–志村猜想說，每條橢圓曲線的 $\{a_p\}$ 恰好等於某個模形式的 $\{a_p(f)\}$。要陳述這個猜想，必須先把橢圓曲線這一側的 $\{a_p\}$ 完全講清楚。

## 習題

**5.2.1**　驗證 $y^2 = x^3 + 1$ 上 $(2,3)$ 的倍數：計算 $2(2,3), 3(2,3)$，確認 $3(2,3) = (-1, 0)$ 是 $2$-撓點，故 $(2,3)$ 是 $6$-撓。

**5.2.2 ★**　$y^2 = x^3 - x$ 的撓子群：找出所有 $2$-撓點（$y = 0$ 的點）與其他小撓點，論證撓子群是 $\mathbb{Z}/2 \times \mathbb{Z}/2$。（這條曲線秩為 $0$，所以這就是全部有理點。）

**5.2.3**　Mazur 定理說撓子群階至多 $16$。用一句話說明：為什麼「找一條撓子群為 $\mathbb{Z}/11$ 的橢圓曲線」是徒勞的。

**5.2.4 ★**　解釋 Mordell–Weil 證明中「下降」與費馬「無窮遞降」的關係：兩者都依賴什麼共同的原理（提示：第 0.1 章良序原理 / 高度有界的點有限）？

**5.2.5**　$y^2 = x^3 - 2$ 秩為 $1$，由 $(3, 5)$ 生成。計算 $2(3,5)$，驗證它是一個新的（非撓）有理點，座標更複雜（高度更大 —— 體現「下降」的反面：生成無窮多點）。

**5.2.6（前瞻）**　BSD 猜想說 $\mathrm{rank}\,E(\mathbb{Q}) = \mathrm{ord}_{s=1}L(E,s)$。對比第 3.3 章 Dirichlet 類數公式（$h_K R_K$ 與 $\zeta_K$ 在 $s=1$）。用一句話說明這兩個「算術 = L 函數特殊值」陳述的共同精神，以及為什麼 BSD 比 Dirichlet 難（提示：橢圓曲線是「彎曲的數域」）。
