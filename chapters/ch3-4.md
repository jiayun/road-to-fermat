## 開場：古典時代所能到達的最遠處

這一章是第三部的頂點，也是 FLT「古典理論」—— 不使用橢圓曲線與模形式的純代數數論 —— 所能登上的最高峰。1847 年，Ernst Kummer 用前三章建立的全部機器（理想唯一分解、類群、單位、分圓整數），一舉證明了 FLT 對一整類質數成立。這是費馬之後兩百年裡最大的單一突破，把零星的 $p = 3, 5, 7$ 戰果，提升為對**無窮多個**質數的統一結論。

但這一章也將揭示這條路的盡頭。Kummer 的方法只對「正則質數」有效，而「非正則質數」有無窮多個，且沒有任何古典手段能逐一補救。

**本章的誠實聲明，放在最前面。** 本書**不會**完整證明 Kummer 定理。我們會做四件事，界線清楚：

1. **完整證明**核心命題「障礙化為類群條件」—— 它只用到第 1.3 章的 Lagrange 定理，是整個正則性概念的來源，也是本章唯一你能逐行檢驗的定理。
2. 給出 Kummer 論證的**完整骨架**（第一情形 8 個步驟），並標出每一步的狀態。
3. 把兩塊真正的深水區點名：**第二情形**（$p \mid xyz$）與 **Kummer 單位引理**，兩者本書都不證。
4. 誠實列出古典方法到 1993 年為止**確切**證到了 FLT 的哪些指數 —— 這份清單比任何模糊的「Kummer 幾乎證出 FLT」都更有資訊。

理解這個「幾乎」—— 它到達了哪裡、又為何到不了終點 —— 是理解「為什麼需要橢圓曲線」的最佳方式。

## 本章前置檢查點

1. **理想唯一分解與「理想層次的開方」推論**（第 3.2 章）。
2. **類群、類數、Lagrange 定理**（第 3.3、1.3 章）。
3. **$\mathbb{Q}(\zeta_p)$ 的單位：秩 $\frac{p-3}{2}$、實化 $u = \zeta_p^r v$**（第 3.3 章）。
4. **$\lambda = 1 - \zeta_p$ 與 $p = (\text{單位})\lambda^{p-1}$**（第 2.3 章，完整證明）—— 第二情形的全部算術都在數 $\lambda$ 的冪次。
5. **$\mathcal{O}_{\mathbb{Q}(\zeta_p)} = \mathbb{Z}[\zeta_p]$**（第 3.1 章，外部黑盒）—— 沒有它，下面每一步的「理想」都不知道住在哪個環裡。

## 障礙的精確形態

回憶第 3.2 章末留下的障礙。在 $\mathbb{Z}[\zeta_p]$ 裡，FLT 方程分解成
$$(x + y)(x + \zeta_p y)\cdots(x + \zeta_p^{p-1}y) = z^p.$$
Kummer 把論證搬到理想層次：可以證明（在 $p \nmid xyz$ 的假設下）這 $p$ 個因子生成的**理想**兩兩互質，而它們的積是 $p$ 次方理想 $(z)^p$。由第 3.2 章的推論「理想層次的開方」，每個因子理想都是某個理想的 $p$ 次方：
$$(x + \zeta_p^k y) = \mathfrak{a}_k^{\,p}.$$
到這裡完全嚴格。障礙在下一步：我們想說「所以 $x + \zeta_p^k y$ 是某個**元素**的 $p$ 次方」，但這需要 $\mathfrak{a}_k$ 是**主理想**。

::: {.proposition name="障礙化為類群條件"}
設 $\mathfrak{a}$ 是 $\mathcal{O}_K$ 的非零理想，$p$ 質數，且 $\mathfrak{a}^p$ 是主理想。則
$$\mathfrak{a} \text{ 是主理想} \iff p \nmid h_K.$$
更精確地：$\mathfrak{a}^p$ 主理想時 $[\mathfrak{a}]$ 的階必為 $1$ 或 $p$；若 $p \nmid h_K$ 則階為 $p$ 的元素不存在（Lagrange），故階必為 $1$，即 $\mathfrak{a}$ 主。
:::

**假設**：$\mathfrak{a}^p$ 主；$p$ 質數。**用途**：這是「正則質數」這個定義的**唯一**來源。整章的關鍵詞從這裡長出來。**狀態**：完整證明（下方；輸入只有 Lagrange 定理與類群的有限性）。

::: {.proof}
$\mathfrak{a}^p$ 是主理想，表示在類群中 $[\mathfrak{a}]^p = [\mathcal{O}_K]$（單位元），即 $[\mathfrak{a}]$ 的階整除 $p$。$p$ 為質數，故階是 $1$ 或 $p$。

階為 $1$ $\iff$ $[\mathfrak{a}]$ 是單位元 $\iff$ $\mathfrak{a}$ 是主理想 —— 這正是我們要的。階為 $p$ 則 $\mathfrak{a}$ 非主，障礙出現。

現在看什麼時候「階為 $p$」不可能發生。若類群中存在階為 $p$ 的元素 $g$，則 $\langle g \rangle$ 是 $p$ 階子群，由 Lagrange 定理（第 1.3 章）$p \mid h_K$。反之，若 $p \mid h_K$，由 Cauchy 定理（Lagrange 的伴生結果）類群中確有 $p$ 階元素。

於是：$p \nmid h_K$ $\Rightarrow$ 類群無 $p$ 階元素 $\Rightarrow$ $[\mathfrak{a}]$ 階必為 $1$ $\Rightarrow$ $\mathfrak{a}$ 主。
:::

一個乾淨的數論條件浮現了。

## 正則質數

::: {.definition}
奇質數 $p$ 稱為**正則**（regular），若 $p$ **不**整除分圓域的類數：
$$p \nmid h_p, \qquad h_p := h_{\mathbb{Q}(\zeta_p)}.$$
否則稱**非正則**（irregular）。
:::

正則性恰好是「障礙消失」的條件：由上面的命題，$p \nmid h_p$ 時每個 $\mathfrak{a}_k$ 都是主理想，論證可以從理想層次安全地下降回元素層次。

::: {.remark name="正則性與唯一分解是兩件事"}
第 3.3 章習題 3.3.6 已經要你分辨過，這裡再強調一次，因為它是本章最容易被誤讀的地方：

- **唯一分解成立**：$h_p = 1$。這是很強的條件，$p \ge 23$ 就開始失效（$h_{23} = 3$）。
- **正則**：$p \nmid h_p$。這弱得多。$23$ 不滿足前者（$h_{23} = 3 \ne 1$），卻滿足後者（$23 \nmid 3$）。

Lamé 的錯誤是假設了**前者**；Kummer 的定理只需要**後者**。這正是為什麼 Kummer 能在 Lamé 倒下的地方繼續前進 —— 他把要求降到剛好夠用的程度。第一個真正的**非正則**質數是 $37$，遠在 $23$ 之後。
:::

## Kummer 定理與它的證明架構

::: {.theorem name="Kummer 定理，1847"}
若奇質數 $p$ 是正則的，則方程 $x^p + y^p = z^p$ 沒有全非零的整數解。亦即 FLT 對指數 $p$ 成立。
:::

**假設**：$p$ 奇質數且正則。**用途**：古典理論的最高成果；一次拿下無窮多個指數。**狀態**：**本書不完整證明**。分解如下：

| 步驟 | 內容 | 本書狀態 |
|---|---|---|
| 0 | 化約到 $x,y,z$ 兩兩互質的解 | 完整證明（同第 0.4 章手法） |
| 1 | 在 $\mathbb{Z}[\zeta_p]$ 中分解 $\prod_k(x + \zeta_p^k y) = (z)^p$（理想等式） | 完整證明 |
| 2 | 第一情形（$p \nmid xyz$）下，因子理想兩兩互質 | 完整證明（見下方） |
| 3 | 故 $(x + \zeta_p^k y) = \mathfrak{a}_k^p$ | 完整證明（第 3.2 章推論） |
| 4 | **正則性登場**：$\mathfrak{a}_k$ 為主，得 $x + \zeta_p^k y = u_k\,\alpha_k^p$ | 完整證明（上面的命題） |
| 5 | 用 $u_k = \zeta_p^{r}v$（實化，第 3.3 章）與 $\alpha^p \equiv$ 有理整數 $\pmod p$ 馴服單位 | 證明骨架 |
| 6 | 比較 $\{1,\zeta_p,\dots,\zeta_p^{p-2}\}$ 座標下的係數，導出模 $p$ 的矛盾 | 證明骨架 |
| 7 | **第二情形**（$p \mid xyz$）：對 $\lambda = 1-\zeta_p$ 的冪次作無窮遞降 | **外部黑盒** |
| 8 | 第二情形所需的 **Kummer 單位引理** | **外部黑盒** |

完整證明見 Washington《Introduction to Cyclotomic Fields》第 9 章，或 Borevich–Shafarevich《Number Theory》第 3 章。

**步驟 2 值得完整走一遍** —— 它是「理想層次開方」能啟用的前提，而且它清楚展示了第一情形的假設用在哪裡。

設質理想 $\mathfrak{q}$ 同時整除 $(x+\zeta_p^i y)$ 與 $(x+\zeta_p^j y)$，其中 $0 \le i \ne j \le p-1$。取兩個組合：
$$\zeta_p^{\,j}(x+\zeta_p^i y) - \zeta_p^{\,i}(x+\zeta_p^j y) = (\zeta_p^{\,j}-\zeta_p^{\,i})\,x, \qquad (x+\zeta_p^i y) - (x+\zeta_p^j y) = (\zeta_p^{\,i}-\zeta_p^{\,j})\,y,$$
兩者都被 $\mathfrak{q}$ 整除。而 $\zeta_p^{\,i}-\zeta_p^{\,j} = -\zeta_p^{\,j}\bigl(1 - \zeta_p^{\,i-j}\bigr)$，由第 2.3 章（$\gcd(i-j, p) = 1$）它與 $\lambda = 1-\zeta_p$ 只差一個單位。故
$$\mathfrak{q} \supseteq (\lambda x) \quad\text{且}\quad \mathfrak{q} \supseteq (\lambda y).$$

**情形 A：$\mathfrak{q} \ne (\lambda)$。** 由理想唯一分解，$\mathfrak{q} \mid (\lambda)(x)$ 且 $\mathfrak{q} \nmid (\lambda)$（兩者皆質理想且相異），故 $\mathfrak{q} \mid (x)$；同理 $\mathfrak{q} \mid (y)$。但 $\gcd(x,y) = 1$ 給 Bézout 等式 $ax+by = 1$（第 0.2 章），於是 $1 \in \mathfrak{q}$，$\mathfrak{q} = \mathcal{O}_K$ —— 與 $\mathfrak{q}$ 是質理想矛盾。

**情形 B：$\mathfrak{q} = (\lambda)$。** 因 $\zeta_p \equiv 1 \pmod \lambda$，得 $x + \zeta_p^i y \equiv x + y \pmod\lambda$，故 $\lambda \mid (x+y)$。而 $(\lambda) \cap \mathbb{Z} = p\mathbb{Z}$（$\lambda$ 是 $p$ 上方唯一的質理想，$N(\lambda) = p$），且 $x + y \in \mathbb{Z}$，故 $p \mid x+y$。再由費馬小定理（第 0.2 章）$x^p + y^p \equiv x + y \pmod p$，得 $p \mid z^p$，故 $p \mid z$ —— 與第一情形的假設 $p \nmid xyz$ 矛盾。

兩種情形都不可能，故因子理想兩兩互質。**注意第一情形的假設 $p \nmid xyz$ 只在情形 B 用到，但它至關重要**：第二情形正是情形 B 真的發生的時候，於是「兩兩互質」整個垮掉，第 3 步的開方推論不再適用。這就是為什麼第二情形必須換一套完全不同的論證。

::: {.remark name="第一情形與第二情形為什麼不同"}
FLT 對指數 $p$ 的證明，古典上一律拆成兩塊：

- **第一情形**（$p \nmid xyz$）：三個數都不被 $p$ 整除。此時分圓分解裡的因子「乾淨」，論證主要是模 $p$ 的同餘計算。
- **第二情形**（$p \mid xyz$）：某一個數被 $p$ 整除。此時 $\lambda = 1-\zeta_p$ 會整除某個因子，第 2.3 章那條 $p = (\text{單位})\lambda^{p-1}$ 使得 $\lambda$ 的冪次爆炸性地累積，因子不再兩兩互質，整個第 2 步失效。必須改用一個更一般的方程（把 $z^p$ 換成 $\lambda^{np}z^p$ 的形式），對 $n$ 作無窮遞降 —— 第 0.1、0.4 章那個老骨架又出現了，但這次跑在 $\mathbb{Z}[\zeta_p]$ 上。

這就是為什麼 Sophie Germain（第 3.6 章）只證得了第一情形，而 Kummer 的第二情形要多花好幾倍的篇幅。任何說「Kummer 的證明大致就是把 Lamé 的論證搬到理想上」的說法，都低估了第二情形。
:::

::: {.theorem name="Kummer 單位引理"}
設 $p$ 為**正則**質數，$u \in \mathbb{Z}[\zeta_p]^\times$ 是一個單位。若存在有理整數 $a$ 使 $u \equiv a \pmod{p\,\mathbb{Z}[\zeta_p]}$，則 $u$ 是某個單位的 $p$ 次方：$u = v^p$，$v \in \mathbb{Z}[\zeta_p]^\times$。
:::

**假設**：$p$ 正則；$u$ 同餘於某個**有理**整數。**用途**：第二情形論證中，把礙事的單位因子整個吸收掉，讓遞降能繼續。**狀態**：外部黑盒（Washington 第 5 章）。**注意這條引理本身也依賴正則性** —— 所以正則性在 Kummer 定理中出現**兩次**：一次讓 $\mathfrak{a}_k$ 變主（本章的命題），一次讓單位變 $p$ 次方（這條引理）。只講第一次而不提第二次，是常見的簡化，也是不完整的。

::: {.remark name="檢查點 3.4.A"}
1. 若某個 $p$ 滿足 $h_p = p$，它正則嗎？（**不正則** —— $p \mid h_p = p$。$p = 37$ 正是這個情形。）
2. 若 $h_p = 2p+1$ 呢？（正則，因為 $p \nmid 2p+1$（$p$ 奇質數時 $2p+1 \equiv 1 \bmod p$）。）
3. 正則性在 Kummer 定理裡用了幾次？（**兩次**：讓理想降為主理想；以及 Kummer 單位引理。）
4. 步驟 4 那個式子 $x + \zeta_p^k y = u_k\alpha_k^p$ 裡，$u_k$ 是哪來的？為什麼不能直接說 $x+\zeta_p^k y = \alpha_k^p$？（$\mathfrak{a}_k = (\alpha_k)$ 只決定 $\alpha_k$ 到**相差一個單位**；理想相等不等於生成元相等。這個單位就是步驟 5、8 全部麻煩的來源。）
:::

## Kummer 判準：用 Bernoulli 數檢驗

「計算 $h_{\mathbb{Q}(\zeta_p)}$ 再看是否被 $p$ 整除」很困難（類數難算）。Kummer 的另一個天才，是給出一個**完全初等**的等價判準，不必碰類數。

::: {.theorem name="Kummer 判準"}
奇質數 $p$ 正則 $\iff$ $p$ 不整除 Bernoulli 數 $B_2, B_4, \dots, B_{p-3}$ 中任何一個的分子（分數已化為最簡）。
:::

**假設**：$p$ 奇質數。**用途**：把「類數可除性」這個深刻的代數問題，化成「檢查有限多個有理數的分子」這個機械計算 —— 這是所有非正則質數表格（下面那串 $37, 59, 67, \dots$）的計算依據。**狀態**：外部黑盒（Washington 第 5 章；證明用類數公式與 $p$ 進 $L$ 函數）。

Bernoulli 數 $B_k$ 由
$$\frac{t}{e^t - 1} = \sum_{k \ge 0} B_k \frac{t^k}{k!}$$
定義，是有理數：$B_2 = \frac16$、$B_4 = -\frac1{30}$、$B_6 = \frac1{42}$、$B_8 = -\frac{1}{30}$、$B_{10} = \frac{5}{66}$、$B_{12} = -\frac{691}{2730}$、…，分子增長很快。

::: {.example name="$37$ 為什麼非正則"}
$37$ 是第一個非正則質數。原因是 $37$ 整除 $B_{32}$ 的分子（$32 \le 37 - 3 = 34$，在判準的檢查範圍內）。於是由 Kummer 判準，$37$ 非正則，$37 \mid h_{37}$。

事實上 $h_{37} = 37$，所以類群是 $37$ 階群，由 Lagrange 它必是循環群 $\mathbb{Z}/37$，其中有 $36$ 個階為 $37$ 的元素。（**注意**：不要說「恰有一個 $37$ 階元素」—— 一個 $37$ 階循環群只有一個 $37$ 階**子群**，但有 $36$ 個 $37$ 階**元素**。）

Kummer 定理的論證在步驟 4 斷掉：那些 $37$ 階理想類，讓某個 $\mathfrak{a}_k$ 無法降為主理想，障礙不消，證明失效。（另外，Kummer 單位引理對 $p=37$ 也失效。）
:::

::: {.remark name="Bernoulli 數的神祕橋樑"}
為什麼**類數**（分圓體的深層算術不變量）會與 **Bernoulli 數**（一個來自微積分、與 $\sum n^k$ 求和公式相關的序列）扯上關係？橋樑是 zeta 函數：$\zeta(1-k) = -B_k/k$（zeta 在負整數的值由 Bernoulli 數給出），而第 3.3 章的類數公式又把類數與 zeta 函數相連。於是 Bernoulli 數成了「類數的可計算代理」。

這條「Bernoulli 數 ↔ zeta 特殊值 ↔ 類數」的線索，會在現代以驚人的方式延續：**岩澤理論**（Iwasawa theory）把它發展成關於分圓域類數如何隨 $p$ 的冪增長的精密理論，而岩澤理論是 Wiles 證明的技術祖先之一。（**狀態**：本段是**直觀說明**；「$\zeta(1-k) = -B_k/k$」本身是標準結果，本書不證也不使用。）
:::

## 牆：為什麼這條路到不了終點

Kummer 定理輝煌，但有一道無法逾越的牆。

::: {.theorem name="Jensen, 1915"}
非正則質數有**無窮多個**。
:::

**狀態**：外部黑盒（K. L. Jensen；證明相對初等，用 Bernoulli 數的同餘性質）。

這是致命的。Kummer 方法只對正則質數有效，而非正則質數無窮多 —— 所以這個方法**結構性地**漏掉無窮多個指數，不可能靠它證明完整的 FLT。更糟的是：

**諷刺的是，正則質數是否有無窮多個，至今仍是未解問題。** 數值上，Siegel（1964）給出一個**啟發式**（heuristic，不是定理）預測：正則質數的密度應為 $e^{-1/2} \approx 60.65\%$，與計算數據吻合得很好。但沒有人能證明它們無窮多。**我們能證明「壞」的質數無窮多，卻證不出「好」的質數無窮多** —— 古典理論在自己的地基上就站不穩。

::: {.example name="數字要說對"}
前幾個非正則質數是
$$37,\ 59,\ 67,\ 101,\ 103,\ 131,\ 149,\ 157,\ \dots$$
**$100$ 以下的 $24$ 個奇質數中，只有 $3$ 個非正則**（$37, 59, 67$），即 $21$ 個正則，比例 $87.5\%$。（$101$ 與 $103$ 已經超過 $100$，別把它們算進來；另外 $2$ 不是奇質數，也別算。）

這個比例會隨範圍擴大而下降，趨向 Siegel 啟發式的 $60.65\%$ 左右 —— 小質數「特別乾淨」是取樣偏差，不是規律。
:::

## 誠實的戰果清單：古典方法到底證出了什麼

「Kummer 幾乎證出了 FLT」這句話太模糊。以下是精確的版本。

**首先，一個歸約（第 0.4 章）：** 若 FLT 對指數 $m$ 成立，則對 $m$ 的所有倍數成立（因為 $x^{km} = (x^k)^m$）。每個 $n \ge 3$ 要嘛被 $4$ 整除，要嘛有奇質因數。所以：

> 只要證明 FLT 對 $n = 4$ 與所有**奇質數** $p$ 成立，完整的 FLT 就成立。

**其次，古典時代的實際戰果：**

| 結果 | 涵蓋範圍 | 年代 |
|---|---|---|
| Fermat：$n = 4$ | 所有 $4 \mid n$ | 十七世紀 |
| Euler：$n = 3$ | 所有 $3 \mid n$ | 1770（有缺口，後被補上） |
| Dirichlet、Legendre：$n = 5$ | 所有 $5 \mid n$ | 1825 |
| Lamé：$n = 7$ | 所有 $7 \mid n$ | 1839 |
| Sophie Germain | 對 Germain 質數 $p$ 的**第一情形** | 約 1820 |
| **Kummer：所有正則質數** | 所有有正則奇質因數的 $n$ | 1847 |
| Vandiver 等的精細判準＋電腦 | 逐一驗證到很大的 $p$ | 二十世紀 |
| Buhler 等的計算 | 所有 $n < 4\,000\,000$ | 1993 |

**於是，Kummer 定理（配上 $n = 4$）的確切涵蓋範圍是：**

> FLT 對指數 $n$ 成立，只要 $4 \mid n$，**或** $n$ 有一個**正則**奇質因數。

**沒被涵蓋的是**：那些 $4 \nmid n$ 且**所有**奇質因數都非正則的 $n$。最小的例子是 $n = 37$，接著是 $37^2, 59, 67, 37\cdot59, \dots$。由 Jensen 定理，這樣的 $n$ 有**無窮多個**。

::: {.remark name="這道牆的意義"}
第三部的整個故事，至此完成了它的弧線。從第 0.2 章唯一分解的建立，到第 1.6 章 Euler 在新數系的僥倖，到本部 Kummer 用理想、類群、單位把唯一分解的失效精確馴服 —— 人類把「元素層次的混亂」一路降伏到「一個數論條件（正則性）」。這是智力的巨大勝利。

然而牆就在那裡，而且上面那張清單讓它的形狀變得具體：**無窮多個指數，古典方法連碰都碰不到**。正則性不是一個能被「修補」的技術瑕疵，而是這條進路的本質邊界。問題的根源，是這整套方法把 FLT 當成**分圓域內部**的算術問題來處理 —— 而 FLT 的真相，似乎根本不住在分圓域裡。要前進，不能再加深對 $\mathbb{Z}[\zeta_p]$ 的理解，而必須換一個完全不同的舞台。

那個新舞台，是橢圓曲線與模形式。下一個世紀的數學家會發現：把 FLT 的假想反例，不放進分圓域，而放進一條**橢圓曲線**（Frey 曲線），然後用模形式的對稱性逼出矛盾 —— 這條路，能一次處理**所有**質數，正則與非正則一視同仁。Kummer 撞上的牆，被 Frey、Ribet、Wiles 從一個分圓理論完全看不見的維度繞了過去。

但 Kummer 的遺產不會消失：理想、類群、分圓域、Bernoulli 數、岩澤理論 —— 它們都將在 Wiles 的證明裡，以零件的身分重新登場。古典戰場不是死路，而是通往現代的必經之地。
:::

## 本章地圖與下一章預告

- **障礙的形態**：$(x+\zeta_p^k y) = \mathfrak{a}_k^p$ 理想層次成立，下降到元素需 $\mathfrak{a}_k$ 主。
- **障礙化為類群條件**：$\mathfrak{a}^p$ 主時，$\mathfrak{a}$ 主 $\iff p \nmid h_K$（完整證明，靠 Lagrange）。
- **正則質數**：$p \nmid h_p$；比「$h_p = 1$」弱得多，這正是 Kummer 勝過 Lamé 的原因。
- **Kummer 定理**：正則 $p \Rightarrow$ FLT 對 $p$ 成立；本書給骨架，第二情形與單位引理是黑盒；正則性在證明中用了**兩次**。
- **Kummer 判準**：正則 $\iff p \nmid$ 任何 $B_2, \dots, B_{p-3}$ 的分子；$37$ 是第一個例外（$37 \mid B_{32}$ 分子，$h_{37} = 37$）。
- **牆**：非正則質數無窮多（Jensen）；正則質數是否無窮多**未知**；無窮多個指數古典方法碰不到。

下一章《$p$ 進數》是第三部的技術尾聲，引入一個將在第六、七部至關重要的工具：$p$ 進數 $\mathbb{Q}_p$。它是「在單一質數 $p$ 處把有理數完備化」的產物 —— 把第 2.4 章的局部化推到極致。$p$ 進數讓「局部–整體原則」有了堅實的數系載體，而第六部的 Galois 表示，正是逐個質數地在 $\mathbb{Q}_p$ 上分析「局部表示」。第三部以古典的巔峰開始，以通往現代的橋樑結束。

## 習題

**3.4.1**　補齊 Proposition「障礙化為類群條件」的細節：說明為什麼 $\mathfrak{a}^p$ 主理想蘊涵 $[\mathfrak{a}]^p$ 是類群的單位元，並由此推出 $[\mathfrak{a}]$ 的階整除 $p$。

**3.4.2 ★**　用 Lagrange 定理與 Cauchy 定理證明：類群有 $p$ 階元素 $\iff p \mid h_K$。由此說明正則性 $p \nmid h_p$ 恰好排除這種障礙元素。

**3.4.3**　計算或查出 $B_2, B_4, B_6, B_8$，並用 Kummer 判準驗證 $p = 5, 7, 11$ 都正則。（注意判準對 $p$ 只需檢查 $B_2, \dots, B_{p-3}$：$p=5$ 只查 $B_2$；$p=7$ 查 $B_2, B_4$；$p=11$ 查 $B_2, B_4, B_6, B_8$。）

**3.4.4 ★**　$691$ 整除 $B_{12}$ 的分子（$B_{12} = -\frac{691}{2730}$），且 $12 \le 691-3$。由此論證 $691$ 是非正則質數。（$691$ 在模形式理論裡也以神祕的方式出現 —— 它與 Ramanujan 的 $\tau$ 函數同餘有關，第五部會再遇到這個數字。）

**3.4.5 ★（邏輯練習）**　假設有人明天證明了「正則質數有無窮多個」。這會給出完整的 FLT 嗎？（**不會**。想清楚為什麼：涵蓋範圍是「有正則奇質因數的 $n$」，而 $n = 37$ 這種所有奇質因數皆非正則的指數，仍然一個都沒被處理。多證明一些「好」質數，完全不影響「壞」質數那一側。這一題的目的，是讓你分辨「涵蓋很多」與「涵蓋全部」。）

**3.4.6 ★（範圍練習）**　用本章的「誠實的戰果清單」判斷下列指數在 1847 年後是否已被古典方法解決：$n = 12$、$n = 37$、$n = 74$、$n = 111$、$n = 37^2$、$n = 59 \cdot 67$。（提示：$74 = 2\cdot 37$，$4 \nmid 74$ 且唯一奇質因數 $37$ 非正則 $\Rightarrow$ **未解決**；$111 = 3\cdot 37$，$3$ 正則 $\Rightarrow$ **已解決**。）

**3.4.7（狀態練習）**　用一句話說出：本章哪一條定理是完整證明的？哪兩塊是本書明確不證的？（若答不出，重讀「開場」的誠實聲明。）

**3.4.8（前瞻）**　Kummer 把 FLT 當成分圓域 $\mathbb{Q}(\zeta_p)$ 的內部問題。Frey 的想法是把 FLT 的反例變成橢圓曲線 $y^2 = x(x-a^p)(x+b^p)$。用一句話對比：為什麼後者能「一次處理所有 $p$」而前者不能？（提示：Frey 曲線的方法不依賴 $\mathbb{Q}(\zeta_p)$ 的類數，而依賴一個對所有 $p$ 統一成立的結構 —— 模性。這是第五、六部的核心。）
