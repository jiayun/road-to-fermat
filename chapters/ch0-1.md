## 序幕：一行頁邊註記

大約在 1637 年，法國土魯斯的一位法官皮埃爾・德・費馬（Pierre de Fermat），在他那本丟番圖《算術》的頁邊空白處，用拉丁文寫下了一段話。翻譯過來是：

> 「將一個立方數分為兩個立方數之和、將一個四次方數分為兩個四次方數之和，或者一般地，將一個高於二次的冪分為兩個同次冪之和，是不可能的。我發現了一個真正美妙的證明，可惜這裡的空白太小，寫不下。」

用今天的記號來說，費馬宣稱：當整數 $n \ge 3$ 時，方程式
$$x^n + y^n = z^n$$
沒有正整數解。

這行註記在費馬死後由他的兒子整理出版，從此折磨了人類三百五十七年。Euler、Legendre、Dirichlet、Sophie Germain、Kummer──數學史上一連串響亮的名字都向它發起過進攻，各自攻下一些山頭，但沒有人拿下全部。直到 1995 年，Andrew Wiles 與 Richard Taylor 的論文發表，這個「費馬最後定理」（Fermat's Last Theorem，以下簡稱 FLT）才真正成為定理。

而 Wiles 的證明所動用的武器──橢圓曲線、模形式、Galois 表示──沒有一樣是費馬的時代存在的。幾乎所有數學家都相信：費馬並沒有一個正確的證明。他大概是搞錯了，就像他在另一件事上搞錯了一樣（這一章稍後你就會看到那個著名的烏龍）。

這本書的目標，是帶你從現在的位置──高中數學──一路走到能夠理解 Wiles 證明的整體結構。這趟路很長，而它的第一步，是先弄清楚一件事：**「證明」到底是什麼？為什麼數學家如此在乎它？**

## 驗證一萬次，不等於證明

先看一個小遊戲。考慮這個多項式：
$$f(n) = n^2 + n + 41.$$
代入 $n = 0$，得到 $41$，是質數。代入 $n = 1$，得到 $43$，質數。$n = 2$ 得 $47$，質數。$n = 3$ 得 $53$，質數。

你可以繼續算下去：$61, 71, 83, 97, 113, \dots$ 一路全是質數。事實上從 $n = 0$ 到 $n = 39$，整整四十個值，**全部是質數**。

那麼，「$f(n)$ 永遠是質數」是真的嗎？

代入 $n = 40$：
$$f(40) = 1600 + 40 + 41 = 1681 = 41^2.$$
不是質數。四十次成功的驗證，敵不過一個反例。

再看一個更切題的故事──主角正是費馬本人。費馬研究過這種形狀的數：
$$F_n = 2^{2^n} + 1.$$
$F_0 = 3$、$F_1 = 5$、$F_2 = 17$、$F_3 = 257$、$F_4 = 65537$──五個全是質數。費馬於是猜想（而且語氣相當篤定）：所有的 $F_n$ 都是質數。

將近一百年後，Euler 檢查了下一個：
$$F_5 = 2^{32} + 1 = 4294967297 = 641 \times 6700417.$$
不是質數。而且戲劇性的是：從 $F_5$ 開始直到今天，人類再也沒有找到任何一個新的費馬質數。費馬不只是錯了，他幾乎是以最徹底的方式錯了。

這兩個故事說明同一件事：**在整數的世界裡，「前面一萬個都成立」對「全部成立」幾乎不構成證據**。整數有無窮多個，而無窮是不講情面的。有些命題的第一個反例出現在天文數字的深處──數論裡有著名的例子，反例小於 $10^{316}$ 但人類至今寫不出它的確切位置。

這就是為什麼數學需要證明。**證明是一條有限長的推理鏈，每一步都依據明確的規則，從已知為真的事實推出新的事實**──它讓我們用有限的論證，一次性地搞定無窮多個情況。

FLT 正是這種命題的極端範例。電腦可以驗證 $x, y, z, n$ 在某個範圍內沒有解（人們確實驗證過極大的範圍），但這對「所有正整數」毫無幫助。要殺死無窮，只能用證明。

## 命題與它的變形

要打造推理鏈，先要認識鏈條的環節。

**命題**（proposition）是一個非真即假的陳述句。「$7$ 是質數」是命題（真）。「$8$ 是質數」是命題（假）。「$x$ 是質數」不是命題──它的真假取決於 $x$，這種含變數的句子稱為**述語**（predicate），要等變數被指定或被量詞鎖定後才變成命題。

命題可以用邏輯連接詞組合：

- **且**（$P \wedge Q$）：兩者皆真才為真。
- **或**（$P \vee Q$）：至少一個為真即為真。注意數學的「或」是**包含性**的──「$P$ 或 $Q$」允許兩者都真。
- **非**（$\neg P$）：真假翻轉。
- **若 $P$ 則 $Q$**（$P \Rightarrow Q$）：這是最重要、也最容易誤解的一個。

關於「若 $P$ 則 $Q$」，有兩件事必須說清楚。

**第一，它只在「$P$ 真而 $Q$ 假」時為假。** 特別地，當 $P$ 為假時，整個條件句自動為真──「若豬會飛，則 $1 + 1 = 3$」是一個真命題，因為豬不會飛。這個約定初看古怪，但它是讓數學推理順暢運作的唯一合理選擇：「所有被 $4$ 整除的數都是偶數」這句話，不應該因為 $7$ 不被 $4$ 整除就出問題。

**第二，它和「若 $Q$ 則 $P$」是兩回事。** 「若 $4 \mid n$，則 $n$ 是偶數」為真；反過來「若 $n$ 是偶數，則 $4 \mid n$」為假（$n = 6$）。把命題和它的**逆命題**混為一談，是日常推理中最常見的謬誤。

但有一個變形與原命題**完全等價**：**逆否命題**（contrapositive）。

$$P \Rightarrow Q \quad\text{等價於}\quad \neg Q \Rightarrow \neg P.$$

「若 $4 \mid n$ 則 $n$ 是偶數」等價於「若 $n$ 是奇數則 $4 \nmid n$」。兩者同真同假，證明了一個就等於證明了另一個。這不是修辭技巧，而是實戰武器：很多命題正面難攻，逆否方向卻有現成的路。本書後面會反覆使用它──事實上，**整個 FLT 的現代證明就是一個巨型的逆否論證**：

> 「若 FLT 有反例，則存在一條具有某些性質的橢圓曲線」；然後證明「這樣的橢圓曲線不存在」；所以 FLT 沒有反例。

你在第六部會看到這個結構的全貌。現在只需要記住：逆否，是把「證明某物不存在」轉化為「假設它存在，然後看著它自我毀滅」的開關。

## 量詞：對所有、存在

數學命題的力量，大半來自兩個量詞：

- **全稱量詞 $\forall$**：「對所有」（for all）
- **存在量詞 $\exists$**：「存在」（there exists）

「每個大於 $1$ 的整數都有質因數」寫成：
$$\forall n > 1,\ \exists \text{質數 } p,\ p \mid n.$$

量詞的順序至關緊要。比較這兩句：

- $\forall n\, \exists m,\ m > n$──「對每個數，都存在比它大的數」。真。
- $\exists m\, \forall n,\ m > n$──「存在一個比所有數都大的數」。假。

只是交換順序，真假就翻轉了。

接著是全書都會用到的核心技能：**否定一個帶量詞的命題**。規則很機械：

$$\neg\bigl(\forall x,\ P(x)\bigr) = \exists x,\ \neg P(x), \qquad \neg\bigl(\exists x,\ P(x)\bigr) = \forall x,\ \neg P(x).$$

否定號穿過量詞時，$\forall$ 與 $\exists$ 互換，最後落在內層述語上。

現在把這套工具用在主角身上。FLT 的精確陳述是：

::: {.conjecture name="費馬最後定理，1637 年陳述、1995 年成為定理"}
$$\forall n \ge 3,\ \forall x, y, z \in \mathbb{N}:\quad x^n + y^n \ne z^n.$$
:::

它的否定──也就是「FLT 是錯的」──是：
$$\exists n \ge 3,\ \exists x, y, z \in \mathbb{N}:\quad x^n + y^n = z^n.$$

注意這個不對稱性：要推翻 FLT，只需要**一組**具體的數字（就像 $641$ 推翻了費馬的質數猜想）；要證明 FLT，卻必須處理**所有**的 $n$ 和**所有**的 $x, y, z$。這正是它難的原因，也是它適合作為「反證法」獵物的原因──因為它的否定如此具體：一組假想中的數字 $(n, x, y, z)$。整個現代證明，就是接過這組假想的數字，把它鍛造成一條假想的曲線，然後證明那條曲線是不可能的。

## 反證法：請君入甕

**反證法**（proof by contradiction）的格式：要證明 $P$，先假設 $\neg P$，然後從這個假設推出一個矛盾──推出某個既真又假的東西。既然 $\neg P$ 導致荒謬，$\neg P$ 必為假，故 $P$ 為真。

來看數學史上最著名的反證法。這個證明出自兩千多年前，至今仍是典範。

::: {.theorem}
$\sqrt{2}$ 是無理數。亦即，不存在正整數 $p, q$ 使得 $(p/q)^2 = 2$。
:::

::: {.proof}
假設不然：存在正整數 $p, q$ 使得 $p^2 = 2q^2$。在所有滿足此式的正整數對中，取 **$q$ 最小**的一組（為什麼一定取得到「最小」？請先存疑，下一節回答）。

$p^2 = 2q^2$ 表示 $p^2$ 是偶數。若 $p$ 是奇數，$p^2$ 必是奇數（奇 $\times$ 奇 $=$ 奇），故 $p$ 是偶數，可寫 $p = 2k$。

代回：$4k^2 = 2q^2$，即 $q^2 = 2k^2$。同樣的論證告訴我們 $q$ 也是偶數，$q = 2m$。

但這樣一來，$q^2 = 2k^2$ 變成 $4m^2 = 2k^2$，即 $k^2 = 2m^2$──我們得到了一組**新的**解 $(k, m)$，而 $m = q/2 < q$。

這與「$q$ 是最小的」矛盾。所以一開始的假設錯誤：這樣的 $p, q$ 不存在。
:::

請特別注意這個證明的內在結構：我們假設解存在，取了**最小的**一個，然後從它製造出**更小的**一個。矛盾不是來自外部，而是解自己生出了否定自己的後代。

這個模式有個名字：**無窮遞降法**（infinite descent）──而它的發明者，正是費馬。費馬用它證明了 FLT 的 $n = 4$ 情形，那是人類在這個問題上的第一場真正勝利，你將在第 0.4 章親手完整走過那個證明。從 $\sqrt{2}$ 到 $n = 4$，用的是同一把刀，只是後者的刀工繁複得多。

::: {.remark}
反證法雖然好用，但不要濫用。如果一個命題能直接證明，直接證明通常更清晰、提供更多資訊。反證法最適合的獵物，是那些「斷言某物不存在」的命題──因為它的否定送給你一個具體的東西可以下手。FLT 正是這種命題。
:::

## 數學歸納法與良序原理

反證法處理「不存在」，**數學歸納法**（mathematical induction）處理「對所有正整數成立」。

格式：要證明「對所有正整數 $n$，$P(n)$ 成立」，只需兩步：

1. **基底**：證明 $P(1)$。
2. **歸納步**：證明「若 $P(k)$ 成立，則 $P(k+1)$ 成立」。

骨牌的比喻你大概聽過：第一張會倒，且每張倒下都會推倒下一張，那麼所有骨牌都會倒。

::: {.proposition}
$\displaystyle 1 + 2 + \cdots + n = \frac{n(n+1)}{2}$。
:::

::: {.proof}
基底：$n = 1$ 時左邊 $= 1$，右邊 $= \tfrac{1 \cdot 2}{2} = 1$，成立。

歸納步：設 $1 + \cdots + k = \tfrac{k(k+1)}{2}$。則
$$1 + \cdots + k + (k+1) = \frac{k(k+1)}{2} + (k+1) = (k+1)\Bigl(\frac{k}{2} + 1\Bigr) = \frac{(k+1)(k+2)}{2},$$
正是 $P(k+1)$。
:::

有時推倒第 $k+1$ 張骨牌需要的不只是前一張，而是**前面全部**。這是**強歸納法**：歸納步改為「若 $P(1), \dots, P(k)$ 全部成立，則 $P(k+1)$ 成立」。範例：

::: {.proposition}
每個大於 $1$ 的整數都能寫成質數的乘積。
:::

::: {.proof}
對 $n$ 用強歸納。$n = 2$ 是質數，成立。設所有 $2$ 到 $k$ 的整數都能寫成質數乘積。看 $k+1$：若它是質數，完成；若不是，則 $k+1 = ab$，其中 $2 \le a, b \le k$。由歸納假設，$a$ 和 $b$ 各自是質數乘積，於是 $k+1$ 也是。
:::

::: {.remark}
這是「算術基本定理」的一半──存在性。另一半「唯一性」深刻得多，是第 0.2 章的主菜。而「唯一性在更大的數系中會失效」這件事，將是第三部整個 Kummer 故事的引爆點。請把這個伏筆放在心上。
:::

現在回收上一節欠的債：$\sqrt{2}$ 的證明裡，憑什麼能取「$q$ 最小的一組解」？

依據是**良序原理**（well-ordering principle）：

::: {.theorem name="良序原理"}
正整數的任何非空子集合，都有最小元素。
:::

這句話看似廢話，卻是整數最深刻的性質之一──注意它對正實數**不**成立（「所有正實數」這個集合就沒有最小元素）。良序原理、數學歸納法、無窮遞降法，三者其實在邏輯上**互相等價**，是同一個真理的三套衣服：

- 歸納法說：性質會從 $1$ 開始向上傳染到所有數。
- 良序原理說：任何非空的「反例集合」必有最小反例。
- 無窮遞降說：正整數不存在無窮的嚴格遞減序列──你不能永遠「再找一個更小的」。

費馬的無窮遞降法正是良序原理的攻擊型態：假設反例存在，則有最小反例；從最小反例造出更小的反例；矛盾。在第 0.4 章，你會看到費馬如何用這一招，讓 $x^4 + y^4 = z^4$ 的假想解一路向下崩塌。

## 第一個歸約：FLT 只需要證 $n = 4$ 與奇質數

學了一章的工具，現在做一件真正的事。我們要證明本書的第一個定理──它不解決 FLT，但它把 FLT 的戰場縮小了無窮倍。

先做一個觀察。指數有個簡單但威力強大的性質：$x^{ab} = (x^a)^b$。所以，如果 $n = ab$，而 $(x, y, z)$ 是 $x^n + y^n = z^n$ 的正整數解，那麼
$$(x^a)^b + (y^a)^b = (z^a)^b,$$
也就是說 $(x^a, y^a, z^a)$ 是**指數 $b$ 的解**。一句話：**若指數 $n$ 有解，則 $n$ 的每個因數也有解**。

取逆否命題：**若指數 $b$ 無解，則所有 $b$ 的倍數都無解。**

::: {.theorem name="歸約定理"}
若 FLT 對 $n = 4$ 成立，且對所有奇質數 $p$ 成立，則 FLT 對所有 $n \ge 3$ 成立。
:::

::: {.proof}
設 $n \ge 3$。分兩種情況。

**情況一：$n$ 有奇質數因數 $p$。** 則 $n$ 是 $p$ 的倍數。由假設，指數 $p$ 無解；由上面的逆否觀察，指數 $n$ 無解。

**情況二：$n$ 沒有任何奇質數因數。** 將 $n$ 質因數分解（上一節剛證明了分解的存在性）：$n$ 的質因數只能是 $2$，故 $n = 2^k$。由 $n \ge 3$ 得 $k \ge 2$，所以 $4 \mid n$。由假設，指數 $4$ 無解；由逆否觀察，指數 $n$ 無解。

兩種情況都無解，證畢。
:::

停下來體會一下這個定理做了什麼。FLT 原本是關於**無窮多個**指數 $n$ 的命題；現在它被化約為「$n = 4$」加上「$n$ 是奇質數」。費馬本人解決了 $n = 4$（第 0.4 章）。於是從十八世紀起，整個戰役的目標變成：

> 對每個奇質數 $p$，證明 $x^p + y^p = z^p$ 無正整數解。

Euler 攻下 $p = 3$，Dirichlet 與 Legendre 攻下 $p = 5$，Lamé 攻下 $p = 7$……然後 Kummer 一口氣攻下一整類的「正則質數」（第三部的高潮）。但奇質數仍有無窮多個，逐個擊破永遠到不了終點。要一次處理所有質數，需要的就是那條穿過橢圓曲線與模形式的路。

注意這一章的所有工具都已經上場：指數律提供彈藥，逆否命題完成轉向，質因數分解（用強歸納法證明的）支撐情況二，而整個定理的形狀──把大問題化約成小問題──正是這本書接下來四十章會反覆出現的主旋律。數學的進展很少是正面強攻，更多時候是一連串漂亮的化約：把你不會的問題，變成另一個你（將來）會的問題。

## 本章地圖與下一章預告

本章建立的工具箱：

- **證明 vs 驗證**：有限的推理鏈對付無窮的個案；$f(n) = n^2 + n + 41$ 與費馬數 $F_5$ 的教訓。
- **逆否命題**：$P \Rightarrow Q$ 等價於 $\neg Q \Rightarrow \neg P$；FLT 的現代證明是一個巨型逆否論證。
- **量詞與其否定**：FLT 的否定是「存在一組 $(n, x, y, z)$」──一個具體到可以動手術的對象。
- **反證法與無窮遞降**：$\sqrt{2}$ 的證明展示了「最小反例自我毀滅」的模式。
- **歸納法、強歸納法、良序原理**：三位一體；質因數分解的存在性。
- **歸約定理**：FLT 化約為 $n = 4$ 與奇質數情形。

下一章《整數的個性》，我們深入整數世界的內部結構：輾轉相除法、最大公因數、質因數分解的**唯一性**，以及將伴隨全書的利器──同餘與模算術。那是 Gauss 十九歲時為數論打造的語言，也是三百年後 Wiles 的證明裡 $\bmod\ 3$ 與 $\bmod\ 5$ 表示的源頭。

## 習題

證明導向的書，習題不是配菜。每一章請至少完成標 ★ 的題目。

**0.1.1**　寫出下列命題的逆否命題，並判斷原命題真假：
(a) 若 $n^2$ 是偶數，則 $n$ 是偶數。
(b) 若 $x + y$ 是無理數，則 $x$ 是無理數或 $y$ 是無理數。

**0.1.2 ★**　否定下列命題（把否定號推到最內層）：
(a) $\forall n,\ \exists p > n$，$p$ 是質數。
(b) $\exists x,\ \forall y,\ x + y = y$。
(c) FLT 對 $n = 3$ 的情形（先把它寫成量詞語句）。

**0.1.3 ★**　模仿 $\sqrt{2}$ 的證明，證明 $\sqrt{3}$ 是無理數。然後試著對 $\sqrt{4}$ 跑同一個證明，找出論證在哪一步斷掉。（這題很重要：知道一個證明**為什麼在不該成立的地方失敗**，跟知道它為什麼成立一樣有價值。）

**0.1.4**　用歸納法證明：$1^2 + 2^2 + \cdots + n^2 = \dfrac{n(n+1)(2n+1)}{6}$。

**0.1.5 ★**　用良序原理直接證明數學歸納法：設 $P(1)$ 成立且 $P(k) \Rightarrow P(k+1)$，考慮集合 $S = \{n : P(n)\ \text{不成立}\}$，假設 $S$ 非空，導出矛盾。

**0.1.6**　證明：不存在最大的質數。（提示：Euclid 的經典反證──假設質數只有有限個 $p_1, \dots, p_k$，考慮 $p_1 p_2 \cdots p_k + 1$。小心一個常見的誤解：這個數本身不一定是質數，正確的結論是什麼？）

**0.1.7 ★**　在歸約定理中，我們需要「每個 $n \ge 3$ 都被 $4$ 或某個奇質數整除」。如果 FLT 改成只對 $n = 8$ 與所有奇質數成立，能推出全部的 FLT 嗎？為什麼？（這題解釋了為什麼是 $n = 4$ 而不是 $n = 8$ 擔任那個特殊角色。）

**0.1.8（挑戰）**　驗證 $641 \mid 2^{32} + 1$，但禁止直接做長除法。提示：$641 = 5^4 + 2^4 = 5 \cdot 2^7 + 1$。Euler 當年大致就是這樣看穿 $F_5$ 的。
