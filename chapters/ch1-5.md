## 開場：為什麼數論需要分析

到目前為止，第一部都在代數的世界裡 —— 群、環、體都是離散的結構。但 FLT 證明的兩位主角之一，**模形式**，是一個**解析**對象：它是定義在複數上半平面的函數，由一個無窮級數給出，而它的全部魔力都依賴這個級數的收斂行為。要嚴格地談模形式，必須先嚴格地談「無窮多個東西加起來等於什麼」。

這一章不假設你已學過嚴格分析。我們把高中課裡憑圖像使用的極限、連續、級數收斂，用 $\varepsilon$–$\delta$ 的語言逐一定義。最需要留心的是**一致收斂**：它是把有限次操作推到無窮極限時的重要控制條件。究竟能保住連續、積分或微分，需要不同的附加假設；本章只完整證明「連續性」那一項，不把它們混成一句口號。

本章只取通往模形式所必需的分析，不走測度論等更重的機器。目標明確：讓「$\sum a_n q^n$ 是一個好函數」這句話有嚴格意義。

**依賴箭頭：** 0.1 量詞順序 + 高中函數與不等式
$\to$ 數列／函數極限 $\to$ 級數 $\to$ 一致收斂
$\to$ 局部一致收斂的冪級數 $\to$ 後文模形式的 $q$ 展開。

本章沿用五種結果標籤：**【完整證明】、【特殊情形】、【證明略圖】、【直覺】、【接受的黑箱】**。

## 極限：$\varepsilon$–$\delta$ 的精確

直覺說「$x$ 趨近 $a$ 時 $f(x)$ 趨近 $L$」。嚴格化的關鍵，是把「趨近」翻譯成可驗證的不等式挑戰。

::: {.definition name="函數極限"}
$\displaystyle\lim_{x \to a} f(x) = L$ 意思是：對任意 $\varepsilon > 0$，存在 $\delta > 0$，使得當 $0 < |x - a| < \delta$ 時，$|f(x) - L| < \varepsilon$。
:::

::: {.example name="【完整證明】$\lim_{x\to2}(3x-1)=5$"}
給定 $\varepsilon>0$，取 $\delta=\varepsilon/3$。若 $0<|x-2|<\delta$，則
$$|(3x-1)-5|=3|x-2|<3\delta=\varepsilon.$$
這裡 $\delta$ 是看見對手給的 $\varepsilon$ 後才選，正合量詞順序。
:::

把它讀成一場博弈：對手任意給一個「誤差容忍度」$\varepsilon$（要 $f(x)$ 離 $L$ 多近），你必須回應一個「鄰域半徑」$\delta$（$x$ 要離 $a$ 多近就夠），保證在這個鄰域內函數值都落在容忍範圍。能對**所有** $\varepsilon$ 回應，極限才成立。$\varepsilon$ 在前、$\delta$ 在後，順序不可顛倒 —— 這正是第 0.1 章量詞順序的活用：$\forall \varepsilon\, \exists \delta$，不是 $\exists \delta\, \forall \varepsilon$。

數列極限是同一回事的離散版：

::: {.definition name="數列極限"}
$\displaystyle\lim_{n \to \infty} a_n = L$ 意思是：對任意 $\varepsilon > 0$，存在 $N$，使得 $n > N$ 時 $|a_n - L| < \varepsilon$。
:::

## 連續

::: {.definition}
函數 $f$ 在 $a$ **連續**，若 $\displaystyle\lim_{x \to a} f(x) = f(a)$。即極限存在、且等於函數值。
:::

::: {.theorem name="【接受的黑箱】連續函數的有限次運算"}
在有定義的地方，連續函數的和、積與合成仍連續。
:::

這是有限次運算的保持性；一旦涉及**無窮多個函數的極限**，就會出問題 —— 那正是下一節一致收斂要解決的危機。

## 級數收斂

無窮級數 $\sum_{n=1}^\infty a_n$ 的意義，由**部分和** $S_N = \sum_{n=1}^N a_n$ 的極限定義：若 $\lim_{N\to\infty} S_N = S$ 存在，稱級數收斂於 $S$。

最基本、也最貼近模形式的例子是**幾何級數**：

::: {.proposition name="【完整證明】幾何級數"}
$|q| < 1$ 時，$\displaystyle\sum_{n=0}^\infty q^n = \frac{1}{1 - q}$；$|q| \ge 1$ 時發散。
:::

::: {.proof}
部分和 $S_N = \dfrac{1 - q^{N+1}}{1 - q}$（第 0.5 章單位根求和用過此恆等式）。$|q| < 1$ 時 $q^{N+1} \to 0$，故 $S_N \to \dfrac{1}{1-q}$。$|q| \ge 1$ 時 $q^{N+1}$ 不趨於零，部分和不收斂。
:::

收斂的一個強化版本，在後面極其重要：

::: {.definition name="絕對收斂"}
若 $\sum |a_n|$ 收斂，稱 $\sum a_n$ **絕對收斂**。
:::

上句包含三個標準結果。為避免把定義與定理混在一起，精確標示如下：

::: {.theorem name="【接受的黑箱】絕對收斂的安全操作"}
絕對收斂蘊涵收斂；絕對收斂級數可重排而和不變；兩個絕對收斂級數的 Cauchy 乘積收斂到兩者和的乘積。
:::

絕對收斂是「可以放心操作」的收斂。模形式的 $q$ 展開在收斂區域內絕對收斂，這正是允許我們對它做 Hecke 算子運算、比較係數的技術前提。

## 一致收斂：保住好性質的閘門

現在來到本章的核心，也是分析中最微妙的概念之一。考慮一**列**函數 $f_1, f_2, f_3, \dots$，它們可能「收斂到」一個極限函數 $f$。但「收斂」有兩種強度，差別關乎成敗。

::: {.definition name="逐點 vs 一致收斂"}
- **逐點收斂**：對每個固定的 $x$，$f_n(x) \to f(x)$。（$N$ 可以依賴 $x$。）
- **一致收斂**：對任意 $\varepsilon > 0$，存在**單一**的 $N$（不依賴 $x$），使 $n > N$ 時對**所有** $x$ 都有 $|f_n(x) - f(x)| < \varepsilon$。
:::

差別又在量詞順序：逐點是「$\forall x\, \forall\varepsilon\, \exists N$」（$N$ 看 $x$ 臉色），一致是「$\forall\varepsilon\, \exists N\, \forall x$」（一個 $N$ 通吃所有 $x$）。這個順序差異，決定了極限函數能否繼承好性質。

::: {.example name="【完整證明】逐點不夠：連續性會破裂"}
取 $f_n(x) = x^n$ 在 $[0, 1]$ 上。逐點極限是
$$f(x) = \begin{cases} 0, & 0 \le x < 1 \\ 1, & x = 1 \end{cases}$$
每個 $f_n$ 都連續，但極限函數 $f$ 在 $x = 1$ **不連續**！收斂是逐點的卻非一致的：當 $x$ 逼近 $1$，要讓 $x^n$ 小於 $\varepsilon$ 所需的 $N$ 會無限增大，沒有單一 $N$ 通吃。連續性在逐點收斂下破裂了。
:::

::: {.theorem name="【完整證明】一致收斂保持連續"}
若連續函數列 $f_n$ 在某區間上**一致**收斂於 $f$，則 $f$ 也連續。
:::

::: {.proof}
（$\varepsilon/3$ 論證）要證 $f$ 在 $a$ 連續。給 $\varepsilon > 0$。由一致收斂取 $N$ 使 $|f_N(x) - f(x)| < \varepsilon/3$ 對所有 $x$ 成立。由 $f_N$ 連續，取 $\delta$ 使 $|x - a| < \delta$ 時 $|f_N(x) - f_N(a)| < \varepsilon/3$。則對這樣的 $x$：
$$|f(x) - f(a)| \le |f(x) - f_N(x)| + |f_N(x) - f_N(a)| + |f_N(a) - f(a)| < \tfrac{\varepsilon}{3} + \tfrac{\varepsilon}{3} + \tfrac{\varepsilon}{3} = \varepsilon.$$
故 $f$ 在 $a$ 連續。
:::

「一致收斂保持連續，逐點不保證」是本章已完整證明的結論。逐項積分另有定理；逐項微分則需要導數列一致收斂等更強條件，**不能只靠原函數列一致收斂**。複變函數的局部一致極限定理也另有內容，下面會明列為黑箱。

判斷一致收斂，最常用的工具是：

::: {.theorem name="【接受的黑箱】非負級數的比較與尾和判準"}
若 $0\le a_n\le b_n$ 且 $\sum b_n$ 收斂，則 $\sum a_n$ 收斂；此外，收斂的非負級數尾和 $\sum_{n>N}b_n$ 趨近 $0$。這依賴實數的完備性。
:::

::: {.theorem name="【完整證明；依賴實數完備性黑箱】Weierstrass M-判別法"}
設函數項級數 $\sum f_n(x)$，若存在常數 $M_n$ 使 $|f_n(x)| \le M_n$ 對所有 $x$ 成立，且 $\sum M_n$ 收斂，則 $\sum f_n(x)$ 一致（且絕對）收斂。
:::

::: {.proof}
固定 $x$，比較判別法先給 $\sum|f_n(x)|\le\sum M_n<\infty$，故 $f(x):=\sum f_n(x)$ 存在。給 $\varepsilon>0$；因 $\sum M_n$ 收斂，可取 $N$ 使尾和 $\sum_{n>N}M_n<\varepsilon$。對所有 $x$，
$$\left|f(x)-\sum_{n=1}^Nf_n(x)\right|
\le\sum_{n>N}|f_n(x)|
\le\sum_{n>N}M_n<\varepsilon.$$
同一個 $N$ 對所有 $x$ 都成立，所以一致收斂；第一個比較也給絕對收斂。
:::

::: {.remark name="【接受的黑箱／路線定位】從局部一致收斂到全純"}
模形式長這樣（第 5.4 章）：$f(\tau) = \sum_{n=0}^\infty a_n q^n$，其中 $q = e^{2\pi i \tau}$，$\tau$ 在上半平面（故 $|q| < 1$）。係數 $a_n$ 雖然可能增長（例如 $\sigma_3(n)$ 那樣的除數和），但只要在 $|q| \le r < 1$ 的區域內，$|a_n q^n| \le |a_n| r^n$，而 $|a_n|$ 多項式增長、$r^n$ 指數衰減，乘積仍給出收斂的 $\sum M_n$。由 Weierstrass M-判別法，$q$ 展開在上半平面的緊緻子集上一致收斂，於是 $f$ 是全純函數。

還需要一條複分析定理：全純函數列若在每個緊緻子集上一致收斂，極限仍全純，且可在相應條件下逐項微分。這條在本章標為**接受的黑箱**。因此本章提供收斂估計，複分析黑箱提供「全純」結論；兩者缺一不可。
:::

**檢查點 1.5**　逐點收斂的量詞是 $\forall x\,\forall\varepsilon\,\exists N$；一致收斂是 $\forall\varepsilon\,\exists N\,\forall x$。請指出 $f_n(x)=x^n$ 在 $[0,1]$ 中，為何靠近 $1$ 的 $x$ 會阻止同一個 $N$ 通吃。

## 本章地圖與下一章預告

- **$\varepsilon$–$\delta$ 極限**：把「趨近」釘成量詞博弈；順序 $\forall\varepsilon\,\exists\delta$ 不可逆。
- **連續**：極限等於函數值；保持性在無窮極限下會出問題。
- **級數收斂**：部分和的極限；幾何級數 $\frac{1}{1-q}$；絕對收斂可放心操作。
- **一致收斂**：單一 $N$ 通吃所有 $x$；保持連續（$\varepsilon/3$ 論證）；$x^n$ 的破裂反例。
- **Weierstrass M-判別法**：模形式 $q$ 展開良好的技術後盾。

下一章《歷史插曲 I：Euler 與 $n=3$》以一場證明審核收尾。古典路線迫使我們離開 $\mathbb Z$；但 $\mathbb Z[\sqrt{-3}]$ 不是唯一分解環，不能把整數中的推理原封不動搬過去。下一章會完整證明這個失敗反例，再把正確的 Eisenstein 整數路線拆成「已證計算」與「明示黑箱」，不會宣稱幾頁內已完成全部 $n=3$ 證明。

## 習題

**1.5.1**　用 $\varepsilon$–$\delta$ 定義證明 $\lim_{x \to 2}(3x - 1) = 5$。（給定 $\varepsilon$，明確寫出 $\delta$。）

**1.5.2 ★**　證明數列 $a_n = \dfrac{n}{n+1}$ 收斂於 $1$。（給定 $\varepsilon$，求出 $N$。）

**1.5.3**　判斷下列級數斂散：(a) $\sum \frac{1}{n^2}$；(b) $\sum \frac{1}{n}$（調和級數）；(c) $\sum \frac{1}{2^n}$。（提示：(b) 用分組比較證發散。）

**1.5.4 ★**　證明 $f_n(x) = \dfrac{x}{1 + nx^2}$ 在 $\mathbb{R}$ 上一致收斂於 $0$。（提示：求 $|f_n|$ 的最大值，證它與 $x$ 無關地趨於 $0$ —— 這是「一個 $N$ 通吃」的具體展示。）

**1.5.5 ★**　用 Weierstrass M-判別法證明 $\sum_{n=1}^\infty \dfrac{\cos(nx)}{n^2}$ 在 $\mathbb{R}$ 上一致收斂，故其和為連續函數。

**1.5.6**　驗證模形式 $q$ 展開收斂性的玩具版：設 $|a_n| \le C n^k$（多項式增長），證明 $\sum a_n q^n$ 在 $|q| \le r < 1$ 上絕對且一致收斂。（提示：$\sum n^k r^n$ 收斂 —— 比值判別法。這正是上面 remark 的嚴格版。）

**1.5.7（前瞻）**　Eisenstein 級數候選 $E_4$ 的非定值 $q$-係數是 $240\,\sigma_3(n)$，其中 $\sigma_3(n)=\sum_{d\mid n}d^3$。證明 $\sigma_3(n)\le n\cdot n^3=n^4$，從而相應 $q$-級數在 $|q|<1$ 內收斂。這只驗證解析定義的一部分；模變換律要到後文另證。
