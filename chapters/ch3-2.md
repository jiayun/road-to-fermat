## 開場：唯一分解的復活

第 0.2 章建立了整數的唯一分解；此後第零部三次、第 1.6 章一次，我們眼看著它在更大的數系裡崩塌。$\mathbb{Z}[\sqrt{-5}]$ 裡 $6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5})$，同一個數兩種本質不同的分解。第 3.1 章又確認：即使選對了整閉的環，這個崩塌仍可能發生。

這一章是反轉。Kummer 與 Dedekind 的偉大洞見是：**崩塌的只是「元素」的唯一分解；只要把分解的對象從「元素」換成「理想」，唯一分解就完美復活。** 在 $\mathcal{O}_K$ 裡，每個非零理想都唯一地分解成質理想之積 —— 無一例外。

「理想」這個詞的來歷也在此揭曉：Kummer 原本稱它們為「理想數」（ideale Zahlen）—— 為了挽救唯一分解而**理想化、想像**出來的因子。它們不是 $\mathcal{O}_K$ 裡的真實元素，而是元素的「最大公因子的影子」，是 Kummer 憑數學直覺召喚出來、Dedekind 用集合論落實的幽靈因子。

## 本章前置檢查點

1. **理想、主理想、極大理想、商環**（第 1.4 章）。
2. **Noether、整閉**（第 2.4 章）；**整基底 $\Rightarrow$ Noether**（第 3.1 章）。
3. **範數（元素版與理想版）**（第 3.1 章）—— 本章的每一個「非主理想」論證都靠它。
4. **有限整環是體**（第 1.4 章習題 1.4.4）—— Dedekind 條件 (3) 的證明就是這一句。

## 理想的乘法

第 1.4 章定義了理想（吸收乘法的加法子群）。現在讓理想之間做乘法。

::: {.definition}
兩個理想 $I, J$ 的**積** $IJ$ 是由所有乘積 $ab$（$a \in I, b \in J$）的有限和構成的理想：
$$IJ = \left\{ \textstyle\sum_{k} a_k b_k : a_k \in I,\ b_k \in J,\ \text{有限和} \right\}.$$
:::

理想乘法把「整除」幾何化。在 $\mathbb{Z}$ 裡，$(a)(b) = (ab)$，主理想的乘法就是元素的乘法 —— 所以理想乘法是元素乘法的推廣。關鍵的新觀念是「**整除即包含**」：

> 理想 $I$「整除」理想 $J$，定義為 $J \subseteq I$（$J$ 被 $I$ 包含）。

直覺：在 $\mathbb{Z}$ 裡 $2 \mid 6$ 對應 $(6) \subseteq (2)$（$6$ 的倍數都是 $2$ 的倍數）。**越小的因子，對應越大的理想** —— 包含關係與整除關係恰好相反。這個口訣（to divide is to contain）是理想算術的核心。

::: {.definition}
理想 $\mathfrak{p} \ne \mathcal{O}_K$ 是**質理想**（prime ideal），若 $ab \in \mathfrak{p}$ 蘊涵 $a \in \mathfrak{p}$ 或 $b \in \mathfrak{p}$。
:::

這正是第 0.2 章「質數的整除版定義」（Euclid 引理的性質）升級成理想語言 —— 而且這次，它是**定義**，不再需要從「不可分解」推導。第 0.2 章那個「質數的兩種定義」的微妙區分（不可分解 vs 整除性質），在理想層次得到根本性的釐清：我們直接用「整除性質」定義質理想，繞過了「不可分解」這個會在元素層次出問題的概念。**崩塌的根源，被定義本身規避了。**

## Dedekind 環：三根支柱合攏

::: {.definition}
整環 $R$ 是 **Dedekind 環**，若它同時滿足：

1. **Noether**（第 2.4 章，保證分解終止）；
2. **整閉**（第 2.4 章，沒有遺漏整元素）；
3. **維度 $1$**：每個非零質理想都極大（「沒有介於非零質理想與整個環之間的東西」）。
:::

::: {.theorem name="數域整數環是 Dedekind 環"}
每個數域 $K$ 的整數環 $\mathcal{O}_K$ 都是 Dedekind 環。
:::

**假設**：$K$ 是數域。**用途**：本章主定理的唯一前提。**狀態**：證明骨架 —— 三個條件的來源分別是：

- (1) Noether：來自第 3.1 章「整基底存在」（$\mathcal{O}_K$ 是秩 $n$ 的自由 $\mathbb{Z}$-模，故每個理想作為子模由至多 $n$ 個元素生成）。**這一條的狀態繼承自「整基底存在」，是證明骨架。**
- (2) 整閉：由 $\mathcal{O}_K$ 的定義即得（它就是整閉包），**完整證明**。
- (3) 維度 $1$：設 $\mathfrak{p} \ne 0$ 質理想。$\mathcal{O}_K/\mathfrak{p}$ 是整環，且**有限**（因為 $\mathfrak{p}$ 含某個非零有理整數 $m$ —— 取 $0 \ne \alpha \in \mathfrak{p}$，$N(\alpha) \in \mathfrak{p} \cap \mathbb{Z}$ —— 故 $\mathcal{O}_K/\mathfrak{p}$ 是 $\mathcal{O}_K/m\mathcal{O}_K$ 的商，後者有 $m^n$ 個元素）。由第 1.4 章習題 1.4.4，有限整環必為體，故 $\mathfrak{p}$ 極大。**這一條完整證明**（模掉 $N(\alpha) \in (\alpha) \subseteq \mathfrak{p}$ 這個小驗算，見習題 3.2.2）。

三根支柱 —— 第 2.4 章辛苦搭建的螺絲釘、第 3.1 章的整基底 —— 在此合力。

## 分歧、分裂、慣性：質數在 $\mathcal{O}_K$ 裡的三種命運

第 3.1 章欠了一個定義。現在補上。

設 $p$ 是有理質數。$p\mathcal{O}_K$ 是 $\mathcal{O}_K$ 的理想，由下面的主定理它唯一分解成
$$p\,\mathcal{O}_K = \mathfrak{p}_1^{e_1}\cdots\mathfrak{p}_g^{e_g},$$
其中 $\mathfrak{p}_i$ 是相異質理想。定義 $e_i$ 為 $\mathfrak{p}_i$ 的**分歧指數**（ramification index），$f_i = [\mathcal{O}_K/\mathfrak{p}_i : \mathbb{F}_p]$ 為**剩餘次數**（residue degree，於是 $N(\mathfrak{p}_i) = p^{f_i}$）。

::: {.theorem name="基本恆等式"}
$$\sum_{i=1}^{g} e_i f_i = n = [K:\mathbb{Q}].$$
:::

**用途**：這是「一個質數在 $\mathcal{O}_K$ 裡能怎麼裂」的守恆律 —— 給定 $n$，可能的分解型態只有有限多種，於是可以逐一檢查。**狀態**：外部黑盒（Neukirch《Algebraic Number Theory》第 I 章）。

三種命名：

- **分歧**（ramified）：某個 $e_i > 1$。由第 3.1 章的 Dedekind 定理，這等價於 $p \mid \mathrm{disc}(K)$，只有有限多個 $p$ 會這樣。
- **分裂**（split）：$g > 1$ 且所有 $e_i = 1$。
- **慣性**（inert）：$g = 1, e_1 = 1$，即 $p\mathcal{O}_K$ 本身就是質理想。

::: {.example name="$\mathbb{Z}[i]$：三種命運一次看全"}
$K = \mathbb{Q}(i)$，$n = 2$，$\mathrm{disc} = -4$。基本恆等式給 $\sum e_i f_i = 2$，所以只有三種可能，而三種都出現：

| $p$ | 分解 | $(e, f, g)$ | 命運 |
|---|---|---|---|
| $2$ | $(2) = (1+i)^2$ | $(2, 1, 1)$ | 分歧 |
| $5$ | $(5) = (2+i)(2-i)$ | $(1, 1, 2)$ | 分裂 |
| $3$ | $(3)$ 本身是質理想 | $(1, 2, 1)$ | 慣性 |

驗算 $p = 2$：$(1+i)^2 = 2i$，而 $i$ 是單位，故 $(1+i)^2 = (2)$ ✓。且 $2 \mid \mathrm{disc} = -4$，與「分歧 $\iff p \mid \mathrm{disc}$」一致 ✓。

驗算 $p = 5$：$(2+i)(2-i) = 4 + 1 = 5$ ✓，且 $N(2\pm i) = 5$ 故兩者都是質元素。

驗算 $p = 3$：若 $(3)$ 可裂，會有範數 $3$ 的元素，即 $a^2+b^2 = 3$ —— 無整數解。故慣性。

**這張表就是費馬兩平方和定理的理想版**：$p$ 分裂 $\iff p = a^2+b^2$ $\iff p \equiv 1 \pmod 4$（或 $p = 2$）。一個初等數論的老定理，在這裡變成「質數在 $\mathbb{Z}[i]$ 裡如何分解」的陳述。這就是代數數論的作風：把算術問題翻譯成理想分解的問題。
:::

::: {.remark name="檢查點 3.2.A"}
1. 在 $\mathbb{Z}[\sqrt{-5}]$ 中，$5$ 分歧嗎？（$\mathrm{disc} = -20$，$5 \mid 20$，故**分歧**。實際上 $(5) = (\sqrt{-5})^2$。）
2. $\mathbb{Q}(\zeta_p)$ 中 $p$ 的 $(e,f,g)$ 是什麼？（$n = p-1$。由第 2.3 章 $p = (\text{單位})(1-\zeta_p)^{p-1}$ 知 $(p) = (1-\zeta_p)^{p-1}$，故 $e = p-1$、$f = 1$、$g = 1$ —— **完全分歧**，$\sum ef = p-1$ ✓。）
3. 第 2 題的 $(1-\zeta_p)$ 範數是多少？（$N(\mathfrak{p}) = p^f = p$。與 $N(1-\zeta_p) = \Phi_p(1) = p$ 一致 ✓。）
:::

## 主定理：理想唯一分解

::: {.theorem name="Dedekind：理想唯一分解"}
設 $\mathcal{O}_K$ 為數域的整數環（更一般地，任何 Dedekind 環）。則每個非零真理想 $I$ 都能寫成質理想之積
$$I = \mathfrak{p}_1^{e_1} \mathfrak{p}_2^{e_2} \cdots \mathfrak{p}_r^{e_r},$$
且這個表示在不計順序的意義下**唯一**。
:::

**假設**：$\mathcal{O}_K$ 是 Dedekind 環（三個條件缺一不可 —— 第 1.6 章 Euler 的 $\mathbb{Z}[\sqrt{-3}]$ 不整閉，這條定理對它**不成立**）。**用途**：整個第三部的武器庫。Kummer 攻擊 FLT 的第一步（「因子理想各自是 $p$ 次方」）就是它的直接推論。**狀態**：證明骨架 —— 架構如下，唯一被略過的是那條標明的**關鍵引理**。

::: {.proof}
（骨架）論證與第 0.2 章整數唯一分解平行，但工具升級。核心是一條引理：

> **關鍵引理（本書略過）**：對非零質理想 $\mathfrak{p}$，令 $\mathfrak{p}^{-1} = \{x \in K : x\mathfrak{p} \subseteq \mathcal{O}_K\}$。則 $\mathfrak{p}^{-1}\mathfrak{p} = \mathcal{O}_K$，即**質理想可逆**。

這條引理是整條定理的樞紐，也是三個 Dedekind 條件真正發力的地方：Noether 用來造出 $\mathfrak{p}^{-1}$ 中的非平凡元素；**整閉性**用來排除 $\mathfrak{p}^{-1}\mathfrak{p} = \mathfrak{p}$ 這個壞情形（若相等，$\mathfrak{p}^{-1}$ 的元素會對 $\mathcal{O}_K$ 整，由整閉性落回 $\mathcal{O}_K$，矛盾 —— **這正是第 2.4 章強調「整閉不是裝飾」的兌現**）；維度 $1$ 用來保證 $\mathfrak{p}$ 極大。完整論證見 Marcus《Number Fields》第 3 章，或 Neukirch《Algebraic Number Theory》第 I 章。

**存在性（給定引理）：** 假設有理想不能分解。由 Noether 的升鏈條件，可取一個「極大的反例」$I$。$I$ 含於某極大理想 $\mathfrak{p}$（Noether 保證極大理想存在），於是 $I \subseteq \mathfrak{p}$，故 $\mathfrak{p}^{-1}I \subseteq \mathfrak{p}^{-1}\mathfrak{p} = \mathcal{O}_K$，即 $I' := \mathfrak{p}^{-1}I$ 是理想，且 $I = \mathfrak{p}I'$。又可證 $I \subsetneq I'$（嚴格變大）。由 $I$ 的極大反例性，$I'$ 可分解，於是 $I = \mathfrak{p}I'$ 也可 —— 矛盾。

**唯一性（給定引理）：** 若 $\mathfrak{p}_1 \cdots \mathfrak{p}_r = \mathfrak{q}_1 \cdots \mathfrak{q}_s$，則 $\mathfrak{p}_1$ 包含右邊的積，由質性必包含某個 $\mathfrak{q}_j$；兩者皆極大（維度 $1$）故相等。用 $\mathfrak{p}_1^{-1}$ 左乘消去，對長度作歸納。

**機制的一句話總結：** 元素 $2$ 在 $\mathbb{Z}[\sqrt{-5}]$ 裡無法「除以」一個更小的真因子，但理想 $(2)$ 可以分解成 $\mathfrak{p}_2^2$。理想比元素「可分」，因為理想有逆 —— 而元素沒有。這就是唯一分解能在理想層次復活的機制根源。
:::

## 完整示範：$\mathbb{Z}[\sqrt{-5}]$ 的 $6$ 被調和

現在回到那個困擾我們整本書的反例，看它如何在理想層次被治癒。在 $\mathbb{Z}[\sqrt{-5}]$（第 3.1 章確認它是正確的整閉環）中，引入三個理想：
$$\mathfrak{p}_2 = (2,\, 1+\sqrt{-5}), \qquad \mathfrak{p}_3 = (3,\, 1+\sqrt{-5}), \qquad \mathfrak{p}_3' = (3,\, 1-\sqrt{-5}).$$

**它們的範數分別是 $2, 3, 3$**（例如 $\mathcal{O}_K/\mathfrak{p}_2$ 中 $\sqrt{-5} \equiv -1$ 且 $2 \equiv 0$，故商只有兩個元素）。範數是質數 $\Rightarrow$ 商環是 $\mathbb{F}_p$ $\Rightarrow$ 商是體 $\Rightarrow$ 理想極大 $\Rightarrow$ 質理想。所以三者都是質理想。

四個主理想的分解（每一條都可直接驗算，習題 3.2.4）：
$$(2) = \mathfrak{p}_2^2, \quad (3) = \mathfrak{p}_3\,\mathfrak{p}_3', \quad (1+\sqrt{-5}) = \mathfrak{p}_2\,\mathfrak{p}_3, \quad (1-\sqrt{-5}) = \mathfrak{p}_2\,\mathfrak{p}_3'.$$

驗算第一條當範例：$\mathfrak{p}_2^2$ 由 $4$、$2(1+\sqrt{-5})$、$(1+\sqrt{-5})^2 = -4+2\sqrt{-5}$ 生成。三個生成元都在 $(2)$ 裡，故 $\mathfrak{p}_2^2 \subseteq (2)$。反過來，$(-4+2\sqrt{-5}) - (2+2\sqrt{-5}) = -6$，配上 $4$ 得 $\gcd$ 型組合 $4 - 6 \cdot 1 \cdot (\dots)$：具體地 $2 = 4 \cdot 2 + (-6)$，故 $2 \in \mathfrak{p}_2^2$，即 $(2) \subseteq \mathfrak{p}_2^2$。兩邊相等 ✓。

現在看那兩個「矛盾的」元素分解，在理想層次發生什麼：
$$\begin{aligned}
(6) = (2)(3) &= \mathfrak{p}_2^2 \cdot \mathfrak{p}_3 \mathfrak{p}_3', \\
(6) = (1+\sqrt{-5})(1-\sqrt{-5}) &= (\mathfrak{p}_2\mathfrak{p}_3)(\mathfrak{p}_2\mathfrak{p}_3') = \mathfrak{p}_2^2 \cdot \mathfrak{p}_3 \mathfrak{p}_3'.
\end{aligned}$$

**兩條路徑得到同一個質理想分解 $\mathfrak{p}_2^2 \mathfrak{p}_3 \mathfrak{p}_3'$。** 用範數覆核：兩邊都是 $N = 2^2 \cdot 3 \cdot 3 = 36 = \lvert N(6)\rvert$，分毫不差。

::: {.remark name="矛盾消失了"}
停下來體會這個調和。元素層次的「矛盾」—— $2 \cdot 3$ 對 $(1+\sqrt{-5})(1-\sqrt{-5})$ —— 其根源是：$2, 3, 1\pm\sqrt{-5}$ 都是「不可分解」的元素（用範數驗證，習題 3.1.6），但它們不是「質的」。它們各自其實還能再分，只是分出來的因子 $\mathfrak{p}_2, \mathfrak{p}_3, \mathfrak{p}_3'$ **不是 $\mathbb{Z}[\sqrt{-5}]$ 裡的真實元素**（沒有任何元素生成 $\mathfrak{p}_2$，習題 3.2.5）。它們是 Kummer 的「理想數」—— 看不見的真質因子。

元素 $2$ 與 $1+\sqrt{-5}$ 之所以看起來「互質又同時整除 $6$」而導致矛盾，是因為它們暗中共享一個隱形因子 $\mathfrak{p}_2$。一旦把這個隱形因子顯影出來，矛盾立刻消解：它們本來就不互質，只是那個公因子藏在 $\mathbb{Z}[\sqrt{-5}]$ 看不見的地方。理想理論，是讓這些隱形因子現形的顯微鏡。

這正是「ideal」的字面意義 —— $\mathfrak{p}_2$ 是一個**理想化**的數，一個 $\mathbb{Z}[\sqrt{-5}]$ 渴望擁有、卻不真正包含的「最大公因子」。Dedekind 的天才，是用一個**集合** $(2, 1+\sqrt{-5})$ 來具現這個不存在的數。看不見的因子，被一個看得見的集合捕捉。
:::

## 為 Kummer 的攻擊備好彈藥 —— 以及新的障礙

理想唯一分解，正是 Lamé 證明所缺、而 Kummer 補上的東西。回憶第 0.5 章：FLT 方程在 $\mathbb{Z}[\zeta_p]$ 裡分解成
$$(x + y)(x + \zeta_p y)\cdots(x + \zeta_p^{p-1}y) = z^p.$$
Lamé 想說「左邊因子兩兩互質，乘積是 $p$ 次方，故各自是 $p$ 次方」—— 但這依賴**元素**唯一分解，在 $\mathbb{Z}[\zeta_p]$ 裡未必成立。

Kummer 的修正：把這個論證**搬到理想層次**。以下這條推論現在**嚴格無誤**：

::: {.corollary name="理想層次的開方"}
設 $\mathfrak{a}_0, \dots, \mathfrak{a}_{p-1}$ 是 $\mathcal{O}_K$ 的兩兩互質的非零理想（即 $\mathfrak{a}_i + \mathfrak{a}_j = \mathcal{O}_K$，$i \ne j$），且 $\prod_k \mathfrak{a}_k = \mathfrak{c}^{\,p}$ 是某理想的 $p$ 次方。則每個 $\mathfrak{a}_k$ 本身都是某理想的 $p$ 次方。
:::

**狀態**：完整證明（給定主定理）—— 把兩邊都寫成質理想的唯一分解；互質表示各 $\mathfrak{a}_k$ 用到的質理想集合互不相交，故右邊每個質理想的指數（是 $p$ 的倍數）必整個落在某一個 $\mathfrak{a}_k$ 裡。逐個質理想比較指數即得。

**但隨即出現一個新障礙。** 我們得到 $(x + \zeta_p^k y) = \mathfrak{a}_k^p$，想推出「$x + \zeta_p^k y$ 是某個**元素**的 $p$ 次方」—— 這需要 $\mathfrak{a}_k$ 是**主理想**。而一般而言它不是。

從「理想是 $p$ 次方」到「元素是 $p$ 次方」之間，隔著一個障礙。這個障礙的大小，由一個叫**類數**的量精確衡量。下一章就去丈量它。

## 本章地圖與下一章預告

- **理想乘法與整除**：$IJ$；「整除即包含」$J \subseteq I$。
- **質理想**：Euclid 引理性質升級為定義；繞過「不可分解」的崩塌。
- **Dedekind 環**：Noether + 整閉 + 維度 $1$；$\mathcal{O}_K$ 必為之。
- **分歧、分裂、慣性**：$\sum e_i f_i = n$；$\mathbb{Z}[i]$ 三種命運與費馬兩平方和定理。
- **理想唯一分解**：永遠成立；樞紐是「質理想可逆」，而整閉性正是它的來源。
- **$\mathbb{Z}[\sqrt{-5}]$ 的 $6$**：兩種元素分解被調和為 $\mathfrak{p}_2^2\mathfrak{p}_3\mathfrak{p}_3'$。
- **新障礙**：理想是 $p$ 次方 $\ne$ 元素是 $p$ 次方，因為理想未必主。

下一章《類群與單位》引入兩個衡量「理想世界與元素世界差距」的量。**類群** $\mathrm{Cl}(K)$ 衡量「有多少理想不是主理想」—— 它的大小（**類數** $h_K$）正是上面那個障礙的精確尺寸；$h_K = 1$ 等價於唯一分解成立。**單位群**則衡量 $\mathcal{O}_K$ 裡有多少可逆元（如第 1.6 章 Eisenstein 整數的六個單位），它控制著「元素分解的不唯一性」中可被單位吸收的部分。掌握這兩個量，才能精確說出 Kummer 對哪些質數能成功 —— 那是第 3.4 章的高潮。

## 習題

**3.2.1**　在 $\mathbb{Z}$ 中驗證「整除即包含」：證明 $a \mid b \iff (b) \subseteq (a)$。並說明為什麼「越小的因子對應越大的理想」。

**3.2.2 ★**　補上「維度 $1$」證明中的小驗算：設 $0 \ne \alpha \in \mathfrak{p} \subseteq \mathcal{O}_K$，證明 $N_{K/\mathbb{Q}}(\alpha)$ 是一個落在 $\mathfrak{p}$ 中的非零有理整數。（提示：$N(\alpha) = \alpha \cdot \prod_{i \ge 2}\sigma_i(\alpha)$，而後面那個積落在 $\mathcal{O}_K$ 中 —— 這是第 3.1 章單位判準證明裡用過的同一個觀察。）

**3.2.3 ★**　證明在 Dedekind 環中，質理想 $\mathfrak{p}$ 滿足「$\mathfrak{p} \supseteq IJ \Rightarrow \mathfrak{p} \supseteq I$ 或 $\mathfrak{p} \supseteq J$」（質理想的「整除版」性質）。（提示：反證，取 $a \in I$ 但 $a \notin \mathfrak{p}$、$b \in J$ 但 $b \notin \mathfrak{p}$，再看 $ab$。）

**3.2.4 ★**　在 $\mathbb{Z}[\sqrt{-5}]$ 中，逐一驗證四條分解 $(2) = \mathfrak{p}_2^2$、$(3) = \mathfrak{p}_3\mathfrak{p}_3'$、$(1+\sqrt{-5}) = \mathfrak{p}_2\mathfrak{p}_3$、$(1-\sqrt{-5}) = \mathfrak{p}_2\mathfrak{p}_3'$。（本文示範了第一條；其餘三條用同樣手法 —— 先驗兩個包含方向，或用範數配合基本恆等式。）

**3.2.5 ★**　證明 $\mathfrak{p}_2 = (2, 1+\sqrt{-5})$ **不是**主理想。（提示：若 $\mathfrak{p}_2 = (\alpha)$ 則 $\lvert N(\alpha)\rvert = N(\mathfrak{p}_2) = 2$，但 $a^2 + 5b^2 = 2$ 無整數解 —— 與習題 3.1.6 同一個算法。這個「非主」正是 $\mathfrak{p}_2$ 作為「理想數」而非真實數的體現。）

**3.2.6**　用範數計算驗證 $\mathbb{Z}[\sqrt{-5}]$ 中 $(6) = \mathfrak{p}_2^2\mathfrak{p}_3\mathfrak{p}_3'$：確認兩邊範數都是 $36$。

**3.2.7（分歧練習）**　用「分歧 $\iff p \mid \mathrm{disc}$」判斷：在 $\mathbb{Z}[\sqrt{-5}]$ 中哪些質數分歧？（$\mathrm{disc} = -20$，故 $2$ 與 $5$。驗證 $(5) = (\sqrt{-5})^2$ 確實分歧。）

**3.2.8（前瞻）**　質理想 $\mathfrak{p}_2$ 不是主理想，但 $\mathfrak{p}_2^2 = (2)$ **是**主理想。所以 $\mathfrak{p}_2$ 在下一章的「類群」中是 $2$ 階元素（它本身非主，平方變主）。猜測 $\mathbb{Z}[\sqrt{-5}]$ 的類數至少是多少，並預測這個 $2$ 階元素說明了什麼樣的「離唯一分解的距離」。（下一章你會算出類數恰好是 $2$。）
