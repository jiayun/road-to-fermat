## 開場：主角二號登場

橢圓曲線（主角一號）已經刻畫完畢，帶著它的算術指紋 $\{a_p\}$。現在主角二號 —— **模形式** —— 從一個截然不同的世界走來：不是代數幾何的曲線，而是複分析的函數，活在上半平面上，擁有一種近乎不可思議的對稱性。

模形式的奇蹟在於：它是一個被「過度約束」的對象。它必須在一個無窮大的對稱群作用下保持特定的變換規律 —— 這個要求如此苛刻，乍看之下幾乎不可能有非零的函數滿足。但它們確實存在，而且一旦存在，這種過度約束反而使它們**異常剛硬**：每個權重只有有限維的模形式空間，每個模形式由有限多個係數完全決定。這種剛性，加上它們攜帶的算術指紋 $\{a_p(f)\}$，使它們能與橢圓曲線比對 —— 那就是谷山–志村猜想。

本章定義模形式。前面的線索終於匯流：第 1.5 章證了 $q$ 展開收斂、第 4.1 章證了全純與剛性、第 4.2 章的 $g_2, g_3$ 已是最早的模形式、第 4.4 章看見了上半平面 $\mathbb{H}$ 與模群 $\mathrm{SL}_2(\mathbb{Z})$。現在把它們組裝成正式定義。

## 上半平面與模群

模形式生活在**上半平面**
$$\mathbb{H} = \{\tau \in \mathbb{C} : \mathrm{Im}(\tau) > 0\}$$
上。**模群** $\mathrm{SL}_2(\mathbb{Z})$（行列式為 $1$ 的 $2\times2$ 整數矩陣，第 1.1 章 $\mathrm{SL}_2$ 的整數版）作用在 $\mathbb{H}$ 上：
$$\begin{pmatrix} a & b \\ c & d \end{pmatrix} \cdot \tau = \frac{a\tau + b}{c\tau + d}.$$
這個作用（第 4.4 章習題 4.4.4 驗過保持 $\mathbb{H}$）由兩個元素生成：平移 $T: \tau \mapsto \tau + 1$ 與反演 $S: \tau \mapsto -1/\tau$。直觀上，$\mathbb{H}/\mathrm{SL}_2(\mathbb{Z})$ 是「所有橢圓曲線的參數空間」（第 4.4 章：每個 $\tau$ 給一個格 $\mathbb{Z} + \mathbb{Z}\tau$，故一條橢圓曲線）。模形式就是這個參數空間上「幾乎不變」的函數。

## 模形式的定義

::: {.definition}
**權重 $k$ 的模形式**（對 $\mathrm{SL}_2(\mathbb{Z})$）是全純函數 $f: \mathbb{H} \to \mathbb{C}$，滿足：

1. **變換律**：對所有 $\begin{pmatrix} a & b \\ c & d \end{pmatrix} \in \mathrm{SL}_2(\mathbb{Z})$，
$$f\!\left(\frac{a\tau + b}{c\tau + d}\right) = (c\tau + d)^k\, f(\tau).$$
2. **尖點全純**：$f$ 在「尖點」$\tau \to i\infty$ 處有界（保證 $q$ 展開無負次項）。
:::

變換律是核心。用生成元 $T, S$ 表達，它等價於兩條：
$$f(\tau + 1) = f(\tau) \quad(\text{週期 } 1), \qquad f(-1/\tau) = \tau^k f(\tau) \quad(\text{反演律}).$$
第一條（週期性）讓 $f$ 有 $q$ 展開；第二條（反演律）是真正苛刻的對稱要求。一個函數要同時滿足這兩條，是極強的限制。

::: {.remark name="過度約束的奇蹟"}
停下來體會這個定義有多苛刻。週期性 $f(\tau+1) = f(\tau)$ 還算溫和。但反演律 $f(-1/\tau) = \tau^k f(\tau)$ 把 $\tau$ 與 $-1/\tau$（上半平面裡相距可能很遠的兩點）的值死死綁定。再加上 $\mathrm{SL}_2(\mathbb{Z})$ 的其他無窮多個元素，$f$ 在 $\mathbb{H}$ 上幾乎每個點的值都被其他點約束。

直覺上這樣的非零函數不該存在 —— 約束太多了。但它們存在，而這正是模形式深刻的來源：**過度約束不是 bug，是 feature**。正因為約束如此之多，滿足約束的函數空間極小（有限維），於是每個模形式都攜帶大量「剛性資訊」。一個模形式的有限多個 $q$ 展開係數，就鎖死了整個函數 —— 這種「少量資訊決定一切」的特性（第 4.1 章恆等定理的加強版），是模形式能編碼深刻算術、能與橢圓曲線精確比對的根本原因。模形式是數學中「對稱性產生剛性、剛性產生資訊」的典範。
:::

## $q$ 展開與指紋

由週期性 $f(\tau + 1) = f(\tau)$，$f$ 可以用 $q = e^{2\pi i\tau}$ 展開（第 1.5、4.1 章）。當 $\mathrm{Im}(\tau) \to \infty$，$q \to 0$，於是：

::: {.definition}
模形式 $f$ 的 **$q$ 展開**（Fourier 展開）：
$$f(\tau) = \sum_{n=0}^\infty a_n(f)\, q^n, \qquad q = e^{2\pi i\tau}.$$
係數 $\{a_n(f)\}$ 是模形式的**指紋**。$a_0(f)$ 是 $f$ 在尖點 $i\infty$ 的值。
:::

這個指紋 $\{a_n(f)\}$，正是要與橢圓曲線指紋 $\{a_p\}$ 比對的對象。由第 4.1 章的恆等定理，係數完全決定模形式 —— 所以「兩個模形式指紋相同」等價於「它們是同一個模形式」，這讓「比對指紋」成為一個有意義的、能判定相等的操作。

## 第一個例子：Eisenstein 級數

最容易構造的模形式來自第 4.2 章的 $g_2, g_3$ —— 把它們正規化成 **Eisenstein 級數**。

::: {.definition}
權重 $k$（偶數 $\ge 4$）的 **Eisenstein 級數**：
$$E_k(\tau) = \frac{1}{2\zeta(k)}\sum_{(m,n) \ne (0,0)} \frac{1}{(m\tau + n)^k}.$$
:::

它的變換律直接來自求和的對稱性（習題 5.4.2）。$q$ 展開是（用第 3.4 章的 Bernoulli 數）：
$$E_4 = 1 + 240\sum_{n\ge1}\sigma_3(n)q^n, \qquad E_6 = 1 - 504\sum_{n\ge1}\sigma_5(n)q^n,$$
其中 $\sigma_{k-1}(n) = \sum_{d\mid n}d^{k-1}$ 是除數冪和。

::: {.example name="$E_4$ 的回歸"}
$E_4 = 1 + 240q + 2160q^2 + 6720q^3 + \cdots$ —— 這正是第 1.5 章習題 5.1.7（當時叫 1.5.7）讓你驗證收斂的那個級數！當時你「驗證了人生第一個模形式的收斂」卻還不知道模形式是什麼；現在它有了名字：權重 $4$ 的 Eisenstein 級數。$g_2 = 60\sum\omega^{-4}$（第 4.2 章）正比於 $E_4$，$g_3$ 正比於 $E_6$。第四部埋的種子，在這裡開花。

數值驗證確認了變換律：$E_4(-1/\tau)/[\tau^4 E_4(\tau)] = 1.0000$，反演律 $f(-1/\tau) = \tau^4 f(\tau)$ 精確成立。
:::

## 尖形式與模判別式

Eisenstein 級數有 $a_0 \ne 0$（在尖點不消失）。真正攜帶最深算術的，是在尖點**消失**的模形式。

::: {.definition}
**尖形式**（cusp form）是 $a_0(f) = 0$ 的模形式（在尖點 $i\infty$ 處值為零）。權重 $k$、級 $\mathrm{SL}_2(\mathbb{Z})$ 的尖形式空間記 $S_k$。
:::

第一個非零尖形式出現在權重 $12$：

::: {.definition name="模判別式"}
$$\Delta(\tau) = \frac{E_4^3 - E_6^2}{1728} = q\prod_{n\ge1}(1 - q^n)^{24} = \sum_{n\ge1}\tau(n)q^n.$$
:::

$\Delta$ 是權重 $12$ 的尖形式（$a_0 = 0$，因 $q$ 的最低次是 $1$）。它的係數 $\tau(n)$ 是著名的 **Ramanujan $\tau$ 函數**：$\tau(1) = 1, \tau(2) = -24, \tau(3) = 252, \dots$，充滿神祕的算術性質（如 $\tau(mn) = \tau(m)\tau(n)$ 當 $\gcd(m,n)=1$，第 5.5 章 Hecke 算子會解釋）。

::: {.remark name="$\Delta$、判別式、$691$"}
$\Delta$ 這個名字不是巧合 —— 它與橢圓曲線的判別式同源。對應於格 $\Lambda = \mathbb{Z} + \mathbb{Z}\tau$ 的橢圓曲線，其判別式正比於 $\Delta(\tau)$。模判別式是「判別式作為格的函數」的化身，而它的尖形式性質（$a_0 = 0$）對應「判別式在退化極限消失」。第 4.2、5.1 章的判別式 $\Delta = -16(4a^3+27b^2)$，與這裡的模形式 $\Delta(\tau)$，是同一個東西的兩種面孔。

更神祕的是 Ramanujan 同餘 $\tau(p) \equiv p^{11} + 1 \pmod{691}$ —— 那個 $691$ 正是第 3.4 章的非正則質數（$691 \mid B_{12}$ 分子）！權重 $12$、Bernoulli 數 $B_{12}$、非正則質數 $691$、Ramanujan $\tau$ —— 這些看似無關的東西在 $691$ 處神祕交會。這不是巧合，而是模形式與分圓域算術深層聯繫（岩澤理論，第七部祖先）的冰山一角。第 3.4 章習題 3.4.4 預告的「$691$ 會再遇到」，在這裡兌現。
:::

## 有限維性：剛性的精確形式

模形式「過度約束」的最精確後果，是空間的有限維。

::: {.theorem name="模形式空間有限維"}
每個權重 $k$，模形式空間 $M_k$ 與尖形式空間 $S_k$ 都是**有限維**的。具體地（對 $\mathrm{SL}_2(\mathbb{Z})$）：$\dim M_k$ 約為 $k/12$。
:::

::: {.example name="低權重的維度"}
$\dim M_0 = 1$（常數）、$\dim M_4 = \dim M_6 = \dim M_8 = \dim M_{10} = 1$（各由 $E_k$ 生成），但 $\dim M_{12} = 2$ —— 權重 $12$ 第一次容納兩個獨立模形式（$E_4^3$ 與 $\Delta$），於是第一個尖形式 $\Delta$ 在此誕生。
:::

::: {.remark name="有限維性是 Hecke 對角化的根基"}
有限維性看似技術，實則是第 5.5 章整套理論的根基。回憶第 1.2 章：Hecke 算子是作用在模形式空間上的線性算子，它們兩兩交換，故可同時對角化 —— 但「同時對角化」這個操作需要**有限維**空間（第 1.2 章的同時對角化定理就假設有限維）。正因為 $S_k$ 有限維，Hecke 算子才能被對角化，特徵形式（共同特徵向量）才存在，$\{a_p(f)\}$ 作為 Hecke 特徵值才有意義。

於是模形式的「過度約束 → 有限維 → 可對角化 → 特徵形式 → 算術指紋」這條鏈，全靠最初那個苛刻的變換律。對稱性產生剛性（有限維），剛性產生結構（特徵形式），結構產生算術（指紋）。模形式之所以能編碼橢圓曲線的 $a_p$，根源就在這條從對稱到算術的鏈條。下一章就走完它。
:::

## 本章地圖與下一章預告

- **上半平面與模群**：$\mathbb{H}$、$\mathrm{SL}_2(\mathbb{Z})$ 作用、$T$ 與 $S$ 生成。
- **模形式定義**：變換律 $f(\frac{a\tau+b}{c\tau+d}) = (c\tau+d)^k f(\tau)$；過度約束的奇蹟。
- **$q$ 展開**：$f = \sum a_n q^n$；指紋 $\{a_n(f)\}$；恆等定理保證係數決定一切。
- **Eisenstein 級數與 $\Delta$**：$E_4, E_6$（$g_2, g_3$ 的回歸）；尖形式 $\Delta$、Ramanujan $\tau$、$691$。
- **有限維性**：$\dim M_{12} = 2$ 生出第一個尖形式；Hecke 對角化的根基。

下一章《模形式 II》建立模形式理論的算術心臟：**Hecke 算子**。我們會看到這些算子如何作用在尖形式空間上、兩兩交換、可同時對角化（第 1.2 章的線性代數終於兌現），其共同特徵向量就是**特徵形式**，而特徵值序列 $\{a_p(f)\}$ 就是模形式的指紋。我們還會引入新舊形式（newform/oldform）的概念 —— 這對 Ribet 的 level lowering（第 6.6 章）至關重要。走完第 5.5 章，模形式這一側的指紋就完全建立，第 5.7 章兩位主角的指紋比對 —— 谷山–志村猜想 —— 終於可以正式陳述。

## 習題

**5.4.1**　驗證 $\mathrm{SL}_2(\mathbb{Z})$ 的變換律由 $T: \tau \mapsto \tau+1$ 與 $S: \tau \mapsto -1/\tau$ 推出週期性 $f(\tau+1) = f(\tau)$ 與反演律 $f(-1/\tau) = \tau^k f(\tau)$。

**5.4.2 ★**　證明 Eisenstein 級數 $E_k(\tau) = \frac{1}{2\zeta(k)}\sum'(m\tau+n)^{-k}$ 滿足權重 $k$ 變換律。（提示：$\mathrm{SL}_2(\mathbb{Z})$ 作用置換求和指標 $(m,n)$，配合 $(c\tau+d)^k$ 因子。）

**5.4.3**　計算 $E_4$ 的 $q$ 展開前三項，驗證 $E_4 = 1 + 240q + 2160q^2 + \cdots$（用 $\sigma_3(1)=1, \sigma_3(2)=9$）。

**5.4.4 ★**　證明：權重 $k$ 為奇數時，唯一的模形式是 $0$。（提示：用變換律於 $\begin{pmatrix}-1&0\\0&-1\end{pmatrix}$，得 $f(\tau) = (-1)^k f(\tau)$。）

**5.4.5**　$\Delta = \frac{E_4^3 - E_6^2}{1728}$ 是權重 $12$。驗證 $E_4^3$ 與 $E_6^2$ 都是權重 $12$（權重相乘相加規則），且 $\Delta$ 的 $a_0 = 0$（用 $E_4 = 1 + \cdots$、$E_6 = 1 + \cdots$ 的常數項）。

**5.4.6（前瞻）**　Ramanujan 同餘 $\tau(p) \equiv p^{11} + 1 \pmod{691}$。$691$ 是非正則質數（第 3.4 章，$691 \mid B_{12}$ 分子）。查閱並用一句話說明：為什麼權重 $12$ 的尖形式 $\Delta$ 會與 $B_{12}$、$691$ 神祕相關？（提示：Eisenstein 級數的常數項含 Bernoulli 數，$E_{12}$ 與 $\Delta$ 在 mod $691$ 同餘 —— 這是模形式與分圓算術聯繫的線索。）
