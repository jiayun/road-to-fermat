## 開場：為了攻擊整數，先擴張整數

上一章末尾留下一個尖銳的結論：那套畢氏三元數遞降法停在 $n=4$，不能直接處理一般奇質數 $p$。歷史上最有力的新方向，是離開 $\mathbb{Z}$，進入更大的數系。那些數系長什麼樣？最重要的一族叫**分圓整數** $\mathbb{Z}[\zeta_p]$ —— 把普通整數和「$p$ 次單位根」$\zeta_p$ 攪在一起生成的數。

要理解 $\zeta_p$，得先把複數、單位根、多項式這三件高中只匆匆掠過的東西講清楚。這一章是第零部的最後一塊拼圖，表面上像在補基礎，實際上是在為第三部 Kummer 的戰場鋪設地基。每一節都會指出它將如何在後面被用到。

具體說，本章鋪三條路：

- **複數平面**讓「$n$ 次方根」變成幾何上均勻分布的點 —— 這是 $\zeta_p$ 的形象。
- **代數基本定理**保證任何多項式都能完全分解 —— 這是「在更大數系裡做因式分解」的許可證，而 Kummer 與 Lamé 的攻擊正建立在某個因式分解上。
- **分圓多項式**揭示 $x^p - 1$ 的結構，並交出一個關鍵事實：$\zeta_p$ 滿足一個 $p-1$ 次的不可約方程。這個數字 $p - 1$ 會在第三部反覆出現。

**依賴箭頭：** 高中三角函數 + 0.2 的因式分解
$\to$ 複數極形式 $\to$ 單位根 $\to$ $x^p\pm y^p$ 分解
$\to$ 分圓多項式 $\to$ 第一部的體與向量空間。

本章沿用五種結果標籤：**【完整證明】、【特殊情形】、【證明略圖】、【直覺】、【接受的黑箱】**。

## 複數平面

高中告訴你 $i = \sqrt{-1}$，複數是 $a + bi$。這一節要把這個代數定義升級成**幾何**圖像，因為單位根的一切美感都來自幾何。

把複數 $z = a + bi$ 畫成平面上的點 $(a, b)$，這個平面稱為**複數平面**（或 Argand 平面）。於是複數有了兩個幾何量：

- **模長** $|z| = \sqrt{a^2 + b^2}$，即點到原點的距離。
- **輻角** $\arg z = \theta$，即從正實軸量到 $z$ 的角度。

於是 $z = |z|(\cos\theta + i\sin\theta)$。本章先把
$e^{i\theta}:=\cos\theta+i\sin\theta$ **當作簡寫**；若把左邊理解成複指數函數，Euler 公式在此標為**【接受的黑箱】**。因此
$$z = r\,e^{i\theta}, \qquad r = |z|.$$

這個寫法的威力在於**乘法變成了加法**：
$$r_1 e^{i\theta_1} \cdot r_2 e^{i\theta_2} = r_1 r_2\, e^{i(\theta_1 + \theta_2)}.$$
模長相乘，輻角相加。複數相乘，幾何上就是「縮放 + 旋轉」。

::: {.proposition name="【完整證明；依賴高中加角公式】de Moivre 公式"}
$$(e^{i\theta})^n = e^{in\theta}, \qquad (\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta.$$
:::

::: {.proof}
三角函數加角公式直接給 $e^{i\alpha}e^{i\beta}=e^{i(\alpha+\beta)}$。對正整數 $n$ 歸納重複相乘，就得到 $(e^{i\theta})^n=e^{in\theta}$；展開簡寫即為第二式。
:::

::: {.remark name="【直覺】乘法是旋轉與縮放"}
「乘法 = 縮放 + 旋轉」不只是計算技巧。先就地定義所需名詞：**群**是對某運算封閉、運算可結合、有單位元且每個元素有逆元的集合。單位圓上的複數（模長為 $1$ 者）在乘法下符合這四項：單位元是 $1$，$e^{i\theta}$ 的逆元是 $e^{-i\theta}$。這個群記作 $S^1$ 或 $U(1)$；第 1.3 章會系統發展群論。
:::

## 單位根：均勻分布的解

::: {.definition}
滿足 $z^n = 1$ 的複數稱為 **$n$ 次單位根**（$n$-th root of unity）。
:::

**【完整證明】**用極座標解這個方程。設 $z = re^{i\theta}$，則 $z^n = r^n e^{in\theta} = 1 = 1 \cdot e^{i \cdot 0}$。比較模長得 $r = 1$；角度相差 $2\pi$ 的整數倍代表同一方向，所以 $n\theta=2\pi k$，即 $\theta=2\pi k/n$。取 $k=0,\ldots,n-1$ 得到互不相同的 $n$ 個解；其他整數 $k$ 只會重複其中之一：
$$\zeta_n^k = e^{2\pi i k / n}, \qquad k = 0, 1, \dots, n - 1,$$
其中我們記
$$\boxed{\;\zeta_n = e^{2\pi i / n}\;}$$
為**本原** $n$ 次單位根；精確地說，使 $\zeta_n^k=1$ 的最小正整數 $k$ 恰為 $n$。幾何上，這 $n$ 個解是**單位圓上的正 $n$ 邊形頂點**，從 $1$ 開始均勻分布。$\zeta_n$ 是逆時針數的第一個。

::: {.example name="【完整證明】三次與五次單位根"}
$n = 3$：三個解是 $1,\ \zeta_3 = e^{2\pi i/3},\ \zeta_3^2 = e^{4\pi i/3}$，構成正三角形。其中 $\zeta_3 = -\tfrac12 + \tfrac{\sqrt3}{2}i$，滿足 $\zeta_3^2 + \zeta_3 + 1 = 0$。

$n = 5$：五個解構成正五邊形，$\zeta_5$ 滿足 $\zeta_5^4 + \zeta_5^3 + \zeta_5^2 + \zeta_5 + 1 = 0$。
:::

兩個將反覆使用的基本事實：

::: {.proposition name="【完整證明】單位根的算術"}
設 $n \ge 2$，$\zeta = \zeta_n$。則
$$(1)\quad \zeta^n = 1, \qquad (2)\quad 1 + \zeta + \zeta^2 + \cdots + \zeta^{n-1} = 0.$$
:::

::: {.proof}
(1) 由定義。(2) 這是等比級數：$1 + \zeta + \cdots + \zeta^{n-1} = \dfrac{\zeta^n - 1}{\zeta - 1}$（因 $\zeta \ne 1$，分母非零），而分子 $\zeta^n - 1 = 0$。
:::

事實 (2)「所有單位根之和為零」幾何上對應「正 $n$ 邊形頂點的重心在原點」，代數上則是後面無數計算的引擎。

## 代數基本定理

我們剛才直接解出了 $z^n=1$ 的全部 $n$ 個根。這也是一個更普遍現象的特殊情形。

::: {.theorem name="【接受的黑箱】代數基本定理"}
每個次數 $\ge 1$ 的複係數多項式，在 $\mathbb{C}$ 中至少有一個根。
:::

由它反覆提取根，立得：

::: {.corollary name="【完整證明；依賴黑箱】複多項式完全分解"}
每個 $n$ 次複係數多項式 $f(x)$ 都能在 $\mathbb{C}$ 中完全分解：
$$f(x) = c(x - \alpha_1)(x - \alpha_2)\cdots(x - \alpha_n),$$
其中 $\alpha_1, \dots, \alpha_n \in \mathbb{C}$（可重複），$c$ 為首項係數。計重數，$f$ 恰有 $n$ 個根。
:::

::: {.proof}
黑箱先給一個根 $\alpha_1$，多項式除法給
$f(x)=(x-\alpha_1)f_1(x)$，其中 $f_1$ 次數少一。對 $f_1$ 重複；有限次後降到常數，得到所列的 $n$ 個一次因式。根可以重複，所以是「計重數」恰有 $n$ 個。
:::

代數基本定理本身的完整證明要等後面的複分析；這裡只強調它對本書的意義 —— 它是一張**許可證**：

> 任何整係數方程，只要願意走進 $\mathbb{C}$，就一定能完全因式分解。

這正是十九世紀攻擊 FLT 的核心戰術。

::: {.proposition name="【完整證明／特殊情形】奇數次方和的單位根分解"}
若 $p$ 是奇數，則
$$x^p+y^p=\prod_{k=0}^{p-1}(x+\zeta_p^ky).$$
:::

::: {.proof}
由已列出的全部根與首項係數，
$$T^p-1=\prod_{k=0}^{p-1}(T-\zeta_p^k).$$
先設 $y\ne0$，代入 $T=-x/y$。因 $p$ 為奇數，右式兩邊分別成為
$$-\frac{x^p+y^p}{y^p}
=-\frac1{y^p}\prod_{k=0}^{p-1}(x+\zeta_p^ky).$$
乘以 $-y^p$ 即得公式。$y=0$ 時兩邊都直接等於 $x^p$。
:::

FLT 的方程 $x^p + y^p = z^p$ 於是變成
$$(x + y)(x + \zeta_p y)\cdots(x + \zeta_p^{p-1} y) = z^p.$$
**左邊是 $p$ 個因子的乘積，右邊是一個 $p$ 次方。** 如果這些因子「兩兩互質」，而且我們身處一個**唯一分解成立**的數系，那麼每個因子本身都必須是 $p$ 次方 —— 這會擠出強烈的限制，正是 Lamé 1847 年的思路。

但你已經被警告過兩次了（第 0.2、0.4 章）：在 $\mathbb{Z}[\zeta_p]$ 裡，唯一分解**未必成立**。Lamé 的推論在那道裂縫上塌掉。修補這道裂縫 —— 用 Kummer 的「理想數」恢復某種唯一分解 —— 就是第三部的主線劇情。本章交給你的，是看懂這場戲所需的舞台道具：$\zeta_p$、它的均勻幾何、以及「在 $\mathbb{C}$ 裡萬物皆可分解」這張許可證。

## 分圓多項式：$\zeta_p$ 的最小方程

最後一節聚焦質數情形，挖出一個第三部會反覆引用的結構事實。

$n$ 次單位根是 $x^n - 1 = 0$ 的全部根。把 $x = 1$ 這個平凡根分出來：
$$x^n - 1 = (x - 1)(x^{n-1} + x^{n-2} + \cdots + x + 1).$$
當 $n = p$ 為質數時，右邊第二個因子
$$\Phi_p(x) = x^{p-1} + x^{p-2} + \cdots + x + 1$$
稱為**第 $p$ 個分圓多項式**（cyclotomic polynomial）。它的根恰是
$$\zeta_p,\zeta_p^2,\ldots,\zeta_p^{p-1},$$
總共 **$p-1$ 個**。因 $p$ 是質數，每個 $1\le k\le p-1$ 都與 $p$ 互質，所以這些根全是本原 $p$ 次單位根；剩下的第 $p$ 次單位根 $1$ 不是本原的。

關鍵問題：$\Phi_p(x)$ 還能再分解嗎？答案是不能 —— 而這件事意義重大。

::: {.theorem name="【接受的黑箱】Eisenstein 判準"}
若整係數多項式 $a_nx^n+\cdots+a_0$ 有質數 $q$ 滿足
$q\nmid a_n$、$q\mid a_i$（$i<n$）且 $q^2\nmid a_0$，則它在 $\mathbb Q$ 上不可約。
:::

::: {.theorem name="【完整證明；依賴 Eisenstein 黑箱】質數階分圓多項式不可約"}
對質數 $p$，$\Phi_p(x) = x^{p-1} + \cdots + x + 1$ 在 $\mathbb{Q}$ 上不可約（無法寫成兩個次數較低的有理係數多項式之積）。
:::

::: {.proof}
$\Phi_p(x)$ 本身不直接滿足判準，但作一個平移 $x \mapsto x + 1$ 就現形。利用 $\Phi_p(x) = \dfrac{x^p - 1}{x - 1}$：
$$\Phi_p(x + 1) = \frac{(x+1)^p - 1}{x} = \frac{1}{x}\sum_{k=1}^{p}\binom{p}{k}x^k = \sum_{k=1}^{p}\binom{p}{k}x^{k-1} = x^{p-1} + \binom{p}{1}x^{p-2} + \cdots + \binom{p}{p-1}.$$
首項係數為 $1$（不被 $p$ 整除）。對 $1\le k\le p-1$，恆等式
$$k\binom pk=p\binom{p-1}{k-1}$$
的右邊被 $p$ 整除，而 $p\nmid k$；由第 0.2 章 Euclid 引理，$p\mid\binom pk$。常數項是 $\binom{p}{p-1}=p$，不被 $p^2$ 整除。Eisenstein 判準（取 $q=p$）成立，故 $\Phi_p(x+1)$ 不可約。若 $\Phi_p(x)$ 可約，把其分解中的 $x$ 全換成 $x+1$，便會使 $\Phi_p(x+1)$ 可約；矛盾。因此 $\Phi_p(x)$ 不可約。
:::

::: {.remark name="【直覺／前瞻】為什麼這個 $p-1$ 很重要"}
「$\zeta_p$ 滿足一個 $p-1$ 次的不可約方程」先只表示：在有理係數中，沒有更低次的非零方程能以它為根。第 1.1 章定義向量空間與維度後，第 2.1 章才會證明這等價於 $\mathbb Q(\zeta_p)$ 作為 $\mathbb Q$-向量空間有維度 $p-1$；Galois 群有 $p-1$ 個元素則是更後面的結果。兩者在此都是**前瞻，不是已證結論**。

換句話說，本節的不可約性定理是後面研究 $\mathbb Z[\zeta_p]$ 的入口；至於 Kummer 對正則質數的結果，第三部會另列黑箱與證明範圍，本章不預先認領。
:::

**檢查點 0.5**　對質數 $p$，請分清三個數量：$x^p-1$ 有 $p$ 個不同複根；其中一個是 $1$；$\Phi_p$ 有其餘 $p-1$ 個根，而且它們全是本原根。用 $p=3$ 畫正三角形即可核對。

## 第零部完結：我們帶走了什麼

整個第零部的成果，可以收進一張清單：

- **證明的語言**（0.1）：邏輯、量詞、反證、歸納；FLT 化約為 $n = 4$ 與奇質數。
- **整數的結構**（0.2）：唯一分解及其證明鏈、同餘、費馬小定理；唯一分解會在更大數系失效的預警。
- **有理點的幾何**（0.3）：整數解 $\leftrightarrow$ 曲線上有理點；通往橢圓曲線的台階。
- **第一場勝利**（0.4）：無窮遞降，$x^4 + y^4 = z^2$ 無解；同一機器不直接推廣到奇質數。
- **擴張的工具**（0.5）：複數幾何、代數基本定理、$\zeta_p$ 與分圓多項式 —— 走進更大數系的護照。

這五章的共同訊息是：**FLT 是一個關於 $\mathbb{Z}$ 的問題，但 $\mathbb{Z}$ 太小，裝不下它的解法。** 真正的證明需要把整數放進越來越大、越來越精巧的結構裡 —— 數域、橢圓曲線、模形式 —— 而那些結構的共同語言，是線性代數與抽象代數。

第一部就從這裡開始。

## 本章地圖與下一章預告

- **複數平面**：模長與輻角；乘法 = 縮放 + 旋轉；單位圓上的 $U(1)$ 群。
- **單位根**：$\zeta_n = e^{2\pi i/n}$，正 $n$ 邊形頂點；單位根之和為零。
- **代數基本定理**：$\mathbb{C}$ 上萬物皆可分解的許可證；$x^p + y^p$ 的單位根分解與 Lamé 戰術。
- **分圓多項式**：$\Phi_p$ 經 Eisenstein 黑箱證不可約；其次數 $p-1$ 將在後文轉成向量空間維度。

下一章進入第一部第 1.1 章《線性代數 I》。我們會從零定義向量空間、維度與線性映射；到那時，$\mathbb Q(\zeta_p)$ 的「$p-1$ 個獨立方向」才有精確語言。表示與 $\mathrm{GL}_2$ 也會在所需的群概念先定義後才出場。

## 習題

**0.5.1**　把 $\zeta_3 = e^{2\pi i/3}$ 與 $\zeta_4 = e^{2\pi i/4}$ 寫成 $a + bi$ 的形式，並在複數平面上標出 $\zeta_6$ 的全部六個冪。

**0.5.2 ★**　用 de Moivre 公式，把 $\cos 3\theta$ 表示成 $\cos\theta$ 的多項式。（提示：展開 $(\cos\theta + i\sin\theta)^3$，比較實部。）

**0.5.3 ★**　證明：$n$ 次單位根中，$\zeta_n^k$ 是**本原**的（即它的冪能跑遍全部 $n$ 個單位根），若且唯若 $\gcd(k, n) = 1$。由此說明本原 $n$ 次單位根恰有 $\varphi(n)$ 個（$\varphi$ 為 Euler 函數）。

**0.5.4 ★**　證明因式分解 $\displaystyle\prod_{k=0}^{p-1}(x + \zeta_p^k y) = x^p + y^p$ 對奇質數 $p$ 成立。（提示：先證 $\prod_{k=0}^{p-1}(t - \zeta_p^k) = t^p - 1$，再代入 $t = -x/y$ 並清理符號。注意 $p$ 為奇是符號正確的關鍵。）

**0.5.5**　陳述並證明 Eisenstein 判準。（提示：反證。假設可分解，把係數對質數 $q$ 取模 —— 在「模 $q$ 的多項式」世界裡，原多項式變成 $a_n x^n$，迫使兩個因子的常數項都被 $q$ 整除，與 $q^2 \nmid a_0$ 矛盾。這個「模 $q$ 看多項式」的技巧，是第六部 mod $\ell$ 表示的遠祖。）

**0.5.6**　證明：質數 $p$ 整除二項係數 $\binom{p}{k}$ 對所有 $1 \le k \le p - 1$ 成立。（提示：$\binom{p}{k} = \dfrac{p!}{k!(p-k)!}$，分子有因子 $p$，分母沒有。)

**0.5.7（前瞻）**　$\mathbb{Z}[\zeta_3] = \{a + b\zeta_3 : a, b \in \mathbb{Z}\}$（稱為 Eisenstein 整數）。定義範數 $N(a + b\zeta_3) = a^2 - ab + b^2$。(a) 驗證 $N(\alpha\beta) = N(\alpha)N(\beta)$（可數值抽查）。(b) 找出所有範數為 $1$ 的元素（這些是「單位」，共六個）。(c) 與第 0.2 章的 $\mathbb{Z}[\sqrt{-5}]$ 對比：$\mathbb{Z}[\zeta_3]$ 其實**有**唯一分解 —— 不是所有擴張都會壞掉，這正是「正則 vs 非正則質數」區別的胚芽，第三部詳述。
