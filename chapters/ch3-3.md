## 開場：兩把尺

上一章證明了理想唯一分解永遠成立，但也留下一個障礙：「理想是 $p$ 次方」不等於「元素是 $p$ 次方」，因為理想未必是主理想。Kummer 的攻擊能否成功，全看這個障礙有多大。這一章造兩把尺來量它。

第一把尺是**類群** $\mathrm{Cl}(K)$，量「有多少理想不是主理想」。它的大小 —— **類數** $h_K$ —— 精確地是「唯一分解失效的程度」：$h_K = 1$ 等價於唯一分解成立，$h_K$ 越大，失效越嚴重。

第二把尺是**單位群** $\mathcal{O}_K^\times$，量「$\mathcal{O}_K$ 裡有多少可逆元」。它控制元素分解中「可被單位吸收」的歧義（第 1.6 章 Eisenstein 整數的六個單位，正是讓 Euler 的兩種分解得以調和的關鍵）。

這兩把尺合起來，是 Kummer 判準的全部材料。第 3.4 章「正則質數」的定義 —— $p \nmid h_{\mathbb{Q}(\zeta_p)}$ —— 直接就是用類數寫的，而 Kummer 論證裡最難處理的那一步，靠的是單位群的結構。掌握本章，才能聽懂 Kummer 對哪些 $p$ 成功、為什麼。

## 本章前置檢查點

1. **理想唯一分解**（第 3.2 章）—— 本章每條結果都建在它上面。
2. **範數（元素版與理想版）**（第 3.1 章）。
3. **單位判準 $N(\alpha) = \pm1$**（第 3.1 章，完整證明）。
4. **群、商群、Lagrange 定理**（第 1.3 章）—— 類群是商群，第 3.4 章要對它用 Lagrange。

## 類群：理想模掉主理想

主理想（由單一元素生成的理想）是「乖」的理想 —— 它直接對應一個元素。非主理想則是「理想數」，沒有元素與之對應。類群衡量後者相對前者有多少。

::: {.definition}
$K$ 的**分式理想**是形如 $\frac1d\mathfrak{a}$ 的集合（$\mathfrak{a} \subseteq \mathcal{O}_K$ 非零理想，$0 \ne d \in \mathcal{O}_K$）。在 Dedekind 環中每個非零分式理想可逆（第 3.2 章的關鍵引理），故全體非零分式理想在乘法下構成一個群 $\mathcal{I}_K$。形如 $\alpha\mathcal{O}_K$（$\alpha \in K^\times$）的稱**主分式理想**，構成子群 $\mathcal{P}_K$。**類群**是商群
$$\mathrm{Cl}(K) = \mathcal{I}_K / \mathcal{P}_K,$$
它的階 $h_K = \lvert\mathrm{Cl}(K)\rvert$ 稱為**類數**。
:::

類群的元素是「理想的等價類」—— 兩個理想同類，若它們相差一個主理想。單位元類是「全體主分式理想」。

::: {.theorem name="類群有限（Minkowski）"}
對任何數域 $K$，$\mathrm{Cl}(K)$ 是**有限**群，即 $h_K < \infty$。
:::

**假設**：$K$ 數域。**用途**：這條有限性是第 3.4 章能寫下「$p \nmid h_p$」的前提 —— 若 $h_K$ 可以是無窮，「$p$ 整除類數」根本無從談起。**狀態**：外部黑盒（用下面的 Minkowski 界推出；見 Marcus《Number Fields》第 5 章或 Neukirch 第 I 章）。

::: {.proposition name="類數量化唯一分解"}
下列三者等價：(i) $h_K = 1$；(ii) $\mathcal{O}_K$ 是主理想環（PID）；(iii) $\mathcal{O}_K$ 是唯一分解環（UFD）。
:::

**假設**：$\mathcal{O}_K$ 是 Dedekind 環（本章一律成立）。**用途**：這條命題把抽象的 $h_K$ 翻譯成第 0.2 章那個我們真正在乎的性質。**狀態**：完整證明（下方，唯一輸入是第 3.2 章的理想唯一分解）。

::: {.proof}
**(i) $\iff$ (ii)：** $h_K = 1$ 表示每個分式理想都是主的，特別地每個整理想都是主的，即 PID；反之亦然。

**(ii) $\Rightarrow$ (iii)：** 設 $\mathcal{O}_K$ 是 PID，取 $\alpha \ne 0$ 非單位。由理想唯一分解 $(\alpha) = \mathfrak{p}_1^{e_1}\cdots\mathfrak{p}_r^{e_r}$；每個 $\mathfrak{p}_i = (\pi_i)$ 為主，故 $(\alpha) = \bigl(\prod \pi_i^{e_i}\bigr)$，於是 $\alpha = u\prod\pi_i^{e_i}$（$u$ 單位）。每個 $\pi_i$ 是**質元素**（因為 $(\pi_i)$ 是質理想），而質元素必不可分解。分解的唯一性（至單位與次序）直接繼承自理想分解的唯一性。

**(iii) $\Rightarrow$ (ii)：** 設 $\mathcal{O}_K$ 是 UFD。只需證每個非零質理想 $\mathfrak{p}$ 是主的（因為由理想唯一分解，一般理想是質理想之積，主理想之積仍主）。取 $0 \ne a \in \mathfrak{p}$，$a$ 非單位。在 UFD 中把 $a$ 分解成不可分解元之積 $a = \pi_1\cdots\pi_r$。因 $\mathfrak{p}$ 是質理想且 $a \in \mathfrak{p}$，必有某個 $\pi_i \in \mathfrak{p}$。在 UFD 中「不可分解 $\Rightarrow$ 質」，故 $(\pi_i)$ 是非零質理想，且 $(\pi_i) \subseteq \mathfrak{p}$。但 Dedekind 環維度 $1$，$(\pi_i)$ 已經極大，故 $(\pi_i) = \mathfrak{p}$。
:::

::: {.example name="$\mathbb{Z}[\sqrt{-5}]$ 的類數恰是 $2$（完整計算）"}
把上一章的材料組裝成一個完整結論。

**步驟 1：$[\mathfrak{p}_2]$ 的階是 $2$。** $\mathfrak{p}_2 = (2, 1+\sqrt{-5})$ 不是主理想（習題 3.2.5，用範數：$a^2+5b^2 = 2$ 無解），故 $[\mathfrak{p}_2] \ne 1$。但 $\mathfrak{p}_2^2 = (2)$ 是主的，故 $[\mathfrak{p}_2]^2 = 1$。所以 $[\mathfrak{p}_2]$ 階為 $2$，於是 $h_K$ 是偶數，$h_K \ge 2$。

**步驟 2：$h_K \le 2$。** 由下一節的 Minkowski 界（$M_K \approx 2.85$），每個理想類都含一個範數 $\le 2$ 的理想。範數 $1$ 的只有 $\mathcal{O}_K$（平凡類）；範數 $2$ 的理想必是 $2$ 上方的質理想，而 $(2) = \mathfrak{p}_2^2$ 說明 $2$ 上方只有 $\mathfrak{p}_2$ 一個。所以類群至多有兩個元素：$[\mathcal{O}_K]$ 與 $[\mathfrak{p}_2]$。

**結論：** $\mathrm{Cl}(\mathbb{Q}(\sqrt{-5})) \cong \mathbb{Z}/2\mathbb{Z}$，$h = 2$。

這個 $2$ 精確地說：$\mathbb{Z}[\sqrt{-5}]$ 的唯一分解失效，但「只差一個 $2$ 階障礙」—— 不是無可救藥的混亂，而是一個可測量、可控制的小缺陷。第 0.2 章那個困擾我們的 $6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5})$，其全部「病情」就濃縮在這個數字 $2$ 裡。
:::

## Minkowski 界：讓類數可計算

類群的定義很抽象（無窮多個理想的商）。如何實際算出 $h_K$？關鍵是一個來自**幾何**的有限性定理 —— Minkowski 把數論問題變成「格點幾何」問題。

::: {.theorem name="Minkowski 界"}
$\mathrm{Cl}(K)$ 中每個類都含有一個整理想 $\mathfrak{a}$，其範數滿足
$$N(\mathfrak{a}) \le M_K := \left(\frac{4}{\pi}\right)^{r_2} \frac{n!}{n^n}\sqrt{\lvert\mathrm{disc}(K)\rvert},$$
其中 $n = [K:\mathbb{Q}]$，$r_2$ 是複嵌入的對數（第 3.1 章）。
:::

**假設**：$K$ 數域。**用途**：把「算類群」這個無窮的問題壓成有限檢查 —— 只需看範數 $\le M_K$ 的那些（有限多個）質理想。這是本章唯一能讓人**真的算出**類數的工具。**狀態**：外部黑盒（Marcus 第 5 章）。**證明的想法**（直觀說明）：把 $\mathcal{O}_K$ 透過 $n$ 個嵌入送進 $\mathbb{R}^n$，它成為一個**格**（lattice）；Minkowski 凸體定理說「以原點為中心、體積夠大的對稱凸區域必含非零格點」，翻譯回數論就是「每個理想類含小範數理想」。

::: {.example name="兩個算例"}
$\mathbb{Q}(\sqrt{-5})$：$\mathrm{disc} = -20$，$n = 2$，$r_2 = 1$。
$$M_K = \frac{4}{\pi}\cdot\frac{2!}{2^2}\cdot\sqrt{20} = 1.2732 \times 0.5 \times 4.4721 \approx 2.85.$$
每個理想類都含範數 $\le 2$ 的理想 —— 這正是上面步驟 2 用的。

$\mathbb{Q}(i)$：$\mathrm{disc} = -4$，$M_K = \frac4\pi \cdot \frac12 \cdot 2 \approx 1.27 < 2$。所以每個類都含範數 $\le 1$ 的理想，即只含 $\mathcal{O}_K$ —— 類群平凡，$h = 1$，$\mathbb{Z}[i]$ 是 PID（高斯整數有唯一分解，與你熟知的一致）。
:::

::: {.remark name="幾何進入數論"}
Minkowski 的證明用「格點幾何」，這是**幾何數論**的開端 —— 用空間中的格點來研究數域的算術。

這個「把數論編碼成格、用幾何攻擊」的思路，會在第四、五部以更深的形式回歸：橢圓曲線在 $\mathbb{C}$ 上本身就是一個「格的商」$\mathbb{C}/\Lambda$（第 5.1 章），而模形式是格的空間上的函數。Minkowski 在這裡第一次示範「格是連接離散（數論）與連續（幾何）的橋」。（**狀態**：本段是**直觀說明**，用來建立第五部的預期，不承載論證。）
:::

## 單位群：另一種歧義

類群量「理想層次」的缺陷。單位群量「元素層次」剩餘的歧義 —— 因為元素分解總是差一個單位（$6 = 2\cdot 3 = (-2)(-3)$，差一個單位 $-1$，不算真正不同的分解）。

::: {.definition}
$\mathcal{O}_K$ 的**單位群** $\mathcal{O}_K^\times$ 是所有可逆元構成的乘法群。由第 3.1 章的單位判準，$\alpha \in \mathcal{O}_K^\times \iff N_{K/\mathbb{Q}}(\alpha) = \pm 1$。
:::

單位群的結構由一條漂亮的定理完全決定。

::: {.theorem name="Dirichlet 單位定理"}
$$\mathcal{O}_K^\times \;\cong\; \mu_K \times \mathbb{Z}^{\,r_1 + r_2 - 1},$$
其中 $\mu_K$ 是 $K$ 中的單位根（有限循環群），$r_1$ 是實嵌入數、$r_2$ 是複嵌入對數。秩 $r = r_1 + r_2 - 1$ 稱為**單位秩**。
:::

**假設**：$K$ 數域。**用途**：告訴我們「單位有多少」—— 這決定了 Kummer 論證第 4 步（處理那個礙事的單位因子 $u_k$）的難度。**狀態**：外部黑盒（Marcus 第 5 章）。**證明的想法**（直觀說明）：把 $\alpha \mapsto (\log\lvert\sigma_1(\alpha)\rvert, \dots)$ 這個「對數嵌入」用在單位上，$N = \pm1$ 使像落在一個 $r$ 維超平面裡，再證那個像是一個滿秩格。

::: {.example name="單位群的兩種面貌"}
**虛二次域**（$r_1 = 0, r_2 = 1$，秩 $= 0$）：單位群有限，只有單位根。
$\mathbb{Q}(i)$：$\{\pm 1, \pm i\} = \mu_4$。
$\mathbb{Q}(\sqrt{-3})$：六個單位 $\mu_6$ —— 第 1.6 章 Euler 之謎裡那六個單位，現在由 Dirichlet 定理解釋（它們讓兩種分解得以調和）。
其他虛二次域（含 $\mathbb{Q}(\sqrt{-5})$）：只有 $\{\pm 1\}$。

**實二次域**（$r_1 = 2, r_2 = 0$，秩 $= 1$）：單位群無窮！有一個「基本單位」生成無窮多個單位。
$\mathbb{Q}(\sqrt 2)$：基本單位 $1 + \sqrt 2$（$N = 1 - 2 = -1$），所有單位是 $\pm(1+\sqrt2)^m$。這直接連到 **Pell 方程** $x^2 - 2y^2 = \pm 1$ —— 它的無窮多組解，正是這些單位（第 0.3 章習題 0.3.6 那條雙曲線的整數點之謎，答案在此）。
:::

## $\mathbb{Q}(\zeta_p)$ 的單位：Kummer 真正需要的那一塊

第 3.4 章要用到分圓域單位群的兩件具體事實，先在這裡備好。

**事實一（秩）：** $\mathbb{Q}(\zeta_p)$ 的嵌入全是複的（$\zeta_p$ 不實，$p$ 奇質數），故 $r_1 = 0$、$r_2 = \frac{p-1}{2}$，單位秩
$$r = 0 + \tfrac{p-1}{2} - 1 = \tfrac{p-3}{2}.$$
**狀態**：完整證明（給定 Dirichlet 定理與嵌入計數）。

**事實二（單位的形狀）：**

::: {.theorem name="分圓單位的實化（Kronecker）"}
$p$ 奇質數。$\mathbb{Z}[\zeta_p]$ 的每個單位 $u$ 都能寫成
$$u = \zeta_p^{\,r}\cdot v,$$
其中 $r$ 是某個整數，$v$ 是**實**的單位（即 $v \in \mathbb{Z}[\zeta_p + \zeta_p^{-1}]^\times \subseteq \mathbb{R}$）。
:::

**假設**：$p$ 奇質數。**用途**：這是 Kummer 論證中「把單位 $u_k$ 馴服」的核心工具 —— 有了它，$u_k$ 的自由度從整個單位群縮到「一個單位根乘一個實單位」，而實單位的部分可以用複共軛消掉。沒有這條，第 3.4 章第 4 步無從下手。**狀態**：外部黑盒（Washington《Introduction to Cyclotomic Fields》第 1 章）。

::: {.remark name="單位秩通往 BSD"}
單位秩 $\frac{p-3}{2}$ 告訴 Kummer 舞台有多大：$p = 3$ 時秩 $0$（單位只有單位根，最容易）；$p$ 越大，單位越多，控制越難。Kummer 分析「分圓單位」（cyclotomic units，由 $\frac{1-\zeta^a}{1-\zeta}$ 構造的特殊單位，第 2.3 章我們已經證過它們是單位）正是在這個舞台上進行。

更遠處，「秩」這個概念會在第五部以最深刻的形式重現：橢圓曲線的有理點也構成一個群（Mordell–Weil 群），它也是「有限部分 $\times\ \mathbb{Z}^r$」的形狀（第 5.2 章），那個 $r$ 是橢圓曲線的**秩**。而 BSD 猜想正是關於那個秩。Dirichlet 單位定理是「$\mathbb{Z}^r$ 型結構定理」在數論裡的第一個範例，Mordell–Weil 定理是它的曲線版兄弟。同一個結構模式，數域與曲線各演一次。
:::

::: {.remark name="檢查點 3.3.A"}
1. $\mathbb{Q}(\sqrt 3)$ 的單位秩是多少？（$r_1 = 2, r_2 = 0$，秩 $= 1$。無窮多個單位，基本單位是 $2+\sqrt 3$。）
2. $\mathbb{Q}(\zeta_5)$ 的單位秩？（$r_1=0$、$r_2 = 2$，秩 $= 1 = \frac{5-3}{2}$ ✓。）
3. 若 $h_K = 3$，$\mathcal{O}_K$ 有唯一分解嗎？有沒有 $3$ 階的理想類？（**沒有**唯一分解（$h \ne 1$）；由 Lagrange 與 Cauchy，$3$ 階群必是循環群 $\mathbb{Z}/3$，故確有 $3$ 階元素。這個「$p$ 階元素存不存在」的問題，正是下一章正則性的全部內容。）
:::

## 兩把尺合一：類數公式一瞥

類數 $h_K$ 與單位群（透過**調節子** $R_K$ 衡量單位的「大小」）並非各自獨立，它們被一條深刻的公式綁在一起：

::: {.theorem name="解析類數公式（敘述）"}
數域 $K$ 的 Dedekind zeta 函數 $\zeta_K(s)$ 在 $s = 1$ 有單極點，且
$$\lim_{s \to 1}(s-1)\,\zeta_K(s) \;=\; \frac{2^{r_1}(2\pi)^{r_2}\,h_K\,R_K}{w_K\sqrt{\lvert\mathrm{disc}(K)\rvert}},$$
其中 $w_K = \lvert\mu_K\rvert$ 是 $K$ 中單位根的個數，$R_K$ 是調節子。
:::

**假設**：$K$ 數域。**用途**：在本書的主線上，它的角色是**動機**而非工具 —— 但它是第 3.4 章 Kummer 判準（用 Bernoulli 數檢驗類數）背後的機制。**狀態**：外部黑盒（Neukirch 第 VII 章）。本書不使用它推導任何結果。

::: {.remark name="這是 BSD 的祖先"}
類數公式把**代數**的量（類數 $h_K$、調節子 $R_K$）與一個**解析**對象（zeta 函數在 $s=1$ 的行為）等同起來。這是「算術 = 分析」這個現代數論核心信條的第一個重大實例。

BSD 猜想（第五部）是它在橢圓曲線上的直接類比：橢圓曲線的算術不變量（Tate–Shafarevich 群的大小、調節子、撓群）等同於它的 $L$ 函數在 $s=1$ 的行為。Dirichlet 的類數公式之於數域，正如 BSD 之於橢圓曲線 —— 後者是前者的曲線版猜想，至今未解。你在這裡看到的，是貫穿整個現代數論的一條主旋律的源頭：**最深的算術祕密，藏在 $L$ 函數的特殊值裡**。
:::

## 本章地圖與下一章預告

- **類群 $\mathrm{Cl}(K)$**：分式理想模主分式理想；有限（Minkowski）。
- **$h_K = 1 \iff$ PID $\iff$ UFD**：完整證明，把抽象的類數接回第 0.2 章的唯一分解。
- **$\mathbb{Z}[\sqrt{-5}]$ 類數 $= 2$**：完整計算；唯一分解失效濃縮成一個 $2$ 階障礙。
- **Minkowski 界**：幾何把類數變有限可算；格點進入數論。
- **單位群與 Dirichlet 定理**：$\mu_K \times \mathbb{Z}^{r_1+r_2-1}$；虛二次有限、實二次無窮（Pell）。
- **分圓單位**：秩 $\frac{p-3}{2}$；$u = \zeta_p^r v$（實化），Kummer 第 4 步的鑰匙。
- **類數公式**：算術量 = zeta 函數解析行為；BSD 的祖先。

下一章《Kummer 的攻擊》是第三部的高潮，也是古典 FLT 理論的頂峰。我們終於有了全部工具，可以陳述並理解 Kummer 1847 年的定理：**若奇質數 $p$ 是「正則的」（$p \nmid h_{\mathbb{Q}(\zeta_p)}$），則 FLT 對指數 $p$ 成立。** 你會看到「正則」這個條件如何讓上一章那個障礙恰好消失 —— 類數不被 $p$ 整除，正是讓論證穿過障礙的鑰匙。

下一章也會誠實交代一件事：**本書不會完整證明 Kummer 定理**。我們會完整證明「障礙化為類群條件」這個核心命題（它只用到 Lagrange 定理），給出整條論證鏈的骨架，並明確標出哪幾步是本書略過的深水區（特別是第二情形與 Kummer 單位引理）。這是人類在不使用橢圓曲線的前提下，對 FLT 所能到達的最遠處 —— 也是誠實標記邊界最重要的一章。

## 習題

**3.3.1**　證明 $\mathbb{Q}(i)$ 的類數是 $1$。（用 Minkowski 界 $M_K \approx 1.27 < 2$，說明每個類都含 $\mathcal{O}_K$。）

**3.3.2 ★**　計算 $\mathbb{Q}(\sqrt{-6})$ 的 Minkowski 界，列出需檢查的小範數質理想，論證類數是 $2$。（提示：$\mathrm{disc} = -24$，$M_K \approx 3.1$；檢查範數 $2, 3$ 的質理想 $\mathfrak{p}_2 = (2,\sqrt{-6})$、$\mathfrak{p}_3 = (3,\sqrt{-6})$，證兩者皆非主但 $\mathfrak{p}_2\mathfrak{p}_3 = (\sqrt{-6})$ 為主。）

**3.3.3**　$\mathbb{Q}(\sqrt 2)$ 的基本單位是 $1 + \sqrt 2$。驗證 $N(1+\sqrt 2) = -1$，並用它生成 $x^2 - 2y^2 = \pm 1$ 的前三組正整數解。（連到第 0.3 章習題 0.3.6 的 Pell 方程。）

**3.3.4 ★**　用 Dirichlet 單位定理確定下列單位群的結構（單位秩與單位根群）：$\mathbb{Q}(\sqrt{-7})$、$\mathbb{Q}(\sqrt 3)$、$\mathbb{Q}(\zeta_5)$、$\mathbb{Q}(\zeta_7)$。

**3.3.5 ★（讀證明）**　重走「(iii) $\Rightarrow$ (ii)」的證明。它在哪一步用到了 Dedekind 環的「維度 $1$」？如果拿掉這個條件，論證會停在哪裡？

**3.3.6 ★（為下一章暖身）**　分圓域的類數 $h_p := h_{\mathbb{Q}(\zeta_p)}$ 對小質數是：
$$h_3 = h_5 = h_7 = h_{11} = h_{13} = h_{17} = h_{19} = 1, \qquad h_{23} = 3.$$
(a) 由 $h_{23} = 3 \ne 1$ 與本章命題，論證 $\mathbb{Z}[\zeta_{23}]$ **沒有**唯一分解 —— 這正是 1847 年擊垮 Lamé 的事實（第 3.6 章）。
(b) 下一章會把「$p$ 正則」定義為 $p \nmid h_p$。用這個定義說明：$23$ 雖然讓唯一分解失效，卻**仍是正則質數**（因為 $23 \nmid 3$）。
(c) 由此指出兩個**不同**的門檻：「唯一分解失效」（$h_p > 1$）與「正則性失效」（$p \mid h_p$）。哪一個比較嚴格？第一個非正則質數其實是 $37$，不是 $23$ —— 解釋為什麼這兩個數字不同。

**3.3.7（前瞻）**　類數公式把 $h_K R_K$ 與 $\zeta_K$ 在 $s=1$ 的留數綁在一起。下一章的 Kummer 判準會用 Bernoulli 數檢驗 $p \mid h_p$。猜一猜這兩件事怎麼連上（提示：$\zeta(1-k) = -B_k/k$）。
