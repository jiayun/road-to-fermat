## 開場：兩把尺

上一章證明了理想唯一分解永遠成立，但也留下一個障礙：「理想是 $p$ 次方」不等於「元素是 $p$ 次方」，因為理想未必是主理想。Kummer 的攻擊能否成功，全看這個障礙有多大。這一章造兩把尺來量它。

第一把尺是**類群** $\mathrm{Cl}(K)$，量「有多少理想不是主理想」。它的大小 —— **類數** $h_K$ —— 精確地是「唯一分解失效的程度」：$h_K = 1$ 等價於唯一分解成立，$h_K$ 越大，失效越嚴重。

第二把尺是**單位群** $\mathcal{O}_K^\times$，量「$\mathcal{O}_K$ 裡有多少可逆元」。它控制元素分解中「可被單位吸收」的歧義（第 1.6 章 Eisenstein 整數的六個單位，正是讓 Euler 的兩種分解得以調和的關鍵）。

這兩把尺合起來，是 Kummer 判準的全部材料。第 3.4 章「正則質數」的定義 —— $p \nmid h_{\mathbb{Q}(\zeta_p)}$ —— 直接就是用類數寫的。掌握本章，才能聽懂 Kummer 對哪些 $p$ 成功、為什麼。

## 類群：理想模掉主理想

主理想（由單一元素生成的理想）是「乖」的理想 —— 它直接對應一個元素。非主理想則是「理想數」，沒有元素與之對應。類群衡量後者相對前者有多少。

::: {.definition}
$\mathcal{O}_K$ 的**分式理想**（允許分母的理想）在乘法下構成一個群 $\mathcal{I}_K$（Dedekind 環裡每個非零理想可逆，第 3.2 章）。主分式理想構成子群 $\mathcal{P}_K$。**類群**是商群
$$\mathrm{Cl}(K) = \mathcal{I}_K / \mathcal{P}_K.$$
它的階 $h_K = |\mathrm{Cl}(K)|$ 稱為**類數**。
:::

類群的元素是「理想的等價類」—— 兩個理想同類，若它們相差一個主理想。單位元類是「全體主理想」。於是：

::: {.proposition name="類數量化唯一分解"}
$h_K = 1 \iff \mathcal{O}_K$ 是主理想環（PID）$\iff \mathcal{O}_K$ 有唯一分解。
:::

::: {.proof}
$h_K = 1$ 表示每個理想都是主理想，即 PID。而對 Dedekind 環，PID $\iff$ UFD（理想唯一分解 + 全主理想 $\Rightarrow$ 元素唯一分解；反向亦真）。
:::

::: {.example name="$\mathbb{Z}[\sqrt{-5}]$ 的類數是 $2$"}
上一章的 $\mathfrak{p}_2 = (2, 1+\sqrt{-5})$ 不是主理想（習題 3.2.4），所以它在類群裡不是單位元 —— 它代表一個非平凡的類。但 $\mathfrak{p}_2^2 = (2)$ 是主理想，所以 $[\mathfrak{p}_2]^2 = [\text{單位元}]$，即 $[\mathfrak{p}_2]$ 在類群中**階為 $2$**。可以證明（下一節的 Minkowski 界讓這個「證明」變得有限可查）整個類群就是 $\{[\mathcal{O}_K], [\mathfrak{p}_2]\} \cong \mathbb{Z}/2\mathbb{Z}$，故
$$h_{\mathbb{Q}(\sqrt{-5})} = 2.$$
這個 $2$ 精確地說：$\mathbb{Z}[\sqrt{-5}]$ 的唯一分解失效，但「只差一個 $2$ 階障礙」—— 不是無可救藥的混亂，而是一個可測量、可控制的小缺陷。第 0.2 章那個困擾我們的 $6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5})$，其全部「病情」就濃縮在這個數字 $2$ 裡。
:::

## Minkowski 界：讓類數可計算

類群的定義很抽象（無窮多個理想的商）。如何實際算出 $h_K$？關鍵是一個來自**幾何**的有限性定理 —— Minkowski 把數論問題變成「格點幾何」問題。

::: {.theorem name="Minkowski 界"}
$\mathrm{Cl}(K)$ 中每個類都含有一個理想，其範數
$$N(\mathfrak{a}) \le M_K = \left(\frac{4}{\pi}\right)^{r_2} \frac{n!}{n^n}\sqrt{|\mathrm{disc}(K)|},$$
其中 $n = [K:\mathbb{Q}]$，$r_2$ 是複嵌入的對數。
:::

這把無窮的問題壓成有限：要算類群，只需檢查範數 $\le M_K$ 的那些（有限多個）質理想生成了什麼。

::: {.example name="用 Minkowski 界證 $h = 2$"}
$\mathbb{Q}(\sqrt{-5})$：$\mathrm{disc} = -20$，$n = 2$，$r_2 = 1$。代入得 $M_K = \frac{4}{\pi}\cdot\frac{2}{4}\cdot\sqrt{20} \approx 2.85$。所以每個理想類都含一個範數 $\le 2$ 的理想。範數 $\le 2$ 的質理想只有 $\mathfrak{p}_2$（範數 $2$）和 $\mathcal{O}_K$ 本身（範數 $1$，平凡類）。於是類群至多由 $[\mathfrak{p}_2]$ 生成，而 $[\mathfrak{p}_2]$ 階為 $2$，故 $h_K = 2$ —— 完整證畢，且全部計算有限可查。

對比 $\mathbb{Q}(i)$：$\mathrm{disc} = -4$，$M_K \approx 1.27 < 2$，所以每個類都含範數 $\le 1$ 的理想，即只含 $\mathcal{O}_K$ —— 類群平凡，$h = 1$，$\mathbb{Z}[i]$ 是 PID（高斯整數有唯一分解，與你熟知的一致）。
:::

::: {.remark name="幾何進入數論"}
Minkowski 的證明用「格點幾何」：$\mathcal{O}_K$ 嵌入 $\mathbb{R}^n$ 成為一個格（lattice），而「凸對稱區域夠大就必含非零格點」這個純幾何事實（Minkowski 凸體定理），翻譯成「每個理想類含小範數理想」。這是**幾何數論**的開端 —— 用空間中的格點來研究數域的算術。

這個「把數論編碼成格、用幾何攻擊」的思路，會在第四、五部以更深的形式回歸：橢圓曲線在 $\mathbb{C}$ 上本身就是一個「格的商」$\mathbb{C}/\Lambda$（第 5.1 章），而模形式是格的空間上的函數。Minkowski 在這裡第一次示範「格是連接離散（數論）與連續（幾何）的橋」—— 那座橋，最終通向 Wiles 的證明。
:::

## 單位群：另一種歧義

類群量「理想層次」的缺陷。單位群量「元素層次」剩餘的歧義 —— 因為元素分解總是差一個單位（$6 = 2\cdot 3 = (-2)(-3)$，差一個單位 $-1$，不算真正不同的分解）。

::: {.definition}
$\mathcal{O}_K$ 的**單位群** $\mathcal{O}_K^\times$ 是所有可逆元（$N(\alpha) = \pm 1$ 的元素）構成的乘法群。
:::

單位群的結構由一條漂亮的定理完全決定。

::: {.theorem name="Dirichlet 單位定理"}
$$\mathcal{O}_K^\times \cong \mu_K \times \mathbb{Z}^{r_1 + r_2 - 1},$$
其中 $\mu_K$ 是 $K$ 中的單位根（有限循環群），$r_1$ 是實嵌入數、$r_2$ 是複嵌入對數。秩 $r = r_1 + r_2 - 1$ 稱為**單位秩**。
:::

::: {.example name="單位群的兩種面貌"}
**虛二次域**（$r_1 = 0, r_2 = 1$，秩 $= 0$）：單位群有限，只有單位根。
$\mathbb{Q}(i)$：$\{\pm 1, \pm i\} = \mu_4$。
$\mathbb{Q}(\sqrt{-3})$：六個單位 $\mu_6$ —— 第 1.6 章 Euler 之謎裡那六個單位，現在由 Dirichlet 定理解釋（它們讓兩種分解得以調和）。
其他虛二次域：只有 $\{\pm 1\}$。

**實二次域**（$r_1 = 2, r_2 = 0$，秩 $= 1$）：單位群無窮！有一個「基本單位」生成無窮多個單位。
$\mathbb{Q}(\sqrt 2)$：基本單位 $1 + \sqrt 2$，所有單位是 $\pm(1+\sqrt2)^n$。這直接連到 **Pell 方程** $x^2 - 2y^2 = \pm 1$ —— 它的無窮多組解，正是這些單位（第 0.3 章習題 0.3.6 那條雙曲線的整數點之謎，答案在此）。
:::

::: {.remark name="單位秩通往 Kummer 與 BSD"}
$\mathbb{Q}(\zeta_p)$ 的單位秩是 $\frac{p-3}{2}$（$r_1 = 0$、$r_2 = \frac{p-1}{2}$）。這個數控制著 $\mathbb{Z}[\zeta_p]$ 單位群的複雜度，是 Kummer 分析「分圓單位」（cyclotomic units，由 $\frac{1-\zeta^a}{1-\zeta}$ 構造的特殊單位）的舞台。Kummer 對正則質數的證明，需要精確掌握這些單位 —— 而單位秩告訴他舞台有多大。

更遠處，「秩」這個概念會在第五部以最深刻的形式重現：橢圓曲線的有理點也構成一個群（Mordell–Weil 群），它也是「有限部分 × $\mathbb{Z}^r$」的形狀（第 5.2 章），那個 $r$ 是橢圓曲線的**秩**。而 BSD 猜想 —— 千禧年百萬美元問題之一 —— 正是關於那個秩。Dirichlet 單位定理是「$\mathbb{Z}^r$ 型結構定理」在數論裡的第一個範例，橢圓曲線的 Mordell–Weil 定理是它的曲線版兄弟。同一個結構模式，數域與曲線各演一次。
:::

## 兩把尺合一：類數公式一瞥

類數 $h_K$ 與單位群（透過「調節子」regulator $R_K$ 衡量單位的「大小」）並非各自獨立，它們被一條深刻的公式綁在一起：

::: {.theorem name="解析類數公式（敘述）"}
數域 $K$ 的 Dedekind zeta 函數 $\zeta_K(s)$ 在 $s = 1$ 的留數，正比於
$$\frac{h_K \cdot R_K}{\sqrt{|\mathrm{disc}(K)|}} \cdot (\text{單位根與嵌入的因子}).$$
:::

::: {.remark name="這是 BSD 的祖先"}
類數公式把**代數**的量（類數 $h_K$、單位調節子 $R_K$）與一個**解析**對象（zeta 函數在 $s=1$ 的行為）等同起來。這是「算術 = 分析」這個現代數論核心信條的第一個重大實例。

BSD 猜想（第五部）是它在橢圓曲線上的直接類比：橢圓曲線的「類數類量」（Tate–Shafarevich 群的大小、調節子）等同於它的 L 函數在 $s=1$ 的行為。Dirichlet 的類數公式之於數域，正如 BSD 之於橢圓曲線 —— 後者是前者的曲線版猜想，至今未解。你在這裡看到的，是貫穿整個現代數論的一條主旋律的源頭：**最深的算術祕密，藏在 L 函數的特殊值裡**。第五部的谷山–志村、第七部的 Wiles，都在這條旋律上。
:::

## 本章地圖與下一章預告

- **類群 $\mathrm{Cl}(K)$**：理想模主理想；$h_K = 1 \iff$ 唯一分解。
- **$\mathbb{Z}[\sqrt{-5}]$ 類數 $= 2$**：唯一分解失效濃縮成一個 $2$ 階障礙。
- **Minkowski 界**：幾何把類數變有限可算；格點進入數論。
- **單位群與 Dirichlet 定理**：$\mu_K \times \mathbb{Z}^{r_1+r_2-1}$；虛二次有限、實二次無窮（Pell）。
- **類數公式**：算術量 = zeta 函數解析行為；BSD 的祖先。

下一章《Kummer 的攻擊》是第三部的高潮，也是古典 FLT 理論的頂峰。我們終於有了全部工具，可以陳述並理解 Kummer 1847 年的定理：**若奇質數 $p$ 是「正則的」（$p \nmid h_{\mathbb{Q}(\zeta_p)}$），則 FLT 對指數 $p$ 成立。** 你會看到「正則」這個條件如何讓上一章那個障礙（理想是 $p$ 次方 $\not\Rightarrow$ 元素是 $p$ 次方）恰好消失 —— 類數不被 $p$ 整除，正是讓論證穿過障礙的鑰匙。這是人類在不使用橢圓曲線的前提下，對 FLT 所能到達的最遠處。走完它，第三部的古典戰役就達到頂點，而我們也將看清：為什麼這條路，最終還是到不了終點。

## 習題

**3.3.1**　證明 $\mathbb{Q}(i)$ 的類數是 $1$。（用 Minkowski 界 $M_K \approx 1.27$，說明每個類都含 $\mathcal{O}_K$。）

**3.3.2 ★**　計算 $\mathbb{Q}(\sqrt{-6})$ 的 Minkowski 界，列出需檢查的小範數質理想，論證類數是 $2$。（提示：$\mathrm{disc} = -24$，$M_K \approx 3.1$；檢查範數 $2, 3$ 的質理想。）

**3.3.3**　$\mathbb{Q}(\sqrt 2)$ 的基本單位是 $1 + \sqrt 2$。驗證 $N(1+\sqrt 2) = -1$，並用它生成 $x^2 - 2y^2 = \pm 1$ 的前三組正整數解。（連到第 0.3 章習題 0.3.6 的 Pell 方程。）

**3.3.4 ★**　用 Dirichlet 單位定理確定下列單位群的結構（單位秩與單位根）：$\mathbb{Q}(\sqrt{-7})$、$\mathbb{Q}(\sqrt 3)$、$\mathbb{Q}(\zeta_5)$。

**3.3.5**　證明 Proposition「$h_K = 1 \iff$ PID」的一個方向：若 $\mathcal{O}_K$ 是 PID，則它有唯一分解。（用第 3.2 章理想唯一分解 + 全為主理想。）

**3.3.6（前瞻）**　$\mathbb{Q}(\zeta_p)$ 的類數 $h_p$ 對小質數：$h_3 = h_5 = \cdots = h_{19} = 1$，但 $h_{23} = 3$。據此預測：$p = 23$ 是第一個「非正則」（$p \mid h_p$？不，是另一種判準）的候選 —— 實際上第一個**非正則**質數是 $37$。查閱「正則質數」定義（$p \nmid h_p$），並解釋為什麼 $h_{23} = 3$ 但 $23$ 仍是正則的（提示：$23 \nmid 3$）。
