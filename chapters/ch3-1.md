## 開場：地面測繪

第三部是 FLT 古典攻擊的決戰場。第零部三次預警、第 1.6 章 Euler 之謎所指向的那個問題 ——「唯一分解在更大的數系裡會失效，怎麼辦」—— 終於要在這一部被正面解決。Kummer 的答案（用理想恢復唯一分解）將在第 3.2 至 3.4 章展開。

但在談「理想如何分解」之前，必須先精確知道**我們站在哪個環上**。這一章做地面測繪：給定一個數域 $K$（$\mathbb{Q}$ 的有限擴張），找出它裡面「正確的整數環」$\mathcal{O}_K$。第 1.6 章的教訓還熱著 —— Euler 選錯了環（$\mathbb{Z}[\sqrt{-3}]$ 而非 $\mathbb{Z}[\zeta_3]$）就踩進流沙。本章要確保我們永不再犯：對每個數域，$\mathcal{O}_K$ 有唯一正確的定義，而且可以具體算出來。

工具第 2.4 章已備好（整元素、整閉）。本章把它們組裝成 $\mathcal{O}_K$，並引入兩個度量這個環的量：**整基底**（它作為 $\mathbb{Z}$-模的基底）與**判別式**（一個編碼了「哪些質數會分歧」的整數）。判別式尤其重要 —— 它將在第六部以「導體」的形式回歸，標記 Frey 曲線的算術指紋。

## 整數環 $\mathcal{O}_K$

::: {.definition}
設 $K$ 為**數域**（$\mathbb{Q}$ 的有限擴張）。$K$ 的**整數環** $\mathcal{O}_K$ 是 $K$ 中全體代數整數構成的集合：
$$\mathcal{O}_K = \{\alpha \in K : \alpha \text{ 對 } \mathbb{Z} \text{ 整}\}.$$
:::

由第 2.4 章「整元素構成環」，$\mathcal{O}_K$ 確實是一個環；由同章，它在 $K$ 中整閉（它就是 $\mathbb{Z}$ 在 $K$ 中的整閉包）。這個「整閉」性質，是它配得上「整數環」之名的關鍵 —— 它不遺漏任何該屬於它的整元素，正是 Euler 的 $\mathbb{Z}[\sqrt{-3}]$ 所缺的。

::: {.example name="$\mathbb{Z}$ 自己"}
$K = \mathbb{Q}$ 時，$\mathcal{O}_K = \mathbb{Z}$（$\mathbb{Q}$ 中的代數整數恰是普通整數，第 2.4 章習題 2.4.1）。所以 $\mathcal{O}_K$ 是 $\mathbb{Z}$ 在任意數域裡的自然推廣 —— 第三部全部的算術，都在這些環裡上演。
:::

## 二次域：整數環的第一張完整地圖

最簡單的非平凡數域是二次域 $K = \mathbb{Q}(\sqrt d)$（$d$ 為無平方因子整數）。它的整數環有一個出人意料的判準 —— 答案取決於 $d$ 模 $4$。

::: {.theorem name="二次域的整數環"}
設 $d$ 無平方因子。$\mathbb{Q}(\sqrt d)$ 的整數環是
$$\mathcal{O}_K = \begin{cases} \mathbb{Z}[\sqrt d] = \{a + b\sqrt d\}, & d \equiv 2, 3 \pmod 4, \\[4pt] \mathbb{Z}\!\left[\dfrac{1 + \sqrt d}{2}\right] = \left\{\dfrac{a + b\sqrt d}{2} : a \equiv b \!\!\pmod 2\right\}, & d \equiv 1 \pmod 4. \end{cases}$$
:::

::: {.proof}
（梗概）任取 $\alpha = \frac{a + b\sqrt d}{2} \in K$（$a, b \in \mathbb{Q}$），它對 $\mathbb{Z}$ 整 $\iff$ 它的「跡」$a$ 與「範數」$\frac{a^2 - b^2 d}{4}$ 都是整數（因為 $\alpha$ 滿足 $x^2 - ax + \frac{a^2-b^2d}{4} = 0$，整 $\iff$ 此式整係數）。分析這兩個整數條件，按 $d \bmod 4$ 分類，得上述結果。$d \equiv 1$ 時 $\frac{1+\sqrt d}{2}$ 滿足首一的 $x^2 - x + \frac{1-d}{4} = 0$（$\frac{1-d}{4} \in \mathbb{Z}$），故是代數整數。
:::

::: {.example name="Euler 之謎的最終解答"}
取 $d = -3$。因 $-3 \equiv 1 \pmod 4$，整數環是
$$\mathcal{O}_{\mathbb{Q}(\sqrt{-3})} = \mathbb{Z}\!\left[\frac{1 + \sqrt{-3}}{2}\right] = \mathbb{Z}[\zeta_3].$$
（注意 $\zeta_3 = \frac{-1+\sqrt{-3}}{2}$，與 $\frac{1+\sqrt{-3}}{2}$ 相差一個整數，生成同一個環。）

第 1.6 章 Euler 該用而未用的 Eisenstein 整數環 $\mathbb{Z}[\zeta_3]$，在這裡由統一判準**自動**浮現 —— 不是特例、不是巧合，而是「$d \equiv 1 \pmod 4$ 時整數環含半整數」這條一般定律的實例。Euler 用 $\mathbb{Z}[\sqrt{-3}]$ 的錯誤，現在看來是「忘了檢查 $d \bmod 4$」。$d = -3 \equiv 1$，整數環本就該含 $\frac{1+\sqrt{-3}}{2}$。三章追蹤的謎題，至此完全閉合。
:::

## 整基底與判別式

$\mathcal{O}_K$ 不只是個環，它還是 $\mathbb{Z}$ 上的**自由模**（有基底的模，對比第 2.4 章一般模可能無基底）。

::: {.theorem name="整基底存在"}
$[K : \mathbb{Q}] = n$ 時，$\mathcal{O}_K$ 作為 $\mathbb{Z}$-模有一組基底 $\{\omega_1, \dots, \omega_n\}$（稱**整基底**），即每個 $\alpha \in \mathcal{O}_K$ 唯一地寫成 $\sum c_i \omega_i$（$c_i \in \mathbb{Z}$）。
:::

整基底是「$\mathcal{O}_K$ 的座標系」。例如 $\mathbb{Z}[\sqrt 2]$ 的整基底是 $\{1, \sqrt 2\}$，$\mathbb{Z}[\zeta_p]$ 的是 $\{1, \zeta_p, \dots, \zeta_p^{p-2}\}$（$p-1$ 個，第 0.5 章那個維度再次現身）。

衡量整基底的「大小」的量，是判別式。

::: {.definition}
設 $\{\omega_1, \dots, \omega_n\}$ 是整基底，$\sigma_1, \dots, \sigma_n$ 是 $K \to \mathbb{C}$ 的 $n$ 個嵌入。**判別式**
$$\mathrm{disc}(K) = \det\bigl(\sigma_i(\omega_j)\bigr)^2.$$
它是一個不依賴整基底選取的整數。
:::

判別式看似抽象，但它編碼一個極重要的算術資訊：

::: {.theorem name="判別式偵測分歧"}
質數 $p$ 在 $\mathcal{O}_K$ 中**分歧**（ramifies，下一章精確定義，直覺是「$p$ 的分解出現重複因子」）$\iff p \mid \mathrm{disc}(K)$。
:::

::: {.example}
- $\mathbb{Q}(\sqrt d)$，$d \equiv 1 \pmod 4$：$\mathrm{disc} = d$；否則 $\mathrm{disc} = 4d$。
- $\mathbb{Q}(\zeta_p)$：$\mathrm{disc} = \pm p^{p-2}$，唯一質因數是 $p$。所以**在 $\mathbb{Q}(\zeta_p)$ 中，只有 $p$ 分歧**，其餘所有質數都「乾淨地」分解。
:::

::: {.remark name="判別式 → 導體 → Frey 曲線"}
「判別式的質因數 = 分歧質數」這個原理，是第六部的伏筆。橢圓曲線也有一個判別式 $\Delta$ 和一個更精細的不變量**導體** $N$（conductor），它們的質因數標記「曲線在哪些質數處有壞約化」（第 5.3 章）。

而 Frey 曲線的魔力（第 6.5 章），正在於它的判別式異常「光滑」—— 由假想的 FLT 反例 $a^p + b^p = c^p$ 構造的 Frey 曲線 $y^2 = x(x - a^p)(x + b^p)$，其判別式是 $(abc)^{2p}$ 的形狀，導體小得反常。這個「反常的光滑」，透過 Ribet 定理導致矛盾。本章的「判別式偵測分歧」是這套機制的最初原型：一個代數對象的判別式，洩漏了它在每個質數處的算術行為。你在數域上看到的，第六部會在橢圓曲線上重演，而那次重演會殺死 FLT 的反例。
:::

## 為什麼 $\mathbb{Z}[\zeta_p]$ 是正確的環

把本章用在第三部的主戰場 $K = \mathbb{Q}(\zeta_p)$ 上，收一個關鍵結論。

::: {.theorem name="分圓整數環"}
$\mathbb{Q}(\zeta_p)$ 的整數環恰好是 $\mathbb{Z}[\zeta_p]$，整基底為 $\{1, \zeta_p, \dots, \zeta_p^{p-2}\}$。
:::

這條定理（證明用判別式 $\pm p^{p-2}$ 的計算，本書取用）保證：Lamé 與 Kummer 在 $\mathbb{Z}[\zeta_p]$ 裡工作是**正確**的選擇 —— 不像 Euler 的 $\mathbb{Z}[\sqrt{-3}]$，$\mathbb{Z}[\zeta_p]$ 確實是整閉的、是 $\mathbb{Q}(\zeta_p)$ 的全部代數整數。所以他們的論證若失敗，**不是因為選錯環**（那個錯誤已被排除），而是因為更深的原因：即使在正確的整閉環裡，唯一分解仍可能崩塌。下一章將揭示，這個「更深的崩塌」如何發生，以及 Kummer 如何用「理想」修復它。

問題被乾淨地隔離了：環是對的，崩塌的是「元素層次的唯一分解」本身。這正是 Kummer 理論的起點。

## 本章地圖與下一章預告

- **整數環 $\mathcal{O}_K$**：數域中全體代數整數；整閉，是 $\mathbb{Z}$ 的自然推廣。
- **二次域判準**：$d \equiv 1 \pmod 4$ 含半整數，否則不含；$\mathbb{Z}[\zeta_3]$ 自動浮現，Euler 之謎閉合。
- **整基底**：$\mathcal{O}_K$ 作為 $\mathbb{Z}$-模的座標系。
- **判別式**：偵測分歧質數；通往導體與 Frey 曲線。
- **$\mathbb{Z}[\zeta_p]$ 是正確的環**：問題隔離 —— 環對了，崩塌的是元素唯一分解本身。

下一章《理想的算術》是第三部的核心，也是 Kummer 思想的精華。我們將看到：雖然 $\mathbb{Z}[\zeta_p]$ 中**元素**的唯一分解可能失效，但**理想**的唯一分解**永遠成立** —— 每個理想都唯一地分解成質理想之積。這是 Dedekind 把 Kummer 的「理想數」現代化的成果，是十九世紀數論的最高成就之一。「理想」之所以叫 ideal，正因為它是 Kummer 為了挽救唯一分解而**理想化**（想像）出來的因子。下一章，我們見證唯一分解如何在更高的層次上復活。

## 習題

**3.1.1**　求 $\mathbb{Q}(\sqrt{-1}) = \mathbb{Q}(i)$ 的整數環。（$-1 \equiv 3 \pmod 4$，所以是 $\mathbb{Z}[i]$ —— 高斯整數。）

**3.1.2 ★**　求 $\mathbb{Q}(\sqrt 5)$ 的整數環與整基底。驗證黃金比例 $\frac{1+\sqrt5}{2}$ 在其中（第 2.4 章習題 2.4.2 已證它是代數整數）。

**3.1.3 ★**　證明二次域整數環判準的一半：若 $d \equiv 1 \pmod 4$，則 $\frac{1+\sqrt d}{2}$ 是代數整數。（提示：找它的首一最小多項式，檢查係數整性。）

**3.1.4**　計算 $\mathbb{Q}(\sqrt{-5})$ 的判別式，並指出哪些質數分歧。（這個環就是第 0.2 章唯一分解失效的 $\mathbb{Z}[\sqrt{-5}]$ —— 下一章會看到它的理想如何拯救分解。）

**3.1.5 ★**　$\mathbb{Q}(\zeta_5)$ 的判別式是 $125 = 5^3$。確認唯一分歧質數是 $5$，並說明這與「$\mathbb{Q}(\zeta_p)$ 中只有 $p$ 分歧」一致。

**3.1.6（前瞻）**　橢圓曲線 $y^2 = x^3 + ax + b$ 的判別式是 $\Delta = -16(4a^3 + 27b^2)$。對 $y^2 = x^3 - x$（即 $a = -1, b = 0$）計算 $\Delta$，並找出它的質因數。（第 5.3 章會說明這些質因數標記「壞約化」的質數 —— 與本章「判別式偵測分歧」是同一個精神。你正在為橢圓曲線版本熱身。）
