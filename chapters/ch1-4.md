## 開場：兩種運算的結構

群只有一種運算。但數學裡最熟悉的對象 —— 整數、多項式、數域 —— 同時有加法**與**乘法，且兩者透過分配律咬合。承載這種雙運算結構的，是**環**（ring）；而當乘法也好到「人人可逆」時，環升級為**體**（field）。第 1.1 章已先完整定義體，讓線性代數能起步；本章從環出發重新放置它，並解釋體在雙運算結構中的位置。

這一章是第一部的代數收官，也是通往第三部的最後一塊地基。第三部 Kummer 拯救唯一分解的核心工具 ——「理想」（ideal）—— 就是環論的概念；而 Kummer 的戰場 $\mathbb{Z}[\zeta_p]$ 是一個環。更近的目標是兌現一個反覆出現的承諾：證明 $\mathbb{Z}/p\mathbb{Z}$ 在 $p$ 為質數時是一個體 $\mathbb{F}_p$，從而上一章的乘法群 $(\mathbb{Z}/p\mathbb{Z})^\times$ 被放回完整的四則脈絡。$\mathbb{F}_p$ 是 Wiles 證明裡 mod $p$ 表示的純量體，沒有它，第六部的 $\mathrm{GL}_2(\mathbb{F}_p)$ 連寫都寫不出來。

**依賴箭頭：** 0.2 同餘與 Bézout + 1.3 群、商群、同態
$\to$ 環 $\to$ 理想與商環 $\to$ 體與 $\mathbb F_p$
$\to$ 不可約多項式造體 $\to$ 第二部體擴張。

本章沿用五種結果標籤：**【完整證明】、【特殊情形】、【證明略圖】、【直覺】、【接受的黑箱】**。

## 環

::: {.definition}
**環**是一個集合 $R$，配備加法 $+$ 與乘法 $\cdot$，滿足：

1. $(R, +)$ 是交換群（單位元記 $0$）。
2. 乘法結合：$(ab)c = a(bc)$，且有乘法單位元 $1$。
3. 分配律：$a(b + c) = ab + ac$，$(b + c)a = ba + ca$。

若乘法也交換（$ab = ba$），稱**交換環**。本書的環預設交換、且含 $1$。
:::

::: {.example name="【完整證明】本書的環"}
- $\mathbb{Z}$：整數環，第零部的全部舞台。
- $\mathbb{Z}/n\mathbb{Z}$：模 $n$ 剩餘類環（加法與乘法都模 $n$）。
- $F[x]$：體 $F$ 上的多項式環。
- $\mathbb{Z}[\sqrt{-5}]$、$\mathbb{Z}[\zeta_p]$：第 0.2、0.5 章遇過的數環 —— 唯一分解的成敗就在這些環裡上演。
:::

環裡可能出現一個 $\mathbb{Z}$ 中沒有的病態現象：兩個非零元相乘得零。

::: {.definition}
環中的非零元 $a$ 是**零因子**，若存在非零 $b$ 使 $ab = 0$。沒有零因子的（含 $1 \ne 0$ 的交換）環稱為**整環**（integral domain）。
:::

::: {.example}
$\mathbb{Z}$ 是整環。但 $\mathbb{Z}/6\mathbb{Z}$ 不是：$2 \cdot 3 = 6 \equiv 0$，$2$ 與 $3$ 都是零因子。零因子的存在，會讓「消去律」失效（第 0.2 章的消去律陷阱，根源正在於此）—— 在有零因子的環裡，$ab = ac$ 推不出 $b = c$。整環是「乘法行為良好」的環，而它正是建立唯一分解理論的最低門檻。
:::

## 理想與商環

群有正規子群與商群；環的對應物是**理想**與**商環**。理想是環論的核心概念 —— 也是第三部的主角。

::: {.definition}
交換環 $R$ 的子集 $I$ 是**理想**，若 $I$ 是加法子群，且**吸收乘法**：對任何 $r \in R$、$a \in I$，有 $ra \in I$。
:::

「吸收乘法」是比子環更強的條件：理想被整個環的乘法「吞噬」。最重要的例子是**主理想**：由單一元素生成，$(a) = aR = \{ra : r \in R\}$。

::: {.example}
在 $\mathbb{Z}$ 中，$n\mathbb{Z}=(n)$ 是主理想。**【接受的黑箱；習題 1.4.2 補證】**$\mathbb Z$ 的每個理想都是主理想；這樣的環叫**主理想整環**（PID）。**【接受的黑箱】**每個 PID 都有元素的唯一分解；不是 PID 的數環則可能失去元素的唯一分解。第三部會精確區分這些蘊涵，不在此把「可能」說成「必然」。
:::

理想 $I$ 讓我們造商環 $R/I$：元素是陪集 $a + I$，加法與乘法逐項定義。「吸收乘法」這個條件，恰恰是保證乘法在商上良定義所需要的（習題 1.4.3）。

::: {.proposition name="【完整證明】商環乘法良定義"}
若 $a+I=a'+I$、$b+I=b'+I$，則 $ab+I=a'b'+I$。
:::

::: {.proof}
寫 $a'=a+i$、$b'=b+j$，其中 $i,j\in I$。則
$$a'b'-ab=aj+bi+ij.$$
理想吸收乘法，所以三項都在 $I$，其和也在 $I$；故兩乘積代表同一陪集。
:::

::: {.example name="同餘就是商環"}
$\mathbb{Z}/n\mathbb{Z}$ 正是 $\mathbb{Z}$ 對理想 $(n)$ 的商環。第 0.2 章的同餘 $a \equiv b \pmod n$，環論意思是「$a - b \in (n)$」，即 $a, b$ 在商環 $\mathbb{Z}/(n)$ 中相等。Gauss 的同餘記號，本質上是在商環裡計算。
:::

::: {.definition name="環同態"}
映射 $\phi:R\to S$ 若保持加法、乘法與 $1$，即
$\phi(a+b)=\phi(a)+\phi(b)$、$\phi(ab)=\phi(a)\phi(b)$、$\phi(1_R)=1_S$，就稱為**環同態**。其核是 $\ker\phi=\{a:\phi(a)=0\}$。
:::

::: {.theorem name="【證明略圖】環的第一同構定理"}
環同態 $\phi:R\to S$ 的核是理想，且
$$R/\ker\phi\cong\operatorname{im}\phi.$$
:::

證明沿用第 1.3 章同一張地圖：$a+\ker\phi\mapsto\phi(a)$；保持乘法是環版本新增的核對。完整的良定義檢查留作習題。

## 體：人人可除的環

::: {.definition}
**體**（field）是一個交換環 $F$，其中 $1 \ne 0$，且**每個非零元都有乘法逆元**。等價地，$F^\times=\{a\in F:a\ne0\}$ 在乘法下是交換群。
:::

體就是「四則運算全暢通」的環 —— 加減乘除（除以非零）都封閉。$\mathbb{Q}, \mathbb{R}, \mathbb{C}$ 是體，$\mathbb{Z}$ 不是（$2$ 沒有整數逆元）。

::: {.proposition name="【完整證明】體沒有零因子"}
每個體都是整環。
:::

::: {.proof}
若 $ab=0$ 且 $a\ne0$，兩邊乘 $a^{-1}$ 得 $b=0$。所以兩個非零元不可能乘成零。
:::

現在兌現核心承諾。

::: {.theorem name="【完整證明】$\mathbb{F}_p$ 的誕生"}
$\mathbb{Z}/n\mathbb{Z}$ 是體，若且唯若 $n$ 為質數。質數情形記作 $\mathbb{F}_p$。
:::

::: {.proof}
**$n$ 為質數 $\Rightarrow$ 體：** 取非零元 $a$（即 $p \nmid a$），則 $\gcd(a, p) = 1$。由 Bézout（第 0.2 章），存在 $x, y$ 使 $ax + py = 1$，即 $ax \equiv 1 \pmod p$。故 $x$ 是 $a$ 的逆元。每個非零元可逆，是體。

**$n$ 合數 $\Rightarrow$ 非體：** 寫 $n = ab$，$1 < a, b < n$。則 $a, b$ 在 $\mathbb{Z}/n\mathbb{Z}$ 中非零，但 $ab \equiv 0$ —— $a$ 是零因子。體無零因子，故非體。
:::

::: {.remark name="【直覺】Bézout 的第三次出場"}
注意這個證明的引擎又是 Bézout 等式。第 0.2 章它證了 Euclid 引理（通往唯一分解）；同章它給出模逆元；現在它讓 $\mathbb{F}_p$ 成為體。一條等式 $ax + py = 1$，撐起了初等數論半壁江山。「互質」之所以是數論裡最有用的條件，正因為它能翻譯成這條可運算的等式 —— 而這條等式的根，是整數的除法演算法，是良序原理。整座大廈的地基，仍是第 0.1 章那塊「正整數有最小元素」。
:::

$\mathbb{F}_p$ 是**有限體**（有限多個元素的體）最簡單的例子。它是第六部所有 mod $p$ 表示的純量體：當 Wiles 把橢圓曲線「約化 mod $p$」，曲線的座標就落在 $\mathbb{F}_p$ 裡，Galois 群的表示就落在 $\mathrm{GL}_2(\mathbb{F}_p)$ 裡。$\mathbb{F}_p$ 的「有限」與「可除」這兩個性質缺一不可 —— 有限讓計數論證可行，可除讓線性代數（上一章的整套機器）能在其上運作。

## 用商環製造新的體

商環不只是回收舊結構，它能**製造**全新的體。關鍵判準：

::: {.theorem name="【接受的黑箱】極大理想與體"}
設 $R$ 為交換環，$I$ 為理想。則 $R/I$ 是體，若且唯若 $I$ 是**極大理想**：$I\ne R$，而 $I\subseteq J\subseteq R$ 對理想 $J$ 只可能有 $J=I$ 或 $J=R$。
:::

（證明見習題 1.4.6。）還需要另一條明示黑箱：

::: {.theorem name="【接受的黑箱】多項式的極大理想判準"}
在體 $F$ 上，非定值多項式 $f\in F[x]$ 不可約，若且唯若主理想 $(f)$ 是 $F[x]$ 的極大理想。
:::

於是：

::: {.corollary name="【完整證明；依賴兩個黑箱】由不可約多項式造體"}
設 $F$ 為體，$f \in F[x]$ 不可約。則 $F[x]/(f)$ 是一個體，它「包含」$F$，並且 $f$ 在其中**有了根**。
:::

::: {.proof}
$f$ 不可約，依多項式極大理想判準，$(f)$ 極大；再依極大理想與體的判準，$F[x]/(f)$ 是體。常數映射 $c\mapsto c+(f)$ 把 $F$ 嵌入商環；商環中 $x+(f)$ 代入 $f$ 後等於 $f(x)+(f)=0+(f)$，所以它是 $f$ 的一個根。
:::

這是抽象代數最具創造力的構造之一：給一個沒有根的多項式，憑空造出一個含其根的更大的體。兩個將主導後續的例子：

::: {.example name="造出 $\mathbb{C}$ 與 $\mathbb{F}_4$"}
**複數：** $x^2 + 1$ 在 $\mathbb{R}$ 上不可約（它是二次式且無實根）。$\mathbb{R}[x]/(x^2 + 1)$ 是體，並藉 $a+bx+(x^2+1)\mapsto a+bi$ 與 $\mathbb C$ 同構；商中的 $x$ 對應 $i$。

**有限體 $\mathbb{F}_4$：** $x^2 + x + 1$ 在 $\mathbb{F}_2$ 上不可約（代入 $0, 1$ 都不為零）。$\mathbb{F}_2[x]/(x^2 + x + 1)$ 是有 $4$ 個元素的體，記 $\mathbb{F}_4$。注意它**不是** $\mathbb{Z}/4\mathbb{Z}$（後者有零因子 $2 \cdot 2 = 0$，根本不是體）。更一般的分類是**【接受的黑箱】**：有限體的元素個數必為質數冪 $p^k$，而每個 $p^k$ 都存在一個、且在**同構意義下唯一**的有限體。
:::

::: {.remark name="【直覺／前瞻】這個構造就是體擴張"}
「給多項式造出含其根的體」這件事，正是第二部**體擴張**的核心機制，也是 Galois 理論的出發點。$\mathbb{Q}[x]/(x^2 - 2) \cong \mathbb{Q}(\sqrt 2)$、$\mathbb{Q}[x]/(\Phi_p) \cong \mathbb{Q}(\zeta_p)$ —— 第 0.5 章那個 $p - 1$ 維的分圓體，原來就是用分圓多項式 $\Phi_p$ 對多項式環取商得到的。第 0.5 章證 $\Phi_p$ 不可約，現在顯出它的用途：正因為不可約，$(\Phi_p)$ 才極大，商才是體，$\mathbb{Q}(\zeta_p)$ 才確實是個體。第零部埋的那顆種子，在這裡長成了第二部的入口。
:::

## 代數段落回顧：語言已經備齊

第一部的代數地基到此完成。我們建立了三套結構，外加一條貫穿的線性代數：

- **線性代數**（1.1–1.2）：向量空間、線性映射、矩陣、特徵值、對角化 —— 「表示」的舞台，Hecke 算子與特徵形式的本體。
- **群**（1.3）：對稱性的代數、Lagrange、同態、群作用 —— Galois 群的母結構。
- **環與體**（1.4）：雙運算結構、理想、商環、$\mathbb{F}_p$ —— 數環與唯一分解的舞台，mod $p$ 表示的純量體。

這三者不是孤立的。第一同構定理在群與環裡是同一句話，秩-零度定理是它的線性版；體是乘法行為最好的環；$\mathrm{GL}_2(\mathbb{F}_p)$ 同時用到群、體、線性代數三者。它們將在第二部的 Galois 理論裡第一次大會師：Galois 理論的全部內容，就是把「體擴張」（環論）與「Galois 群」（群論）透過一一對應綁在一起，而這個對應作用在「根」這個有限集合上（群作用）。

**檢查點 1.4**　請比較三個句子：$\mathbb Z$ 是整環但不是體；$\mathbb Z/6\mathbb Z$ 有零因子；$\mathbb Z/7\mathbb Z=\mathbb F_7$ 中每個非零元可逆。若能各舉一個具體算式，就已分清環、整環、體。

## 本章地圖與下一章預告

- **環與整環**：雙運算結構；零因子與消去律失效。
- **理想與商環**：吸收乘法；$\mathbb{Z}/n\mathbb{Z}$ 即 $\mathbb{Z}/(n)$；主理想與 PID。
- **體**：人人可除；$\mathbb{Z}/n\mathbb{Z}$ 是體 $\iff n$ 質數，得 $\mathbb{F}_p$。
- **商環造體**：不可約多項式 $\Rightarrow$ 極大理想 $\Rightarrow$ 商為體；$\mathbb{C}$、$\mathbb{F}_4$、$\mathbb{Q}(\zeta_p)$ 的統一構造。

下一章第 1.5 章轉向分析，從零精確定義極限、級數與一致收斂；這是後面把模形式當成解析函數所需的另一條地基。第 1.6 章再以 Euler 的 $n=3$ 歷史路線收束第一部，之後第 2.1 章才正式進入體擴張。

## 習題

**1.4.1**　判斷下列何者為整環、何者為體：$\mathbb{Z}$、$\mathbb{Z}/6\mathbb{Z}$、$\mathbb{Z}/7\mathbb{Z}$、$\mathbb{Q}[x]$、$\mathbb{R}[x]/(x^2 + 1)$、$\mathbb{R}[x]/(x^2 - 1)$。（最後一個要小心：$x^2 - 1$ 可約。）

**1.4.2 ★**　證明 $\mathbb{Z}$ 的每個理想都是主理想 $(n)$。（提示：非零理想中取最小正元素，用除法演算法證它生成整個理想 —— 與第 0.2 章 Bézout 的證明同一招。）

**1.4.3**　證明：理想的「吸收乘法」性質，正好保證商環 $R/I$ 上的乘法 $(a + I)(b + I) = ab + I$ 良定義（不依賴陪集代表的選取）。

**1.4.4 ★**　證明體必為整環（無零因子）。反之，**有限**整環必為體（提示：對非零 $a$，映射 $x \mapsto ax$ 是有限集到自身的單射，故滿射，於是 $1$ 在像中）。由此給出 $\mathbb{F}_p$ 是體的第二種證明。

**1.4.5**　在 $\mathbb{F}_5$ 中計算 $3^{-1}$、$2^{-1}$，並解線性方程 $2x + 1 = 4$。

**1.4.6 ★**　證明：$R/I$ 是體 $\iff I$ 極大。（提示：$R/I$ 是體 $\iff$ 它只有 $\{0\}$ 與自身兩個理想 $\iff$ $I$ 與 $R$ 之間沒有中間理想。用環的對應定理：$R/I$ 的理想對應 $R$ 中包含 $I$ 的理想。）

**1.4.7**　驗證 $\mathbb{F}_2[x]/(x^2 + x + 1)$ 是體：列出四個元素，造出乘法表，確認每個非零元有逆。再驗證 $\mathbb{F}_2[x]/(x^2 + 1)$ **不是**體（提示：$x^2 + 1 = (x+1)^2$ 在 $\mathbb{F}_2$ 上，可約）。

**1.4.8（前瞻）**　$\mathbb{Q}[x]/(x^2 - 2)$ 與 $\mathbb{Q}(\sqrt 2)$ 同構。明確寫出同構映射，並用它計算 $(\sqrt 2)^{-1}$ 在商環表示下對應到哪個多項式（次數 $< 2$）。（這題把「商環造體」與「數域」的兩種觀點對接，正是第二部的日常語言。）
