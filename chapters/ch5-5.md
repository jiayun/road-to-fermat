## 開場：兌現第 1.2 章的承諾

上一章定義了模形式與它的 $q$ 展開指紋 $\{a_n(f)\}$。但指紋的真正威力，要等這一章才顯現 —— 因為指紋的乘性結構（$a_p$ 之間的關係）來自一族作用在模形式空間上的算子：**Hecke 算子**。

這一章兌現一張很早的支票。第 1.2 章建立特徵值與「同時對角化」理論時，我承諾過：那套線性代數的最終用途，是讓 Hecke 算子可以對角化、讓特徵形式（共同特徵向量）存在。現在這個承諾要實現了。Hecke 算子兩兩交換、可同時對角化，其共同特徵向量就是**特徵形式**，而特徵值序列 $\{a_p(f)\}$ 就是要與橢圓曲線比對的指紋。

走完這一章，模形式這一側的指紋就完全建立。加上新舊形式的概念（Ribet level lowering 的關鍵），第 5.7 章的谷山–志村猜想就可以正式陳述了。

## Hecke 算子

::: {.definition}
對每個質數 $p$，**Hecke 算子** $T_p$ 是作用在權重 $k$ 模形式空間 $M_k$ 上的線性算子。在 $q$ 展開上，它的作用是：若 $f = \sum a_n q^n$，則 $T_p f = \sum b_n q^n$，其中
$$b_n = a_{pn} + p^{k-1}a_{n/p}$$
（$a_{n/p}$ 在 $p \nmid n$ 時取 $0$）。
:::

$T_p$ 把模形式送到模形式（保持變換律，需證明），所以它是 $M_k$ 上的線性算子。它的幾何來源是「對橢圓曲線的 $p$-同源求和」—— 把一條曲線送到所有與它 $p$-同源的曲線之和，這個操作反映在模形式上就是 $T_p$（本書不深入幾何來源）。

關鍵性質有兩條，它們讓第 1.2 章的機器啟動：

::: {.theorem name="Hecke 算子的性質"}
1. **交換性**：$T_p T_q = T_q T_p$ 對所有質數 $p, q$。
2. **自伴性**：相對於 Petersson 內積，$T_p$ 是自伴的。
:::

## 特徵形式：兌現同時對角化

現在第 1.2 章的定理直接適用。$\{T_p\}$ 是模形式空間上一族**交換**的**自伴**算子，而空間**有限維**（第 5.4 章）。由第 1.2 章的譜定理與同時對角化定理：

::: {.theorem name="特徵形式存在"}
尖形式空間 $S_k$ 有一組基底，由所有 $T_p$ 的**共同特徵向量**構成。這些共同特徵向量稱為**特徵形式**（Hecke eigenform）。每個特徵形式 $f$ 滿足
$$T_p f = \lambda_p f \qquad \text{對每個質數 } p.$$
:::

::: {.remark name="第 1.2 章的回收"}
這正是第 1.2 章末那個 remark 預言的場景，逐字成真。當時我說：「模形式空間 $S_k$ 上的 Hecke 算子 $T_p$ 兩兩交換、透過 Petersson 內積自伴，故同時對角化，共同特徵向量就是特徵形式。」當時這是一張對未來的支票；現在 Hecke 算子已定義、交換性與自伴性已陳述，支票兌現。

第 1.2 章那條抽象的線性代數定理（交換的可對角化算子族有共同特徵基），在這裡找到了它存在的理由 —— 它就是為了讓特徵形式存在。沒有有限維（第 5.4 章）、沒有交換自伴（本章）、沒有同時對角化（第 1.2 章），「特徵形式」三個字無從定義。三章合力，才造出這個概念。而特徵形式，正是谷山–志村猜想裡與橢圓曲線配對的那個 $f$。
:::

## 特徵值就是指紋

特徵形式的特徵值，與它的 $q$ 展開係數有一個漂亮的關係。

::: {.theorem name="特徵值 = 係數"}
設 $f = \sum a_n q^n$ 是特徵形式，正規化使 $a_1 = 1$。則 Hecke 特徵值恰好是 $q$ 展開係數：
$$T_p f = a_p f, \qquad \text{即} \quad \lambda_p = a_p(f).$$
更進一步，係數滿足乘性關係：
$$a_m a_n = a_{mn}\ (\gcd(m,n)=1), \qquad a_{p^{r+1}} = a_p a_{p^r} - p^{k-1}a_{p^{r-1}}.$$
:::

::: {.proof}
（梗概）比較 $T_p f = a_p f$ 兩邊的 $q$ 展開係數。$T_p f$ 的 $q^1$ 係數是 $a_p$（由定義 $b_1 = a_p$），而 $a_p f$ 的 $q^1$ 係數是 $a_p \cdot a_1 = a_p$。一般項給出遞迴關係。乘性由遞迴推出。
:::

::: {.example name="Ramanujan $\tau$ 的全部祕密"}
模判別式 $\Delta = \sum\tau(n)q^n$（第 5.4 章）是權重 $12$ 唯一的尖形式，故自動是特徵形式。於是 Ramanujan $\tau$ 函數的那些神祕性質，全部是「$\Delta$ 是特徵形式」的後果：

- **乘性** $\tau(mn) = \tau(m)\tau(n)$（$\gcd(m,n)=1$）：例如 $\tau(2)\tau(3) = (-24)(252) = -6048 = \tau(6)$，$\tau(2)\tau(5) = -115920 = \tau(10)$ —— 數值驗證精確成立。
- **遞迴** $\tau(p^2) = \tau(p)^2 - p^{11}$：例如 $\tau(4) = \tau(2)^2 - 2^{11} = 576 - 2048 = -1472$ ✓。

Ramanujan 在 1916 年憑直覺**猜出**這些性質，當時無法解釋為什麼。答案是 Hecke 理論（1937）：$\tau(n)$ 的乘性結構，是 $\Delta$ 作為 Hecke 特徵形式的必然。Ramanujan 看到的算術奇蹟，根源是模形式空間的線性代數。$\tau(p)$ 就是 $T_p$ 在 $\Delta$ 上的特徵值 —— 一個純粹的線性代數量，卻控制著一個深刻的數論序列。
:::

## $L$ 函數與 Euler 乘積

特徵形式的乘性係數，讓它的 L 函數有 Euler 乘積 —— 與橢圓曲線完全平行。

::: {.definition}
特徵形式 $f = \sum a_n q^n$ 的 **L 函數**：
$$L(f, s) = \sum_{n\ge1}\frac{a_n}{n^s} = \prod_p \frac{1}{1 - a_p p^{-s} + p^{k-1-2s}}.$$
:::

乘性係數 $\iff$ Euler 乘積（求和變連乘）。把這個與第 5.3 章橢圓曲線的 L 函數
$$L(E,s) = \prod_p\frac{1}{1 - a_p(E)p^{-s} + p^{1-2s}}$$
並排：對權重 $k = 2$ 的模形式，兩個 Euler 乘積形式**完全一樣**！谷山–志村猜想的精確陳述，就是「存在權重 $2$ 的特徵形式 $f$ 使 $L(E,s) = L(f,s)$」—— 即兩個 Euler 乘積逐因子相等，即 $a_p(E) = a_p(f)$ 對所有 $p$。兩位主角的指紋，在 L 函數這裡正式對齊。

## 新舊形式：為 Ribet 鋪路

最後一個概念，對第六部的 Ribet 定理至關重要。模形式有「級」（level）—— 上一章是對全模群 $\mathrm{SL}_2(\mathbb{Z})$（級 $1$），但一般考慮子群 $\Gamma_0(N)$（級 $N$，對應導體 $N$ 的橢圓曲線）。

::: {.definition}
級 $N$ 的尖形式分兩類：
- **舊形式**（oldform）：來自更低級 $M \mid N$（$M < N$）的形式「提升」上來的（如 $f(\tau) \mapsto f(d\tau)$）。
- **新形式**（newform）：真正「屬於」級 $N$、不來自更低級的正規化特徵形式。
:::

新形式是模形式理論的「原子」—— 每個尖形式都由新舊形式組合而成，而新形式攜帶級 $N$ 的本質資訊。

::: {.remark name="level lowering 的舞台"}
新舊形式的區分，是 Ribet 定理（第 6.6 章）的舞台。Ribet 的「level lowering」說的是：在某些條件下，一個級 $N$ 的新形式，模 $p$ 約化後「來自」一個級 $N/\ell$（去掉一個質因子 $\ell$）的新形式。換句話說，模 $p$ 看，級可以降低。

這對 FLT 是致命武器。Frey 曲線（第 6.5 章）若是模的，對應一個級 $N$（無平方因子、含 $abc$ 的質因子）的新形式。Ribet 的 level lowering 一路把級降到 $2$ —— 但級 $2$、權重 $2$ 的新形式空間是**零維的**（對應 $X_0(2)$ 虧格 $0$，第 4.4 章！）。於是 Frey 曲線對應一個「住在零維空間裡的非零新形式」，矛盾。FLT 反例不存在。

本章的新舊形式概念，是這把刀的刀柄。第 4.4 章的「$X_0(2)$ 虧格 $0$」是刀刃，本章的「level lowering 把級降到 $2$」是揮刀的手臂。兩者在第六部合一，斬斷 FLT 的反例。你現在已經握有這把刀的全部零件，只差第六部把它們組裝起來。
:::

## 模形式刻畫完成

模形式的兩章到此完成，主角二號的全貌：

- **定義**（5.4）：上半平面的全純函數、變換律、$q$ 展開指紋、有限維。
- **算術**（5.5）：Hecke 算子、特徵形式、特徵值 = 指紋、L 函數、新舊形式。

模形式從一個純解析的對象（上半平面上的對稱函數），透過 Hecke 算子，長出了算術靈魂（指紋 $\{a_p(f)\}$）。而這個指紋，與橢圓曲線的指紋 $\{a_p(E)\}$ 形式完全一樣。兩位主角各自帶著一串 $\{a_p\}$ 站在舞台兩端 —— 一個來自幾何（數點），一個來自分析（Hecke 特徵值）。它們會相等嗎？那就是谷山–志村猜想。

## 本章地圖與下一章預告

- **Hecke 算子 $T_p$**：作用在 $q$ 展開上；交換、自伴。
- **特徵形式**：Hecke 算子的共同特徵向量；第 1.2 章同時對角化的兌現。
- **特徵值 = 指紋**：$T_p f = a_p f$；乘性與遞迴；Ramanujan $\tau$ 的祕密。
- **L 函數 Euler 乘積**：與橢圓曲線形式一致；谷山–志村比對的場所。
- **新舊形式**：Ribet level lowering 的舞台；通往 $X_0(2)$ 的零維刀刃。

下一章《模曲線》把模形式幾何化。模形式是上半平面 $\mathbb{H}$ 上的函數，而 $\mathbb{H}/\Gamma_0(N)$ 緊化後就是模曲線 $X_0(N)$（第 4.4 章一瞥過）。模形式對應模曲線上的「微分形式」，尖形式對應全純微分 —— 於是尖形式空間的維度 = 模曲線的虧格（這解釋了第 4.4 章「虧格 $0$ 無尖形式」）。模曲線把「模形式」與「橢圓曲線的參數空間」統一起來，是谷山–志村猜想幾何化陳述的舞台，也是 Wiles 證明的幾何場景。走完它，第五部就只剩猜想本身的陳述（5.7）與歷史（5.8）。

## 習題

**5.5.1**　用 Hecke 算子定義 $b_n = a_{pn} + p^{k-1}a_{n/p}$，計算 $T_2$ 作用在 $f = \sum a_n q^n$ 上的前幾個係數 $b_0, b_1, b_2$。

**5.5.2 ★**　驗證 Ramanujan $\tau$ 的乘性：用 $\tau(2) = -24, \tau(3) = 252, \tau(5) = 4830$ 計算 $\tau(6), \tau(10), \tau(15)$，驗證 $\tau(mn) = \tau(m)\tau(n)$。

**5.5.3 ★**　驗證遞迴 $\tau(p^2) = \tau(p)^2 - p^{11}$ 對 $p = 2, 3$：用 $\tau(2) = -24$ 算 $\tau(4)$，用 $\tau(3) = 252$ 算 $\tau(9)$。

**5.5.4**　解釋為什麼「$\Delta$ 自動是特徵形式」：權重 $12$ 的尖形式空間 $S_{12}$ 是幾維？一維空間上的任何線性算子作用如何？（故 $\Delta$ 必為 $T_p$ 的特徵向量。）

**5.5.5 ★**　證明乘性係數 $\iff$ Euler 乘積：從 $a_{mn} = a_m a_n$（$\gcd=1$）推出 $\sum a_n n^{-s} = \prod_p(\sum_r a_{p^r}p^{-rs})$。（提示：唯一分解 + 乘性，與 Riemann zeta 的 Euler 乘積同理。）

**5.5.6（前瞻）**　Ribet level lowering 把級 $N$ 的新形式降到級 $N/\ell$。Frey 曲線對應級 $N = \prod_{\ell\mid abc}\ell$，最終降到級 $2$。已知級 $2$ 權重 $2$ 的新形式空間是零維（$X_0(2)$ 虧格 $0$）。用一句話完成 FLT 的邏輯骨架：為什麼這導致矛盾？（第 6.6 章的全部精髓濃縮在這一題。）
