## 開場：把兩位主角放進同一個空間

前面五章把兩位主角分別刻畫完畢：橢圓曲線（幾何/算術物件，5.1–5.3）與模形式（解析物件，5.4–5.5）。它們各自帶著一串指紋 $\{a_p\}$。但它們仍住在不同的世界 —— 一個是 $\mathbb{P}^2$ 中的曲線，一個是上半平面的函數。要讓它們相遇，需要一個共同的舞台。

那個舞台是**模曲線** $X_0(N)$。它有一個神奇的雙重身分：一方面，它是模形式生活的空間（$\mathbb{H}/\Gamma_0(N)$ 緊化，第 4.4 章一瞥過）；另一方面，它**參數化橢圓曲線**（它的點對應橢圓曲線）。於是模曲線同時裝著兩位主角 —— 模形式是它上面的微分形式，橢圓曲線是它的點所代表的對象。這個雙重身分，是谷山–志村猜想得以陳述、Wiles 得以證明的幾何根基。

本章建立模曲線，揭示三個關鍵對應：尖形式 = 微分形式（故尖形式維度 = 虧格，解釋第 4.4 章的謎）、模曲線參數化橢圓曲線、以及 Eichler–Shimura 關係（連接 Hecke 與 Frobenius，這是兩個指紋相等的幾何根源）。走完它，谷山–志村猜想就可以正式陳述了。

## 模曲線 $X_0(N)$

::: {.definition}
**模曲線** $Y_0(N) = \mathbb{H}/\Gamma_0(N)$，其中 $\Gamma_0(N)$ 是 $\mathrm{SL}_2(\mathbb{Z})$ 中左下角 $\equiv 0 \pmod N$ 的矩陣構成的子群。補上有限個尖點得到緊緻 Riemann 曲面 $X_0(N)$。
:::

$X_0(N)$ 是一個緊緻 Riemann 曲面（第 4.4 章），有確定的虧格。第 4.4 章已列過：$X_0(1), X_0(2)$ 虧格 $0$，$X_0(11)$ 虧格 $1$，等等。它的關鍵性質是「模解釋」（moduli interpretation）：

::: {.theorem name="模曲線參數化橢圓曲線"}
$Y_0(N)$ 的點一一對應「帶有一個 $N$-同源結構的橢圓曲線對 $(E, C)$」的同構類，其中 $C$ 是 $E$ 的一個 $N$ 階循環子群。特別地，$X_0(1)$ 的點對應橢圓曲線的同構類（透過 $j$-不變量）。
:::

::: {.remark name="模曲線是橢圓曲線的「目錄」"}
這個模解釋是模曲線的靈魂。$X_0(N)$ 不只是一個抽象的 Riemann 曲面 —— 它是橢圓曲線的**目錄**：曲面上每個點，代表一條（帶額外結構的）橢圓曲線。沿著曲面移動，就是讓橢圓曲線連續變形。

這把「橢圓曲線」與「模形式」放進了同一個空間：橢圓曲線是模曲線的**點**，模形式是模曲線上的**函數/微分**。第 4.2 章說「所有格的空間是上半平面」，現在精確化：所有橢圓曲線（的同構類）構成模曲線。橢圓曲線不再是孤立的對象，而是模曲線這個大家庭裡的成員 —— 而模形式，是這個大家庭上的調和分析。兩位主角的相遇，就發生在這個目錄空間裡。
:::

## 尖形式就是微分形式

模曲線把模形式幾何化。關鍵對應是：

::: {.theorem name="尖形式 = 全純微分"}
權重 $2$ 的尖形式 $f \in S_2(\Gamma_0(N))$ 與 $X_0(N)$ 上的**全純微分形式**一一對應，對應方式是 $f(\tau) \mapsto f(\tau)\,d\tau$（變換律的權重 $2$ 恰好使 $f\,d\tau$ 在 $\Gamma_0(N)$ 作用下不變）。
:::

由此立得一個漂亮的維度公式 —— 因為「緊緻 Riemann 曲面上全純微分的維度 = 虧格」（第 4.3 章三種虧格定義之一）：

::: {.corollary name="尖形式維度 = 虧格"}
$$\dim S_2(\Gamma_0(N)) = \mathrm{genus}(X_0(N)).$$
:::

::: {.example name="解開第 4.4 章的謎"}
這條公式解釋了第 4.4 章那個關鍵的「虧格 $0$ 無尖形式」：
- $X_0(1), X_0(2)$ 虧格 $0$ $\Rightarrow \dim S_2 = 0$ —— **權重 $2$、級 $1$ 或 $2$ 的尖形式空間是零維的，一個非零尖形式都沒有**。
- $X_0(11)$ 虧格 $1$ $\Rightarrow \dim S_2 = 1$ —— 第一個權重 $2$ 尖形式，對應導體 $11$ 的橢圓曲線。

第 4.4 章我預告過「$X_0(2)$ 虧格 $0$ 是 FLT 證明最後一刀的刀刃」。現在看清了刀刃的本質：虧格 $0$ 透過這條維度公式，等價於「沒有權重 $2$ 級 $2$ 的尖形式」。Frey 曲線若是模的、又被 Ribet 降到級 $2$，就需要這樣一個不存在的尖形式 —— 矛盾。第 4.4 章的拓撲事實（虧格 $0$）與第 5.5 章的算術武器（level lowering），透過本章的維度公式接通。
:::

## 模參數化：模性的幾何形式

模曲線給「橢圓曲線是模的」一個幾何陳述。

::: {.definition name="模參數化"}
橢圓曲線 $E$（導體 $N$）稱為**模的**（modular），若存在一個非常數的全純映射
$$\phi: X_0(N) \longrightarrow E.$$
（等價地：存在權重 $2$ 級 $N$ 的特徵形式 $f$ 使 $L(E,s) = L(f,s)$。）
:::

::: {.remark name="兩種模性陳述的等價"}
「模的」有兩個等價陳述，值得並列：
- **解析版**（第 5.5 章）：存在權重 $2$ 特徵形式 $f$ 使 $a_p(E) = a_p(f)$（指紋相等）。
- **幾何版**（本章）：存在模曲線到 $E$ 的非常數映射 $X_0(N) \to E$（模參數化）。

兩者等價，因為權重 $2$ 尖形式 = $X_0(N)$ 的微分（本章），而一個對應 $E$ 的微分給出到 $E$ 的映射。幾何版更直觀：$E$ 是模的，意思是它能被模曲線「覆蓋」—— 模曲線這個橢圓曲線的目錄，有一條通向 $E$ 的路。谷山–志村猜想（所有橢圓曲線都模）的幾何形式，就是「每條橢圓曲線都能被某個 $X_0(N)$ 覆蓋」。模曲線是橢圓曲線世界的「萬有覆蓋」。
:::

## Eichler–Shimura：指紋相等的根源

最後一塊拼圖：為什麼模參數化會導致**指紋相等** $a_p(E) = a_p(f)$？根源是 Eichler–Shimura 關係。

::: {.theorem name="Eichler–Shimura 關係"}
在 $X_0(N)$ 約化 mod $p$ 上，Hecke 算子 $T_p$ 與 Frobenius 滿足
$$T_p = \mathrm{Frob}_p + p \cdot \mathrm{Frob}_p^{-1}\!\!\pmod p.$$
:::

::: {.remark name="兩個指紋為何相等"}
這個關係是谷山–志村機制的心臟。回憶兩個指紋的來源：
- 橢圓曲線指紋 $a_p(E) = \mathrm{tr}\,\rho_E(\mathrm{Frob}_p)$ —— 來自 **Frobenius**（第 4.5、5.3 章）。
- 模形式指紋 $a_p(f) = $ Hecke 特徵值 $\lambda_p$ —— 來自 **Hecke 算子 $T_p$**（第 5.5 章）。

Eichler–Shimura 關係把 Hecke 算子 $T_p$ 與 Frobenius 直接等同起來（在模曲線約化 mod $p$ 上）。於是「Hecke 特徵值」與「Frobenius 跡」變成同一個東西 —— 這就是為什麼 $a_p(f) = a_p(E)$。兩個從完全不同世界（解析的 Hecke、幾何的 Frobenius）來的指紋，透過模曲線的幾何被焊接在一起。

這完成了第 1.2、2.3、3.5、4.5 章一路鋪陳的 $a_p$ 三位一體：
$$\underbrace{a_p(E) = p + 1 - \#E(\mathbb{F}_p)}_{\text{數點}} = \underbrace{\mathrm{tr}\,\rho_E(\mathrm{Frob}_p)}_{\text{Frobenius}} = \underbrace{a_p(f) = \lambda_p}_{\text{Hecke}}.$$
最後那個等號，正是 Eichler–Shimura 給的。模曲線是讓這三者相等的幾何場所 —— 數點、Frobenius、Hecke 在 $X_0(N)$ 上匯為一點。谷山–志村猜想斷言這個匯合對**每條**橢圓曲線都發生。下一章正式陳述它。
:::

## 本章地圖與下一章預告

- **模曲線 $X_0(N)$**：$\mathbb{H}/\Gamma_0(N)$ 緊化；參數化橢圓曲線的目錄。
- **尖形式 = 微分形式**：$f \mapsto f\,d\tau$；$\dim S_2(\Gamma_0(N)) = \mathrm{genus}(X_0(N))$。
- **虧格 $0$ 無尖形式**：第 4.4 章刀刃的本質；$X_0(2)$ 通往 FLT 矛盾。
- **模參數化**：$E$ 模 $\iff$ 存在 $X_0(N) \to E$；模曲線是萬有覆蓋。
- **Eichler–Shimura**：$T_p = \mathrm{Frob}_p + p\,\mathrm{Frob}_p^{-1}$；指紋相等的根源；$a_p$ 三位一體完成。

下一章《谷山–志村猜想》是第五部的頂點，也是全書中央的陳述。我們終於可以正式寫下這個連接兩位主角的猜想：**每一條定義在 $\mathbb{Q}$ 上的橢圓曲線都是模的** —— 它的指紋 $\{a_p(E)\}$ 恰好是某個權重 $2$ 特徵形式的指紋 $\{a_p(f)\}$。我們會解釋這個猜想為何如此深刻（它是 Langlands 綱領在 $\mathrm{GL}_2$ 的第一個非平凡情形）、它與 FLT 的關係（透過 Frey 曲線與 Ribet 定理），以及為什麼證明它需要第六、七部的全部機器（Galois 表示與變形理論）。兩位主角站到了一起，世紀相會就在下一章。

## 習題

**5.6.1**　$\Gamma_0(N)$ 是 $\mathrm{SL}_2(\mathbb{Z})$ 中 $c \equiv 0 \pmod N$ 的矩陣。驗證它是子群（對乘法與取逆封閉）。

**5.6.2 ★**　用 $\dim S_2(\Gamma_0(N)) = \mathrm{genus}(X_0(N))$ 與第 4.4 章虧格表，說明為什麼權重 $2$ 級 $11$ 恰有一個（至同倍數）新形式，而級 $1, 2, 3, 5, 7$ 都沒有尖形式。

**5.6.3**　$X_0(11)$ 虧格 $1$，本身是橢圓曲線（導體 $11$）。解釋這個「自指」現象：模曲線參數化橢圓曲線，而它自己也是橢圓曲線 —— 它參數化自己嗎？（提示：它對應導體 $11$ 那一條特定曲線。）

**5.6.4 ★**　用 Eichler–Shimura 關係 $T_p = \mathrm{Frob}_p + p\,\mathrm{Frob}_p^{-1}$ 與 Frobenius 滿足 $\mathrm{Frob}_p^2 - a_p\mathrm{Frob}_p + p = 0$，推出 $T_p$ 的「特徵值」與 $a_p$ 的關係（提示：取跡）。

**5.6.5**　「$E$ 模的」幾何版是 $X_0(N) \to E$，解析版是 $a_p(E) = a_p(f)$。用一句話說明兩者為何等價（透過尖形式 = 微分）。

**5.6.6（前瞻）**　谷山–志村說每條橢圓曲線都被某 $X_0(N)$ 覆蓋（$N$ = 導體）。Frey 曲線導體 $N = \prod_{\ell\mid abc}\ell$。如果 Frey 曲線是模的，它被 $X_0(N)$ 覆蓋；Ribet 把這降到 $X_0(2)$。用一句話預測：$X_0(2)$ 虧格 $0$ 如何終結這個故事？（第六部的全貌濃縮於此。）
