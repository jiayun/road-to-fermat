## 開場：把刀磨利之後

到目前為止，你已經備齊了攻打 FLT 第一個情形所需的全部武器：

- 第 0.1 章的**無窮遞降法** —— 假設最小反例存在，再從它造出更小的反例，逼出矛盾。
- 第 0.2 章的**唯一分解**與本原解化約 —— 「不失一般性，設互質」。
- 第 0.3 章的**畢氏三元數分類** —— $(m^2 - n^2,\ 2mn,\ m^2 + n^2)$。

這一章把三者組裝起來，給出本書第一個**完整證明**的 FLT 情形：$x^4 + y^4 = z^4$ 無正整數解。費馬在《算術》另一處留下了與直角三角形面積相關的遞降論證，後世由此整理出 $n=4$ 的證明；本章給的是同一精神下的現代化版本，不宣稱逐字重現費馬原稿。

走完這一章，你不再只是「聽說 FLT 很難」的旁觀者 —— 你會親手關上 $n = 4$ 這扇門，而且關得嚴絲合縫。

**依賴箭頭：** 0.1 良序與無窮遞降 + 0.2 本原化與唯一分解
$+$ 0.3 畢氏三元數分類 $\to$ 強化四次方程
$\to$ FLT 的 $n=4$ 特殊情形 $\to$ 0.5 的單位根分解。

本章沿用五種結果標籤：**【完整證明】、【特殊情形】、【證明略圖】、【直覺】、【接受的黑箱】**。

## 一個更強的目標

我們不直接證 $x^4 + y^4 = z^4$，而是證一個**更強**的命題。這聽起來矛盾 —— 更強的命題不是更難證嗎？但在遞降法裡，更強的命題往往**更容易**證，因為它給遞降提供了更大的迴旋空間。這是數學裡一個反直覺卻常見的策略：適當地加強歸納（或遞降）假設，反而讓論證走得通。

::: {.theorem name="【完整證明】費馬的 $n = 4$ 強化命題"}
方程
$$x^4 + y^4 = z^2$$
沒有正整數解。
:::

先說清楚為什麼這蘊涵了我們要的結論。

::: {.corollary name="【完整證明／特殊情形】FLT 對 $n=4$ 成立"}
$x^4 + y^4 = z^4$ 沒有正整數解。
:::

::: {.proof}
若 $(x, y, z)$ 是 $x^4 + y^4 = z^4$ 的解，把右邊寫成 $(z^2)^2$，則 $(x, y, z^2)$ 就是 $x^4 + y^4 = w^2$ 的解（取 $w = z^2$）。但定理說後者無解，矛盾。
:::

為什麼證 $z^2$ 版本而非 $z^4$ 版本？因為遞降過程中產生的新解，天生長著「平方」的形狀而非「四次方」的形狀（你馬上會看到 $(y/2)^2 = \dots$ 這樣的式子冒出來）。把目標定成 $z^2$，遞降才能首尾相銜、自我複製。**選對要證的命題，是這個證明最關鍵的一手棋。**

## 主證明：無窮遞降

::: {.proof}
**（定理：$x^4 + y^4 = z^2$ 無正整數解）**

假設不然，解存在。由良序原理，在所有正整數解中，取 **$z$ 最小**的一組 $(x, y, z)$。整個證明的目標，是從這組「最小」的解，造出一組 $z$ 更小的解 —— 那將與最小性矛盾。

**第 0 步：化約到本原。** 先證 $\gcd(x, y) = 1$。若質數 $p$ 同時整除 $x, y$，則 $p^4 \mid x^4 + y^4 = z^2$。由第 0.2 章唯一分解，比較 $p$ 的指數得 $p^2\mid z$。那麼 $(x/p,\ y/p,\ z/p^2)$ 也是解，且 $z/p^2 < z$，與最小性矛盾。故 $x, y$ 互質。

進一步，$x, y$ 不同為奇（否則 $x^4 + y^4 \equiv 1 + 1 = 2 \pmod 4$，但 $z^2 \equiv 0, 1 \pmod 4$，矛盾 —— 又是第 0.2 章那塊磚）。不失一般性設 $x$ 奇、$y$ 偶。

**第 1 步：第一次套用畢氏分類。** 把方程讀成
$$(x^2)^2 + (y^2)^2 = z^2,$$
這是一組畢氏三元數 $(x^2,\ y^2,\ z)$！而且它本原：$x, y$ 互質蘊涵 $x^2, y^2$ 互質。$x^2$ 奇、$y^2$ 偶，正是標準型。由第 0.3 章的分類定理，存在互質、一奇一偶的 $m > n \ge 1$，使得
$$x^2 = m^2 - n^2, \qquad y^2 = 2mn, \qquad z = m^2 + n^2.$$

**第 2 步：第二次套用畢氏分類。** 看第一式，重排成
$$x^2 + n^2 = m^2.$$
**又是一組畢氏三元數** $(x,\ n,\ m)$！它也本原：若質數 $r\mid x,n$，由 $x^2+n^2=m^2$ 得 $r\mid m^2$，Euclid 引理推出 $r\mid m$，與 $\gcd(m,n)=1$ 矛盾；其餘兩對同理。由 $x$ 奇可推得 $n$ 偶、$m$ 奇（習題 0.4.1）。再次用分類定理：存在互質、一奇一偶的 $p > q \ge 1$，使得
$$x = p^2 - q^2, \qquad n = 2pq, \qquad m = p^2 + q^2.$$

**第 3 步：擠出一個新的四次方程。** 現在回頭看第 1 步的第二式 $y^2 = 2mn$。代入 $n = 2pq$：
$$y^2 = 2mn = 2m \cdot 2pq = 4pqm \;\Longrightarrow\; \left(\frac{y}{2}\right)^2 = pq\,m = pq(p^2 + q^2).$$
（$y$ 偶，故 $y/2$ 是整數。）

關鍵：**$p$、$q$、$p^2 + q^2$ 兩兩互質。** 前兩個互質是假設；$p$ 與 $p^2 + q^2$ 的公因數必整除 $q^2$，但 $\gcd(p, q) = 1$ 故為 $1$，$q$ 與 $p^2 + q^2$ 同理。於是三個兩兩互質的數，乘積是完全平方 $(y/2)^2$。由第 0.3 章已完整證明的互質因子冪次引理，三者各自都是完全平方：
$$p = a^2, \qquad q = b^2, \qquad p^2 + q^2 = c^2$$
對某些正整數 $a, b, c$。把前兩式代入第三式：
$$\boxed{\,a^4 + b^4 = c^2\,}$$

**這正是原方程的形狀 —— 我們造出了一組新解 $(a, b, c)$。**

**第 4 步：遞降 —— 新解更小。** 只需證 $c < z$。由構造：
$$c \le c^2 = p^2 + q^2 = m \le m^2 < m^2 + n^2 = z.$$
（中間 $m \le m^2$ 因 $m \ge 1$；又 $n \ge 1$ 故 $m^2 < m^2 + n^2$。）於是
$$c < z.$$

我們從「$z$ 最小的解」造出了一組 $z$ 值為 $c < z$ 的新解。這與 $z$ 的最小性矛盾。

故假設錯誤：$x^4 + y^4 = z^2$ 沒有正整數解。
:::

停下來欣賞這個證明的形狀。它不是靠某個神來一筆的恆等式，而是靠**畢氏分類定理連用兩次**，像剝洋蔥一樣一層層往下，最後在第 3 步擠出一個與起點同形的方程。「同形方程 + 嚴格變小的參數」正是無窮遞降的標準簽名 —— 跟第 0.1 章證 $\sqrt 2$ 無理時「$(p, q) \to (k, m)$，$m < q$」是同一個靈魂，只是這裡的刀工繁複了一個數量級。

## 一個立即且精確的幾何翻譯

::: {.corollary name="【完整證明／特殊情形】不存在兩股皆為非零平方數的整數直角三角形"}
不存在正整數 $x,y,z$ 使邊長 $x^2,y^2,z$ 構成直角三角形。
:::

::: {.proof}
若存在，畢氏定理正給出
$$(x^2)^2+(y^2)^2=z^2,$$
也就是主定理已排除的 $x^4+y^4=z^2$。
:::

歷史上費馬留下的是與「直角三角形面積不為平方」相關的遞降論證；它可導向 $n=4$。本章選擇直接證強化方程，並不冒充已在此證完所有同餘數問題的等價敘述。

## 戰報：我們現在站在哪裡

把第 0.1 章的歸約定理請回來對帳：

> FLT 對所有 $n \ge 3$ 成立 $\iff$ FLT 對 $n = 4$ 成立，且對所有奇質數 $p$ 成立。

本章剛剛**結清了 $n = 4$ 這一項**。剩下的，是無窮多個奇質數 $p$。戰線變成這樣：

| 指數 | 狀態 | 經手人 |
|---|---|---|
| $n = 4$（及 $4$ 的倍數） | （已完成） | 費馬 |
| $p = 3$ | 第 1.6 章審核路線（保留明示黑箱） | Euler |
| $p = 5$ | 之後 | Dirichlet、Legendre |
| $p = 7$ | 之後 | Lamé |
| 一類「正則質數」 | 第三部高潮 | Kummer |
| **所有奇質數，一網打盡** | 第七部終點 | Wiles |

注意一件意味深長的事：本章的方法 —— 無窮遞降 + 畢氏分類 —— 把 $n = 4$ 收拾得乾淨俐落，**但它無法原樣推廣到奇質數**。對 $x^3 + y^3 = z^3$，沒有可直接代換的「三次版畢氏分類」；古典路線會進入 $\mathbb{Z}[\sqrt{-3}]$ 或 $\mathbb{Z}[\zeta_3]$ 一類新數系。第 1.6 章會審核這條路線，並明說唯一分解在哪個環失效、哪個修補仍作黑箱。

換句話說：**本章這套「畢氏分類連用兩次」的機器不能直接推廣到奇質數。** $p=3,5$ 等指數仍有別的初等或代數數論論證，但要統一處理所有質數，確實必須走進更大的結構。這是路線分岔，不是「所有初等方法都已被證明不可能」的研究性斷言。

## 本章地圖與下一章預告

- **強化目標**：證 $x^4 + y^4 = z^2$（比 $z^4$ 強），讓遞降能自我複製。
- **遞降引擎**：畢氏分類連用兩次 → 擠出 $a^4 + b^4 = c^2$ 與 $c < z$ → 矛盾。
- **幾何特殊情形**：主定理立即排除「兩股皆為非零平方數」的整數直角三角形；不把平方面積定理冒充成已證等價。
- **方法邊界**：畢氏分類連用兩次的機器不能直接處理奇質數；這不是對所有初等方法的不可能性宣告。

第零部還有最後一章。第 0.5 章會補上複數、單位根與多項式因式分解，讓「離開 $\mathbb Z$」成為可以精確計算的動作；完成後才進入第一部線性代數。

**檢查點 0.4**　請在紙上畫出遞降的依賴箭頭：
$$x^4+y^4=z^2
\to(x^2,y^2,z)
\to(m,n)
\to(p,q)
\to(a,b,c),\qquad c<z.$$
每一箭旁各寫「畢氏分類」「互質乘積為平方」或「大小比較」。若有一箭說不出理由，回到主證明相應步驟。

## 習題

**0.4.1**　補上主證明第 2 步的奇偶推理：在本原畢氏三元數 $(x, n, m)$ 中，已知 $x$ 為奇，證明 $n$ 為偶、$m$ 為奇。（提示：用第 0.3 章的奇偶引理，並注意標準型裡偶的那一項。）

**0.4.2 ★**　補完主證明第 2 步的本原性：由 $\gcd(m,n)=1$ 與 $x^2+n^2=m^2$，證明 $x,n,m$ 兩兩互質。

**0.4.3 ★**　在第 3 步逐對證明 $p,q,p^2+q^2$ 互質，並用質因數指數完整證明：三個兩兩互質正整數之積若為平方，則三者各為平方。

**0.4.4**　證明 $x^4 - y^4 = z^2$ 也沒有正整數解。（提示：類似地套用畢氏分類做遞降。注意符號變化會讓奇偶分析略有不同。）

**0.4.5 ★**　證明 $x^4 + y^4 = z^2$ 無解蘊涵：方程 $x^2 = y^4 + 1$ 沒有滿足 $x, y \ge 1$ 的整數解。（即：除了平凡情形，連續整數 $y^4$ 與 $x^2$ 不能只差 $1$ 太多次 —— 把它轉成本章的形狀。）

**0.4.6（挑戰）**　Fermat 還用遞降證過：$x^4 + y^4 = z^2$ 無解這件事，等價於「$1$ 不是同餘數」（不存在面積為 $1$ 的有理邊直角三角形）。試著陳述並證明這個等價性的一個方向。（這把本章與第 0.3 章的同餘數問題正式接通。）

**0.4.7（挑戰，前瞻）**　查閱「同餘數問題」，用一兩句話說明：判斷一個整數 $N$ 是否為同餘數的現代判準（Tunnell 定理）為什麼被認為「尚未完全證明」。（提示：它的某個方向依賴一個未解決的猜想。把這個猜想的名字記下來 —— 第五部會與它重逢。）
