## 開場：把刀磨利之後

到目前為止，你已經備齊了攻打 FLT 第一個情形所需的全部武器：

- 第 0.1 章的**無窮遞降法** —— 假設最小反例存在，再從它造出更小的反例，逼出矛盾。
- 第 0.2 章的**唯一分解**與本原解化約 —— 「不失一般性，設互質」。
- 第 0.3 章的**畢氏三元數分類** —— $(m^2 - n^2,\ 2mn,\ m^2 + n^2)$。

這一章把三者組裝起來，給出本書第一個**完整證明**的 FLT 情形：$x^4 + y^4 = z^4$ 無正整數解。這是費馬本人唯一留下完整證明的 FLT 情形（透過他在另一處頁邊寫下的遞降論證），也是人類在這個問題上三百五十年長征的第一步。

走完這一章，你不再只是「聽說 FLT 很難」的旁觀者 —— 你會親手關上 $n = 4$ 這扇門，而且關得嚴絲合縫。

## 一個更強的目標

我們不直接證 $x^4 + y^4 = z^4$，而是證一個**更強**的命題。這聽起來矛盾 —— 更強的命題不是更難證嗎？但在遞降法裡，更強的命題往往**更容易**證，因為它給遞降提供了更大的迴旋空間。這是數學裡一個反直覺卻常見的策略：適當地加強歸納（或遞降）假設，反而讓論證走得通。

::: {.theorem name="費馬，$n = 4$ 的強化版"}
方程
$$x^4 + y^4 = z^2$$
沒有正整數解。
:::

先說清楚為什麼這蘊涵了我們要的結論。

::: {.corollary}
$x^4 + y^4 = z^4$ 沒有正整數解。
:::

::: {.proof}
若 $(x, y, z)$ 是 $x^4 + y^4 = z^4$ 的解，把右邊寫成 $(z^2)^2$，則 $(x, y, z^2)$ 就是 $x^4 + y^4 = w^2$ 的解（取 $w = z^2$）。但定理說後者無解，矛盾。
:::

為什麼證 $z^2$ 版本而非 $z^4$ 版本？因為遞降過程中產生的新解，天生長著「平方」的形狀而非「四次方」的形狀（你馬上會看到 $(y/2)^2 = \dots$ 這樣的式子冒出來）。把目標定成 $z^2$，遞降才能首尾相銜、自我複製。**選對要證的命題，是這個證明最關鍵的一手棋。**

## 主證明：無窮遞降

::: {.proof}
**（定理：$x^4 + y^4 = z^2$ 無正整數解）**

假設不然，解存在。由良序原理，在所有正整數解中，取 **$z$ 最小**的一組 $(x, y, z)$。整個證明的目標，是從這組「最小」的解，造出一組 $z$ 更小的解 —— 那將與最小性矛盾。

**第 0 步：化約到本原。** 先證 $\gcd(x, y) = 1$。若質數 $p$ 同時整除 $x, y$，則 $p^4 \mid x^4 + y^4 = z^2$，故 $p^2 \mid z$。那麼 $(x/p,\ y/p,\ z/p^2)$ 也是解，且 $z/p^2 < z$，與最小性矛盾。故 $x, y$ 互質。

進一步，$x, y$ 不同為奇（否則 $x^4 + y^4 \equiv 1 + 1 = 2 \pmod 4$，但 $z^2 \equiv 0, 1 \pmod 4$，矛盾 —— 又是第 0.2 章那塊磚）。不失一般性設 $x$ 奇、$y$ 偶。

**第 1 步：第一次套用畢氏分類。** 把方程讀成
$$(x^2)^2 + (y^2)^2 = z^2,$$
這是一組畢氏三元數 $(x^2,\ y^2,\ z)$！而且它本原：$x, y$ 互質蘊涵 $x^2, y^2$ 互質。$x^2$ 奇、$y^2$ 偶，正是標準型。由第 0.3 章的分類定理，存在互質、一奇一偶的 $m > n \ge 1$，使得
$$x^2 = m^2 - n^2, \qquad y^2 = 2mn, \qquad z = m^2 + n^2.$$

**第 2 步：第二次套用畢氏分類。** 看第一式，重排成
$$x^2 + n^2 = m^2.$$
**又是一組畢氏三元數** $(x,\ n,\ m)$！它也本原（因 $\gcd(m, n) = 1$）。由 $x$ 奇可推得 $n$ 偶、$m$ 奇（習題 0.4.1）。再次用分類定理：存在互質、一奇一偶的 $p > q \ge 1$，使得
$$x = p^2 - q^2, \qquad n = 2pq, \qquad m = p^2 + q^2.$$

**第 3 步：擠出一個新的四次方程。** 現在回頭看第 1 步的第二式 $y^2 = 2mn$。代入 $n = 2pq$：
$$y^2 = 2mn = 2m \cdot 2pq = 4pqm \;\Longrightarrow\; \left(\frac{y}{2}\right)^2 = pq\,m = pq(p^2 + q^2).$$
（$y$ 偶，故 $y/2$ 是整數。）

關鍵：**$p$、$q$、$p^2 + q^2$ 兩兩互質。** 前兩個互質是假設；$p$ 與 $p^2 + q^2$ 的公因數必整除 $q^2$，但 $\gcd(p, q) = 1$ 故為 $1$，$q$ 與 $p^2 + q^2$ 同理。於是三個兩兩互質的數，乘積是完全平方 $(y/2)^2$。由第 0.3 章習題 0.3.3 的引理（互質因子各自為平方），三者各自都是完全平方：
$$p = a^2, \qquad q = b^2, \qquad p^2 + q^2 = c^2$$
對某些正整數 $a, b, c$。把前兩式代入第三式：
$$\boxed{\,a^4 + b^4 = c^2\,}$$

**這正是原方程的形狀 —— 我們造出了一組新解 $(a, b, c)$。**

**第 4 步：遞降 —— 新解更小。** 只需證 $c < z$。由構造：
$$c \le c^2 = p^2 + q^2 = m \le m^2 < m^2 + n^2 = z.$$
（中間 $m \le m^2$ 因 $m \ge 1$；又 $n \ge 1$ 故 $m^2 < m^2 + n^2$。）於是
$$c < z.$$

我們從「$z$ 最小的解」造出了一組 $z$ 值為 $c < z$ 的新解。這與 $z$ 的最小性矛盾。

故假設錯誤：$x^4 + y^4 = z^2$ 沒有正整數解。
:::

停下來欣賞這個證明的形狀。它不是靠某個神來一筆的恆等式，而是靠**畢氏分類定理連用兩次**，像剝洋蔥一樣一層層往下，最後在第 3 步擠出一個與起點同構的方程。「同構的方程 + 嚴格變小的參數」正是無窮遞降的標準簽名 —— 跟第 0.1 章證 $\sqrt 2$ 無理時「$(p, q) \to (k, m)$，$m < q$」是同一個靈魂，只是這裡的刀工繁複了一個數量級。

## 它順手解決的另一個問題

回收第 0.3 章章末埋的伏筆。

::: {.corollary name="無平方面積的整數直角三角形"}
不存在三邊皆整數、面積為完全平方數的直角三角形。
:::

::: {.proof}
設直角三角形三邊 $(a, b, c)$ 為整數，面積 $\tfrac12 ab$ 為平方數。可化約到本原情形，於是 $(a, b, c)$ 是本原畢氏三元數，由分類定理 $a = m^2 - n^2$、$b = 2mn$、$c = m^2 + n^2$。面積
$$\tfrac12 ab = mn(m^2 - n^2) = mn(m - n)(m + n).$$
這四個因子 $m,\ n,\ m - n,\ m + n$ 兩兩互質（習題 0.4.2）。它們的乘積若是平方數，則四者各自皆為平方數。設 $m = s^2$、$n = t^2$、$m - n = u^2$、$m + n = v^2$。則
$$u^2 + t^2 = m - n + n = \dots$$
更利落地：$v^2 - u^2 = (m+n) - (m-n) = 2n = 2t^2$，且 $v^2 + u^2 = 2m = 2s^2$。由此可導出一組更小的 $x^4 + y^4 = z^2$ 式的解（細節見習題 0.4.3），再次遞降至矛盾。
:::

於是「面積為平方的整數直角三角形」與「$x^4 + y^4 = z^2$」是同一個不可能性的兩種面貌 —— 費馬當年正是先證前者，順勢拿下後者。

## 戰報：我們現在站在哪裡

把第 0.1 章的歸約定理請回來對帳：

> FLT 對所有 $n \ge 3$ 成立 $\iff$ FLT 對 $n = 4$ 成立，且對所有奇質數 $p$ 成立。

本章剛剛**結清了 $n = 4$ 這一項**。剩下的，是無窮多個奇質數 $p$。戰線變成這樣：

| 指數 | 狀態 | 經手人 |
|---|---|---|
| $n = 4$（及 $4$ 的倍數） | （已完成） | 費馬 |
| $p = 3$ | 待第 1.6 章 | Euler |
| $p = 5$ | 之後 | Dirichlet、Legendre |
| $p = 7$ | 之後 | Lamé |
| 一類「正則質數」 | 第三部高潮 | Kummer |
| **所有奇質數，一網打盡** | 第七部終點 | Wiles |

注意一件意味深長的事：本章的方法 —— 無窮遞降 + 畢氏分類 —— 把 $n = 4$ 收拾得乾淨俐落，**但它無法推廣到奇質數**。對 $x^3 + y^3 = z^3$，沒有「三次版的畢氏分類」可用；硬要走下去，你會被迫進入形如 $\mathbb{Z}[\sqrt{-3}]$ 或 $\mathbb{Z}[\zeta_3]$ 的新數系（第 1.6 章 Euler 的證明就踩在這裡），而一旦進入那些數系，第 0.2 章警告過的唯一分解失效問題就會浮現。

換句話說：**$n = 4$ 是初等方法的天花板。** 從 $p = 3$ 開始，數論不得不離開 $\mathbb{Z}$ 的舒適區，去更大的數系裡冒險 —— 那趟冒險就是第一部到第三部的全部內容。本章既是第零部的頂點，也是初等時代的終點。

## 本章地圖與下一章預告

- **強化目標**：證 $x^4 + y^4 = z^2$（比 $z^4$ 強），讓遞降能自我複製。
- **遞降引擎**：畢氏分類連用兩次 → 擠出 $a^4 + b^4 = c^2$ 與 $c < z$ → 矛盾。
- **同一不可能性的兩面**：四次方程 $\leftrightarrow$ 無平方面積的整數直角三角形。
- **天花板**：初等方法到 $n = 4$ 為止；奇質數迫使我們離開 $\mathbb{Z}$。

第零部到此完成。你已經掌握證明的語言、整數的結構、有理點的幾何，並親手證明了 FLT 的第一個情形。

下一部《基礎語言》進入大學數學的正殿。第 1.1 章從**線性代數**開始 —— 向量空間與線性映射。你或許會問：解整數方程，干向量空間什麼事？答案要到很後面才完全揭曉，但這裡先給個指北針：FLT 的現代證明，最終是把「橢圓曲線」和「模形式」這兩個天差地遠的對象，各自翻譯成**矩陣群裡的表示**（$\mathrm{GL}_2$ 的 Galois 表示），再證明這兩個表示其實是同一個。而「表示」這個詞的意思，就是「把抽象對象實現為線性映射」。沒有線性代數，連 Wiles 證明的主角都無法登場。我們從最基礎的地方，開始搭建那座舞台。

## 習題

**0.4.1**　補上主證明第 2 步的奇偶推理：在本原畢氏三元數 $(x, n, m)$ 中，已知 $x$ 為奇，證明 $n$ 為偶、$m$ 為奇。（提示：用第 0.3 章的奇偶引理，並注意標準型裡偶的那一項。）

**0.4.2 ★**　證明推論證明裡用到的互質性：若 $\gcd(m, n) = 1$ 且 $m, n$ 一奇一偶，則 $m,\ n,\ m - n,\ m + n$ 兩兩互質。

**0.4.3 ★**　完成「無平方面積直角三角形」推論的遞降細節：從 $v^2 - u^2 = 2t^2$ 與 $v^2 + u^2 = 2s^2$ 出發，導出一組正整數解滿足某個 $X^4 + Y^4 = Z^2$ 型方程，且其規模嚴格小於原三角形。（這題把兩個推論真正縫在一起。）

**0.4.4**　證明 $x^4 - y^4 = z^2$ 也沒有正整數解。（提示：類似地套用畢氏分類做遞降。注意符號變化會讓奇偶分析略有不同。）

**0.4.5 ★**　證明 $x^4 + y^4 = z^2$ 無解蘊涵：方程 $x^2 = y^4 + 1$ 沒有滿足 $x, y \ge 1$ 的整數解。（即：除了平凡情形，連續整數 $y^4$ 與 $x^2$ 不能只差 $1$ 太多次 —— 把它轉成本章的形狀。）

**0.4.6（挑戰）**　Fermat 還用遞降證過：$x^4 + y^4 = z^2$ 無解這件事，等價於「$1$ 不是同餘數」（不存在面積為 $1$ 的有理邊直角三角形）。試著陳述並證明這個等價性的一個方向。（這把本章與第 0.3 章的同餘數問題正式接通。）

**0.4.7（挑戰，前瞻）**　查閱「同餘數問題」，用一兩句話說明：判斷一個整數 $N$ 是否為同餘數的現代判準（Tunnell 定理）為什麼被認為「尚未完全證明」。（提示：它的某個方向依賴一個未解決的猜想。把這個猜想的名字記下來 —— 第五部會與它重逢。）
