## 開場：兌現全書最大的承諾

從第 1.1 章起，本書反覆預告一個對象：$\rho: G_{\mathbb{Q}} \to \mathrm{GL}_2$，從絕對 Galois 群到二階矩陣群的表示。第 1.1 章說它是「FLT 證明的核心對象」、第 1.2 章說 $\mathrm{tr}\,\rho(\mathrm{Frob}_p) = a_p$、第 2.3 章說 $\det\rho = \chi$（分圓特徵）、第 5.1 章說橢圓曲線撓點給出它。現在，第六部終於要嚴格建立這個對象，兌現全書最大的承諾。

為什麼需要 Galois 表示？因為它是讓兩位主角**用同一種語言說話**的關鍵。第五部結束時，橢圓曲線與模形式各自帶著指紋 $\{a_p\}$，谷山–志村猜想說它們相等。但「指紋相等」是一個關於無窮序列的陳述，難以直接證明。Galois 表示把這個陳述提升：橢圓曲線給出一個表示 $\rho_E$，模形式給出另一個 $\rho_f$，而「指紋相等」變成「兩個表示同構」$\rho_E \cong \rho_f$。表示是比序列更剛硬、更結構化的對象 —— 證明兩個表示相等，可以用群論、上同調、變形理論的全套重武器，這正是 Wiles 證明的戰場。

本章建立 Galois 表示的基本理論：定義、$\ell$-進表示、分歧、Frobenius。這是第六、七部的通用語言。

## 絕對 Galois 群，再相見

回憶第 2.2 章：絕對 Galois 群 $G_{\mathbb{Q}} = \mathrm{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$ 是「所有代數數的對稱性」的總和。它龐大、無窮、非交換，至今無人完全理解。研究它的策略（第 2.2 章末預告）是看它如何**表示**成矩陣群。

::: {.definition}
**Galois 表示**是一個連續同態
$$\rho: G_{\mathbb{Q}} \longrightarrow \mathrm{GL}_n(A),$$
其中 $A$ 是某個拓撲環（如 $\mathbb{C}$、有限體 $\mathbb{F}_\ell$、$\ell$-進整數 $\mathbb{Z}_\ell$、$\ell$-進數 $\mathbb{Q}_\ell$）。$n$ 是表示的**維度**。
:::

「表示」這個詞，正是第 1.1 章定義的（群同態到 $\mathrm{GL}_n$，第 2.5 章認出它是函子）。Galois 表示就是把 $G_{\mathbb{Q}}$ 這個特定的群表示出來。第 1.1 章費力鋪墊的「表示 = 保持乘法的矩陣化」，在這裡找到它最重要的應用對象。

::: {.example name="維度 1：分圓特徵"}
最簡單的非平凡 Galois 表示是一維的（$\mathrm{GL}_1$ 即純量）。最重要的一個是**分圓特徵** $\chi$（第 2.3 章）：$G_{\mathbb{Q}}$ 作用在所有單位根上，$\sigma(\zeta_N) = \zeta_N^{\chi(\sigma)}$，給出
$$\chi: G_{\mathbb{Q}} \to \mathbb{Z}_\ell^\times = \mathrm{GL}_1(\mathbb{Z}_\ell).$$
它滿足 $\chi(\mathrm{Frob}_p) = p$（不分歧的 $p$）。第 2.3 章說它是「行列式的源頭」—— 下面會看到，橢圓曲線二維表示的行列式恰好是 $\chi$。一維 Galois 表示由 Kronecker–Weber 完全分類（第 2.3 章），它們對應分圓體。難的、有趣的、與 FLT 相關的，是**二維**表示。
:::

## 橢圓曲線的 Galois 表示

現在嚴格建立 $\rho_E$ —— 第 5.1 章撓點上的作用。

回憶第 5.1 章：橢圓曲線的 $\ell$-撓點 $E[\ell] \cong \mathbb{F}_\ell^2$ 是二維 $\mathbb{F}_\ell$-向量空間。撓點是代數數（它們的座標滿足多項式方程），所以 $G_{\mathbb{Q}}$ 作用在它們上 —— 而這個作用保持加法（Galois 自同構尊重橢圓曲線的群律，因加法公式係數在 $\mathbb{Q}$ 裡，被 $G_{\mathbb{Q}}$ 固定，第 5.1 章習題 5.1.7）。保持加法 = 線性，於是得到一個二維表示：

::: {.definition name="橢圓曲線的 mod $\ell$ 表示"}
$$\bar\rho_{E,\ell}: G_{\mathbb{Q}} \longrightarrow \mathrm{GL}_2(\mathbb{F}_\ell),$$
由 $G_{\mathbb{Q}}$ 在 $E[\ell] \cong \mathbb{F}_\ell^2$ 上的線性作用給出。
:::

把所有 $E[\ell^n]$ 整合（取逆極限），得到更精細的 **$\ell$-進表示**：

::: {.definition name="Tate module 與 $\ell$-進表示"}
**Tate module** $T_\ell(E) = \varprojlim E[\ell^n] \cong \mathbb{Z}_\ell^2$，給出
$$\rho_{E,\ell}: G_{\mathbb{Q}} \longrightarrow \mathrm{GL}_2(\mathbb{Z}_\ell).$$
:::

mod $\ell$ 表示 $\bar\rho$ 是 $\ell$-進表示 $\rho$ 的「約化」（取 mod $\ell$）。兩者的關係 —— 從 $\bar\rho$「變形」回 $\rho$ —— 正是第七部變形理論的核心。Wiles 在這兩個層次之間工作：$\bar\rho$（剩餘表示，有限、可控）與 $\rho$（$\ell$-進，完整、精細）。

## Frobenius 與指紋

Galois 表示的算術資訊，集中在每個質數的 **Frobenius 元素**上（第 3.5 章預告）。

::: {.definition name="不分歧與 Frobenius"}
表示 $\rho$ 在質數 $p$ **不分歧**（unramified），若 $p$ 處的慣性群在 $\rho$ 下平凡。此時有良定義的 Frobenius 共軛類 $\mathrm{Frob}_p$，其像 $\rho(\mathrm{Frob}_p)$ 是一個確定的矩陣（至共軛）。
:::

對橢圓曲線表示 $\rho_{E,\ell}$，關鍵定理把它與第五部的指紋連起來：

::: {.theorem name="橢圓曲線表示的 Frobenius"}
$E$ 在 $p$ 好約化且 $p \ne \ell$ 時，$\rho_{E,\ell}$ 在 $p$ 不分歧，且 $\rho_{E,\ell}(\mathrm{Frob}_p)$ 的特徵多項式是
$$x^2 - a_p\, x + p,$$
即 $\mathrm{tr}\,\rho_{E,\ell}(\mathrm{Frob}_p) = a_p$，$\det\rho_{E,\ell}(\mathrm{Frob}_p) = p$。
:::

::: {.remark name="所有預告在此兌現"}
這條定理把第 1.2 章以來的所有預告一次性兌現：
- $\mathrm{tr}\,\rho(\mathrm{Frob}_p) = a_p$（第 1.2 章）—— 跡是橢圓曲線指紋。
- $\det\rho(\mathrm{Frob}_p) = p$，事實上 $\det\rho_{E,\ell} = \chi$（分圓特徵，第 2.3 章）—— 行列式是分圓特徵，因 $\chi(\mathrm{Frob}_p) = p$。
- 特徵多項式 $x^2 - a_px + p$ 正是第 1.2 章習題 1.2.6、第 5.3 章 Hasse 界用的那個。

數值驗證（導體 $11$ 曲線，$\ell = 5$）：$\rho(\mathrm{Frob}_p)$ 的跡 $\equiv a_p \pmod 5$、行列式 $\equiv p \pmod 5$ —— 例如 $p = 13$，$a_{13} = 4$，跡 $\equiv 4$、行列式 $\equiv 3 = 13 \bmod 5$。橢圓曲線的指紋 $\{a_p\}$，現在被編碼成一個 Galois 表示在每個 Frobenius 處的跡。**指紋升級成了表示。**

這個升級是決定性的。一個序列 $\{a_p\}$ 只是一串數字；而一個 Galois 表示 $\rho$ 是一個有豐富結構的對象 —— 它有維度、有行列式、有在每個質數的局部行為、可以約化、可以變形。把「指紋相等」提升為「表示同構」，等於把一個關於數列的問題，提升為一個關於結構化對象的問題 —— 後者才有足夠的把手讓 Wiles 的重武器施力。
:::

## 模形式的 Galois 表示

谷山–志村的另一半：模形式也給出 Galois 表示。這是 Deligne 的深刻定理（本書取用，不證）。

::: {.theorem name="Deligne，模形式的 Galois 表示"}
設 $f$ 是權重 $2$、級 $N$ 的特徵形式，特徵值 $\{a_p(f)\}$。則存在一個二維 Galois 表示
$$\rho_{f,\ell}: G_{\mathbb{Q}} \to \mathrm{GL}_2(\overline{\mathbb{Q}_\ell}),$$
在 $p \nmid N\ell$ 不分歧，且 $\mathrm{tr}\,\rho_{f,\ell}(\mathrm{Frob}_p) = a_p(f)$，$\det\rho_{f,\ell}(\mathrm{Frob}_p) = p$。
:::

於是模形式的指紋 $\{a_p(f)\}$，也被編碼成一個 Galois 表示的 Frobenius 跡。兩位主角現在說同一種語言了。

::: {.remark name="谷山–志村的表示版"}
把兩個定理並排：
$$\mathrm{tr}\,\rho_{E,\ell}(\mathrm{Frob}_p) = a_p(E), \qquad \mathrm{tr}\,\rho_{f,\ell}(\mathrm{Frob}_p) = a_p(f).$$
谷山–志村猜想 $a_p(E) = a_p(f)$，現在等價於兩個 Galois 表示有相同的 Frobenius 跡。而一個基本定理（Chebotarev 密度定理 + Brauer–Nesbitt）說：**半單表示由它的 Frobenius 跡完全決定**。於是「跡相等」等價於「表示同構」：
$$a_p(E) = a_p(f)\ \forall p \quad\Longleftrightarrow\quad \rho_{E,\ell} \cong \rho_{f,\ell}.$$

這是谷山–志村猜想的**表示論重述**，也是 Wiles 真正要證的形式：每條橢圓曲線的 Galois 表示 $\rho_{E,\ell}$，都同構於某個模形式的 Galois 表示 $\rho_{f,\ell}$。換句話說，**每個來自橢圓曲線的二維 Galois 表示都是「模的」**（來自模形式）。第七部 Wiles 的全部工作，是證明這個「表示的模性」。指紋 → 表示 → 同構，這條提升鏈，是現代證明能啟動的根本前提。
:::

## 為什麼這是正確的語言

::: {.remark name="Galois 表示的三重優勢"}
為什麼把問題翻譯成 Galois 表示是對的策略？三個原因，貫穿第六、七部：

**其一，剛性。** 表示比序列剛硬。半單表示由 Frobenius 跡決定（上面），所以「比對無窮多個 $a_p$」化約為「比對兩個表示」—— 一個有限的、結構化的比較。

**其二，可變形。** mod $\ell$ 表示 $\bar\rho$ 可以「變形」回 $\ell$-進表示 $\rho$（第七部）。Wiles 的策略是：先在 mod $\ell$（有限、可控）層次證明模性，再透過控制所有變形，提升到 $\ell$-進層次。這個「變形」操作只在表示的語言裡有意義 —— 序列無法變形。

**其三，可局部化。** 表示可以限制到每個質數的局部 Galois 群 $G_{\mathbb{Q}_p}$（第 3.5 章），逐個質數分析其行為（分歧、約化類型）。Frey 曲線的半穩定性、Ribet 的 level lowering、Wiles 的局部條件，全都是局部表示的精細控制。$p$-進數（第 3.5 章）在這裡成為分析局部表示的舞台。

Galois 表示把 FLT 從「數列的比對」變成「結構化對象的操控」—— 而數學家有一整套操控結構化對象的工具（同調、變形、局部–整體）。這就是為什麼現代證明能成功，而古典的數列方法（Kummer）不能。語言的選擇，決定了能用的工具。
:::

## 本章地圖與下一章預告

- **Galois 表示**：$\rho: G_{\mathbb{Q}} \to \mathrm{GL}_n(A)$；研究 $G_{\mathbb{Q}}$ 的途徑。
- **分圓特徵**：一維表示 $\chi$，$\chi(\mathrm{Frob}_p) = p$；橢圓曲線表示的行列式。
- **橢圓曲線表示**：$\rho_{E,\ell}$ 由撓點作用；$\mathrm{tr}\,\rho(\mathrm{Frob}_p) = a_p$、$\det = \chi$。
- **模形式表示**：Deligne 的 $\rho_{f,\ell}$；$\mathrm{tr} = a_p(f)$。
- **谷山–志村重述**：$\rho_{E,\ell} \cong \rho_{f,\ell}$；指紋 → 表示 → 同構。

下一章《橢圓曲線的表示》深入 $\rho_{E,\ell}$ 的細節：它的像有多大（Serre 的開像定理）、mod $\ell$ 表示 $\bar\rho_{E,\ell}$ 何時不可約、它在壞約化質數的局部行為。這些細節決定了 Frey 曲線表示的特殊性質 —— 而那些性質，正是 Ribet 定理（第 6.6 章）能對它動刀的前提。我們開始把 Galois 表示的通用理論，特化到 FLT 所需的具體情形，一步步逼近 Frey 曲線的絕境。

## 習題

**6.1.1**　驗證分圓特徵 $\chi$ 是同態：$\chi(\sigma\tau) = \chi(\sigma)\chi(\tau)$。（提示：$\sigma\tau(\zeta) = \sigma(\zeta^{\chi(\tau)}) = \zeta^{\chi(\sigma)\chi(\tau)}$。）

**6.1.2 ★**　$E[\ell] \cong \mathbb{F}_\ell^2$ 上 $G_{\mathbb{Q}}$ 的作用是線性的。詳細說明為什麼（Galois 自同構保持橢圓曲線加法，故保持 $\mathbb{F}_\ell$-向量空間結構）。

**6.1.3**　$\det\rho_{E,\ell} = \chi$（分圓特徵）。用 $\det\rho(\mathrm{Frob}_p) = p = \chi(\mathrm{Frob}_p)$ 驗證這個等式在 Frobenius 上成立。（這把第 2.3 章的「行列式 = 分圓特徵」嚴格化。）

**6.1.4 ★**　導體 $11$ 曲線，$\ell = 5$。計算 $\rho_{E,5}(\mathrm{Frob}_p)$ 的跡與行列式 mod $5$，對 $p = 3, 7, 13$（用 $a_3 = -1, a_7 = -2, a_{13} = 4$）。驗證跡 $\equiv a_p$、行列式 $\equiv p \pmod 5$。

**6.1.5**　Brauer–Nesbitt + Chebotarev 說「半單表示由 Frobenius 跡決定」。用一句話說明這為什麼讓「$a_p(E) = a_p(f)\ \forall p$」等價於「$\rho_E \cong \rho_f$」。

**6.1.6（前瞻）**　Wiles 在 mod $\ell$ 表示 $\bar\rho$ 與 $\ell$-進表示 $\rho$ 之間工作。用一句話說明為什麼「先在有限的 mod $\ell$ 層次證模性，再變形提升」是合理的策略（提示：$\mathrm{GL}_2(\mathbb{F}_\ell)$ 有限，可控；第 1.1 章 $|\mathrm{GL}_2(\mathbb{F}_p)|$ 的計算）。
