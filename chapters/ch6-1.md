## 開場：兌現全書最大的承諾

從第 1.1 章起，本書反覆預告一個對象：$\rho: G_{\mathbb{Q}} \to \mathrm{GL}_2$，從絕對 Galois 群到二階矩陣群的表示。第 1.1 章說它是「FLT 證明的核心對象」、第 1.2 章說 $\mathrm{tr}\,\rho(\mathrm{Frob}_p) = a_p$、第 2.3 章說 $\det\rho = \chi$（分圓特徵）、第 5.1 章說橢圓曲線撓點給出它。現在，第六部終於要嚴格建立這個對象，兌現全書最大的承諾。

為什麼需要 Galois 表示？因為它是讓兩位主角**用同一種語言說話**的關鍵。第五部結束時，橢圓曲線與模形式各自帶著指紋 $\{a_p\}$，谷山–志村猜想說它們相等。但「指紋相等」是一個關於無窮序列的陳述，難以直接證明。Galois 表示把這個陳述提升：橢圓曲線給出一個表示 $\rho_E$，模形式給出另一個 $\rho_f$，而「指紋相等」變成「兩個表示同構」$\rho_E \cong \rho_f$。表示是比序列更剛硬、更結構化的對象 —— 證明兩個表示相等，可以用群論、上同調、變形理論的全套重武器，這正是 Wiles 證明的戰場。

本章建立 Galois 表示的基本理論：定義、$\ell$-進表示、分歧、Frobenius。這是第六、七部的通用語言。

### 標籤圖例：什麼是算的、證的、化約的、接受的

整部書我們會用四種標籤，誠實標出每一環的性質。這四種標籤是本書的「誠實契約」：

- **〔算〕**：本書**完整計算**給你看的（例如 Frey 曲線的判別式 $\Delta = 16(abc)^{2p}$）。你可以自己驗算。
- **〔證〕**：本書**給出證明骨架**的（例如「級 $2$ 沒有尖形式」$\dim S_2(\Gamma_0(2)) = 0$）。主線論證完整，細節分層。
- **〔化約〕**：本書**把一個問題翻譯成另一個問題**，證明兩者等價或一方蘊涵另一方（例如「指紋相等」化約為「表示同構」）。化約本身是本書證明的。
- **〔接受〕**：**研究級定理**，本書陳述並解釋其意義，但**不證明**（例如 Deligne 的模形式表示、Ribet 的 level lowering、Wiles 的模性定理、Mazur 的有理質數同源定理）。這些是二十世紀數論的深水區，本書把它們當作黑盒子，但會**精確交代它們的假設**，讓你知道黑盒子吃什麼、吐什麼。

這四種標籤會出現在各章的定理與關鍵箭頭旁。看到〔接受〕時，你不必慚愧 —— 連專業數學家也是把這些當黑盒子用。本書的承諾是：**化約鏈本身是完整的、可逐環檢驗的**；黑盒子只在鏈的兩端出現，且每個黑盒子的輸入輸出都被精確標明。

### 記號約定：$p$、$q$、$\lambda$

第六部會嚴格區分三個容易混淆的質數，這是讀懂後面的關鍵：

- **$p$**：FLT 的指數，也是我們看的**剩餘表示** $\bar\rho_{E,p}$ 的係數特徵（residual characteristic）。在 FLT 證明裡 $p \ge 5$。
- **$q$**：一個**壞質數**（bad prime）或**降級質數**（level-lowering prime）—— 即 $q \mid abc$ 的質數，或我們想從模形式級中移除的質數。$q$ 與 $p$ 是**不同**的對象：$q$ 是曲線的壞約化質數，$p$ 是表示的係數特徵。
- **$\lambda$**：模形式 $f$ 的**係數體**（Hecke 特徵值所在的數體）中的一個質理想，用來取 $\lambda$-進表示 $\rho_{f,\lambda}$。當 $f$ 的係數是整數時，$\lambda$ 就是一個質數 $\ell$。

一句話記住：**$p$ 是「看表示的眼睛」，$q$ 是「曲線壞掉的地方」，$\lambda$ 是「模形式係數的質點」**。三者通常不同，混用會造成嚴重的邏輯錯誤。本書從這裡開始嚴格遵守這個約定。

## 絕對 Galois 群，再相見

回憶第 2.2 章：絕對 Galois 群 $G_{\mathbb{Q}} = \mathrm{Gal}(\overline{\mathbb{Q}}/\mathbb{Q})$ 是「所有代數數的對稱性」的總和。它龐大、無窮、非交換，至今無人完全理解。研究它的策略（第 2.2 章末預告）是看它如何**表示**成矩陣群。

::: {.definition}
**Galois 表示**是一個連續同態
$$\rho: G_{\mathbb{Q}} \longrightarrow \mathrm{GL}_n(A),$$
其中 $A$ 是某個拓撲環（如 $\mathbb{C}$、有限體 $\mathbb{F}_\ell$、$\ell$-進整數 $\mathbb{Z}_\ell$、$\ell$-進數 $\mathbb{Q}_\ell$）。$n$ 是表示的**維度**。
:::

「表示」這個詞，正是第 1.1 章定義的（群同態到 $\mathrm{GL}_n$，第 2.5 章認出它是函子）。Galois 表示就是把 $G_{\mathbb{Q}}$ 這個特定的群表示出來。第 1.1 章費力鋪墊的「表示 = 保持乘法的矩陣化」，在這裡找到它最重要的應用對象。

::: {.example name="維度 1：分圓特徵"}
最簡單的非平凡 Galois 表示是一維的（$\mathrm{GL}_1$ 即純量）。最重要的一個是**分圓特徵** $\chi$（第 2.3 章）：$G_{\mathbb{Q}}$ 作用在所有單位根上，$\sigma(\zeta_N) = \zeta_N^{\chi(\sigma)}$，給出
$$\chi: G_{\mathbb{Q}} \to \mathbb{Z}_\ell^\times = \mathrm{GL}_1(\mathbb{Z}_\ell).$$
它滿足 $\chi(\mathrm{Frob}_p) = p$（不分歧的 $p$）。第 2.3 章說它是「行列式的源頭」—— 下面會看到，橢圓曲線二維表示的行列式恰好是 $\chi$。一維 Galois 表示由 Kronecker–Weber 完全分類（第 2.3 章），它們對應分圓體。難的、有趣的、與 FLT 相關的，是**二維**表示。
:::

## 橢圓曲線的 Galois 表示

現在嚴格建立 $\rho_E$ —— 第 5.1 章撓點上的作用。

回憶第 5.1 章：橢圓曲線的 $\ell$-撓點 $E[\ell] \cong \mathbb{F}_\ell^2$ 是二維 $\mathbb{F}_\ell$-向量空間。撓點是代數數（它們的座標滿足多項式方程），所以 $G_{\mathbb{Q}}$ 作用在它們上 —— 而這個作用保持加法（Galois 自同構尊重橢圓曲線的群律，因加法公式係數在 $\mathbb{Q}$ 裡，被 $G_{\mathbb{Q}}$ 固定，第 5.1 章習題 5.1.7）。保持加法 = 線性，於是得到一個二維表示：

::: {.definition name="橢圓曲線的 mod $\ell$ 表示"}
$$\bar\rho_{E,\ell}: G_{\mathbb{Q}} \longrightarrow \mathrm{GL}_2(\mathbb{F}_\ell),$$
由 $G_{\mathbb{Q}}$ 在 $E[\ell] \cong \mathbb{F}_\ell^2$ 上的線性作用給出。
:::

把所有 $E[\ell^n]$ 整合（取逆極限），得到更精細的 **$\ell$-進表示**：

::: {.definition name="Tate module 與 $\ell$-進表示"}
**Tate module** $T_\ell(E) = \varprojlim E[\ell^n] \cong \mathbb{Z}_\ell^2$，給出
$$\rho_{E,\ell}: G_{\mathbb{Q}} \longrightarrow \mathrm{GL}_2(\mathbb{Z}_\ell).$$
:::

mod $\ell$ 表示 $\bar\rho$ 是 $\ell$-進表示 $\rho$ 的「約化」（取 mod $\ell$）。兩者的關係 —— 從 $\bar\rho$「變形」回 $\rho$ —— 正是第七部變形理論的核心。Wiles 在這兩個層次之間工作：$\bar\rho$（剩餘表示，有限、可控）與 $\rho$（$\ell$-進，完整、精細）。

## Frobenius 與指紋

Galois 表示的算術資訊，集中在每個質數的 **Frobenius 元素**上（第 3.5 章預告）。

::: {.definition name="不分歧與 Frobenius"}
表示 $\rho$ 在質數 $p$ **不分歧**（unramified），若 $p$ 處的慣性群在 $\rho$ 下平凡。此時有良定義的 Frobenius 共軛類 $\mathrm{Frob}_p$，其像 $\rho(\mathrm{Frob}_p)$ 是一個確定的矩陣（至共軛）。
:::

對橢圓曲線表示 $\rho_{E,\ell}$，關鍵定理把它與第五部的指紋連起來：

::: {.theorem name="橢圓曲線表示的 Frobenius　〔接受〕"}
$E$ 在 $p$ 好約化且 $p \ne \ell$ 時，$\rho_{E,\ell}$ 在 $p$ 不分歧，且 $\rho_{E,\ell}(\mathrm{Frob}_p)$ 的特徵多項式是
$$x^2 - a_p\, x + p,$$
即 $\mathrm{tr}\,\rho_{E,\ell}(\mathrm{Frob}_p) = a_p$，$\det\rho_{E,\ell}(\mathrm{Frob}_p) = p$。
:::

::: {.remark name="四層：指紋 → 表示"}
這條定理是第六部第一條**中央箭頭**「指紋 → 表示」的內容。用四層來拆解它：

**第一層，直觀圖像。** 橢圓曲線的指紋 $\{a_p\}$ 是一串數字，散落在每個質數上。這條定理說：這串數字其實是**同一個結構化對象**（Galois 表示 $\rho_{E,\ell}$）在每個質數處的「投影」—— 就像一個多面體在每個方向的影子。指紋不是一堆孤立的點，而是一個整體的側影。

**第二層，精確定理。** 上面方框裡的陳述。注意它的**假設**：$E$ 在 $p$ **好約化**且 $p \ne \ell$。這兩個條件缺一不可 —— 好約化保證不分歧（Frobenius 良定義），$p \ne \ell$ 保證特徵多項式是乾淨的 $x^2 - a_p x + p$。在壞約化或 $p = \ell$ 處，局部行為不同（第 6.2 章）。

**第三層，在 FLT 中的角色。** 這條箭頭讓「比對兩條曲線的指紋」變成「比對兩個表示」。谷山–志村猜想 $a_p(E) = a_p(f)$，現在等價於 $\rho_{E,\ell}$ 與 $\rho_{f,\lambda}$ 的半單化同構（見下）。這個化約是整個現代證明的起點 —— 沒有它，Wiles 的變形理論無從施力。

**第四層，技術深潛（選讀）。** 這條定理的證明是代數幾何的深水區：它來自橢圓曲線的 $\ell$-進上同調 $H^1_{\acute{e}t}(E_{\overline{\mathbb{Q}}}, \mathbb{Z}_\ell)$，而 Frobenius 特徵多項式正是 Lefschetz 跡公式在 $E$ 上的應用。本書不展開，但你要知道：**這條箭頭本身是〔接受〕的** —— 它是 Weil 猜想／代數幾何的成果，不是本書能證的。本書證的是它**之後**的化約鏈。
:::

::: {.remark name="所有預告在此兌現"}
這條定理把第 1.2 章以來的所有預告一次性兌現：
- $\mathrm{tr}\,\rho(\mathrm{Frob}_p) = a_p$（第 1.2 章）—— 跡是橢圓曲線指紋。
- $\det\rho(\mathrm{Frob}_p) = p$，事實上 $\det\rho_{E,\ell} = \chi$（分圓特徵，第 2.3 章）—— 行列式是分圓特徵，因 $\chi(\mathrm{Frob}_p) = p$。
- 特徵多項式 $x^2 - a_px + p$ 正是第 1.2 章習題 1.2.6、第 5.3 章 Hasse 界用的那個。

數值驗證（導體 $11$ 曲線，$\ell = 5$）：$\rho(\mathrm{Frob}_p)$ 的跡 $\equiv a_p \pmod 5$、行列式 $\equiv p \pmod 5$ —— 例如 $p = 13$，$a_{13} = 4$，跡 $\equiv 4$、行列式 $\equiv 3 = 13 \bmod 5$。橢圓曲線的指紋 $\{a_p\}$，現在被編碼成一個 Galois 表示在每個 Frobenius 處的跡。**指紋升級成了表示。**

這個升級是決定性的。一個序列 $\{a_p\}$ 只是一串數字；而一個 Galois 表示 $\rho$ 是一個有豐富結構的對象 —— 它有維度、有行列式、有在每個質數的局部行為、可以約化、可以變形。把「指紋相等」提升為「表示同構」，等於把一個關於數列的問題，提升為一個關於結構化對象的問題 —— 後者才有足夠的把手讓 Wiles 的重武器施力。
:::

## 模形式的 Galois 表示

谷山–志村的另一半：模形式也給出 Galois 表示。這是 Deligne 的深刻定理（本書取用，不證）。

::: {.theorem name="Deligne，模形式的 Galois 表示　〔接受〕"}
設 $f$ 是權重 $2$、級 $N$ 的**新形式**（newform），其 Hecke 特徵值 $\{a_p(f)\}$ 落在係數體 $K_f$ 中。則對 $K_f$ 的每個質理想 $\lambda$，存在一個二維 Galois 表示
$$\rho_{f,\lambda}: G_{\mathbb{Q}} \to \mathrm{GL}_2(\overline{\mathbb{Q}_\lambda}),$$
在 $p \nmid N\lambda$ 不分歧，且 $\mathrm{tr}\,\rho_{f,\lambda}(\mathrm{Frob}_p) = a_p(f)$，$\det\rho_{f,\lambda}(\mathrm{Frob}_p) = p$。
:::

::: {.remark name="Deligne 定理是黑盒子"}
這條定理是**研究級定理**（〔接受〕），本書不證明。它是 Deligne 在 1969 年證明 Eichler–Shimura 構造的推廣，建立在模曲線的 $\ell$-進上同調上。對本書而言，它是一個黑盒子：**輸入**是一個權重 $2$ 的**新形式** $f$（及其係數體中的質理想 $\lambda$），**輸出**是一個二維 Galois 表示 $\rho_{f,\lambda}$，且兩者的指紋一致。你不需要知道盒子內部，只需要信任這個輸入輸出契約 —— 以及記住：**模形式側的表示，是本書接受的，不是本書證的**。注意這裡要求 $f$ 是**新形式**（第 5.5 章）—— 一般的尖形式未必有良定義的單一表示（第 6.3 章會細說）。
:::

於是模形式的指紋 $\{a_p(f)\}$，也被編碼成一個 Galois 表示的 Frobenius 跡。兩位主角現在說同一種語言了。

::: {.remark name="谷山–志村的表示版"}
把兩個定理並排：
$$\mathrm{tr}\,\rho_{E,\ell}(\mathrm{Frob}_p) = a_p(E), \qquad \mathrm{tr}\,\rho_{f,\lambda}(\mathrm{Frob}_p) = a_p(f).$$
谷山–志村猜想 $a_p(E) = a_p(f)$，現在等價於兩個 Galois 表示有相同的 Frobenius 跡。而一個基本定理（Chebotarev 密度定理 + Brauer–Nesbitt）說：**半單表示由它的 Frobenius 特徵多項式完全決定**。於是「跡相等」等價於「半單化同構」：
$$a_p(E) = a_p(f)\ \forall p \quad\Longleftrightarrow\quad \rho_{E,\ell}^{\mathrm{ss}} \cong \rho_{f,\lambda}^{\mathrm{ss}}.$$

::: {.remark name="精確措辭：特徵多項式與半單化"}
上面這個等價需要兩點精確化，本書在此修正常見的簡化：

**其一，比的是特徵多項式，不是單一跡。** 嚴格說，決定表示的是每個 Frobenius 的**特徵多項式** $x^2 - a_p x + p$（由跡與行列式給出），而不只是跡。對二維表示，跡與行列式合起來就給出特徵多項式，所以「跡相等 + 行列式相等」等價於「特徵多項式相等」。

**其二，結論是「半單化同構」，不是「表示同構」。** Chebotarev + Brauer–Nesbitt 的準確結論是：若兩個表示在**密度為 $1$ 的共同不分歧質數集合**上有相同的特徵多項式，則它們的**半單化**（semisimplification，把可約部分「剝掉」後得到的半單表示）同構。若兩個表示本身都是半單的（例如不可約），則半單化同構就是同構。橢圓曲線的 $\ell$-進表示 $\rho_{E,\ell}$ 對幾乎所有 $\ell$ 是不可約的（第 6.2 章），所以對我們關心的情形，半單化同構就是同構。但這個「半單化」的限定是必要的 —— 不假設半單性就宣稱「跡相等 ⟺ 同構」是過度陳述。
:::

這是谷山–志村猜想的**表示論重述**，也是 Wiles 真正要證的形式：每條橢圓曲線的 Galois 表示 $\rho_{E,\ell}$，都同構於某個模形式的 Galois 表示 $\rho_{f,\lambda}$。換句話說，**每個來自橢圓曲線的二維 Galois 表示都是「模的」**（來自模形式）。第七部 Wiles 的全部工作，是證明這個「表示的模性」。指紋 → 表示 → 同構，這條提升鏈，是現代證明能啟動的根本前提。

::: {.remark name="化約的性質：〔化約〕"}
注意「指紋相等 $\iff$ 半單化同構」這條箭頭是**〔化約〕**：它把一個關於無窮數列的陳述，翻譯成一個關於結構化對象的陳述。這個化約的**前提**是兩條定理：Chebotarev 密度定理（Frobenius 特徵多項式在無窮多質數上相等，足以決定表示）與 Brauer–Nesbitt（半單表示由特徵多項式決定）。這兩條都是本書接受的深定理，但它們的**使用方式**（把「跡相等」翻譯成「半單化同構」）是本書可以講清楚的。化約本身是乾淨的、可檢驗的；黑盒子只在化約的兩端。
:::

## 檢查點：你跟上這條鏈了嗎？

第六部的第一條中央箭頭已經建立。停下來，用三個問題確認你真的懂了，而不是假裝懂了：

1. **指紋 → 表示**：為什麼「$a_p(E) = a_p(f)$ 對所有 $p$」等價於「$\rho_{E,\ell}$ 與 $\rho_{f,\lambda}$ 的半單化同構」？（答案：半單表示由 Frobenius 特徵多項式決定，Chebotarev + Brauer–Nesbitt；對不可約表示半單化同構就是同構。）
2. **兩側的表示**：橢圓曲線側的 $\rho_{E,\ell}$ 的**定義**（撓點作用）是〔算〕的，但它的 **Frobenius 特徵多項式定理**（$\mathrm{tr}\,\rho(\mathrm{Frob}_p) = a_p$）是〔接受〕的；模形式側的 $\rho_{f,\lambda}$ 整個是〔接受〕的（Deligne）。你能說出「定義可算」與「特徵多項式定理被接受」的區別嗎？
3. **行列式**：為什麼 $\det\rho_{E,\ell} = \chi$（分圓特徵）？這在 FLT 裡為什麼重要？（答案：$\chi(\mathrm{Frob}_p) = p$，它把「行列式」與「質數本身」連起來，是表示歸一化的標準。）

若三題都答得出來，你已經掌握了第六部的地基。若卡住，回頭看本章的「四層」註記與前置檢查。下一章我們深入 $\rho_{E,\ell}$ 的細節 —— 它的像多大、何時不可約、在壞質數的局部行為 —— 這些是 Frey 曲線表示特殊性的來源。
:::

## 為什麼這是正確的語言

::: {.remark name="Galois 表示的三重優勢"}
為什麼把問題翻譯成 Galois 表示是對的策略？三個原因，貫穿第六、七部：

**其一，剛性。** 表示比序列剛硬。半單表示由 Frobenius 特徵多項式決定（上面），所以「比對無窮多個 $a_p$」化約為「比對兩個表示」—— 一個有限的、結構化的比較。

**其二，可變形。** mod $\ell$ 表示 $\bar\rho$ 可以「變形」回 $\ell$-進表示 $\rho$（第七部）。Wiles 的策略是：先在 mod $\ell$（有限、可控）層次證明模性，再透過控制所有變形，提升到 $\ell$-進層次。這個「變形」操作只在表示的語言裡有意義 —— 序列無法變形。

**其三，可局部化。** 表示可以限制到每個質數的局部 Galois 群 $G_{\mathbb{Q}_p}$（第 3.5 章），逐個質數分析其行為（分歧、約化類型）。Frey 曲線的半穩定性、Ribet 的 level lowering、Wiles 的局部條件，全都是局部表示的精細控制。$p$-進數（第 3.5 章）在這裡成為分析局部表示的舞台。

Galois 表示把 FLT 從「數列的比對」變成「結構化對象的操控」—— 而數學家有一整套操控結構化對象的工具（同調、變形、局部–整體）。這就是為什麼現代證明能成功，而古典的數列方法（Kummer）不能。語言的選擇，決定了能用的工具。
:::

## 本章地圖與下一章預告

- **證明鏈地圖**：FLT 反例 → Frey 曲線 → mod p 表示 → 模性 → level lowering → 級 2 矛盾；四層講法與四種標籤（算/證/化約/接受）。
- **記號約定**：$p$（FLT 指數／剩餘特徵）、$q$（壞質數／降級質數）、$\lambda$（新形式係數體質理想）。
- **Galois 表示**：$\rho: G_{\mathbb{Q}} \to \mathrm{GL}_n(A)$；研究 $G_{\mathbb{Q}}$ 的途徑。
- **分圓特徵**：一維表示 $\chi$，$\chi(\mathrm{Frob}_p) = p$；橢圓曲線表示的行列式。
- **橢圓曲線表示**：$\rho_{E,\ell}$ 由撓點作用（定義〔算〕）；$\mathrm{tr}\,\rho(\mathrm{Frob}_p) = a_p$、$\det = \chi$（Frobenius 定理〔接受〕）。
- **模形式表示**：Deligne 的 $\rho_{f,\lambda}$（〔接受〕黑盒子，限新形式）；$\mathrm{tr} = a_p(f)$。
- **谷山–志村重述**：特徵多項式相等 ⟹ 半單化同構（〔化約〕）；指紋 → 表示 → 同構。

下一章《橢圓曲線的表示》深入 $\rho_{E,\ell}$ 的細節：它的像有多大（Serre 的開像定理）、mod $\ell$ 表示 $\bar\rho_{E,\ell}$ 何時不可約、它在壞約化質數的局部行為。這些細節決定了 Frey 曲線表示的特殊性質 —— 而那些性質，正是 Ribet 定理（第 6.6 章）能對它動刀的前提。我們開始把 Galois 表示的通用理論，特化到 FLT 所需的具體情形，一步步逼近 Frey 曲線的絕境。

## 習題

**6.1.1**　驗證分圓特徵 $\chi$ 是同態：$\chi(\sigma\tau) = \chi(\sigma)\chi(\tau)$。（提示：$\sigma\tau(\zeta) = \sigma(\zeta^{\chi(\tau)}) = \zeta^{\chi(\sigma)\chi(\tau)}$。）

**6.1.2 ★**　$E[\ell] \cong \mathbb{F}_\ell^2$ 上 $G_{\mathbb{Q}}$ 的作用是線性的。詳細說明為什麼（Galois 自同構保持橢圓曲線加法，故保持 $\mathbb{F}_\ell$-向量空間結構）。

**6.1.3**　$\det\rho_{E,\ell} = \chi$（分圓特徵）。用 $\det\rho(\mathrm{Frob}_p) = p = \chi(\mathrm{Frob}_p)$ 驗證這個等式在 Frobenius 上成立。（這把第 2.3 章的「行列式 = 分圓特徵」嚴格化。）

**6.1.4 ★**　導體 $11$ 曲線，$\ell = 5$。計算 $\rho_{E,5}(\mathrm{Frob}_p)$ 的跡與行列式 mod $5$，對 $p = 3, 7, 13$（用 $a_3 = -1, a_7 = -2, a_{13} = 4$）。驗證跡 $\equiv a_p$、行列式 $\equiv p \pmod 5$。

**6.1.5**　Brauer–Nesbitt + Chebotarev 說「半單表示由 Frobenius 特徵多項式決定」。用一句話說明這為什麼讓「$a_p(E) = a_p(f)\ \forall p$」等價於「$\rho_E$ 與 $\rho_f$ 的半單化同構」，並指出何時半單化同構就是同構。

**6.1.6（前瞻）**　Wiles 在 mod $\ell$ 表示 $\bar\rho$ 與 $\ell$-進表示 $\rho$ 之間工作。用一句話說明為什麼「先在有限的 mod $\ell$ 層次證模性，再變形提升」是合理的策略（提示：$\mathrm{GL}_2(\mathbb{F}_\ell)$ 有限，可控；第 1.1 章 $|\mathrm{GL}_2(\mathbb{F}_p)|$ 的計算）。
