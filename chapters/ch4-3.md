## 開場：先整理曲線的工作條件

「橢圓曲線是平滑射影虧格 $1$ 的曲線並帶一個有理點」這句話包含四個先決詞。本章依次處理射影化、平滑、虧格與有理點，並說明費馬曲線的虧格能告訴我們什麼、不能告訴我們什麼。

## 射影平面與齊次方程

::: {.definition}
對體 $K$，射影平面 $\mathbb P^2(K)$ 的點是非零三元組 $(X,Y,Z)$ 的比例類
$$[X:Y:Z]=[\lambda X:\lambda Y:\lambda Z]\qquad(\lambda\in K^\times).$$
開片 $Z\ne0$ 可寫成 $[x:y:1]$；$Z=0$ 是無窮遠直線。
:::

射影曲線由齊次多項式 $F(X,Y,Z)$ 定義。仿射方程
$y^2=x^3+Ax+B$ 齊次化為
$$Y^2Z=X^3+AXZ^2+BZ^3.$$
令 $Z=0$ 可見唯一無窮遠點 $O=[0:1:0]$。

## 平滑性與判別式

::: {.definition}
平面射影曲線 $F=0$ 上的幾何點 $P$ 是**奇點**，若
$$F_X(P)=F_Y(P)=F_Z(P)=0.$$
在代數閉包上沒有奇點，稱曲線幾何平滑。
:::

::: {.proposition name="短 Weierstrass 方程的平滑判準【完整證明】"}
若 $\operatorname{char}K\ne2,3$，曲線
$$Y^2Z=X^3+AXZ^2+BZ^3$$
平滑若且唯若 $4A^3+27B^2\ne0$；通常把
$\Delta=-16(4A^3+27B^2)$ 稱為判別式。
:::

::: {.proof}
無窮遠點的 $F_Z$ 不為零，所以奇點只能在 $Z=1$。對
$F=y^2-x^3-Ax-B$，奇點須滿足 $2y=0$、$3x^2+A=0$ 與 $F=0$。因特徵不是 $2,3$，消去 $x,y$ 後恰得 $4A^3+27B^2=0$；反向把重根代回即可。
:::

::: {.example name="工作例：平滑與退化只差一個係數"}
$y^2=x^3-x$ 的判別式是 $64$，所以在特徵 $0$ 平滑；$y^2=x^3$ 在 $(0,0)$ 有 $F_x=F_y=0$，是尖點，不是橢圓曲線。壞約化正是某個整係數模型模 $p$ 後出現這類奇點，但第 4.5 章會補上「必須先取極小模型」的條件。
:::

## Bézout 與弦切圖像

::: {.theorem name="Bézout 定理【研究級黑箱】"}
在代數閉域上，兩條沒有公共分量、次數為 $m,n$ 的射影平面曲線，其交點的交重數總和為 $mn$。
:::

**輸入**包含射影平面、代數閉域、無公共分量；**輸出**是「含無窮遠點且計重數」的交點總數。對直線與平滑三次曲線，總交重數為 $3$；切點要按重數 $2$ 計。這解釋弦切法的第三交點，但**不**單獨證明群律的結合律；第 5.1 章會清楚區分兩件事。

## 虧格與平面曲線公式

::: {.theorem name="平滑平面曲線虧格公式【研究級黑箱】"}
若 $C\subset\mathbb P^2_{\mathbb C}$ 是次數 $d$ 的平滑連通曲線，則
$$g(C)=\frac{(d-1)(d-2)}2.$$
:::

此處 $g$ 可定義為全純微分空間的維度
$\dim_{\mathbb C} H^0(C,\Omega_C^1)$；第 4.4 章再說它等於底層緊緻曲面的洞數。公式只對**平滑平面模型**直接成立；奇曲線的幾何虧格要先正規化，不能把次數硬代公式。

::: {.example name="低次數檢查"}
直線與平滑圓錐曲線有 $g=0$；平滑三次曲線有 $g=1$；平滑四次曲線有 $g=3$。第 4.2 章的環面正好落在 $g=1$。
:::

## 費馬曲線：虧格給有限性，不給空集

在特徵 $0$，費馬曲線
$$C_n:X^n+Y^n=Z^n$$
是平滑的：若三個偏導同時為零，便有 $X=Y=Z=0$，這不是射影點。因此
$$g(C_n)=\frac{(n-1)(n-2)}2.$$

::: {.theorem name="Faltings 定理【研究級黑箱】"}
若 $K$ 是數域，$C/K$ 是平滑、射影、幾何連通且虧格 $g\ge2$ 的曲線，則 $C(K)$ 有限。
:::

**輸入**不是任意方程，而是上述四項幾何條件；**輸出**只有有限性，沒有列出所有點，也沒有說點集為空。應用於每個固定 $n\ge4$，得 $C_n(\mathbb Q)$ 有限。這並不證明 FLT，因為有限集合仍可能含非平凡點。

| $n$ | $g(C_n)$ | 本章可推出什麼 |
|---|---:|---|
| $2$ | $0$ | 有一個有理點後可參數化，故有無窮多有理點 |
| $3$ | $1$ | 有有理基點後成橢圓曲線；有限或無窮取決於 Mordell–Weil 秩 |
| $\ge4$ | $\ge3$ | Faltings 給每個固定 $n$ 的有理點有限性 |

::: {.remark name="兩個常見過度推論"}
第一，虧格 $0$ 不自動保證有理點；一條 $K$ 上的 genus-$0$ 曲線若有一個 $K$-點，才同構於 $\mathbb P^1_K$。第二，虧格 $1$ 不自動保證有理點有限；有指定有理點後得到橢圓曲線，其有理點群可能有正秩而無窮。費馬三次曲線只有平凡有理點是額外算術結果，不是「$g=1$」的形式推論。
:::

## 為什麼後文改看 Frey 曲線

Faltings 對固定 $n$ 給「有限」，FLT 要對所有 $n>2$ 給「沒有非平凡點」。第六部採取另一條路：先把指數化約到奇質數 $\ell$（另處已完成），再把假想解製成 Frey 橢圓曲線。Ribet 對它的 mod $\ell$ Galois 表示降級；Wiles 證明半穩定橢圓曲線模。矛盾排除假想解。這是「反例 $\to$ 另一條曲線 $\to$ 表示」的統一論證，不是從費馬曲線虧格直接推出空集。

## 依賴檢查點

1. Bézout 解釋第三交點，卻不證結合律。
2. 虧格公式有平滑、射影、平面曲線等假設。
3. Faltings 給有限性，不給 FLT。
4. 第五部「橢圓曲線」將採用平滑、射影、虧格 $1$、帶有理基點的定義。

## 習題

**4.3.1**　齊次化 $y^2=x^3-x$，找出無窮遠點並驗證它平滑。

**4.3.2 ★**　完整驗證 $C_n$ 在特徵 $0$ 平滑，再算 $n=5$ 的虧格。

**4.3.3**　找出 $y^2=x^3$ 的奇點，並說明為何不能直接宣稱它的幾何虧格為 $1$。

**4.3.4 ★**　一條直線與三次曲線在某點相切。用交重數說明為何「第三點」仍要計入。

**4.3.5**　說明「$C_n(\mathbb Q)$ 有限」為何不蘊涵「$C_n(\mathbb Q)$ 只有平凡點」。
